**Реестр v2** — с 20.11.2026 это карточки `kb/decision/В-N.md`, единственный источник: новые решения пишутся карточкой (порядок — `kb/README.md`, «Как записать решение»). Прежний файл `.claude/decisions.md` заморожен — снимок [[docs/archive/decisions-2026-11-20.md]], на старом пути заглушка. 161 запись (В-1…В-161, 14.10 → 20.11.2026), слова владельца дословно. Формат снимка: запись `## В-N · дата время`, строки `> слова владельца`, `Суть:`, `Заменяет:`. Ранний реестр — [[settled-registry]].

## Карточки

- Одна карточка на решение — `kb/decision/В-N.md` (id с кириллической «В»), создана разовым конвертером [[tools/kb_import_decisions.py]] (слова владельца дословно, «Суть», «Заменяет», ссылки на упомянутые решения, протоколы, задачи); поле `source: kb_import_decisions` — след конвертера. С 20.11 карточки правятся руками; конвертер поверх существующих пишет только с `--force` и затрёт правки. Карточки без `source` (В-161 и новее) он не трогает.
- «Заменяет: В-M» — только номер → `supersedes: [В-M]`, у В-M статус `superseded`. «Заменяет» с оговоркой («в части …», текст без номера) → у старой карточки пометка «Частично заменена», статус не меняется.
- Нумерация: **В-N** — этот реестр, **S-N** — SETTLED («SETTLED В-NNN» в брифах и коде = карточка `S-NNN`). Номера двух реестров пересекаются, id — нет.
- Поиск: `python tools/kb.py find "<слова>"`, `python tools/kb.py list --type decision --status superseded`.
