## Оглавление

Летопись = мастер плана и факта (оси гипотез, сетки фракций, сито, хеши); матрица/выписки — витрины из БД (2026-10-11, владелец).

## Запись реестра

**В-225. Летопись — мастер плана и факта, документы — витрины (2026-10-11 ~17:40, владелец).** «я ваще хотел чтобы летопись
была не просто архивом а взаимодействовала как раз с этим документом. а этот документ ... тоже в бд чтобы переехал» → CEO:
слои БД (параметры, стеки, оси гипотез, клетки с каноническим хешем, результаты, сито) и команды `plan --fraction k` (сетка →
дедуп по хешу → файл только новых клеток + выписка В-224) / `sieve` → владелец: «ака, понял, летопись как мастер, док витрина.
ок». Матрица гипотеза×параметр и выписки печатаются из БД, руками не собираются; протокол — текст правил, числа (диапазоны,
шаги, пороги) — в БД с версией, протокол ссылается на версию.
