## Оглавление

Сквозной учёт времени бэктеста (e2e): узкое место не угадывать, а читать из водопада волны; гипотезы принимать по нему (2026-10-05, владелец).

## Запись реестра

**В-187. Сквозной учёт времени бэктеста (2026-10-05 ~03:20, владелец).** «Чтоб не гадать че прокачивать может обложим
все e2e?» Каждый прогон волны даёт один отчёт-водопад: 15 × стена поток-секунд разложены по корзинам (ЦП по стадиям,
ожидание чтения, простой без единицы, накладные оркестровки; неразобранное < 3 %). Очередь гипотез строится по
крупнейшим корзинам, гипотеза принимается/убивается по изменению своей корзины. Работа — TK-052 (+ учёт оркестровки в TK-048).

Реестр — [[docs/plan/SETTLED.md]], оглавление — [[docs/plan/SETTLED-index.md]]; номер в реестре «В-187».
