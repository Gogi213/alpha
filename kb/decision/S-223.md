## Оглавление

сборки/тесты Rust на сервере счёта (параллельно, через alsched), VPS — запасной; пока calc свободен (2026-10-10, владелец).

## Запись реестра

**В-223. Сборки и тесты Rust — на сервере счёта, пока он свободен (2026-10-10 ~21:35, владелец).**
CEO: «Переносим сборки на сервер счёта, пока счёт на паузе?» — владелец: «сервер счета вообще пустой почти». VPS София
(4 ядра, сборки по одной под замком) — очередь 30–50 мин на 5 инженеров рефактора; calc (16 потоков, 62 ГБ) простаивает.
`vps-check` получает хост calc (по умолчанию на время рефактора), сборки — через alsched (бюджет ядер/памяти, не мешают
будущему счёту), несколько параллельно; VPS остаётся запасным. Замеры скорости (benchrun) со сборками не пересекаются.
