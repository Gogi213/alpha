## Запись реестра

**В-110. Код для всех запланированных первостепенных гипотез пишем (2026-09-26, владелец: «писать для всех
запланированных важных штук код»).** **Решено:** гипотеза П-02, для честной проверки которой нужен код, получает
его, а не закрывается по дешёвой предпроверке — первым T5 (гейт «пружинки», Г-88: предпроверка шла на всех касаниях,
а не на сигналах главного варианта; Судья, `docs/research/reviews/P-02-2026-09-26-stage2-g07-g88.md`). Список и
тикеты — Исследователь (T-11), код — Инженер (T-12), бинарник счёта меняется только после гейта «байт в байт».
Там же владелец: Paperclip (`paperclipai/paperclip`) и заимствования из него пока не ставим.
