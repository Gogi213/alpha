## Оглавление

Число испытаний N для DSR — по родословной варианта, не весь журнал (2026-09-27 ~05:21 по `date`, владелец).

## Запись реестра

**В-124. Число испытаний N для DSR — по родословной варианта, не весь журнал (2026-09-27 ~05:21 по `date`, владелец).**
На пробу T-26 (DSR при N журнала 0,0016): «а смысл считать все испытания????», «там же может быть абсолютная ересь которая
считалась просто чтобы прощупать edge кейсы». Решено: главным — N испытаний, **соревновавшихся за выбор** этого варианта
(эксперименты, чьи итоги выбрали его параметры, + семейство его протокола; для Г-85 — перебор главного варианта В-104
на августе/сентябре + П-02), с поправкой на похожесть (похожие испытания склеиваются в кластеры — эффективное N, как у
Бейли — Лопеса де Прадо); прощупывание краёв и прогоны других семейств не считаются. Рядом справочно — N семейства
протокола. «Весь журнал» главным не печатать. Список родословной — Судья до счёта; реализация — Инженер (T-26).
