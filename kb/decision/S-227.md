## Оглавление

строки 3–6 матрицы (56 гипотез) реализовать в текущем рантайме, чистым дизайном; новых рантаймов нет (2026-10-12, владелец).

## Запись реестра

**В-227. Гипотезы строк 3–6 матрицы — в план реализации; только текущий рантайм, чистый дизайн (2026-10-12 ~03:40, владелец).**
«то есть с 3 по 6 вполне себе надо реализовать. бери в план. новые рантаймы не делаем делаем только красивый дизайном код для
текущего рантайма». Объём: Д старого движка (31), код есть — клеток нет (6), Python «вне пакета» (15), новый признак/ядро
(4: Г-72, Г-60, Г-132, g82-60s) = 56 гипотез. Порядок: спецификация (оси под П-14) → дизайн расширения рантайма (общие
механизмы, не 56 заплаток) → реализация пакетами с гейтом «выкл = прежний» diff 0 → оси в Летопись (В-225) → фракции П-14.
