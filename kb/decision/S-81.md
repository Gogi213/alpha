## Запись реестра

**В-81. TypeSafe (System One, `jev-latest`) включён в мета-контур проекта (2026-09-21, вечер, владелец: «включай тайпсейф»).** Не горячий путь и не конвейер стакан → уровни → очередь → круги → вердикт (там суждений нет), а суждения **над** ним, которые сегодня делали люди и старшая модель и не сделала младшая: страж предрегистрации (`tools/compute/prereg-guard.py`: обе семьи флоров в одном наборе, имя ночного набора с другими ключами, числа без ссылок на В-##/замер — отказ до запуска; первый прогон 21.09 поймал набор E15 `a45-bid:…,flow=100` с p=0.98/0.97 и строку предрегистрации без ссылок с p=0.05), дальше — чтение ночи (`ALERTS.log`/вердикты → ок/смотреть/сломано), сверка план ↔ лог ↔ SETTLED, сортировка находок ревью. Клиент — `tools/typesafe/judge.py`; ключ **только** из окружения `TYPESAFE_API_KEY` (на диск машин не пишется; без ключа страж выходит 2 и печатает причину, прогон не блокируется молча); код собирает факты, модель даёт типизированное суждение, порог решения — 0,5 по `noul`/`choice`. Ключ на счётной машине: владелец 21.09 — «мне всё равно», решение исполнителя — `/etc/alpha/typesafe.env` (0600, root; значение передано через stdin двух ssh-хопов, в argv/логах не было), drop-in `alpha-grid-nightly.service.d/typesafe.conf` (`EnvironmentFile=-…`), `f10-approach-run.sh` подхватывает файл сам; страж на машине проверен живьём (4 набора — ок).

Реестр — [[docs/plan/SETTLED.md]], оглавление — [[docs/plan/SETTLED-index.md]]; номер в реестре «В-81».
