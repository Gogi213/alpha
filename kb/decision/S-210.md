## Оглавление

из пула убрать TRUMP, TRX, BCH → пул v171c; в отчётах итог с ними и без; правило отсева проверять вне выборки (2026-10-09, владелец).

## Запись реестра

**В-210. Из пула убрать TRUMP, TRX, BCH (2026-10-09 ~04:30, владелец).** После разреза по монетам (TK-113,
docs/archive/findings/coins-breakdown-2026-10-09.md: база B1 янв–2 окт TRUMP −220 $ / 7 мес. из 9 в минусе, BCH −120 $ / 8 из 9,
TRX −42 $ / 0 плюсовых): «Убирай трамп трх бсаш». Новый пул v171c = v171b без TRUMPUSDT, TRXUSDT, BCHUSDT — для всего
дальнейшего счёта и чтения (титрование TK-113, перечтение П-12 TK-063). Решение владельца задним числом: в отчётах
печатать итог и с этими монетами, и без (честность сравнения), правило отсева монет для будущего — проверять вне
выборки (Судья). TRX (В-198 «на время исследования») — снят.
