## Оглавление

Перенос круга через полночь UTC — правило бэктеста (2026-09-23, найдено при стресс-тесте, `e5c8847`).

## Запись реестра

**В-94. Перенос круга через полночь UTC — правило бэктеста (2026-09-23, найдено при стресс-тесте, `e5c8847`).** Дефект: позиция, открытая до полуночи UTC и не закрытая к ней, выпадала из итога целиком — не считалась ни прибылью, ни убытком, потому что бэктест не читал данные следующих суток для уже открытого круга. У кандидата это 35 символо-суток из 189 сделок на «истории» (~18 %) и 8 из 43 на «записи». **Решено:** круг дочитывает бинлоги следующих суток до своего настоящего выхода — флаг `--carry-root` у `lob bounce-grid`; `oos-frozen.sh` передаёт его по умолчанию (`CARRY`). Правило действует для всех бэктестов с этого дня; числа кандидата, посчитанные без переноса (в т. ч. прежние +$515/+$272), недействительны как есть — пересчёт идёт вместе с В-89 (E23).
