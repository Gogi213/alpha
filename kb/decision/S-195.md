## Запись реестра

**В-195. Логистика задач — без ИИ: события CI в шину, вливание по правилу, без ложных тревог (2026-10-07 ~01:10, владелец).**
«Одна из ключевых задач шины — убрать всё, что дёргает ИИ в процессе логистики задач. Роли спят, пока шина не скажет,
что для них есть работа». На предложения CEO: «1 — надо чинить точно» (конец CI на GitHub → событие в шину, а не
скрипты CEO), «2 — да» (вливание PR по правилу: Судья принял именно эту голову + CI зелёный на ней → влить программой,
с проверкой, что влито), «4 — да» (убрать ложные тревоги сторожа, будящие CEO). ИИ тратится только на работу
(код, счёт, проверка), не на «кто следующий / когда будить / чего ждать». Дополнение владельца: «почему всё не идёт
через диспетчер, который сам и разбудит роль, что бы ни было написано в конце задачи?» — маршруты в диспетчере: роль
сообщает только итог шага, кого будить — решает диспетчер по таблице маршрута. И (01:35): «надо жесточайше это
стандартизировать, чтобы в диспетчер приходили ТОЛЬКО команды, которые он чётко понимал: что, когда, зачем, почему,
куда» — протокол команд с обязательными полями, отказ неполного на входе, выход роли без команды итога блокируется
хуком Stop. Работа — TK-079 п.0 (в плагин, В-194).
