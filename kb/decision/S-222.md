## Запись реестра

**В-222. Рефактор режет код: меньше кода — меньше чтения и токенов (2026-10-10 ~18:00, владелец).**
«Нужно стремиться срезать код. Чтобы ты его не грепал лишний раз. Это экономия токенов». Каждый КТ рефактора: строки
активного кода до/после (src, tools без archive) в отчёте; чистый рост — только с причиной; мёртвое, дубли, старые пути
после приёмки нового (не «под флагом навсегда»), неиспользуемые флаги/env — удаляются тем же КТ. Архивы исключаются из
поиска (`.rgignore`), чтобы поиск по проекту не читал их. Числовой цели нет — замер в КТ-10 (строк до/после).
Дополнение CEO 19:15 (по списку Судьи TK-166, `docs/archive/findings/kt-code-cuts-2026-10-10.md`): исследовательский слой 09.2026
(pilot/profiles/shortlist/react/markup/watch/markout/levels/power, ≈11 000 строк, 0 потребителей) — срезать (КТ-11, TK-168);
процедура В-30 (pilot, k пола H3) уходит в архив вместе со слоем (тег archive/research-layer-0925).
