## Запись реестра

**В-69. E7 — дробная позиция: тейк половиной и выход по съеданию плотности (2026-09-19).** Владелец: «позиция одна за раз, но может быть дробной» (В-67) и «продолжаем» после В-68; числа — из файлов и чужих ботов, не наши. **Решено, механизм:** круг может закрываться двумя ногами — `lob::strategy` получил долю выхода (`take_frac`), пороги съедания (`eaten_half_pct`/`eaten_all_pct` от **максимума размера плотности с входа**, динамический режим чужих ботов), размер плотности на сигнале (`level_qty`) и шаг лота (`lot_qty`, дробь округляется **вниз** до кратного шага; ноль лотов — выход целиком); фаза `ExitPending { resume }` возвращает остаток в `Holding` с прежними часами круга (дедлайн от входа); драйвер даёт одну `Fill` на круг — цена выхода средневзвешенная по ногам, комиссия выхода тейкерская, если тейкером ушла хоть одна нога; `forms.csv` — колонки `n_eaten`, `n_partial`. **Формы тейка:** `half1to1` — половина лимитом на 1:1 (Z 1:07:37 «половина на середине хода»), остаток бежит до стопа/дедлайна/трейла — «по замедлению» из файлов не формализовано, взято «до плана»; `eat<h>x<a>` — тейк 1:1 целиком плюс выход по съеданию: `h` % → половина по рынку, `a` % → всё по рынку; `eat50x80` — дефолты чужих ботов (`density-bots-2026-09-19.md`). Порядок решений в круге: стоп → съедено всё → трейл → тейк (доля) → съедено наполовину → досрочный → дедлайн. **Размер:** с одним минимальным лотом пула половина — ноль, формы вырождаются в цельные (проверено на ZEC 09-13: `half1to1` ≡ `1to1`); для E7 сетка идёт с `--order-qty-mult 2` (два лота пула — наименьшее, при котором есть половина; это не число владельца, а арифметика деления). Проверка на ZEC 09-13 при двух лотах: `eat50x80` закрывает круги за секунды — кругов 438 против 236 у `1to1` («занято» разжато вдвое), `net` на круг −6.2 bps (≈ комиссии + спред, все выходы `eaten`); `half1to1` — единицы частичных кругов, знак не читается (n = 3–5). Вердикт — с пула (`v69e7`). **Отвергнуто:** выход по «замедлению» как правило (нет определения в файлах); пороги съедания от размера на касании вместо максимума с входа (у ботов — от максимума, «трейлинг по объёму»); частичный выход без округления к шагу лота (биржа отвергнет); включать 1:1 при двух лотах в предрегистрацию E7 заново (те же формы, размер — не ось формы).
