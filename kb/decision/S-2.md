## Запись реестра

**Возражение (блокирующее для требования).** Шаг 6.2 меряет RTT по REST (`/v5/order/create`, `/v5/order/cancel`, `probe.rs:45`), и это распределение — вход гейта G4. Торговать система будет кадрами WS: у Bybit v5 есть `wss://stream.bybit.com/v5/trade` с `order.create`/`order.amend`/`order.cancel` и батчами (проверено по документации биржи, не по памяти). Два разных транспорта дают два разных распределения, и G4 стоит на том, которым система не торгует

**Ответ плана.** Новый шаг **6.4**: тот же цикл трёх меток `Instant`, но по WS trade; REST-число остаётся в отчёте отдельной колонкой с подписью, каким транспортом померено, и входом в G4 быть перестаёт. Зависимость 6.3 переписана с 6.2 на 6.4. Шаг 6.2 не переоткрывается: подпись, ключи и статистика распределения в силе, заменяется только транспорт
