## Запись реестра

**В-176. Данные с нарушениями теста 3 verify — исправлять, а не исключать и не ослаблять порог (2026-10-04 ~00:55, владелец).**
На вопрос CEO о 57 монето-месяцах (1 095 суток, сделки по ценам, которых нет в восстановленной книге; варианты A —
исключить, B — порог по суткам, C — тест 3 только справка): «всё исправлять надо». Порог В-56 не пересматривается;
причина нарушений находится и устраняется так, чтобы данные были как на бирже (В-172) — по всем месяцам, где она
действует, не только по 57. Работа — TK-043. Уточнение (~01:00, после диагностики: окно ob200 = 100 мс, сделки чаще):
«внутри часов просто так исправлять нельзя. нужен лучший алгоритм» — никаких точечных правок данных внутри часа;
способ восстановления книги между обновлениями выбирается по В-170 (известные способы → замер качества и скорости на
образцах → лучший без потери качества → боевой прогон), в отчёте — что сравнивали и почему выбран.
