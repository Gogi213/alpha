## Оглавление

Уточнения владельца к базе: сила = «×поток», киты стратегии, разбор по монетам (2026-09-19, ночь).

## Запись реестра

**В-67. Уточнения владельца к базе: сила = «×поток», киты стратегии, разбор по монетам (2026-09-19, ночь).** На логлайн вводных прогона владелец: (1) **сила плотности** — как в скринерах: объём плотности / **проторгованный объём монеты за последний час** («откуда мнение про 20 bps???») — определение «×соседи в ±20 bps» (В-61) было выбором исполнителя по данным, не владельца, и снимается; полы В-66 читаются так: номинал ≥ $10k **и** сила ×поток ≥ 100 %, оба — в момент касания. (2) **Киты стратегии, по порядку:** фильтр по времени жизни плотности с постановки (главный), объём, сила ×поток, спуфинг, наличие на других биржах/споте («потом, сначала МВП»). (3) Стоп **за** плотностью — по файлам отрицательное матожидание; в сетке только как контрольная форма. (4) Позиция одна за раз, но может быть дробной/частичной/долевой (E7). (5) Отсутствие трейла и фильтра по возрасту — «плохо»: трейл добавлен формой тейка `tr<активация>x<откат>` (%), возраст — `--min-age-secs`. (6) **Пул как одно целое — плохой агрегат**: задача — выяснить, на каких монетах/под-пулах работает, поэтому любой замер — с разбивкой по монетам. (7) На числа из файлов и из данных «ок» не нужен. Данные: `titration-v66-2026-09-19.md` — markout растёт монотонно с силой ×поток (+0.3 → +10.6 bps/ч от «любая» до ≥ 100 %), полы владельца дают 253 касания/сутки на пул; возраст работает с ~45 мин (час из файлов — не особая точка), ось {15, 30, 45, 60} мин, пол называет владелец; по монетам возраст держится на ATOM/LTC/ADA/TRUMP/DRAM/ICP/WIF/ONDO, сила ×поток — на тонких SNXX/XAG/KORU/BZ/BCH. **Отвергнуто:** «×соседи» как определение силы; предрегистрация без разбивки по монетам.
