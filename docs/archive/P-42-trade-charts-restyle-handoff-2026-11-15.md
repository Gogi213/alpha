## Задача (слова владельца через координатора, дословно)
«громоздко ниче не понятно стрелка большая перекрывает полосочками просто сделай понятнее будет» (скриншот: большая стрелка + 9 налезающих подписей тейков + подписи стопов в одной минуте).

Новый стиль маркеров — остальное не менять:
- Без стрелки, без кружков на входе/выходах, без выносок-рамок на графике.
- Вход = горизонтальная линия (зелёная лонг / красная шорт, 1,5 px) на цене входа от времени входа до времени выхода.
- Каждый тейк = тонкий зелёный горизонтальный отрезок на его цене от входа до времени исполнения (на конце маленькая засечка); выход по трейлу = тонкий бирюзовый отрезок; стоп = тонкая красная пунктирная линия на цене стопа (ступенька в точку входа после 1-го тейка); выход по безубытку рисуется на этой линии.
- Подписи — мелкий текст в **ПРАВОМ поле вне графика**, одна строка на подпись, автоматически разведены по вертикали (вход, стоп, тейки, трейл), например «вход 0.054295», «тейк 1–8 0.054522…0.055430 +$3.11» (тейки в одну строку, если > 3), «стоп −5 % 0.051581».
- Касания: маленькие маркеры только с номерами; подробности касаний — только списком в поле.
