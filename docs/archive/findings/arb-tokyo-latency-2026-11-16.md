## Данные и модель
- **Окно: 13.11 06:14 UTC (10:14 GMT+4) → 16.11 10:04 UTC (14:04 GMT+4), 75,83 ч** — весь общий промежуток Binance, Bybit, OKX, BingX на момент счёта (прежний отчёт — 61,77 ч); 606 монет с данными минимум на двух биржах (пулы дня 16.11; прежние 639). Сутки GMT+4: 13.11 (13,8 ч), 14.11, 15.11, 16.11 (14,07 ч) — **4 суток**. Хвост книг и сделок дочитан `tokyo_assemble.sh` с состояния прежней сборки (прежнее не трогалось).
- **Отсечка устаревания 60 с** (по слову владельца): ряд пары берётся только в моменты, когда у обеих ног последнее изменение лучшей цены не старше 60 с; центр (авто-центр viking) считается по минутным барам этого же ряда. Доля времени ряда с обеими ногами не старше 60 с: медиана по парам 98,61 %, p10 90,29 %, min 14,46 %. Пропуски сбора — `gaps_scan` (Binance 13.11 21:49:29 → 21:50:21 UTC) **и обрыв Binance 15.11 18:12:18–18:14:20 UTC** (из проверки, п. 2 «Что исправить»); круги, пересекающие пропуск ± 2 мин, исключены.
- **Единицы — %**: 1 bps = 0,01 %. θ = 0,1 / 0,15 / 0,2 / 0,3 / 0,5 / 0,75 / 1,0 % — расхождение к центру. Комиссия круга: тейкер-тейкер 4 × 0,0315 = **0,126 %**; мейкер-вход + хедж с закрытием тейкером **0,1071 %** (тариф владельца −10 %).
- **Жизнь расхождения ≥ θ**: от первого момента, когда исполнимая цена (Sell или Buy) на θ выгоднее центра, до первого момента без такого расхождения; метка времени — E биржи, мс.
- **Задержка L ∈ {0, 1, 2, 5, 10, 20, 50} мс — на обеих ногах**: тейкер-тейкер — и вход, и выход идут по ценам через L мс после сигнала (код прежний: `outlier.simulate_tt`, `cross.simulate_cross`); мейкер-вход в стиле Viking — лимитка на ноге M по цене из H ± θ, хедж на H агрессивной заявкой (тейкер) через L мс после сделки на M, выход тейкером через L мс. Для мейкера добавлен период пересчёта котировки D: режим **«D = L»** (котировка идёт за H с задержкой L, не меньше 1 мс) и режим **«D = 300 мс»** (как прежние отчёты). Исполнение лимитки — сделка **строго** за ценой (касание, очередь, частичные не засчитываются).
- **Выходы**: «к центру» (середина пары вернулась к центру, `c-t`) и **«из − в +»** = «через центр θ» (`x1-t`): позиция, открытая при −θ, закрывается на +θ (Buy ≤ c − θ / Sell ≥ c + θ). Прежние «через центр θ/2» и «переворот» не считались.
- **Рейтинг и плацебо — как в прежних отчётах**: кругов ≥ окно_ч / 6 (= 12,6) и медиана чистого итога круга > 0 в **каждых из 4 суток** (плацебо — < 0). **L\*** — наибольшая L сетки, при которой есть плюс при всех L от 1 мс до неё («подряд»; L = 0 — мгновенно, исполнимым не считается); «сумма» — чистая сумма кругов > 0 при n ≥ 12,6; «рейтинг» — условие рейтинга; «наибольшая» (без «подряд») — в таблицах приложения.
- $/сут = Σ размер (≤ 100 $ и не больше объёма лучшего уровня) × чистый итог по закрытым кругам на сутки; пары независимы, капитал и запас не ограничены. **BingX — вне всех заявлений на мс-масштабе** (см. часы): группа «без BingX» — BingX не на любой ноге (у мейкера — исправление по проверке п. 1: прежняя группа пускала BingX-мейкера и давала ложный плюс).
- **Сверка кода с прежним отчётом**: при отключённой отсечке на окне прежнего `cross.pkl` (до 15.11 20:00 UTC) для EVAA, SOPH, DOGE, IDOL (θ 0,2 / 0,5 %) прежние настройки (тейкер-тейкер L = 0 «к центру» и «через центр θ»; мейкер-вход D = 300, L = 50) дают те же `n`, `закрыто`, `$/сут` — 172 строки, расхождений 0.
- **Счётчик испытаний**: на пару — тейкер-тейкер 7 θ × 7 L × 2 выхода = 98 настроек, мейкер-вход 7 θ × 7 L × 2 выхода × 2 режима D = 196; пар — 1 825 (тейкер-тейкер, с жизнью) и упорядоченные мейкер-пары по тем же монетам (с сделками на ноге M). Выбор по максимуму не делался; числа «разных пар с L\* ≥ …» — объединение по настройкам пары, то есть выбор по максимуму внутри пары (верхняя оценка). Найдено на этих же данных.

Мейкер-вход Viking (D = L): θ = 0,2 %: +2024 / +1546 / −13 / −1455; θ = 0,3 %: +1415 / +1157 / **+254** / −602; D = 300 мс (как в прежних отчётах): θ = 0,3 %: +921 / +766 / +72 / −723 (L = 1 / 2 / 5 / 10).
2. **Агрегатный L\* (сумма по всем парам без BingX)** — тейкер-тейкер «из − в +»: **5 мс** при θ 0,15–0,75 % (L = 5: +56 … +191 $/сут, L = 10: −755 … +1), при θ = 0,1 % — 2 мс (L = 5: −359); «к центру»: 2 мс при θ 0,2–0,3 %, 5 мс при θ ≥ 0,5 %, при θ ≤ 0,15 % — меньше 1 мс (θ = 0,15 %: −298 $/сут уже при L = 1). Мейкер Viking D = L, «из − в +»: 2 мс при θ ≤ 0,2 % (θ = 0,2 %: L = 5 = −13 ≈ 0), 5 мс при θ ≥ 0,3 %; D = 300 мс: 2 мс при θ 0,15–0,2 %, 5 мс при θ ≥ 0,3 %. L = 0 — верхняя граница (тейкер-тейкер θ = 0,2 %, «из − в +»: +1036; «к центру»: +905 против прежних +1152 / +986 на окне 61,77 ч без отсечки).
3. **Пар (монета × биржи) с L\* ≥ 5 мс и ≥ 10 мс — таблица ниже; сидят почти все на Bybit.** Рейтинг, «подряд», объединение по θ и выходам, без BingX: тейкер-тейкер — **62 пары с L\* ≥ 5 мс** (Binance–Bybit 52, Binance–OKX 5, Bybit–OKX 5) и **5 пар с L\* ≥ 10 мс** (Binance–Bybit 3, Bybit–OKX 2); мейкер D = L — 130 / 13 (≥ 5: Binance→Bybit 84, Binance→OKX 13, OKX→Bybit 13, Bybit→OKX 12, Bybit→Binance 7; ≥ 10: Binance→Bybit 8, OKX→Bybit 2, Bybit→OKX 2, Bybit→Binance 1); мейкер D = 300 мс — 72 / 12. Лучшая пара при L = 10 мс даёт +5,2 $/сут (IDOL Binance→Bybit, θ = 0,75 %, мейкер D = L); при L = 5 мс — EVAA Binance→Bybit, мейкер D = L, θ = 0,15 %: **+59,7 $/сут** (L = 1: +107,2; по суткам при L = 5: +3,7 / +66,0 / +108,6 / +20,1).
4. **Жизнь расхождения (Binance–Bybit / Binance–OKX / Bybit–OKX, θ = 0,2 %): p10 / p50 / p90 = 1,0 / 9,2 / 729 мс; 1,0 / 9,2 / 917 мс; 3,1 / 49 / 1 728 мс.** Дольше 5 мс живёт 61 / 60 / 80 % расхождений, дольше 10 мс — 44 / 45 / 64 %, дольше 50 мс — 30 / 34 / 50 %: распределение с длинным хвостом, поэтому плюс не кончается на медиане (9 мс) — он кончается там, где вход после задержки L перестаёт попадать в живое расхождение (5–10 мс). Нижний p10 = 1 мс — это пол разрешения меток (целые мс), ниже планки ошибки не заявляется.
5. **Планка ошибки часов — ±2 мс** (см. раздел): дрейфа часов нет (пол лага стабилен ±1 мс за 3 суток), постоянный сдвиг не отделяется от настоящего опережения; по сделкам Binance, Bybit и OKX совпадают в пределах 0,9 мс. Сдвиг меток второй биржи на −5…+5 мс оставляет агрегатный L\* в 2–5 мс (θ = 0,2 %, «из − в +»; L = 10 — минус при всех сдвигах: −133 … −25 $/сут, у θ = 0,3 % при +5 мс +21 ≈ 0). **Значит, заявляется: плюс при L ≤ 2 мс и минус при L ≥ 10 мс; L = 5 мс — в пределах планки ошибки (знак меняется при сдвиге на −2 мс), «L\* ≥ 5 мс» у отдельных пар не доказано.** L = 0 и 1 мс ниже планки по разрешению: заявляется только знак (плюс при L = 1 мс при всех сдвигах −5…+5 мс и для «из − в +», и для «к центру»; при L = 2 мс «к центру» θ = 0,2 % уходит в минус при −5 мс).
6. **BingX (вне заявлений):** метки E BingX нельзя читать на мс-масштабе — пол лага p1 20 мс против 105–115 у остальных, у 0,18 % записей лаг отрицательный, почасовой пол от −6 до 79 мс, книга — снимки ≈ 2,6/с. Жизнь расхождения «с BingX» 100–150 мс (медиана) — это шаг снимков, не рынок. Таблицы с BingX — в приложении, плюс там при любом L — следствие устаревших снимков, как и в прежних отчётах.

## Оговорки
- **Одно окно 75,83 ч (4 суток GMT+4), одна рыночная картина; рейтинг, L\* и топы выбраны по тем же данным** (внутривыборочно; «найдено на этих данных»); интервал бутстрепом по суткам не считался — показано $/сут по суткам и число суток с плюсом.
- **L = 0 и L = 1 мс ниже разрешения меток и планки ±2 мс**; L = 0 — мгновенно по ценам сигнала. Время в модели — E биржи; реальная задержка Токио = сеть до биржи + обработка бота, а «доставка данных» (лаг srv 105–123 мс до перенесения) в этой модели не участвует — это и есть слова владельца: считается только L от события на бирже до исполнения.
- **Мейкер-вход** — модель «сделка строго за ценой, без очереди и частичных», D = L — предельно быстрое переставление котировки (на Viking реальный период — D = 300 мс, строки «D = 300»); заявка Viking на ноге A при L ≤ 2 мс в реальной очереди может не исполниться — исполнение завышено.
- Фандинг не считался (в прежнем отчёте — не фактор); размер круга ≤ 100 $ и вершина книги; $/сут по закрытым кругам (незакрытые — доли в приложении).
- **Концентрация:** суммы по паре сильно скошены (EVAA, SOPH, IDOL); при L = 10 мс по 49 настройкам топ-10 даёт 87 %. Пары на Bybit-ноге — единственные с L\* ≥ 10 мс, при этом у Bybit самый неустойчивый пол лага (см. часы).
