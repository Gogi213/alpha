## Что сделано (`tools/collector_health/page-dense.html`)
- Ряд «пилюль» пар («Все», «Binance → BingX», …, 11 кнопок, строка 28 px + отступ 8) **убран**; таблица поднялась на 36 px.
- В верхней панели справа от «Арбитраж / Здоровье» — чипы бирж `#ex`: Binance · Bybit · OKX · BingX · Gate (порядок и подписи — `names` из `/api/arb`), по 24 px, кольцо вместо рамки (размер не меняется при переключении), включённый — зелёный фон 10 % и кольцо 80 % (как прежние кнопки). Ширина всех пяти ≈ 255 px (вместо 11 кнопок отдельной строкой). На вкладке «Здоровье» чипы скрыты, часы остаются справа.
- **Множественный выбор**: в таблице пары, у которых выбраны **обе** биржи; по умолчанию выбраны все. Счётчик «пустых: N из TOT» / «скрыто N из TOT» — по выбранным парам.
- **Не меньше 2**: две последние выбранные не откликаются (`aria-disabled`, курсор по умолчанию, подсказка «Выбрано минимум 2 биржи»).
- **Хранение**: `localStorage` `alpha.arb.ex.hidden` — список *скрытых* бирж (как у «Столбцов»: новая биржа появляется выбранной; все выбраны — ключа нет). Мусор в ключе (слом JSON, скрыты все, осталась одна, не массив, неизвестные id) → выбраны все.
- Кнопки чипов строятся при смене набора бирж, дальше меняются только классы — фокус с клавиатуры (Tab, Space / Enter) не теряется. Смена набора закрывает открытый график (как прежде смена пары).
