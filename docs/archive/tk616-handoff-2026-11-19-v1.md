**Мейкер-вход (опция движка `mk`, 0 = выкл. байт-в-байт; 1 = строго сквозь; 2 = касание — только чувствительность, описательно).** Те же сигналы и тот же допуск, что у тейкера (`ew=5`, `ex=0`: цена-заменитель ask = последняя сделка покупателя-тейкера ≤ T, возраст ≤ 5 мс, не за уровнем; иначе `Stale`/`Beyond`). Лимитка стоит в момент `T = sig_ms + lat`, цена = ask − 1 тик (лонг; шорт зеркально: bid + 1 тик), тик = НОД разностей цен сделок суток монеты (целые ×1e8; < 100 сделок за сутки → отказ `Stale`). Заявка живёт до конца минуты, содержащей `T`; отмена раньше, если сделка с ценой ≥ уровня (рама) — уровень сорван (как `pb`). Исполнение — первая сделка после `T` строго «сквозь» цену заявки (лонг: цена < лимита; для шорта зеркально) — очередь консервативна, как у мейкерных тейков движка; цена входа = цена лимитки, проскальзывание 0, комиссия входа мейкер; время входа = время сквозной сделки, выходы — по сделкам строго после него. NATR, стопы, тейки, трейл, `rf/rs`, `tt/tb`, `bm` — без изменений («стопы не трогаем»). Не заполнилась / сорван уровень — отказ, уровень не расходуется (следующая минута даёт новый сигнал → новая заявка). Лот 2 шорта (`e2`): та же логика мейкера; «сразу» (цена ask лота 1 уже в пределах d) — заполняется тем же событием, что лот 1; иначе заявка в момент подхода (`t2 = ms + lat`), живёт до конца минуты `t2` и не дольше выхода лота 1. Новые причины отказа в `entryrej.csv`: `unfilled`, `touched`. Счётчики мейкера (заявок, заполнено, не заполнено, сорван уровень) — только при `mk>0`, в отдельный файл (существующие выходы не менять).
