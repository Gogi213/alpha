# Архив — отменено редакцией 3

Файлы здесь не описывают текущую работу. Они архивированы таском 01 разработки
редакции 3 бизнес-задачи (2026-09-11) как исторический след прежних решений,
а не как источники открытых вопросов или незакрытых замечаний.

- `OPEN_QUESTIONS.md` — вопросы дизайна, отменённого редакцией 3 (два
  кандидата-финалиста, гейт G2 на двух ячейках, дистанция в тиках и другое —
  см. `.autopilot/2026-09-11-lob-density-ed3--wip/interfaces.md`, раздел «Что
  построено под отменённый дизайн»).
- `critique-1.json` … `critique-7.json` — семь проходов адверсариальной
  проверки плана (поле `pass`, 1–7) более ранних редакций спеки. Каждый файл —
  снимок находок ревью на момент своего прохода; более поздний проход не
  переиздаёт находки предыдущего как открытые, поэтому файлы не сводятся в
  один. Формат — `{"pass": N, "blocking": [...], "note"?: "..."}`, находки —
  `{"id", "axis", "issue"}` без поля статуса: у JSON нет места для шапки
  «отменено», поэтому это разъяснение вынесено в этот README вместо
  правки самих файлов.

Актуальные открытые места и покрытие требований — `spec.md` и `REQUIREMENTS.md`
текущей волны, не эта директория.
