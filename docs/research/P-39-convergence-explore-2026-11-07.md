## 4. Метрика, таблицы, правило чтения поиска
**Метрика (П-38 §7.4, §9.2).** `y_d` = [Σ net закрытых сделок суток `d` + MTM на конце] / число активных пар-суток; интервалы — блочный t и студентизованный блочный бутстреп (B = 3000, seed 37), 90 %; skew ряда. **Знаменатель** [P39-N02]: активные пары-сутки базы (§6 П-38) **на универсуме варианта**: фильтры входа (фандинг, разрыв, шорт Bybit, выбросная нога, стопы, задержка) знаменатель не уменьшают (иначе фильтр «улучшает» `y_d` сжатием знаменателя); подмножества пар (без биржи X, терцили, Gate, eq) знаменатель сужают по построению. Рядом печатается Σ net / число суток.
**Для каждого варианта печатается (всё из сделок, одним кодом):**
1. сделки, активы, суток со сделками; gross, комиссия, фандинг, net на сделку; **`c*` = среднее (gross + фандинг)**; net при границах издержек 8,82 и 5,04 — **колонки справочные**, в ранжирование не входят (§4.1);

3. **половины H1 и H2 раздельно:** сделки, net на сделку, `y_d` с интервалами (`n_эфф` 5 и 7) — обязательны в каждой строке;

6. шум: сумма `y_d` трёх лучших суток и среднее без них; среднее без лучшего актива и без трёх лучших; доля побед, отношение выигрыш / проигрыш, квантили 5 % / 1 %, худшая сделка;

### 6.B. ФАНДИНГ — фильтр на входе по известной ставке (16 вариантов)
**Вопрос.** Если не входить в направление, где известный на момент входа фандинг обеих ног против позиции, сколько фандинга и сделок уйдёт, и что станет с net?
**Основание.** Факты 7, 11. **Определение (все величины — ТОЛЬКО по данным ≤ минуты решения `t`).**
- Известная ставка ноги `r̂` = последняя расчётная ставка с минутой выплаты ≤ `t` (прогноз по инерции), интервал ноги `I` = расстояние между двумя последними выплатами ≤ `t` (если известна одна — колонка `interval_h`; если нет — нога «неизвестна»: `r̂` = 0, счётчик `fund_unknown`; сигналы начинаются с 02.10, к этому времени у всех ног с интервалом ≤ 8 ч есть выплата, остаток печатается). Следующие выплаты — `m_s + k·I`, `k ≥ 1`.
- Ожидаемое начисление за горизонт `h` от номинала входа `f ≈ t + 2`: `Ê(h) = 1e4 · dir · (r̂_A · n_A(h) − r̂_B · n_B(h))`, bps, плюс = получаем; `n(h)` — число выплат ноги в `(f, f + h − 1]` по расписанию выше (детерминированное, расписание известно заранее). Знак и форма как в `PairSim._funding` (двухногий, `dir = +1`: шорт A, лонг B).
- **Фильтр:** вход разрешён, если `Ê(h) ≥ −φ · (1 − ρ) · g_in`, т. е. ожидаемый фандинг против позиции не больше доли `φ` ожидаемого gross (цель схождения `0,75·g_in`) [P39-N05]. `φ = 0` — **правило «знак фандинга диктует разрешённое направление»**: входим только туда, где известный фандинг не против нас.
- **Сетка** [P39-N06]: `φ` ∈ {0; 0,25; 0,5; 1,0} × `h` ∈ {T; `h_q90` (121 / 69 мин)} × `base` ∈ {B1, B2} = 16. Горизонт T (24 ч / 2 ч) — по поручению CEO; `h_q90` показывает фильтр на реальном горизонте удержания (средняя длительность V1 63,7 мин).
**Читается:** сколько сделок и какая доля фандинга убрана; парная разность; **точность прогноза** ex ante — корреляция и знак `Ê` с фактическим фандингом сделок базы (диагностика механизма §10, вместе с таблицей по бирже шорта).

**Читается:** доля отсечённых пар и сделок; попали ли в отсечение S1-эпизоды и BIRB 23.10 (описательно, порог от них не зависит); парная разность. Разбиение отсечённого по знаку относительно направления сделки (премия «в нашу сторону» или против) печатается без отдельных вариантов.

## 13. Честные оговорки
1. **Пост hoc.** Все семейства рождены разложением окна (§2), которое видено; половина H2 — не независимая проверка для них. Независима только проверка на сутках ≥ 2500.

3. **Победитель среди 192.** Нижняя граница лучшего варианта смещена вверх; варианты почти одни и те же сделки (`M_эфф` окна 1,18), поэтому реальное число независимых испытаний меньше, но не равно 1. Нуль §9 не поправка к издержкам.
4. **Издержки.** Основной результат — тейкер / тейкер при +1 мин без проскальзывания сверх +1 мин; граница 8,82 — верхняя, заполнение лимиток не смоделировано (число заполненных и отбор против нас неизвестны); нет стакана и спреда, разрешение — минутная свеча по последней сделке (§0.6 з П-38): секундные всплески видео не наблюдаются.
5. **Фандинг.** Прогноз ставки — «последняя расчётная» (инерция); для смены интервала внутри окна и аномальных ставок прогноз может промахиваться (счётчик `fund_sched_miss`). Механизм знака не установлен (§10).
6. **Одна фаза рынка** (октябрь–начало ноября 2026), 35 суток; три суток дают 99,8 % суммы `y_d` окна (факт 10).
7. **Выжившие:** список контрактов на 05.11; снятые не видны. Без спота, без Hyperliquid, без сессионных классов кроме `eq`. Gate — описательно (E-G).
