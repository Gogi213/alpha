## 4. Правило вердикта (единое, §3 п.3 плана — слово в слово)
«подтверждено» — нижняя граница интервала Δ (Холм) > 0 **и** знак Δ одинаков в **каждом** году с N≥8 и ≥5 монет **и** совпал против всех контролей теста; «оспорено» — верхняя граница ≤ 0 при тех же проверках; иначе «не различимо». Год с данными и иным знаком → «не различимо». Числа порога нет; год подтверждения не выбирается; ось выбирается по итогу, не по лучшему году. Утверждение bp, которое несколько тестов покрывают, получает вердикт худшего по строгости теста-носителя («подтверждено» только если все тесты — подтверждены; иначе «не различимо»/«оспорено»).
