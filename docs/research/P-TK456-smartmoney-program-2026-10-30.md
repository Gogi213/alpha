## 6. Правило вердикта и «слой закрыт»

| слой | вердикт по строке | слой закрыт, когда |
|---|---|---|
| L1 | «воспроизводится при определениях из области …» / «не воспроизводится ни при каких разумных» / «не различимо»; без подгонки под одно число | у каждого заявления автора есть строка, область на осях названа, итог + по годам |
| L2 | рамка §6 + пункт 3 §3 | та же таблица против контроля, число семейства и N по строкам, замечания Судьи сняты |
| L3 | на строку (форма входа/стопа/цели): рамка §6 для метрики «средний R после издержек минус контроль» | сетка закрыта в пределах заявки, издержки измерены, годы показаны |
| L4 | по заявлению канала: подтверждено / оспорено / нельзя проверить (+причина) | все 142 поста обработаны, извлечение сверено с TV-снимками |
| B1 | нет вердикта | реестр + словарь + число испытаний зафиксированы |
| B2 | как L2 | таблица по группам G1–G8 |
| S | как L2 | 6 сочетаний обработаны |

**Критерий общей остановки ветки:** по слою «не различимо» на всех строках и после проверки на другом годе → ветка закрыта «не отличимо
от контроля» (запись в `EXPERIMENTS.md`/журнал; сырьё не удаляем). Возврат — только новым словом владельца (В-N).

4. Что общий слой баров уже есть на диске — не проверено.
5. 6 сочетаний S — выбор по общему событию «свип/касание уровня»; возможны другие осмысленные пары (в этом плане они не считаются).

## 15. Алгоритм (В-170)

Алгоритм: варианты — (а) идти по слоям Санчо, затем отдельно bp, затем синтез; (б) сразу общий каталог осей Санчо+bp и единая сетка; (в) bp
первым (шире, дешевле формализовать); замер — число испытаний: (б) ≈ произведение осей двух авторов, взрыв семейства; (в) bp не имеет
чисел автора, воспроизводить нечего; выбран — (а) с общим словарём и заранее перечисленным синтезом (6 сочетаний), потому что порядок
слоёв сохраняет принятое (TK-451/454/455 уже идут), ворота делают дорогой синтез условным, а число испытаний фиксируется до счёта.
