## 3. Эпизод схождения (без стопов, вход мейкером) — как в r2
- **Величины:** `d⁽¹⁾_t = ln(mid_A/mid_B) − P̄_L(t)`, где `P̄_L` — среднее `ln(mark/index)`-премий прошлого окна `L` (у пары без index на обеих ногах — медиана `ln(mid_A/mid_B)` за `[t−L, t−1 мин]`); запасной `d⁽²⁾` — медиана прошлого окна; `d⁽³⁾` — сырой. Фандинг в уровень не входит: признак `Φ_t` и фактическое начисление в итоге эпизода.
- **Эпизод:** `|d|` пересёк `θ` снизу, пара была взведена (`|d| < θ/2` в течение `W = 60 с`). Продаём дорогую ногу, покупаем дешёвую. Конец — `dir·d ≤ 0` (сошлось); промежуточные уровни ½, ¼ печатаются. **Стопов и таймаутов нет**; усечение — только §2.2.
- **Вход:** лимитки на лучшей цене (ask дорогой, bid дешёвой), модель очереди `prob:3`, задержка `L_ms`; `T_life = 60 с`; снимаются при `dir·d ≤ θ/2` или по истечении. Одна нога исполнена — закрывается мейкер-заявкой, живёт `T_life`, затем тейкер — исход «страховка».
- **Выход:** при обеих исполненных мейкер-заявки на лучшей цене своей стороны ставятся при `dir·d ≤ ½·d_вход` и живут, пока не исполнятся, до усечения §2.2 (то же для K2). «Сошлось по mid, не вышел» — отдельный исход.
- **Комиссия:** мейкер 1,26 bps/нога (5,04 bps за 4 ноги), тейкер 3,15 bps/нога; фандинг — фактический по расчётам между входом и выходом.
- **Меряется по эпизоду:** исполнение каждой ноги, время до исполнения, маркаут 1/10/60 с, пик и время до пика, время схождения (Каплан–Мейер с цензурой), **МПУ** (худший плавающий результат от цен исполнения по исполнимой стороне книги; по mid справкой), лучший плавающий, итог `net_bps`, лидер/догоняющий, форма пути. Это **описание**; сводная величина — `net_bps` (§4).
- **Таблица эпизодов** для статистики — схема `SCHEMA` в `tools/p40stats/p40stats.py` (+ `armed` — флаг взведённого эпизода, `trunc` — причина усечения, `net_bps` — по ITT: нет исполнения = 0, страховка и усечение включены). Недели и части S/T не нужны.

## 4. Наивный бэктест как описание
**4.1 Правило (одно, без подбора):** на каждом взводе `|d| ≥ θ = 12,6 bps` выставлять мейкер-вход §3 на фиксированном `N = 1 000 USDT`, выход — §3; фильтров нет, признаки не используются, пары бирж не выбираются. Вывод — только про это правило на этом периоде.

**4.2 Что печатается (описание, без правила вердикта):**
1. **Объём:** число взводов, эпизодов, пара-суток, активов по парам бирж; доли исходов (обе ноги / одна+страховка / нет / сошлось не вышел / усечён).
2. **Как расходится:** размах `|d|` в момент взвода и пик до схождения (квантили 50/90/99), скорость расхождения до `θ` (bps/с), лидер/догоняющий, форма пути.
3. **Как сходится:** время до ½ и до 0 (Каплан–Мейер с цензурой), доля «сошлось за `H`», промежуточные уровни ½ и ¼.
4. **Путь и МПУ:** пик, время до пика, МПУ по исполнимой стороне (по mid справкой), доля «МПУ > X», лучший плавающий; квантили, не только средние.
5. **Мейкер:** доля исполнения каждой ноги и обеих, время до исполнения, маркаут 1/10/60 с.
6. **Итог после комиссии:** `ȳ` — средний `net_bps` на взведённый эпизод (ITT, главное число); справкой — `ȳ` на эпизод «обе исполнены», `ȳ` без усечённых, по суткам, по блокам 7 суток от 17.09, по парам бирж, без 3 лучших активов и 3 лучших суток; фандинг отдельной колонкой.
7. **Срезы по признакам** (закономерности в расхождениях): 13 признаков r2 §3.5 — номинал L1 `l1_notional` (вместо «глубины `N`», r3.1→r3.2), спред книги, волатильность 5 мин, `P̄_L`, ΔOI 5 мин, дисбаланс потока 1 мин, дисбаланс L1 `bookimb1` (вместо top-5), размер `d` при взводе (терцили верх/низ **по всему периоду и всем парам вместе**); знак `Φ`, ликвидации 5 мин, лидер за 10 с, нога Bybit (да/нет, на объединении всех пар — внутри одной пары признак постоянен, Р-2); час суток — 4 блока по 6 ч, каждый против остальных. Итого 12 контрастов + 4 часовых = **16 контрастов**; контраст — разность среднего `net_bps` страты и дополнения; минимумы страты §8; BH `q = 0,10` на 16 — только **отсев шума** (отметка «выделяется над шумом»); правило из страт не строится и не проверяется.

**4.3 Контроли (считает ядро, тот же прогон):**
- **K1** — сдвиг ноги B во времени на ±1 с, ±10 с, ±60 с, ±1 ч: тот же конвейер (уровень, взвод, эпизоды, мейкер) на сдвинутом ряде. Сдвиг ломает совместное движение, сохраняет маргиналии книги.
- **K2** — случайный вход: на тех же пара-сутки столько же случайных моментов (равномерно по годному времени, не ближе 600 с к настоящему взводу), направление «продаём дорогую / покупаем дешёвую» по знаку `d`, мейкер-вход §3 с одним отличием (Р-8): заявки входа K2 **не снимаются** по `dir·d ≤ θ/2` (в случайный момент `|d| < θ/2` почти всегда, условие снимало бы вход сразу) — живут только `T_life`; то же передаётся ядру TK-500; выход — как в §3: мейкер на лучшей цене своей стороны при `dir·d ≤ ½·d_вход`, живёт до усечения §2.2 (Р-5); время держания не задаётся. Отвечает: даёт ли плюс сама механика «вход мейкером — выход мейкером» без взвода.
- **Разности с контролем** — три отдельные величины (Р-3): `ȳ − ȳ_K1(+60 с)`, `ȳ − ȳ_K1(−60 с)`, `ȳ − ȳ_K2`. Спаривание — по ячейкам актив × сутки: в ячейке суммы `net_bps` и число эпизодов настоящих и контрольных, пустая на одной стороне ячейка входит нулями; `ȳ` каждой стороны — отношение сумм `Σnet/Σn`; интервал разности — схемой §6.1 по совместной переоценке пар ячеек.

**4.4 Испытания и поправка.** Семейство Холма (0,05) для утверждений «`ȳ` отличается от 0»: 1 главное (все пары бирж вместе, θ = 12,6, `T_life` = 60 с, `L_ms` = 500 мс) + пары бирж — все 15 сочетаний из Binance, Bybit, OKX, Bitget, Aster, Gate; в семейство входят пары, прошедшие минимум §8 по **числу эпизодов, пара-суток и активов (без чтения `net_bps`)**; `m` = 1 + число таких пар (≤ 16) фиксируется в отчёте G0 до чтения `net_bps` (Р-4). Прочие `θ` (5,04; 25,2; 50; 100), `L_ms`, `T_life` из сеток §8 — справкой, без поправки и без утверждений. Разности с контролями (3 величины) — справкой, без поправки.

**4.5 Формулировка отчёта (заранее).** Допускается: «в этих 35 сутках среднее `net_bps` на взведённый эпизод = … bps, 90 % интервал […]; различимо выше / ниже нуля / не различимо (Холм)»; разности с K1 и K2 — числа и интервалы. **Запрещено:** «стратегия работает», «кандидат», «подтверждено» и прогноз вне периода: период один, проверочного нет (В-107), перенос не проверялся (В-110), срезы получены на тех же сутках. Нижняя граница `ȳ` > 0 — описание чистого итога при допущениях §9, а не вывод об устойчивости; рядом всегда печатаются K1/K2 и «без лучших».

**4.6 Достижимость плюса (до счёта):** при θ = 12,6 выход на ½·d даёт брутто ≈ 6,3 bps против 5,04 bps издержек (+1,3 bps на эпизод с обеими исполненными ногами), схождение до 0 — до +7,5 bps; плюс по построению достижим. `ȳ` по ITT разбавлен долей исполнения, поэтому MDE (§6.3) сравнивается с запасом × доля эпизодов «обе исполнены» из G0 (З-3); **если MDE главного `ȳ` больше этого запаса, отличие чистого итога от нуля различается только описательно** (запись в отчёте, правило не меняется).

## 6. Статистика
### 6.1 Единицы и схема интервала
Единица независимости — актив × сутки, но внутри актива зависимость постоянна (TK-502): **двусторонняя кластеризация (актив и сутки)**; единица счёта — эпизод. Кандидаты схем: бутстреп с произведением весов `twoway`; аналитическая CGM `V_A+V_D−V_AD` с неотрицательной поправкой; бутстреп с вычитанием ячеек; поправка малого G. **Правило выбора (до счёта, Р-7):** по перезапуску TK-502 (четыре режима покрытия, мощность при k = 1; 1,5; 2) берутся схемы с покрытием 90 %-го интервала **не ниже 0,85 во всех четырёх режимах**; из них — схема с наибольшей мощностью при k = 1,5; если таких нет — схема с наибольшим покрытием в худшем из режимов (самая консервативная). Выбор механический по таблице TK-502; схема и её покрытие записываются в §8 до счёта, Судья подтверждает; до записи — CGM. Печатается `n_эфф`. Блочный бутстреп по суткам r2 §5.1 не используется.
### 6.2 Число испытаний
Холм: 1 главное + ≤ 15 пар бирж (§4.4). Срезы: 16 контрастов, BH 0,10. Контроли и сетки — справкой без статуса. Отчёт печатает фактические числа испытаний и сколько выделилось.
### 6.3 Мощность (до счёта)
`MDE(разность) = (z_{0,95}+z_{0,80})·σ·√(DEFF·(1/n₁+1/n₂))`, `z_{0,95}=1,645`, `z_{0,80}=0,84`; для `ȳ` (одна выборка) — `√(DEFF/n_эфф)`; `σ`, `DEFF`, доля исполнения — из G0 по двусторонней схеме, без разбивки по стратам. Печатаются: MDE главного `ȳ` (35 сут, ≈100 активов), MDE контраста для минимальной страты и мощность из симуляции по выбранной схеме. Сравнение с запасом — §4.6.
### 6.4 Распределения
Описание — квантили (50/90/99), не только средние; Каплан–Мейер с цензурой для времени схождения; МПУ с интервалами.
