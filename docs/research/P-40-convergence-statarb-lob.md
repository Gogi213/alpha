## 3. Этап 1 — эпизоды схождения (один актив, две биржи), без стопов
### 3.1 Величины
- `mid`, `bid`, `ask`, глубина до размера `N` по книге каждой ноги; as-of по времени события (значения строго до `t`).
- **Уровень (Р-2):** `P̄_L(t) = mean_{u∈[t−L, t−1 мин]} [ ln(mark_A/index_A) − ln(mark_B/index_B) ]` (bps) — только прошлое, только медленная часть. У ног без index (OKX и др.) — `P̄_L = median_{u∈[t−L, t−1 мин]} ln(mid_A/mid_B)`; пара, где index есть только у одной ноги, идёт по этой же медиане mid-спреда (З-2). G0 печатает по паре медиану и p10/p90 `d⁽¹⁾` рядом с проверкой тавтологии (З-1: постоянный сдвиг `ln(index_A/index_B)` при разных корзинах индексов; описательно, `d⁽²⁾` печатается всегда).
- **Расхождение:** главный `d⁽¹⁾_t = ln(mid_A/mid_B) − P̄_L(t)`; запасной `d⁽²⁾_t = ln(mid_A/mid_B) − median_{[t−L, t−1 мин]} ln(mid_A/mid_B)`; `d⁽³⁾` = сырой `ln(mid_A/mid_B)` — справкой. Мгновенных премий в уровне нет.
- **Фандинг в уровень не входит** (иначе уровень смещается на время держания). Он учитывается: (а) признак `Φ_t = n_s·(r_A − r_B)` в bps для позиции «продаём A / покупаем B» (получаем `r_A − r_B` за каждый расчёт), `r` — ставки, известные на `t`, `n_s ∈ {0,1}` — есть ли расчёт любой ноги в ближайшие `H` секунд; (б) фактическое начисление в итоге эпизода — по расчётам, прошедшим между входом и выходом.

### 3.2 Эпизод
- Начало: `|d|` пересёк порог `θ_i` снизу (пара «взведена»: `|d| < θ_i/2` в течение `W = 60 с` до пересечения). Пороги — сетка **для описания** (§8).
- Конец: `d` вернулся к уровню (`dir·d ≤ 0`) — «сошлось»; печатаются и промежуточные уровни (½, ¼ входного). Нет стопов, нет таймаутов. Конец данных/дыра — эпизод **цензурирован**.
- Одна нога «дорогая» → продаём там, «дешёвая» → покупаем.

### 3.3 Вход, жизнь заявки, выход (мейкер)
- **Вход:** в момент начала эпизода ставятся лимитки: продажа на ask дорогой ноги, покупка на bid дешёвой (**главный — на лучшей цене**; улучшение на тик — справкой). Исполнение — модель очереди (`hftbacktest`, `prob:3`); задержка постановки `L_ms`.
- **Жизнь заявки входа `T_life = 60 с`.** Обе заявки снимаются, если до исполнения `dir·d ≤ θ/2` (сошлось наполовину) или истёк `T_life`.
- **Одна нога исполнена, вторая нет:** при снятии исполненная нога закрывается **заявкой мейкера** на своей стороне книги, живёт ещё `T_life`; если и она не исполнена — закрытие тейкером (3,15 bps) — **отдельный исход «страховка»** со своим результатом. Страховка тейкером второй ноги сразу при исполнении первой — справкой.
- **Выход при обеих исполненных:** заявки выхода мейкером ставятся при `dir·d ≤ ½·d_вход` на лучшей цене своей стороны; живут до конца данных. Если `d` дошло до `≤ 0`, а выход не исполнен, — отдельный исход «сошлось по mid, не вышел» (долей и дальнейшим путём до исполнения/цензуры; не потеря). Тейкер-выход — справкой (3,15 bps на ногу).
- Меряются: доля исполнения каждой ноги, время до исполнения, доля «обе ноги», доля «одна нога» и результат страховки; **маркаут после исполнения** (1, 10, 60 с).
- Ограничение: у Bybit-архива и Gate только биржевое время — локальные метки синтетические с задержкой `L_ms` (допущение, §9).
- Комиссия мейкера: тариф владельца 0,014 % минус 10 % (В-47) = 1,26 bps на ногу, 5,04 bps за 4 ноги; тейкер 3,15 bps на ногу.

### 3.4 Что меряется по каждому эпизоду
Пик расхождения и время до пика; время схождения (Каплан–Мейер с цензурой; конкурирующие исходы — сошлось / ушло за уровень `X` / цензура); **МПУ** — худший плавающий результат позиции от цен исполнения, по исполнимой стороне книги (по mid справкой), квантили 50/90/99 с интервалами; лучший плавающий результат; итог при выходе на схождении (мейкер, комиссии, фактический фандинг); какая нога двигалась (лидер/догоняющий); длительность и форма пути.

### 3.5 Закономерности
Признаки (фиксированы до счёта, 14): пара бирж; глубина книги на `N` (терцили); спред книги `(ask−bid)/mid` (терцили); час суток (4 блока по 6 ч); реализованная волатильность mid за прошлые 5 мин (терцили); `P̄_L` (терцили); `Φ_t` (знак); изменение OI за 5 мин (терцили); ликвидации за 5 мин (есть/нет); дисбаланс потока сделок за 1 мин (терцили); дисбаланс книги top-5 (терцили); размер `d` при взводе (терцили); лидер за последние 10 с (A/B); нога Bybit да/нет.
**Контраст признака (одно испытание на признак × пару бирж × исход):** для порядковых (терцили) — верхняя против нижней терцили; для бинарных — да против нет; для «час суток» — один χ²-тест однородности долей исхода по 4 блокам (df = 3), эффектом для п. 1, 3, 4 считается размах `max − min` долей по блокам при порядке блоков, зафиксированном по D1 и тем же на D2. «Пара бирж» и «нога Bybit» внутри пары бирж не тестируются: «пара бирж» — одно испытание χ² однородности по парам на каждый исход на объединении пар; «нога Bybit» — только H-Bybit на Q1.
**Исходы сравнения:** (i) «сошлось за `H`» против «нет»; (ii) «МПУ > `X`» против «нет». `H`, `X` — по одному главному значению (§8), остальное справкой.
**H-Bybit (Р-6), записана до счёта:** у эпизодов с ногой Bybit время схождения дольше (медиана) и вероятность «МПУ > X» выше, чем без ноги Bybit. Проверяется на Q1 (читается один раз) как проверка Холма; срез «без Bybit +9,6 bps» из П-38 статуса не имеет.
**Правило «закономерность есть» (числа):** признак/страта получает статус **«кандидат»** (не выше), если одновременно:
1. эффект (разность долей исходов (i) или (ii), верхняя страта против нижней) одного знака на D1 и D2, и на каждом из D1, D2 90 %-й кластерный интервал (кластер актив×сутки, блочный бутстреп по суткам) не накрывает 0 и лежит по ту же сторону от 0, что и точечный эффект на D1;
2. проходит BH (`q = 0,10`) по бюджету §5.1 на D1 ∪ D2;
3. без трёх лучших активов и трёх лучших суток знак сохраняется и 90 %-й интервал не накрывает 0;
4. контроли (сдвиг ноги ±1/10/60 с; случайные моменты с тем же состоянием книги) эффекта не воспроизводят: эффект контроля < ½ эффекта и интервал контроля накрывает 0.
Подтверждение (статус выше «кандидат») — только на Q1 (или Q3 по слову владельца), Холм 0,05 по числу кандидатов.
Этап 1 **не выдаёт торгового вердикта**: результат — описание путей, МПУ, исполнимости мейкера, закономерностей.

- Описание — распределения (квантили), не только средние.
### 5.2 Мощность (до счёта)
`MDE = (z_{0,95}+z_{0,80})·σ·√(DEFF/n_эфф)` при `z_{0,95}=1,645`, `z_{0,80}=0,84`; для разности долей `MDE ≈ 2,49·√(p(1−p)·DEFF/n_эфф)`. `σ`/`p` и `DEFF` — объединённый разброс по эпизодам без разбивки по стратам (не по эффекту), берутся в G0. Значение печатается для D1 (~100 активов × 14 суток) и для Q1. **Если MDE итога на эпизод (bps) выше порога издержек 5,04 bps — этап 1 различает по чистому итогу только описательно;** запись в отчёте, правило не меняется.
