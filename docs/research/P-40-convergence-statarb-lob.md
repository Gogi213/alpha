## 3. Эпизод схождения (без стопов, вход мейкером) — как в r2
- **Величины:** `d⁽¹⁾_t = ln(mid_A/mid_B) − P̄_L(t)`, где `P̄_L` — среднее `ln(mark/index)`-премий прошлого окна `L` (у пары без index на обеих ногах — медиана `ln(mid_A/mid_B)` за `[t−L, t−1 мин]`; З-2); запасной `d⁽²⁾` — медиана прошлого окна; `d⁽³⁾` — сырой. Фандинг в уровень не входит: признак `Φ_t` и фактическое начисление в итоге эпизода.
- **Эпизод:** `|d|` пересёк `θ` снизу, пара была взведена (`|d| < θ/2` в течение `W = 60 с`). Продаём дорогую ногу, покупаем дешёвую. Конец — `dir·d ≤ 0` (сошлось); промежуточные уровни ½, ¼ печатаются. **Стопов и таймаутов нет**; конец окна — усечение (§2.2).
- **Вход:** лимитки на лучшей цене (ask дорогой, bid дешёвой), модель очереди `prob:3`, задержка `L_ms`; `T_life = 60 с`; снимаются при `dir·d ≤ θ/2` или по истечении. Одна нога исполнена — закрывается мейкер-заявкой, живёт `T_life`, затем тейкер — исход «страховка».
- **Выход:** при обеих исполненных мейкер-заявки на лучшей цене своей стороны ставятся при `dir·d ≤ ½·d_вход` и живут до конца недели (усечение §2.2). «Сошлось по mid, не вышел» — отдельный исход.
- **Комиссия:** мейкер 1,26 bps/нога (5,04 bps за 4 ноги), тейкер 3,15 bps/нога; фандинг — фактический по расчётам между входом и выходом.
- **Меряется по эпизоду:** исполнение каждой ноги, время до исполнения, маркаут 1/10/60 с, пик и время до пика, время схождения (Каплан–Мейер с цензурой), **МПУ** (худший плавающий результат от цен исполнения по исполнимой стороне книги; по mid справкой), лучший плавающий, итог `net_bps`, лидер/догоняющий, форма пути. Эти величины — **описание**, без правила вердикта; вердикт шагов 1–2 — только по `net_bps` (§4, §5).
- **Таблица эпизодов** для статистики — схема `SCHEMA` в `tools/p40stats/p40stats.py` (+ `week`, `part` S/T, `armed` — флаг «эпизод взведён», `net_bps` — по ITT: нет исполнения = 0, страховка и усечение включены).

## 4. Шаг 1 — наивный бэктест (все пять недель вместе)
**Правило (одно, без подбора):** на каждом взводе `|d| ≥ θ = 12,6 bps` выставлять мейкер-вход §3 на фиксированном `N = 1 000 USDT`, выход — §3; фильтров нет, признаки не используются, пары бирж не выбираются.
**Измеряемая величина:** `ȳ` — средний `net_bps` на **взведённый эпизод** (ITT: неисполненный вход = 0) — вывод про стратегию «входить на каждый взвод»; справкой `ȳ` на эпизод «обе ноги исполнены» и доли исходов (обе / одна+страховка / нет / сошлось не вышел / усечён).
**Единицы:** актив × сутки, кластеры по активу и по суткам одновременно; единица счёта — эпизод.
**Контроли (считает ядро, включаются в тот же прогон):**
- **K1 сдвиг ноги B во времени** на ±1 с, ±10 с, ±60 с, ±1 ч: тот же конвейер (уровень, взвод, эпизоды, мейкер) на сдвинутом ряде. Сдвиг ломает совместное движение, но сохраняет маргиналии книги.
- **K2 случайный вход:** на тех же пара-сутки столько же случайных моментов (равномерно по годному времени, не ближе 600 с к настоящему взводу), направление «продаём дорогую / покупаем дешёвую» по знаку `d` в момент, тот же мейкер-вход §3; выход мейкером на лучшей цене через время держания, взятое из эмпирического распределения настоящих эпизодов той же пары бирж (фиксированный `seed`). Отвечает на вопрос: даёт ли плюс сама механика «вход мейкером — выход через время» без взвода.
**Испытания и поправка:** семейство Холма (0,05): 1 главное (все пары бирж вместе, θ = 12,6, `T_life` = 60 с, `L_ms` = 500 мс) + ≤ 10 по парам бирж (из Binance, Bybit, OKX, Bitget, Aster, Gate вне дыры) = **≤ 11**. Прочие `θ` (5,04; 25,2; 50; 100), `L_ms`, `T_life` из сеток §8 — **справкой**, статуса не получают (иначе по ним — свой Холм).
**Правило вердикта шага 1** (заранее): статус **«кандидат»** (не выше) получает испытание, если одновременно:
1. нижняя граница 90 %-го двустороннего кластерного интервала `ȳ` > 0 и скорректированное по Холму одностороннее `p` ≤ 0,05;
2. `ȳ` минус эффект K1(±60 с) и минус эффект K2 > 0 с нижней границей интервала разности > 0 (разность по парам актив×сутки);
3. без трёх лучших активов и трёх лучших суток `ȳ` > 0, нижняя граница > 0;
4. знак `ȳ` положителен минимум в 4 из 5 недель (описание согласованности, не тест).
Иначе — «не подтверждено»; если верхняя граница `ȳ` < 0 — «отрицательно». Статус «кандидат» — окончательный в рамках П-40 (проверочного периода нет, В-107): на нём стоит оговорка «подобран в тех же 35 сутках, внутринедельный перенос — шаг 2».
**Достижимость плюса (проверка до счёта):** при θ = 12,6 выход на ½·d даёт брутто ≈ 6,3 bps против 5,04 bps издержек (+1,3), дальнейшее схождение до 0 — до +7,5 bps; плюс по построению достижим. Мощность: MDE шага 1 (§6.3) печатается в G0 до счёта; **если MDE главного испытания > 1,3 bps, шаг 1 по чистому итогу различает только описательно** (запись в отчёте, правило не меняется).

## 5. Шаг 2 — недели: найти в S, проверить на T той же недели
Выполняется независимо для каждой из W1…W5; **после шага 1** (нельзя править правило шага 2 по его результату). Данные шага 1 не фильтруются.
1. **Поиск на S.** Признаки (13 из r2 §3.5 без «пара бирж»): глубина `N`, спред книги, волатильность 5 мин, `P̄_L`, ΔOI 5 мин, дисбаланс потока 1 мин, дисбаланс книги top-5, размер `d` при взводе (терцили: верхняя против нижней); знак `Φ`, ликвидации 5 мин, лидер за 10 с, нога Bybit (да/нет); час суток — 4 блока по 6 ч, каждый против остальных. Контраст — разность среднего `net_bps` эпизодов страты и противоположной страты. Для каждой пары бирж: 12 контрастов + 4 часовых = 16 испытаний; на неделю ≤ 16 × ≤ 10 пар = **≤ 160**; BH `q = 0,10` на неделю; минимумы страты §8.
2. **Правило недели** = объединение страт, прошедших BH на S с положительным эффектом (`net_bps` страты выше дополнения). Фиксируется (список страт, пары бирж) и записывается в таблицу до чтения T. Страт нет → неделя «ничего не найдено» (идёт в итог как неделя без сделок, не пропуск).
3. **Перенос на T.** Тот же мейкер-вход §3 на эпизодах T, входящих в правило недели. Меряется: `ȳ_T` (в правиле), `ȳ_T` дополнения, доля эпизодов в правиле, разность «в правиле − вне правила», **неснижаемо — абсолютный `ȳ_T` > 0**.
4. **Итог по неделям.** Объединяются эпизоды T всех пяти недель; единица — актив × сутки с двусторонней кластеризацией; одно главное испытание (`ȳ_T` в правиле, по пяти неделям); Холм не нужен (единственное); справкой — по неделям отдельно и разность «в правиле − вне правила».
5. **Контроль самого поиска.** Тот же поиск (шаги 1–3) на **K1(±60 с)** и на **K2**: доля недель, где «нашлось» правило, и `ȳ_T` перенесённого. Если поиск на контролях находит правила, переносящиеся с `ȳ_T` ≥ половины настоящего, — поиск не отличает механику от структуры.
**Правило вердикта шага 2** (заранее): «перенос внутри недели есть» (статус «кандидат») — если одновременно: (а) `ȳ_T` по пяти неделям > 0 с нижней границей 90 %-го двустороннего кластерного интервала > 0; (б) `ȳ_T` в правиле минус `ȳ_T` вне правила > 0 с нижней границей > 0; (в) `ȳ_T` > 0 минимум в 4 из 5 недель с найденным правилом; (г) на контролях (п. 5) `ȳ_T` < ½ настоящего и интервал накрывает 0; (д) без трёх лучших активов и трёх лучших суток нижняя граница `ȳ_T` > 0. Иначе — «перенос не показан»; верхняя граница < 0 — «отрицательно».
Описательно (без статуса): какие страты находились в каких неделях, повторяются ли они между неделями (число недель на страту), как менялись пути/МПУ/времена схождения по неделям.

## 6. Статистика
### 6.1 Единицы и схема интервала
Единица независимости — актив × сутки, но с учётом того, что внутри актива зависимость постоянна (TK-502): **двусторонняя кластеризация (актив и сутки)**. Схему (бутстреп с произведением весов `twoway`, аналитическая CGM `V_A+V_D−V_AD` с неотрицательной поправкой, бутстреп с вычитанием ячеек, поправка малого G) выбирает Судья по перезапуску TK-502 с покрытием в четырёх режимах (D = 7 и 22, G ≈ 100) и мощностью k = 1; 1,5; 2; **выбранная схема записывается в §8 до счёта**, до выбора — по умолчанию CGM. Печатается `n_эфф`. Блочный бутстреп по суткам r2 §5.1 не используется.
### 6.2 Число испытаний
Шаг 1: ≤ 11 (Холм 0,05). Шаг 2: поиск ≤ 160 на неделю × 5 недель = ≤ **800** испытаний внутри S (BH 0,10 на неделю; на контролях — те же), подтверждение — **1** главное испытание на T. Все справочные значения сеток (θ, `L_ms`, `T_life`, `H`, `X`) — без статуса. Итоговый отчёт печатает фактические числа испытаний и сколько прошло.
### 6.3 Мощность (до счёта)
`MDE(разность) = (z_{0,95}+z_{0,80})·σ·√(DEFF·(1/n₁+1/n₂))`, `z_{0,95}=1,645`, `z_{0,80}=0,84`; для `ȳ` (одна выборка) — `√(DEFF/n_эфф)`; `σ`, `DEFF` — из G0 по двусторонней схеме, **без разбивки по стратам**. Печатаются MDE шага 1 (35 сут, ≈100 активов) и шага 2 (T одной недели, T пяти недель); и мощность из симуляции по выбранной схеме. Если MDE выше запаса +1,3 bps (§4) — шаг различает чистый итог только описательно.
### 6.4 Распределения
Описание — квантили (50/90/99), не только средние; Каплан–Мейер с цензурой для времени схождения; МПУ с интервалами.
