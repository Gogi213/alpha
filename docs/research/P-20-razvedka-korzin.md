# P-20 · Разведка корзин: есть ли монеты, где B1 устойчиво лучше случайных уровней (TK-301, В-41/G-007) — 18.10.2026

Статус: разведка (без нового счёта), утверждает Судья, не владелец. Заморожено до чтения результата по монетам.
Раскрытие: до записи порогов видел только число сделок по монетам в rounds.csv (ARB, ENA ≫ FART ≫ OP > остальные ≤ 5 сделок/seed) — не исходы Δ.

**Данные (готовые, TK-274):** Г-03 `/data/tk0274/g03/delta/rounds.tgz` (стены, режим paired) и `/data/tk0274/g03nw/delta/rounds.tgz`
(двойники nowall, 5 seed, та же монета/сутки). Скрипт — логика `tk274-g03-delta.py` (usd = net_bps·entry_px·qty/1e4, среднее по 5 seed), разрез по `symbol`.

**Единица:** монета × окно (янв–сен; каждый месяц). d_t = $стены_t − $двойники_t по календарным суткам UTC (сутки без сделок = 0), все 273 сутки окна.

**Читаемый месяц монеты:** сделок стен (среднее по seed) ≥ 5 и сделки двойников/стен ∈ [0,5; 2] (как В-контроль П-15 §5).
**Проверяемая монета:** сделок стен янв–сен ≥ 30 (правило эфф. N < 30 — «совместимо с», не вывод) и контроль янв–сен ∈ [0,5; 2]. Иначе — «мало сделок».
m = число проверяемых монет.

**Статистика:** Σ$-разность D = Σ d_t и dSR = SR(стены) − SR(двойники) (ежесуточные ряды, как Г-03). p — односторонний, парный блочный
циклический бутстреп по суткам (блок ⌈n^{1/3}⌉, 4000, центрированный, seed 15) по среднему d_t.

**«Устойчива»** — всё сразу: (1) проверяемая; (2) ≥ 3 читаемых месяца; (3) D > 0 минимум в 2/3 читаемых месяцев; (4) p ≤ 0,05/m (Бонферрони по m монетам);
(5) D > 0 без двух суток с наибольшим d_t. «Не устойчива» — проверяемая, но (2)–(5) не выполнены целиком. Только (1) не выполнено — «мало сделок»;
проверяемая с < 3 читаемыми месяцами — «мало месяцев» (не судим, не «нет»).
**Ожидается случайно:** (а) при нулевом эффекте с поправкой — 0,05 монеты на весь список; (б) без поправки (по одному p ≤ 0,05) — 0,05·m; (в) по знакам месяцев — биномиально
P(≥ ⌈2k/3⌉ из k при 0,5) для каждой монеты, сумма по монетам. Сравнить с наблюдённым числом.
**Предел:** B1 = единственная ровная стратегия Г-03; вывод — только про «стены B1 против nowall-двойников» на днях Г-03 (41 сутки со сделками, в основном янв), не про корзины вообще.
