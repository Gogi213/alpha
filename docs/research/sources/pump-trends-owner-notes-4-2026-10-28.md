# Тренды и конец пампа — материал владельца (28.10)

«попробуй тут дерни. тут может есть инфа». Ниже — выжимка для формализации (G-017, TK-433), не пересказ целиком.

## Старт тренда (как в материале)
- Выход из «полноценной формации» (консолидации) вверх **и** три условия индикатора: `DV > 350m`, `natr > 1.1`, наличие трендовой
  (наклонной) линии. Вероятно DV — дневной оборот в $, natr — нормированный ATR в %; таймфрейм не указан. Это числа автора
  материала — проверять на данных, не брать как константы.
- Касания трендовой — плавные; на меньшем ТФ у линии консолидация (кто-то держит линию лимитками — ММ, фьючерс или спот).

## Фазы: «теория трёх наклонок»
1. Первая наклонка — основной тренд.
2. Вторая — угол круче, смесь тренда и боковика, возможное начало пампа.
3. Третья — самый крутой угол, ускорение, ликвидации шортов; финальная стадия пампа.

Механика памп→дамп по материалу: набор лонга снизу → разгон (часто спотом) → на хаях закрытие лонга и набор шорта → слив
ранее набранного спота → закрытие шортов на низах → падение OI, стабилизация.

## Признаки конца пампа (дословные пункты материала → формализация)
| № | в материале | как мерить на наших данных |
|---|---|---|
| К1 | ускорение/«финалка» на третьей наклонке | кусочно-линейная аппроксимация ноги: наклон сегментов растёт, последний — самый крутой, затем пробой его линии |
| К2 | падение OI на лонговом выносе, затем медленный рост OI без роста цены; каждый перелой — OI падает без восстановления | OI (Bybit 5 мин TK-425, Gate TK-415/428): знак ΔOI на последнем рывке к пику и после пика |
| К3 | проторговка, «распиливающая» наклонку | время цены по обе стороны последней наклонной линии у пика |
| К4 | конец «робота-покупаша» по споту | доля рыночных покупок на споте падает к норме (сделки спота) |
| К5 | нет давления лонговых покупателей / алгоритмов | доля агрессивных покупок на фьючерсе падает |
| К6 | объём шортовых принтов > лонговых, интенсивность выше | дельта (sell−buy) по сделкам < 0 и растёт число сделок |
| К7 | под хаем не могут обновить максимум, после перехая — агрессивные продажи | повторные тесты пика + отрицательная дельта после нового хая |
| К8 | спотовые продажи — частая причина разворота «алгосных» монет | дельта спота < 0 у пика, сравнение со фьючерсом (связка спот↔фьюч) |

Конец тренда без дампа: выход в консолидацию → возврат к линии (продолжение) или слом (конец).
Медленный памп — ретесты пробитой линии часты; быстрый (крутой угол) — ретест редок.
