## Практики

Источник: `docs/transcripts/` (9 расшифровок: `отскок станок`/`отскок dizzi`, `stanok_*` ×4, `dizzy_*` ×2), читаны целиком пятью субагентами по файлам/парам файлов. Условные обозначения источника: **S** = станок, **D** = dizzi (основные два видео), остальные — по имени файла (`stanok_...`, `dizzy_...`). Таймкоды переведены в `mm:ss` от начала файла. Кросс-проверка формализации — по `docs/findings/bounce-spec-2026-09-17.md`, `docs/findings/order-management-practitioners-2026-09-20.md`, `docs/findings/practitioners-2026-09-13.md`, `docs/plan/HYPOTHESES.md`, `docs/plan/SETTLED.md` (В-64 и др.), `docs/findings/loss-days-2026-09-25.md` (E27–E34).
Обозначения в колонке «формализовано»: **да** — ось/форма/эксперимент есть (где); **да, отклонено** — испытано и не подтвердилось/отклонено владельцем; **нет** — не формализовано.
