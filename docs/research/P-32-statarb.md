## 1. Вопрос и решение
- Вопрос: на минутных свечах 2020–2026 есть ли у стат-арбитража вида V ∈ {пары, корзины, кросс-биржа, фандинг} положительный **чистый** результат (комиссия В-88 + фандинг + измеренное проскальзывание), который держится вперёд по времени и не объясняется отбором.
- «Да» → отдельный тикет: бэктест с портфелем и задержкой исполнения, затем решение о живой проверке. «Нет» → вид закрывается с названным пределом (издержки/сигнал/данные), перебор не продолжается. «Не ясно» → название недостающих данных (см. §4, развилки).

## 2. Механизм (кто на другой стороне)
- **Пары / корзины (одна биржа):** относительная цена двух близких активов возвращается к среднему, пока общий фактор (рынок, сектор) тянет их вместе; платит тот, кто двигает одну монету потоком (листинги, ликвидации, новости по одной монете). Механизм слабый для альтов с нестационарной связью — ожидание «края нет» без доказательства обратного.
- **Кросс-биржа (один контракт на двух биржах, β = 1):** цена одного и того же актива на двух площадках не может расходиться надолго; платит тот, кто торгует на одной площадке и не смотрит на другую. Главное ограничение: ловится не минутой, а секундами — на свечах 1 мин мерим только долгоживущую часть базиса (замер распада по задержке, §6).
- **Фандинг:** (а) перп↔спот — получение выплаты ставки против фиксированной цены хеджа; (б) перп↔перп разных бирж — разница ставок. Платит тот, кто держит перекошенную сторону. Риск — ход базиса между входом и выходом.
- Если на данных видна только комиссия — вердикт «края нет»; поиск без механизма не расширяем.

## 3. Гипотеза и опровержение (до счёта)
- H1 (по каждому варианту §5): в торговых месяцах вне отбора чистый результат на сутки закрытия положителен, интервал блочного бутстрепа по суткам после Холма не накрывает 0.
- Опровергает: интервал накрывает 0 или знак расходится по годам (правило §10); либо результат держится на 1–2 сутках / 1 монете / 1 месяце.

## 6. Что измеряется, а не назначается (до торговых месяцев; только по прошлому)
Все пороги берутся на **окне формирования: 90 суток до торгового месяца** (месяц m торгуется с параметрами, измеренными на m−3…m−1; на торговом месяце ничего не подбирается).
1. **Отбор пар (A, B):** кандидаты — пары монет, обе во вселенной на день формирования. Критерий — без изобретённого числа: устойчивость связи, измеренная на формировании (коинтеграция Энгла–Гренджера на ln-ценах, тест на половине окна и на второй половине — оба прохода), порог p — по Холму на число кандидатов формирования. Отбранные пары торгуются все (без топ-N), так что N не назначается.
2. **Окно W:** из измеренного периода полураспада спреда (AR(1) на формировании): W ∈ {2, 4, 8} × медиана полураспада по отобранным парам (три значения как три клетки; множитель — часть сетки и в счётчике испытаний).
3. **`entry_z`:** безубыточная точка — z, при котором измеренный средний возврат (по формированию) ≥ круг издержек из §5 (для варианта) × m, m ∈ {1, 2, 3} (три клетки). `exit_z` ∈ {0, 0,5}; `stop_z` ∈ {выкл, 2×entry_z}; `max_hold` ∈ {2, 4}× полураспад.
4. **K корзины:** K ∈ {3, 10} (10 — размер замера ядра), состав — K лучших по корреляции на формировании.
5. **Кросс-биржа:** базис и z на ноге Y−X, β = 1; сетка та же; плюс кривая «чистый результат ↔ задержка второй ноги» (0, 1, 2, 5 мин) — измеренная форма распада, что и показывает, есть ли что-то помимо мгновенного ловца.
6. **Проскальзывание (слой L1):** слой L0 — только комиссия В-88 (как просил владелец); слой L1 — плюс **измеренная** половина спреда на ногу как функция медианы оборота (по бинлогам коллектора за период, где они есть; для остальных месяцев экстраполяция по оборотной корзине — оговорка в отчёте). **Вердикт — по L1**, L0 — верхняя граница.
7. **Фандинг:** выплата — нога-перп, державшаяся строго через метку выплаты (ядро); интервал — по меткам файла; D3 вход — трейлинг-среднее последних k выплат × ожидаемое удержание > круг издержек (k и удержание — из формирования).

## 8. Шум и различимость

## 9. Контроли (шум и отбор)
1. **Плацебо-пары:** случайные пары из той же вселенной с теми же правилами (случайный выбор вместо EG-отбора), число — равное отобранному; чистый результат плацебо — шкала «что даёт сам механизм сделки без связи». Различие отбранных и плацебо — главный контроль смещения отбора.
2. **Сдвиг партнёра:** нога X сдвигается на +1 сутки (сохраняет распределения, рушит связь); ожидание — минус комиссии.
3. **Случайные входы:** тот же вид, случайные минуты входа с распределением удержаний факта.
4. **Заглядывание:** сдвиг исполнения t+2 вместо t+1 — результат не должен рушиться на больше, чем говорит замер распада (кросс-биржа ожидаемо рушится — это измерение, не ошибка).
5. **Знак ядра:** тест `statarb` 10/10 и сверка с reference — уже в приёмке TK-479; на этапе счёта сверка на одной паре-месяце с reference (rtol 1e-9, сделки совпадают).

## 10. Правило вердикта (до счёта)
Метрика — **чистый bps номинала ноги по суткам закрытия** на слое L1 (портфель: равный номинал на пару, без плеча; доллары — только при номинале, названном владельцем, В-93). Рядом — KPI «дней до перехая» (В-120) по месяцам: самый долгий период с хвостом и p90 по времени (`kpi-newhigh.py` поверх дневной кривой).
- **Подтверждено** для варианта: (а) знак положителен в каждом из календарных годов 2022…2026 отдельно и в ≥ 2/3 месяцев; (б) интервал блочного бутстрепа по суткам (блок ⌈n^{1/3}⌉) на периоде 2022–2026 не накрывает 0 после Холма §7; (в) результат лучше плацебо-пар (§9.1) по суткам в паре, интервал разницы не накрывает 0; (г) без лучших 2 суток и без лучшей монеты знак и (б) остаются; (д) KPI — не хуже порога, названного владельцем, иначе помечается.
- **Опровергнуто:** (а) нарушено в ≥ 2 годах при интервале, накрывающем 0, и это не 1–2 суток/1 монета; либо плацебо ≥ факта.
- Иначе — «не ясно» + что добавить. Числа «2/3 месяцев», «блок ⌈n^{1/3}⌉», «топ-2 суток» — **предлагаются владельцу на утверждение** (назначаемое, §Вопросы).
- Этап 2 (сетка): только по вариантам «подтверждено» или «не ясно с положительным знаком» этапа 1; плато (соседние клетки того же знака) — условие, одиночный пик не засчитывается.
