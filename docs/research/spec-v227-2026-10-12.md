## 3. Почему прежняя причина снимается

- **«Старый движок TK-009» (Д-6, Г-88):** разбор касаний был инструментом, не ограничением данных: колонки R1 (TK-025: 42 + 21) дают те же признаки на кадре взвода текущего рантайма. Новый код нужен только там, где колонки нет (Г-88, Г-102, Г-108).
- **«Посчитана на авг/сен» (Д-24):** Г-38/145/138/142/143/103/20 — постфильтры P-07 на кругах Г-85 (Python, без хешей), в b14/Летописи клеток нет: возрождаются скрипты `p07-h9r-h14.py`/`p07-h9h10.py` на закрытиях B1 (М5, **выбор по В-170: готовый проверенный код против нового механизма «фильтр последовательности» в рантайме — для 7 осей Python дешевле, хеш-счёт им не нужен; решение Судьи**), нужен счёт; Г-27 — ось usd_min (М3). Г-09 — дубль Г-10.
- **«Код есть — клеток нет» (6):** флаги в бинарнике; нужны строки `--cells`.
- **«Вне пакета» (15):** причина P-10 §6.3 — «источник не задаёт операционализацию». Снимается не кодом, а **назначением протоколом** (окно, порог, доля) — решение владельца при утверждении П-15; значения здесь — предложения, измеримое не придумывается.
- **«Нет колонки»:** g82-60s и `btc24h` уже добавлены (TK-115, TK-189); Г-57, Г-72, Г-98 — действительно новые.
