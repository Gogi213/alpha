## Решение по порогам (В-53) — заморожены числами, не квантилями
- быстрая нога: длит. до пика ≤ **39 мин**; высокий оборот: ≥ **4,84** нормы;
- откат: ≥ **1,0** полный, **0,5–1,0** частичный, < 0,5 малый;
- пауза: нога θ **5 %** обратного знака внутри ноги; пила: **4** смежные ноги, каждая < **1,5 θ**; приоритет форм — как предложено.
- Утверждены как рабочие для итерации 1, с условием (ниже) показать чувствительность.

## Вернуть — одной сдачей
1. Доли форм в двух весах: по ногам и с равным весом инструментов (+ топ-5 инструментов по числу ног).
2. Чувствительность (лёгкий пересчёт по готовым csv): T_FAST p5/p10/p20; пауза θ 5 % против «пауз на 10 % хода» (лестница сейчас частью = длительность: мед. 1078 мин) — доли форм в каждом варианте; вывод о формах только устойчивый.
3. Доля агрессивных покупок по ногам (сделки с направлением, событийные) — по форме и фазе (до пика / после).
4. Слой 3: стаканы по выборке на форму, окно [−2 ч, конец], только событийные данные; закачки `--kind net`, счёт alsched.
5. Каталог `docs/findings/pump-dump-scenarios-catalog-<дата>.md` по заказу: определение, фазы, онлайн-признаки (без заглядывания вперёд; разметка по следующей ноге — только для отбора), частота, 2–3 примера на форму; OI/фандинг — «нужно, не скачано».
