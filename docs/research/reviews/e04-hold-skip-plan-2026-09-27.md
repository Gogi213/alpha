## Условия

1. **Условие пропуска — ровно** `Phase::Holding` ∧ `TradePlan::Bounce` ∧ нет открытых заявок ∧ нет сирот. Порог —
   min(early, если включён и не пройден; deadline). В комментарии к пропуску — перечень сравнений со временем выше
   (файл:строка). Тест, который ломается, если в `on_holding` / `decide_exit` появится новое сравнение с `now`
   (например, счётчик вызовов `now` в `Holding`). Без такого теста следующая правка молча сломает равенство.
2. **Гейт — все семейства выхода, не только 23 клетки П-07.** В нём нет `gone*` / `eat*` / `be` / `bex`, форм П-04
   (`gone50wall0` / `wallx0` / `wallk0`), тейка лимитом (`tk…`: пропуска нет — заявка открыта, это тоже проверить),
   раннего выхода и удержаний 3600 / 7200. Сетка гейта: эти формы × 2 суток (03.08, 21.08) + сутки с переносом
   через полночь (конец развёртки Р6). `poll` против `skip` — `rounds` / `forms` / `signals` побайтно.
3. **Э-04а — режим сверки.** Ключ мемо собирать из той же структуры входов, что читает `decide_exit` (не отдельный
   список полей). На сутках гейта — режим, где полный `decide_exit` считается всегда и сравнивается с мемо
   (`debug_assert` или флаг). Расхождений — ноль.
4. **Э-06 (`target-cpu=x86-64-v3`)** — отдельный бинарник с явным именем, только для деки (Zen 2 — AVX2 есть).
   На коллектор и другие машины без проверки CPU — не выкладывать. Э-06 и Э-07 — тот же гейт побайтно + `cargo test`.

Умолчание `poll` до гейта. После гейта клетки П-07, посчитанные `skip`, равны `poll` по построению — смешивать можно.
