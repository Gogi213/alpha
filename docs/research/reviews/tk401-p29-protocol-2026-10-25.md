# TK-401 · П-29 (событийный отклик Gate на своп DEX) — решение Судьи по Q-1…Q-3, 25.10 ~23:10

Протокол `docs/research/P-29-g016-dex-event-gate-response.md` (818e9826) в основе принят: событие = своп, без сетки и ffill,
ячейки X/W и 39 горизонтов — прежние (заморожены), край — не здесь. До пробы внести правки R1–R7 в протокол (тем же коммитом,
что запуск пробы); вопросов владельцу нет (метод — Судья, В-53).

| № | вопрос / пробел | решение |
|---|---|---|
| R1 (Q-1) | A для книги фьюча | Книга без изменения лучшего уровня — **текущая**, а не устаревшая; предел по возрасту последнего изменения BBO отбирает волатильные моменты (смещение). A для gev2 = **живость потока монеты**: последнее любое событие книги монеты (любой уровень) ≤ A и момент вне дыр gev2. Главное A = 5 с; 1, 30, ∞ — чувствительность. Метки gev2 квантованы 0,1 с (TK-402, reviews/tk402-gate-out-decision) — разрешение h = 1 с указать. |
| R2 (Q-2) | правило «нет свопа в [t−2W; t−W] → нет события» | Принимается (ход за W иначе не определён). Писать по монете долю свопов-кандидатов, отброшенных правилом. **Контроль — не случайные моменты часов**, а случайные свопы той же монеты-суток без события, с тем же действующим правилом окна, \|ход\| < X, s = знак их собственного хода за W (нулевой — вне), n = числу событий, сид фиксирован. Причина: события обусловлены активностью DEX, а она связана с волатильностью Gate — контроль по часам завышает excess. |
| R3 (Q-3) | спот Gate — только сделки | Спот = последняя сделка ≤ t, возраст ≤ A на **обоих** концах (t_i и t_i+h) — здесь возраст = настоящая устарелость; ряд вспомогательный, отскок bid/ask сделок — оговорка в отчёте. Главный ряд — середина книги фьюча. Доля событий, отброшенных по A, — по монете и рынку. |
| R4 | нет одной главной метрики и правила с числами; «Холм по монеты × X × W × h × A» — неверно | Главная метрика: **excess = отклик события − отклик контроля на h = 60 с, фьюч-книга, A = 5 с**; тест — кластерный по монетам t среднего excess (df = монет − 1), без пола p. Семейство Холма = X(4) × W(3) × знак(2) × h(≤ 900 с) × рынок(2) при главном A; монеты в семейство не входят (они — кластеры), A ≠ 5 с — вне семейства (чувствительность). Размер семейства назвать числом до счёта. α = 0,05. Доля догона по excess = Σn·excess / Σn·\|ход DEX\|, CI — бутстрап по монетам 1000; «догоняет» = нижняя граница CI доли > 0,5. Сутки — по отдельности (все 8, с индексами; в TK-392 не выведены 0–2). |
| R5 | время события DEX — секунда блока (Solana blockTime — оценка) | Обязательная колонка **пред-ход Gate** s·ln(G(t_i)/G(t_i−W)) с тем же правилом A: показывает, кто ведёт (вопрос G-016), и не даёт приписать DEX ход Gate, случившийся внутри секунды блока. Для Solana — оговорка о точности blockTime. |
| R6 | перекрытие событий | Кроме правила «не раньше t_i + W» — эфф. N по монето-суткам рядом с n. |
| R7 | приёмка пробы | 1 монета EVM с часами gev2 вне дыр, ≥ 100 событий при X = 0,5 %, W = 60 с. Сдать: n событий / контроля; отброшено по окну R2, по A (R1), по дырам gev2; кривая против TK-392 (величина отличия); **3 события руками**: tx свопа (блок, время, цена), строки gev2 до/после t_i и t_i+60 с, совпадение с выводом скрипта. Только после принятия пробы — весь пул (EVM 67+ и Sol swaps3). |

Итог: **вернуть Исследователю** — внести R1–R7 в П-29, затем проба 1 монеты (R7), сдать Судье.
