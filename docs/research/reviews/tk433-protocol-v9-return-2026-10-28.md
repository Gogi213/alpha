## Что переписать (v9b)

1. **Отбор = цена.** Тренд = нога зигзага по close 1 м, `t_peak − t_start ≥ 90 мин`, E1–E4, склейки. (2)/(3) из
   отбора убрать. Это и есть список для TK-426.
2. **Измерения — признаки, все столбцы csv, список закрыт до счёта:** волатильность (MAD 1 м логдоходностей
   *за вычетом среднего хода ноги* — иначе тавтология с отбором по ходу, прецедент TK-426) внутри ноги и в окне 60 мин
   до старта; оборот (как m протокола) внутри и до; доля рыночных покупок/дельта (Bybit, /data/tk417); спот↔фьючерс
   (разность хода, корреляция 1 м доходностей); OI, фандинг, ликвидации (Gate, TK-415); ход BTC на тех же минутах.
   Покрытие по рынкам — N в каждой строке, без покрытия — пусто, не ноль.
3. **Контроль (главный):** у каждого тренда — окна той же монеты, той же длительности, тот же час UTC, ±7 суток, не
   пересекающие ноги ≥ 90 мин (любого θ), до 5 штук, seed=433. Отбор контроля — только по цене (нет тренда), без
   признаков.
4. **Главная метрика и правило вердикта (по каждому признаку × знак):** r = log(признак тренда / медиана признака
   его контролей). Нуль — то же r для контроль-против-контролей. Интервал 95 % — бутстреп по монетам (кластер-события),
   поправка Холма на всё семейство (признаки × 2 знака). **Подтверждено** — нижняя граница медианы r > 0; **оспорено** —
   верхняя граница ≤ 0; иначе **не различимо**. Доля трендов «с повышенным» признаком = доля r выше 95-го перцентиля
   нулевого r, с интервалом. «Что ещё повышено» — те же правило и семейство, не отдельный поиск.
5. **«С накачкой / без» (кластер):** на log m и log v-до — K1 излом (`tk421-art.py: knee`) и dip-тест Хартигана
   (p бутстрепом, Холм). Излома нет и dip p ≥ 0,05 — «континуум, не разделяются»; это ответ, порог не назначать.
6. **PNG 24** — случайные тренды по новому отбору, на картинке значения r признаков; владелец смотрит сам. Правило
   «> половины не памп → отклонить» снять: определение больше не фильтр, сравнивает владелец.

## Ответы Q1–Q5

- **Q1 θ:** главный — a\*₆₀; a\*₂₄₀ — чувствительность одной строкой воронки и таблицы r, вердикт только по главному.
- **Q2 E4 фитиль:** не новый излом, а правило без нового числа: нога снимается, если её ход без самого сильного
  10-минутного блока < θ (10 мин — верх фитилей 3–10 мин из просмотра 24 PNG TK-421, наблюдение, не подбор). Доля
  хода в лучшем 10-мин блоке — столбец.
- **Q3 норма:** 7 суток — назначено протоколом, принять; < 3 суток истории — отдельная строка воронки. Под главным
  правилом норма нужна только для m/v как признаков; главное сравнение — с контролями п.3.
- **Q4 склейка 90 мин:** не число владельца (оно про длительность). Пара = соседние ноги зигзага вверх→вниз, обе
  ≥ 90 мин (дамп по построению стартует в пике). Без зазора, без числа.
- **Q5:** при перестановке пороги v\*/m\* для отбора не нужны; «нет излома» = ответ «не разделяются» (п.5).
