## Вердикт и статистика

- Данные решения — август и сентябрь, каждый месяц отдельно; «август + сентябрь» — только доп. колонка (В-115) → навык `alpha-research`.

- R2, выбранный после счёта, — пометка «находка поиска на тех же месяцах, не проверка вне выборки» → `P-02-2026-09-27-summary-final.md`.
- Вердикт («подтверждено/опровергнуто») — только по протоколу с правилом до счёта; без протокола — «описание, не вердикт» → `hypotheses-table-2026-09-27.md`.
- «Опровергнуто» — только при значимом вреде; «не улучшение после поправки» ≠ «опровергнуто» → `hypotheses-table-2026-09-27.md`.
- Клетка вне отбора, показанная на проверочном месяце по слову владельца, — только описание: вне Холма, без вердикта, в «подтверждено» не переводится → `P-08-2026-09-28-augsep.md`.
- Неопределимая форма — «не определена», p = 1 в Холме, m не уменьшать → `P-02-2026-09-26-g88-undefined.md`.
- «Значимо» — только после Холма по пакету; вложенные клетки (n2 ⊃ n3 ⊃ n4) — одна находка, не несколько → `P-07-2026-09-27-h9r-h14.md`.
- Порог и правило — с достижимостью на 31/23 сутках **до счёта** (иначе возврат) → `rules-audit-2026-09-27.md`.
- Сравнение вариантов — парная Δ по суткам сигнала с интервалом, не разность точек → навык; `P-07-2026-09-27-h9r-h14.md`.
- K = 10 суток для цветного вердикта; меньше — «описание, суток n < 10» → `v128-decisions-2026-09-27.md`.
- R² кривой счёта — не критерий; справочно + процентиль перестановок суток → `v128-decisions-2026-09-27.md`.
- DSR `bounce-verdict` по сделкам с V = 1 непроходим; DSR — по суткам, отчёт, не ворота (T-26) → `rules-audit-2026-09-27.md`, `t26-dsr-plan-2026-09-27.md`.

## KPI «до перехая» (В-120)

- «p90 ≤ 5 сут» ⇔ доля часов t с ожиданием перехая > 5 сут ≤ 0,10 (t ≤ 19.09); вердикт — точкой + устойчивостью, бутстреп справочно → `kpi-days-to-new-high-2026-09-27.md`, `kpi-newhigh-definition-2026-09-27.md`.
- Месяц FAIL — точка и **минимум** по исключениям (сутки, монета) > 0,10; OK — точка и **максимум** ≤ 0,10; иначе «на границе»; вариант проходит только при OK в обоих → `kpi-verdict-b0f8097-2026-09-27.md`.
- Состояние, меняющееся от долей доллара (фандинг −$0,21), — «на границе», мера с фандингом → `fees-audit-2026-09-27.md` (приёмка b70216f).
- «Не хуже базы» — нижняя граница Δ по суткам ≥ −$X в каждом месяце, X до счёта (В-116) → навык.
