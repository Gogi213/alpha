# Судья: П-07 — правило продолжения после ступени 2 (решение по методике, В-128/устав 125d2d9; до чисел ступени 2)

Записано до итогов ступени 2 (H6/H7/H2, 20 клеток; идёт с ~15:05 27.09). Время фиксации — время коммита этого
файла.

## Правило

После ступеней 1–2 (базы Г-85а/Г-85б, H9/H10 через busy-replay, H6/H7/H2) — по каждому варианту отдельно:

**А. Есть «проходит» — стоп титрованию, сразу в архив.** Если база или клетка «проходит» по §10 П-07 (доля часов с
ожиданием перехая > 5 суток ≤ 0,10 в обоих месяцах, держится без любых одних суток и монеты) — титрование не
продолжать. До 3 таких клеток (по доле августа, ничья — сентябрь) идут в архивную проверку (ниже).

**Б. Есть заметный сдвиг — продолжать только по сдвинувшим осям.** Клетка c «сдвигает», если все три условия:
1. доля > 5 суток: август ≤ база − 0,10, сентябрь ≤ база — по точке;
2. то же держится при исключении любых одних суток: худший случай по исключениям, в каждом месяце;
3. деньги без значимого вреда: верхняя граница Δ$ к базе ≥ 0 в обоих месяцах.

Тогда ступени 3–4 идут только по осям, где есть такая клетка, плюс 2D этих осей (§3). Остальные оси H3–H5, H8, H1 и
ось П-04 — не считать. Потолок — +30 клеток на вариант.

**В. Иначе — стоп.** Ступени 3–4 не считаются, дека уходит на архив (T-30).

## Архивная проверка (январь — июль 2026) — список замораживается сейчас

Проверяются: база Г-85а, база Г-85б, главный (H0). По случаю А — ещё отобранные «проходит»-клетки (до 3). По
случаю В — ещё лучшая клетка ступени 2 каждого варианта по доле августа: справочно, не кандидат.

Правило чтения архива — отдельный короткий протокол до счёта (шаблон навыка). Метрика — та же доля часов > 5 суток
по каждому месяцу и $ по месяцам; достижимость — по числу месяцев (7). Родословная (В-124): архив в неё не входит —
это проверка вне выборки, а не перебор.

## Почему

- Август и сентябрь подтвердить ничего не могут: всё, что на них найдено, — поиск (аудит 25.09, В-115). Каждая
  клетка сверх нужного растит родословную: требуемый Шарп DSR растёт примерно как √(2 ln N). Лишние 50–70 часов деки
  на тех же месяцах ухудшают будущий вердикт, а не улучшают.
- Цель в августе далеко: у `single@fr` доля 0,42 при пороге 0,10. Если ни одна ось не сдвигает её хотя бы на 0,10,
  одиночные оси ступеней 3–4 до цели не дотянут.
- Архив январь — июль — первая настоящая проверка вне выборки: 7 месяцев вместо 2 сожжённых.
