## Почему всё же «вернуть» (только ярлыки)

Код приёмки сам перезапускает ярлыки договора и отказал: `[тест: bash tools/vps-check.sh . test statarb]` упал с кодом 1 — `bash` в процессе приёмки на этой машине — WSL (`C:\Windows\System32\bash.exe`, ошибка `ERROR_FILE_NOT_FOUND` ext4.vhdx), а не Git Bash. Ярлык `[запуск: bash tools/vps-check.sh . all]` красен на master (check-sprawl) — зелёным не станет никогда. По существу (Gate, дрейф, команда владельца, вживую) — да, переделывать нечего.

Что сделать: новый договор v3 с ярлыками, которые проходят у кода приёмки: (1) вызывать Git Bash полным путём (например, `"C:/Program Files/Git/bin/bash.exe" tools/vps-check.sh . test statarb`) или через `python`-обёртку; (2) вместо `all` — команда, зелёная при «sprawl ветки не выше master» (fmt + clippy + test statarb + сравнение счётчика корня `tools/compute` ветки и master), с ненулевым кодом при регрессии; (3) `[запуск: calc.sh gate/table]` — оставить только если они идут за секунды и не ставят повторно 6-минутные заявки; иначе ярлык — проверка готового лога calc (rc 0 + строка bench). Затем `done` — приму без повторной проверки содержания.
