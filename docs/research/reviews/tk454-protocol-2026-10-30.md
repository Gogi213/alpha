## Ответы на развилки

- **Q-1 — разрешено.** Снимки `tradingview.com/x/<id>` — допустимый источник при валидации: на всех сделках, где есть и
  файл в выгрузке, и ссылка, сравнить **напечатанные числа** (цены на шкале, инструмент/ТФ/биржа, время публикации) на
  загруженном снимке и на файле. Побайтное совпадение не требуется (пересжатие). Хоть одно расхождение напечатанного
  числа — источник не валиден, проверка только по файлам выгрузки. Загруженное — в `data/` (gitignored) с sha256 в
  таблице сделок; ссылка не открылась — «не извлечено: снимок недоступен».
- **Q-2 — разрешено.** Фандинг — data.binance.vision `futures/um/monthly/fundingRate` (сверка `.CHECKSUM`) +
  выборочная сверка с REST `/fapi/v1/fundingRate` на нескольких записях (совпадение — в отчёте). Комиссии — официальная
  страница тарифов Binance / объявления об изменении с датой; уровень VIP автора неизвестен → **не выбирать одну ставку**:
  чистое R интервалом [maker, taker] базового уровня на дату сделки; источник и дата доступа — в отчёте. Тариф на дату
  не найден — строка без чистого R (как в §2.7).
- **Q-3 — допустимо только так:** риск на сделку берётся, если он **напечатан в той же цепочке или в посте о периоде**,
  дословной цитатой; нет — «нельзя проверить: риск не назван». Подставлять «типичный» риск автора из других постов
  нельзя.

## Обязательные правки протокола (до извлечения)

1. §2.5: начало поиска «стоп или цель» — назвать явно: для «плана» — минута касания входа (§2.4); для «отчёта/итога» —
   минута первого накрытия entry в окне §2.4; не найдено — «нельзя проверить: нет минуты входа».
2. §2.4: горизонт для цепочки из одного поста (конец цепочки = t_post) — такая сделка без заявленного исхода → только
   «вход достижим/нет» с горизонтом 0 не мерить; пометить «не названо» (§2.6), в сводке отдельной строкой.
3. §2.1: монеты с множителем у Binance (`1000PEPE…`, `1000SHIB…`) — уровень с графика без множителя пересчитывать
   только по напечатанному на картинке инструменту; не совпал масштаб — «база ≠», без домысла.
4. §2.2: «база ≠» в сводку §4 не смешивать с базой Binance-перп — отдельная строка.
