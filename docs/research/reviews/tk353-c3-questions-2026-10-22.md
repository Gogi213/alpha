# TK-353 — ответы Судьи на 4 вопроса Инженера по C3 (22.10)

Основание: методика `docs/research/methodology-wall-edge-2026-10-21.md` (R4.1, R2.10, R5.8), назначаемые —
`docs/research/G013-scope.json` (поле `assigned.C3`, зафиксировано Судьёй в TK-352). Решения по В-53, без владельца.

| вопрос | решение | на чём |
|---|---|---|
| 1. `quiet_s` | Принято предложение Инженера с уточнением: финальный заход — последний непрерывный отрезок, где mid ближе `2·arm_dist` к уровню, заканчивающийся во взводе; `quiet_s` = момент взвода − конец предыдущего отрезка в полосе внутри окна от рождения до взвода. Нет предыдущего — `quiet_s` = возраст `a_w`, флаг `quiet_censored`=1 в выходе. Одно определение для стены и кандидата. | R4.1 п.3 буквально тривиален во взводе (mid в полосе по построению); смысл — «цена давно не подходила» (R3.5, фильтр возраста spot) |
| 2. режим `regime_btc4h` | Режим сравнивается в момент взвода: режим (минутная сетка `--regime-from`) в `τ'+a_w` = режим стены в `t`. Не на сутки, не в момент рождения. | R4.1 п.1 якорит время суток в `τ'+a_w` ↔ `t`; исход читается после взвода; при возрасте spot от 45 мин режим в рождении и во взводе может различаться |
| 3. caliper / k / seed / окно | Уже назначены: `G013-scope.json` → `assigned.C3` (`caliper_SMD`, `k_primary`, `k_sensitivity`, `seed`, `seed_spread_print`, `time_of_day_window_h`, `replacement`). Брать оттуда, в коде — аргументы без умолчаний. | TK-352, прецедент П-24 §C3 |
| 4. подмешанный край | Допустим пост-хок, без Rust: на барьерном исходе реальных стен (P(+a раньше −b), барьеры `barriers_primary`) seed-детерминированно переводится доля исходов −b → +a; дозы назначает Судья в протоколе G1, не код. В отчёте G1 прямо: проверяет только статистический слой и мощность, не детектор и не очередь. | R2.10 строка 8.2, R5.8 «G1 (+)» |

Правка ядра Инженера (ковариаты пути считаются после поиска взвода, caliper после NoArm) — верна: функционал пути R4.1 п.3
определён на окне до `t'`, а `t'` известен только после п.4.

Порог доли стен без контроля, выше которого A_B «не определён» (R4.1 п.7), коду не нужен — печатается доля, порог назначается
до G1 отдельно.

Итог: вопросы закрыты → return Инженеру: ядро + CLI `lob c3-controls`, тесты vps-check, гейт md5 старых выходов, малый срез.
