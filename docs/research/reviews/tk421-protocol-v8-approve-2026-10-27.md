## Решения

1. **Лидер — по своей норме, не по порогу альтов:** условие (а) = `z_T(лидер) ≥ z*_T` — V1-мера (ход в σ самого BTC/ETH,
   MAD×1,4826 за месяц) с тем же K1-порогом z\*_T рынка×знака×T, что уже посчитан для V1. Нового числа нет: «всё летит за
   BTC/ETH» = необычный для самого лидера ход. В отчёт — сколько минут лидер ≥ z\* по BTC и по ETH отдельно.
2. **Сопоставление по T:** событие снимается рыночным периодом **своего** `T_min` (и своего знака, своей биржи-рынка);
   периоды других T его не снимают. В отчёт одной строкой — сколько сняли бы периоды любого T.
3. **Испытаний K1:** v6 20 + доля v8 40 (5 T × 2 знака × 4 рынка) = **60**; z\*_T лидера — уже посчитанные пороги V1, не
   новые. Излом доли — по распределению доли в минуты, где выполнено (а) (как в п.2); бутстреп K1 излома не находит (в т.ч. из-за
   малого числа минут) — «излома нет» (правило v5: без излома = 0), строкой в отчёт с числом минут.
4. Остальное v8 (склейка разрывов < T, пересечение [t_start, t_peak] по минутам, таблица периодов, сравнение с L4 v6) — как
   записано.

**Решение:** v8 утверждён с решениями 1–4. Считать L4 v8 после rc v7 тем же проходом (alsched, 15 ядер), затем отчёт,
