## 1. Ряд и Шарп

- `r_c,d` — $ клетки `c` за сутки UTC `d` = сумма `$_норм` сделок (§6 п. 2, тот же `m` по сделке), **закрытых** в сутки `d`
  (closes portfolio-sim, cap0); сутки без закрытий = 0. Сутки — все календарные сутки определённых (§8) месяцев счёта
  фев–сен; у B1 — те же сутки (пары).
- `SR_c = mean(r_c) / sd(r_c)` (ddof = 1) по суткам пула; в отчёт рядом годовой `SR × √365` — только печать.
- `SR_c,мес` — то же внутри месяца; `sd = 0` → месяц «Шарп ≤ 0».
- `k_c` = число определённых месяцев с `SR_c,мес > 0`.
- `K_c` — доля часов ожидания нового максимума > 5 сут (§6, внутри месяца, максимум с 0 в начале месяца) на кривой
  `$_норм`, пул = Σ часов KPI / Σ часов по определённым месяцам.

## 2. Ворота «в отбор» (все пункты; заменяют §9 п. 1–4)

1. **Шарп выше B1 после перебора.** `ΔSR_c = SR_c − SR_B1`. Парный блочный бутстреп суток (блок ⌈n^{1/3}⌉, 20 000
   повторов, блоки **общие для всех клеток семьи и для B1**; c и B1 берут одни и те же сутки повтора) → `ΔSR*_c`,
   `se_c = sd(ΔSR*_c)`, `T_c = ΔSR_c / se_c`, `T*_c = (ΔSR*_c − ΔSR_c) / se_c`. Step-down max-T WY внутри семьи,
   p семьи = минимум, **Холм по m = 42** (§12 07.10, Q-13; не 39), сравнение p ≤ α_k/2. Ровно машинерия §7 с заменой
   Δ̄$ на ΔSR (Ledoit–Wolf 2008 — бутстреп разности Шарпов). Достижимость: min p ≈ 5·10⁻⁵ < 0,025/42 ≈ 6,0·10⁻⁴.
2. **С3 по месяцам на Шарпе:** в каждом определённом месяце верхняя граница 95 % `ΔSR_мес` (бутстреп внутри месяца,
   блок ⌈n^{1/3}⌉) ≥ 0 — нет значимого ухудшения Шарпа ни в одном месяце. Месяцы с `ΔSR_мес < 0` — списком.
3. **С2:** `ΔSR` ≥ 0 (точечно и нижняя граница 95 % без Холма) без двух суток с наибольшей парной разностью
   `r_c,d − r_B1,d` и, отдельно, без монеты с наибольшим вкладом в `Σ_d (r_c,d − r_B1,d)` (ряды c и B1 без неё).
4. §8 — определена в ≥ 6 из 8 месяцев; §6 п. 1 «на объёме» — ворота 1–3 держатся и на B2 (без изменений).

Сняты как условия (печатаются по месяцам): Δ$ к B1 с Холмом (старый п. 1), $ ≥ 0 в месяце (п. 3), КПИ-2 (п. 2).
**«Опровергнуто»** — зеркально п. 1 (min T, Холм) и не одни двое суток / одна монета (С2 зеркально).

## 3. Порядок (ранжирование = отбор)

Только среди прошедших ворота §2. «Лучшая из пакета» называется (В-208).
1. **Ярусы по Шарпу (без выдуманного «почти равны»):** ярус 1 — лидер по `SR` и все, чей `SR` **не значимо ниже**
   лидера (парный бутстреп `SR_лидер − SR_i` на тех же 20 000 повторах, Холм по сравнениям шага, α = 0,05
   одностор.); убрать ярус, повторить на остатке.
2. Внутри яруса — по `k_c` (больше выше), затем по `K_c` (меньше выше), затем по `SR_c`.

Ключ строки: `(ярус, −k_c, K_c, −SR_c)`. Так п. (2)–(3) владельца решают там, где Шарпы шумом неразличимы, а не только
при точном равенстве (лексикографический порядок по точечному SR сделал бы их мёртвыми).
