# TK-335: что дальше с фильтром П-23 (σ240 < 94,2 bps) — решение Судьи, 21.10

Основа: вердикт П-23 (TK-331, `docs/findings/p23-sigma-filter-2026-10-20.md`, проверка `tk331-p23-2026-10-20.md`):
по правилу §4 «держится», край тонкий — 6/9 мес. ровно, июнь −0,5 $, весь минус Q1 держат март (−83) и июль (−94).
Половина B независима по монетам, **не по времени** (те же янв–сен 2026).

## Решение

1. **Статус фильтра — «кандидат, вне подбора по монетам прошёл, вне времени не проверен».** В бота — не сейчас (бот не
   торгует); включение — только решением владельца после п. 3.
2. **Надстройка в идущих счётах — да, но как переносимость, не подтверждение.** Порог 94,2 фиксирован, не подбирается.
   На готовых rounds принятых счётов фьюча (TK-289 решётка, П-17 F2 TK-314/315, П-22 TK-332 — по мере приёмки каждого)
   — одна описательная строка: Σ$ с фильтром / без по месяцам, n отсечённых; σ240 — join по t0 из готовых `sigma240`
   (`tk327-features.py`, `TK327_NOTAPE=1`), без нового прохода рынка (В-213). Вердикты тех счётов фильтр не меняет.
   Почему не подтверждение: те же месяцы, сигналы коррелированы с B1, перебор конфигураций — зелёное там ничего не
   добавляет к П-23; красное (фильтр ухудшает Σ$ в ≥ 6/9 мес. у конфигурации) — пометка «фильтр специфичен для B1».
   Спот (П-21) — источник находки (LF-1), не проверка.
3. **Подтверждение — только вне времени:** месяцы после 2026-09 (окт+), все монеты пула (обе половины — новая выборка
   по времени), конфигурация B1 П-23 без изменений. Правило (записано до данных):
   - копить месяцы, пока n сделок с σ240 < 94,2 ≥ 100 (на B было ≈ 29/мес на половину → ≈ 2 мес. на весь пул);
   - «подтверждено», если одновременно: Σ$ Q1 < 0 в агрегате; разность (с фильтром − без) > 0, нижний край 90 %
     bootstrap по суткам > 0; ни в одном месяце с n(Q1) ≥ 30 разность не < 0 больше чем на 1 SE месяца;
   - иначе — «не подтверждено ≠ опровергнуто», фильтр остаётся описательной строкой.
   Данные: коллектор остановлен → октябрь из архива Bybit (`lob import-archive`) после закрытия месяца; прогон B1 на
   новом месяце — обычный счёт по слову владельца (G-012), отдельным тикетом, когда архив за октябрь доступен.
