| пункт заказа | итог | проверка |
|---|---|---|
| три пути закоммичены одним коммитом | держится | `git show --name-only <коммит архива>` — файлов вне трёх путей нет (`grep -v` по трём префиксам пуст) |
| тег archive/pump-g017-…-untracked на этом коммите | держится | `git rev-parse <тег>^{commit}` = коммит архива; `git ls-tree -r <тег>` содержит `tk440-exam.py` и отчёт `pump-onset-binance` |
| удалены отдельным коммитом | держится | коммит удаления снимает ровно те же файлы; `git diff --stat <архив>^ <удаление>` по трём путям пуст (в диапазоне только чужой коммит Судьи по TK-505) |
| в рабочем дереве нет | держится | `ls` трёх путей — «No such file»; `git status --porcelain` по именам — пусто |
| `git grep` по именам в коде — ноль | держится | `git grep -e tk440-exam -e pump-onset-binance -- tools src` — пусто; прочие упоминания — CLAUDE.md, JOURNAL, тикеты, вердикты (история) |
| CLAUDE.md не правлен, ссылка отмечена в отчёте | держится | §7 «Для CEO»: строки «СОСТОЯНИЕ» ведут на пути, живущие теперь только в теге |
