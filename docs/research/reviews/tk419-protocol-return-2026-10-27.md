## Что поправить (текстом протокола, счёта не нужно)
1. Число испытаний одной таблицей: A = 16 (+4 R5 контроль), B = 16, C = 48, вар. 6 = 12; итог и делитель Бонферрони для каждой популяции числом.
2. Spot C: либо правило вердикта (как A/B, своя популяция и делитель), либо явно «описательно, вне вердикта» и убрать из числа испытаний.
3. Вар. 6: правило с числами — разрыв T−P (доля принятых) с 95 % интервалом (кластер инструменто-сутки); «подтверждён» = интервал целиком > 10 п.п.; «T≈P» = интервал содержит 0 и лежит в ±10 п.п.; иначе «не различимо». Расшифровать «2 разворота».
4. Разность «принятые − непринятые»: инструмент входит, если ≥ 5 событий в каждой группе; прореживание — внутри группы, по инструменту.
