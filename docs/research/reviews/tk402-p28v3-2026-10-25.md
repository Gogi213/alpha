## Открытые вопросы — решения

**(а) Допуск п.4 (60 с).** 60 с — назначенное число, не принимается. Тишина при живом потоке = книга не менялась,
котировка исполнима; режется только доказанный разрыв. Определение разрыва (измеряемое):
- Bybit: разрывы самого бинлога (переподключения/gap-метки) + сутки без `verify=ok` (п.5);
- Gate: час без файла или вырожденный (1 строка) — целиком; внутри часа — интервал, в котором сделка Gate прошла вне
  [bid; ask] текущего BBO (книга доказуемо устарела), — от последнего события BBO до следующего.
Исполнение в разрыве запрещено, доля отрезанного времени — в охвате. Вариант «60 с» — справочно, одной строкой.

**(б) Отбор моментов по порогу входа.** Допустим только как точное сокращение: момент-кандидат = событие, где для
хотя бы одной клетки выполнено условие входа (минимальный порог = 1× круг со скидкой; для B — по всем 10 опорам).
Выходы — только по полной ленте событий (возврат к опоре ищется по всем событиям, не по кандидатам). Гейт: на пробе
1 монета × 1 сутки полная лента и отбор дают **байт в байт** одинаковый список сделок по всем клеткам.

**(в) Глубина Gate.** Обязательна (A8): иначе размер ограничен только Bybit-ногой — допущение в пользу края, положительный
вердикт на нём невозможен. Пересборка Gate с `bq/aq` — одним проходом вместе с разбором причины по BTC (выше).

## Правки до счёта

1. **Холм не исполним как записан.** N_total ≈ 440 × 4224 ≈ 1,9 млн; B ≥ 20·N/α ≈ 7×10⁸ повторов на клетку, первый порог
   Холма 0,05/1,9 млн ≈ 2,7×10⁻⁸. Заменить на пошаговый max-T (Westfall–Young) с **общими** выборками часовых блоков
   для всех клеток всех монет (173 общих часа), B = 10 000; контроль FWER тот же, зависимость клеток учтена.
2. **Дни.** Правило «net > 0 в ≥ 5 из 7 дней» — по полным суткам 15–21.10; 22.10 (5 ч) — в общей выборке, не день.
   Убрать «по каждому дню 15–22.10».
3. **Один набор вердикта.** «И все, и только покрытие ≥ 95 %» — два набора удваивают перебор. Вердикт — по допущенным
   (п.6, покрытие ≥ 95 %); «все» — справочно.
4. **N по монете.** FS есть только у 184 монет со спотом Bybit — N_total считать по факту (FF у всех, FS у 184), не 4224 × монеты.
5. **Охват/DONE (B14).** `gate.done` записан при неполном охвате (AXIS, DNA, часы с 1 строкой) — переписать: done только
   с файлом причин по каждой недостающей монете-часу; `tk402-coverage-2026-10-25.csv` — с этими причинами.
6. **Шаг 0** включает проверку частоты событий Gate против сделок по всем монетам (как выше для BTC); монеты, где
   ≥ 95 % сделок не в [bid; ask], — исключены с причиной, если таких > трети — сначала причина (как §8.0 v2).
