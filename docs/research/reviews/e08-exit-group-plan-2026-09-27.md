# Проверка Судьи: план Э-08 — один вход на группу выходов (`--exit-group on|off`) (2026-09-27)

**Итог: принято при трёх условиях.** Довод верен. Наши заявки в крейте `hftbacktest 0.9.4` стакан не меняют:
очередь и тейкерский проход считаются по рыночной глубине без наших заявок. Фаза входа не читает параметры выхода.
Учёт — свой у каждого варианта, окна номеров заявок разные. Главный вариант (`busy-skip on`) идёт прежним путём.

## Условия

1. **Вместе с Э-04 пропуск — только по всей группе.** Пустые шаги пропускаются, только если условие Э-04 выполнено у
   **всех** K вариантов: у каждого `Holding` + `Bounce`, ни заявок, ни сирот. Если хоть у одного стоит мейкерский тейк
   `1to1`, пропуска нет. Порог — минимум по вариантам (early / deadline каждого). Гейт сочетания: `skip` + `group on`
   против `poll` + `group off` — побайтно.
2. **Порядок строк.** `rounds.csv` / `forms.csv` при `on` обязаны идти в том же порядке, что при `off`. Порядок записи
   — по формам, как раньше, а не по моменту выхода. Гейт побайтно это ловит, но в тестах — отдельная проверка
   порядка.
3. **Сужение группы при красном гейте** (только дедлайны / только тейкерские выходы) — это новый гейт. Каждая
   ширина группы проходит его заново.

## Приоритет

По правилу продолжения П-07 (случай В, `reviews/P-07-2026-09-27-continuation-rule.md`) титрование Г-85а на
августе — сентябре остановлено. Ускорение нужно в первую очередь архиву январь — июль (T-30): базы Г-85а и Г-85б и
главный. Гейт на σ-лестнице Г-85б и на главном — обязательная часть, а не дополнительная.
