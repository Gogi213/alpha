# Сверка Судьи: протокол схождений, последняя редакция — ПРИНЯТЬ

Предмет — протокол схождений в ветке исследователя (последний коммит редакции указан в логе тикета). Полная таблица сверки со ссылками — соседний файл приёмки этой редакции.

- Последний пункт прошлого возврата (вход контроля со случайным входом вырожден) закрыт: заявка входа живёт только своё время жизни и не снимается по половине порога.
- Пустое условие нулевого расхождения убрано.
- Прочие пункты прошлых возвратов держатся, редакция их строк не трогает.
- Слово владельца соблюдено: только описание без валидации стратегии, без недельных окон; только период владельца; без стопов; вход мейкером.
- Числа назначены до счёта, подбор по результату запрещён.

Торговых чисел владельцу нет. Хвостов нет.
