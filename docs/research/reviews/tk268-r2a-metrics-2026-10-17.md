# TK-268 — развилка R2A: метрики без сверки с каноном или прочерк (Судья, 17.10)

Вопрос (Инженер, 17:31, ш.7): у 24 хешей R2A (Г-87 4, Г-92 9, Г-93 9, Г-95 2, Г-129 1) closes есть в /data/p12r2a,
но канон R2A без $, а число сделок канона ≈2,6× числа сделок closes.

## Решение

1. **Без сверки метрики в Летопись не ставить.** Расхождение n в 2,6 раза — значит closes описывают другую совокупность
   сделок, чем строка канона; метрика из них под строкой канона — изобретённое число (CLAUDE.md, «Правила»).
2. **Сверка, когда $ в каноне нет, — по числу сделок:** хеш-месяц принимается, только если n(closes) == n(канон) точно
   (как у прочих строк: тот же check, но по n). Совпало — метрики ставятся.
3. **Не совпало — прочерк с причиной**, видимой в панели/записи: «R2A: канон без $, n канона ≠ n closes (×2,6)». Это
   засчитывается в критерий «метрики 100 % или с причиной» (по аналогии с «нет кодировки — с причиной», CEO 17:13).
   Пересчёт R2A заново, чтобы подогнать closes, в этот тикет не входит.
4. Отбракованные 9 (апрель ADA 22.04, 0,10–0,20 $; хеш 4173fe49b15b) и строки без closes (Г-106, Г-114, Г-13, Г-112,
   Г-133, Г-65) — тот же порядок: прочерк с названной причиной; 18 «нет кодировки» — ссылкой на TK-272.

Дальше Инженеру: применить п.2–4, в сдаче — таблица «строк с метриками / с прочерком и причиной / итого 1555» по живому API.
