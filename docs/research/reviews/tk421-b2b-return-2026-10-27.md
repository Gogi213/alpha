## Решение по развилке 30.09
Ни (а), ни (б) в предложенном виде: это не «рынок без BTC», а одна минута-артефакт (фитиль h/l на ~56 % контрактов при неизменном close). Правило (измеряемое, без нового числа): минута рынка, в которой экстремум высокого/низкого у доли контрактов выше излома распределения `доля_монет_рынка` по минутам (K1, как в B1), — «артефакт_данных рынка»; такие минуты исключаются из h/l **до** B1 (пересчёт порогов Gate futures) и до событий. Ветка (а) по `доля_монет_рынка` для событий — разрешена тем же изломом (распределение явно двугорбое: 3 рынка p95 ≤ 0,03, Gate fut медиана 0,56). Число исключённых минут и событий — в отчёт по рынкам. Проверить, нет ли такой же минуты в других рынках (13 ч 30.09 Gate fut — 45 пампов, тоже посмотреть).

1. Минуты-артефакты по правилу выше → исключить; B1 Gate futures пересчитать; x\* Gate fut в отчёт до/после.
2. ход_% дампа = low/high − 1 (в %); a для порога — как было.
3. Инвариант в коде и в отчёте: у каждого события `ход_% ≥ exp(a*_T)−1` (по модулю для дампа, в своих единицах), старт < пик; число нарушений = 0 (иначе — показать и объяснить).

Столбец «вид инструмента» (плечевые токены *3S/*3L/*5L и т. п. в Gate spot — AR3S, ARB3S) — только пометка, без исключения.
