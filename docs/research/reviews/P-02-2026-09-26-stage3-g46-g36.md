## Ответы на вопросы автора

1. **H5 «сильнее базовой оси `flow_1h_lots`» — метод для сводки не нужен и сейчас задавать его нельзя.** Задать после
   чтения Г-46 — развилка (и эффект оси `flow_1h_lots` на отскок уже смотрели в профилях касаний). В сводке писать: «H5 —
   не ясно; вторая часть гипотезы («сильнее базовой оси») не операционализирована и не проверялась — подтвердить H5 в
   П-02 нельзя по построению». Если Г-46 пойдёт в П-03 — сравнение с базовой осью заморозить там до счёта (например,
   эффект несовпадения внутри терцилей `flow_1h_lots`), проверка — на сутках после регистрации П-03.
2. **Проверка окна «за 1 с до касания, локальное время» — законна как проверка утечки, не как вариант.** У неё была
   причина до чтения (разбор Г-88: сделки за 1–100 мс до касания — само касание), она может только убрать сигнал, а
   вердикт стоит на замороженном окне. В счётчик испытаний — +1 просмотр (проверка устойчивости), в Холм — нет. Для
   П-03 окно «с отступом по локальному времени» заморозить явно: здесь меняли сразу два параметра (отступ и шкалу
   времени).
3. **Разбивка Г-36 по номеру касания после чтения — законна как толкование** (проверка смешения, не испытание), и она
   нужна: доля отскоков растёт с номером касания (у меня без флага: 36,7 / 44,5 / 53,6 % в августе), а флаг чаще у
   поздних касаний. Но тогда вывод о величине надо поправить — пункт 1 ниже.
4. **Выборка** — как во второй очереди (без TRX, без 4 монет К1 на 16–19.09, 0,28 % сентября вне пула 76) — верно.

## Вернуть

1. **Г-36: часть эффекта — состав по номеру касания.** Разница, стандартизированная по k (средневзвешенная разница
   внутри k = 1 / 2 / 3+, веса — гармоническое среднее размеров корзин; моё чтение, не испытание): **+18,5 п.п. в
   августе и +12,2 в сентябре** против +25,3 / +17,7 без стандартизации, то есть около 30 % разницы даёт состав. В
   вердикте и в «Смысле» не писать «крупный (+25 / +18)» без этой оговорки.
2. **Г-36: суток с флагом меньше, чем в таблице.** «31 / 22,3» и «23 / 13,8» — это все сутки, а касания с флагом есть
   только в **23 из 31** (август) и **20 из 23** (сентябрь); эфф. N считается по ним. В разбивке по k суток с флагом
   ещё меньше: 18 / 14 / 13 и 20 / 18 / **9**. Писать «суток с флагом / эфф. N».
3. **Эфф. N больше числа суток** (k = 1, сентябрь: 143,2 при 20 сутках) — не «оценка неустойчива», а не определено:
   при отрицательной автокорреляции `effective_n_from_autocorr` возвращает N / (множитель < 1) > N. Писать «не
   определено (> N суток)» и не приводить число. (Сам скрипт навыка — предложение `CEO`: ограничивать сверху числом
   наблюдений.)
