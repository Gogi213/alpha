# Судья: геометрия входа Г-85б по шагу цены и волатильности (В-131, 6e31f6e) — решение до счёта (2026-09-27)

Для Исследователя (протокол П-07, поправка 3) и Инженера (форма входа), копия `CEO`.

## 1. Лестница Г-85б в σ с полом в тиках

**Определение формы** (новая форма, код Инженера):
- три ноги над стеной. Ближняя — всегда P+1. Дальняя — на расстоянии D тиков, **D = max(3, ⌈k·σ / шаг⌉)**, где шаг —
  тик монеты в bps по цене стены. Средняя — ⌈D/2⌉, но не ближе P+2. Так три ноги различны всегда, ближе шага цены
  ни одна не встаёт, у мелкого шага ширина задаётся волатильностью;
- доли как у `w2`: ближняя — половина, две другие — по четверти.

**σ** — как в движке уже есть (`lob::sigma` `sigma_bps`), по секундным доходностям середины. **Окно 14 400 с (4 ч),
кончается в момент сигнала**, без заглядывания. Это та же мера, что у `s<a>` / `t<b>` при удержании 4 ч
(`drive.rs`: окно = `deadline_secs` формы) и у люстры Г-25 — одна мера для лестницы, стопа и трейла (предложение
Исследователя 27.09). **Окно — константа формы, не `deadline_secs`**: иначе ось H8 (удержание 1 / 2 / 4 ч) меняла бы
заодно и геометрию входа. Тип оценки для хода цены не важен (E32). Нет σ (меньше 4 ч записи) — сигнал без плана, в
счёт «сделок нет».

**k без выдумки:** k₀ = 4,5 bps / медиана σ₁₄₄₀₀ на моментах сигналов базы в августе. Замер по признаку, без исходов, до
счёта — записать в П-07. Так медианная монета получает ту ширину, что владелец уже одобрил (4,5 bps), а масштаб
каждой монеты — свой. **Сетка H2: k = k₀ × {1/3, 2/3, 1, 5/3}** — та же пропорция, что прежние 1,5 / 3 / 4,5 / 7,5
bps. База — k₀.

Гейт формы (Инженер): юнит-тесты на три ноги при мелком и крупном шаге, пол 3 тика, нет σ → нет плана. Реплей: σ-форма
на сутках прогона Г-85б — ноги плана у трёх монет (мелкий, медианный, крупный шаг) печатаются.

## Поправка 27.09 (предложение Исследователя) — σ за 4 ч вместо 1 ч

Окно σ — 14 400 с, константой формы (см. п. 1). Правило ног не меняется: пол в 3 тика оставлен, потому что владелец

## Окончательно (27.09, с вариантами Инженера через `CEO`) — заменяет п. 1 выше в части источника σ и записи формы

- **Источник σ — минутные свечи (вариант 1 Инженера):** `study/klines/ref-<SYM>-1m.csv`, боковая таблица σ на каждый
  подход, кэш подходов не пересчитывается. **σ = √Σ r² по 1-минутным лог-доходностям закрытий за 240 минут**, в bps.
  Окно кончается на последней **закрытой** минуте до `arm_ms`. Меньше 200 минут из 240 — σ нет, сигнал не торгуется,
  считается в `n_no_sigma`. Секундная σ (вариант 2) не нужна: тип оценки для хода цены не важен (E32), а по свечам
  считались E29–E33 и люстра Г-25. Реплей (вариант 3) — нет.
- **Форма — запись Инженера `ladder<N>x<a>..<b>s[w<k>]`:** отступ ноги = σ·(a…b), переведённый в тики вверх. Ноги не
  сливаются: каждая хотя бы на тик дальше предыдущей, первая — не ближе P±1. Это и есть пол из п. 1 (три различные
  ноги, дальняя ≥ 3 тиков), только общим правилом. **Г-85б = `ladder3x0..<k>s` с `w2`:** ближняя — P+1, средняя —
  k/2·σ, дальняя — k·σ, каждая с полом «+1 тик к предыдущей».
- **k:** k₀ = 4,5 bps / медиана σ₂₄₀ₘᵢₙ на сигналах базы в августе, без исходов, записать в П-07 до счёта. H2:
  k = k₀ × {1/3, 2/3, 1, 5/3}. Предложение Исследователя «k так, чтобы у медианной монеты были 3 разные ноги» при
  правиле «не сливаются» выполняется всегда. Якорь — ширина, которую владелец уже одобрил.
- Гейт формы: тесты — ноги при мелком и крупном шаге, пол, нет σ → нет плана; на сутках — ноги трёх монет и
  `n_no_sigma` в шапке.
