## Решение

Не ask-owner и не новый круг метода: L4 v8 по записанному правилу снимает 0 (рынок в сентябре ни разу не «летел весь
за BTC/ETH» на ход, сравнимый с пампом альта). Новых правил L4 нет. Дальше по протоколу без изменений:
отчёт `docs/findings/pump-events-<дата>.md` (воронка L0→L4 v8 по рынкам, таблица периодов = пусто с числом минут
лидера по ячейкам, сравнение с v6), csv событий, лист ВСЕХ кандидатов без меток (таблица + мини-график 1 м),
контроли C1/C2. «Похоже на рынок» — причина «не памп» при ручной разметке, не фильтр.
