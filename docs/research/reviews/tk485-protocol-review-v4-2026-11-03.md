## Находка (вернуть)

**Н11. §9.4 (`Rule::Ou`) не содержит верхней границы входа.** Правило §3 M1: «вход только при `d ≤ d_hi = min(d_q,
d_stop)` (одна, всегда включена)». В §9.4 условия входа: «`ď ≥ b*(c̃)`, `τ(d) … ≤ τ_max`, `G(d) − k_m·RMSE_cal(τ(d)) > 0`»
— `d_hi` нет; в `Params` перечислены `k_m`, `F`, `τ_max`, `rmse_cal`, `ρ_tail`, `stop_kind` — нет `d_q` (на пару-месяц из
`P-33-params`). Список §9 — то, по чему Инженер пишет ядро; по нему ядро граница входа не получит, а тест §9.3 на неё
упадёт. Нужно: в §9.4 добавить условие `d ≤ d_hi = min(d_q, d_stop)` и поле `d_q` в `Params` (источник —
`P-33-params`, на пару-месяц).

## Замечание (не причина возврата)

**З2.** «`G(ď)` строго растёт по `ď` на `ď ≥ 8`» верно не при любых `κ, F`: `dG/dď ≈ σ_eq − F/(κ·ď)`, при
`F/κ > 8σ_eq` убывает. В тесте §9.3 записать значения, при которых `F/(κ·8) < σ_eq`, или формулировать как
«`dG/dď → σ_eq`». Также при стопе «максимум отклонения на формировании» `d_stop ≥ d_q`, т.е. `d_hi = d_q` — не ошибка.
