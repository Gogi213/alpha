## Условия к гейту («`--variant` = прежние флаги байт в байт»)

1. **Шапку не выбрасывать.** В ней и записана раскрытая конфигурация; если сравнивать строки без `#`, ошибка раскрытия
   параметра, который на выбранных сутках не сработал (перенос через полночь, дедлайн, TTL входа, выход по полосе),
   пройдёт незамеченной. Сравнивать шапку целиком, допуская только добавленную строку с именем и хешем файла варианта.
2. **Сутки гейта** — такие, где работают все параметры: перенос через полночь (`--carry-root`), стоп, трейл и дедлайн,
   истёкший TTL входа, несколько наборов (память кругов); тяжёлая и лёгкая монета; август и сентябрь.
3. **Цепочка равенств до старых артефактов.** Новый бинарник с `--variant` = новый бинарник с прежними флагами = уже
   лежащие артефакты `alpha-7bdf9a4` в `b5/titrc-u500r` на тех же сутках. Второе звено — обычный гейт `gate-g10.sh`.
4. **П-01 не трогать по ходу экзамена.** Ночную дозапись главного варианта переводить на `--variant` только после того,
   как прогон по уже посчитанным свежим суткам (с 24.09) совпал с лежащими файлами байт в байт — сравнение файлов, без
   чтения чисел. Иначе ряд экзамена П-01 окажется из двух разных прогонов.
5. **Все поля файла обязательны**, неизвестное поле и пропуск — ошибка; умолчаний CLI в файле нет. Иначе будущая смена
   умолчания молча поменяет вариант.
6. **Имена форм не менять.** Типизированные параметры (В3) обязаны печатать ту же строку формы
   (`ladder3x2..20w2-pct2-tr1x1-14400-ttl1800`): по ней выбирают сделки `portfolio-sim.py`, дашборд, `fresh-days.py`,
   `exit-sim.py`. Тест: разбор → печать → та же строка для всех форм, что есть в `b5/`.
7. **Денежный слой — в том же файле.** В-105 (без TRX), потолок позиций, дневной стоп, выключатель BTC, депозит и
   размер позиции — часть главного варианта; если они останутся флагами `portfolio-sim.py`/`.dash-notrx.sh`/умолчанием
   `fresh-days.py --drop`, «4+ места» сохранятся для денег.
8. **Воспроизводимость прошлых прогонов.** Старые строки `runs.csv` и артефакты не переписывать. С этой сборки каждый
   прогон пишет в шапку/`manifest.txt` и в `runs.csv` (в `detail` или новой колонкой) **хеш бинарника** (зашитый при
   сборке) и **хеш файла варианта**. В `variants/v104.toml` — строка «история: до <даты> — флаги `nightly-grid.sh`
   <коммит>», и тест, что раскрытие файла равно этим флагам (строкой).

## Замечание к плану (не блокирует)

«Главный вариант записан в 4+ местах, и расхождение мест — источник ошибок» — как угроза верно, как факт на 26.09 не
подтвердилось: по конфигурации места сходятся. Переносить главный вариант в файл первым — правильно, но сначала
закрыть сутки 14.09, чтобы гейт по старым артефактам (условие 3) шёл по полному ряду.
