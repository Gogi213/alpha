## Вернуть — что сделать (развилки решены здесь)
1. **Окно 7 суток, правило не трогаем.** Докачать свопы 15–16.10 тех же 32 пулов ETH/Base (Gate есть 15–21.10), тот же
   USD-слой и банк, правило TK-364 как записано (≥ 5/7 сут, ≥ 10 монет, доля ≤ 0,3, lo > 0, Бонферрони 54). Править
   порог под увиденные 4/5 после исходов — нельзя.
2. **Fee tier без GeckoTerminal:** v3 — on-chain `fee()` пула (тот же публичный RPC, что качал свопы; 32 вызова),
   v2 — 0,30 % по метке `labels`. Таблица пул → fee в json рядом с csv.
3. **Тейкер Gate:** спот VIP0 с публичной страницы тарифа Gate — число + ссылка + дата в отчёте.
4. **Net** по клеткам (и по монетам для лучших): rev (вход в пул, выход хеджем на Gate) = diff − fee пула − тейкер Gate;
   fwd (вход Gate, выход Gate) = diff − 2·тейкер Gate. Газ — не в заказе: строкой «без газа» (для ETH это верхняя граница).
5. **Solana:** строка в таблице охвата «нет данных» с причиной (как BSC) — либо данные, если публичный RPC отдаёт без 429.
6. В выводе rev — оговорка: «догон» = устаревшая цена пула; её закрывает чужой арбитражный своп — значит разрыв не
   окупал fee+газ для арбитражёров; net это покажет.

Хвостов вне заказа нет. CEX-пара Bybit/Binance→Gate — не здесь (решение `tk374-overseer-bsc`).
