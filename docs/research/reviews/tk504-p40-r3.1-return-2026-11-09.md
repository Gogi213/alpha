## Возврат
- **Р-8 · вход K2 вырожден.** §4.3: K2 ставит «мейкер-вход §3», а §3 снимает заявки входа «при `dir·d ≤ θ/2`». Случайный момент K2 почти всегда лежит в `|d| < θ/2` (взведённое состояние — норма пары), значит условие снятия выполнено сразу: заявки K2 снимаются в момент выставления, исполнений почти нет, `ȳ_K2` ≈ 0 по построению, а разность `ȳ − ȳ_K2` равна `ȳ` — контроль механики ничего не проверяет. Записать для K2 своё условие снятия входа: только по `T_life` (или при `dir·d ≤ ½·d_вход`, по аналогии с выходом) — одно до счёта, и то же передать ядру TK-500.
