# TK-410 · П-31 (карта DEX↔Gate) — проверка протокола до счёта, Судья 26.10

Основа — верная (непрерывный X, 16 окон, V = 1 с из урока TK-409 Q, контроль R2, КМ с цензурой, «карта, не стратегия»).
Но в П-31 повторены дефекты, уже исправленные в П-30 (reviews/tk409-p30-protocol-2026-10-26.md V1, V3, V4, V7, V8),
и нет главной метрики с числом испытаний. Вопросов владельцу нет (метод — Судья, В-53).

| № | пункт | решение Судьи |
|---|---|---|
| W1 (Q-1) | возраст A | A — **живость потока монеты** (R1 П-29 / V1 П-30: последняя любая запись gev2 ≤ A, час не дыра), не возраст значения. Вход (tv+L) — всегда A = 5 с; выход при h ≥ 300 с и offset ≥ 5 мин Q5 — A = 60 с главное, 5 с — чувствительность. Метки gev2 квантованы 0,1 с — оговорить L = 0/100 мс. |
| W2 | одна главная метрика | Назвать до счёта: **главная = Q1, исполнимый избыток нетто (касание, −2,6 бп) при h = W, фьюч, класс G, страта P_i < 25 % X**; порог ищется только на ней. Остальное (mid-to-mid, фикс. h, спот, Q2–Q5) — карта/описание, без слова «край». Итог отчёта — по главной, не по лучшей клетке (урок TK-407). |
| W3 | семейство Холма — числом | Семейство главной: 16 W × 2 направления = 32 кривые × 20 интервалов; правило «2 смежных интервала» — это перебор по интервалам: записать размер семейства числом (≤ 32×19 пар) и поправку Холма на него. Отдельно по классам P и G; H не тестируется — «край» в H = подозрение на дефект метода, разбор до вердикта (V5). Бонферрони по W сверх Холма — убрать (двойная поправка). |
| W4 | кластер ДИ | §3 «блоки монета-день (кластер — монета)» противоречит сам себе. Главное: бутстрап по монетам (G), чувствительность — по суткам (общерыночный ход связывает монеты внутри дня; при W ≥ 1 ч это главный источник зависимости). P — только описание, кластер по 13 монетам, df = 12 (Q-4: согласен). |
| W5 (V3) | 01.09–14.10 | **Вне вердикта и N**: событийной книги gev2 нет, сделки вместо BBO — запрещённое упрощение. Строка «нет данных», без чисел. Убрать из §1 «только где есть». |
| W6 (V4) | базис Q2/Q5 | Медиана 24 ч **взвешенная по длительности** (значение живёт до следующего события пары), не по событиям; первые сутки без истории — вне, счётчик. |
| W7 (V7) | дыры и сутки | Дыры — часы, не сутки. Сутки годные, если у монеты ≥ 12 ч вне дыр; правило знака: плюс в ≥ 75 % годных суток и годных ≥ 4, иначе «мало данных». §1 сейчас читается как «сутки 15, 16, 19–21 — дыры» — переписать. |
| W8 (V8) | `mid_src` | Главная — только события с настоящей серединой пула; «исполнение ± ½ комиссии» — чувствительность, доля по монетам в отчёт. |
| W9 (Q-2) | ликвидность пула | Проверить в пробе по файлам: v3/v4 Swap несёт `liquidity` (вместе с sqrtPriceX96), v2 Sync — резервы → ρ₃ для EVM считается; Solana — если в swaps3 есть остатки хранилищ, иначе ρ₃ только EVM с меткой. Не отказываться от ρ₃ целиком. |
| W10 | выбор пула | «Наибольший оборот за окно» — заглядывание в выбор (оборот 22.10 выбирает пул для 15.10). Допустимо для карты, но оговорить; лучше — по обороту предыдущих суток / первых суток (вне счёта). |

Ответы: Q-3 — да, жадно по времени, P_i < 25 % — страта, не отбор. Q-5 — V = 1000 мс единое; чувствительность 2/3 с только
для W ≤ 1 мин. Q-6 — да, Sui/Tron при середине из TK-393, иначе вне со списком.
