Развилки решает Судья (В-53/В-206), владельцу не идут. Решения — обязательная часть v6:

1. **Разметка без признаков шага 3.** Вопросы листа v5 (а) «спокойно до?» и (в) «всплеск оборота?» — **отменены**: иначе
   дормантность и оборот вернутся в «подтверждённые пампы» через разметку и шаг 3 «найдёт» их общим. Метка «не памп»
   ставится только по заранее названной причине: `артефакт_данных` (дыра/скачок одной свечой без сделок, неверная цена),
   `листинг` (первые сутки торгов), `рынок` (L4 пропустил общее движение — видно по BTC/соседям), `не_ход` (ход набран
   медленно/ступенями на всём T и не выглядит единым движением — с описанием формы). Иначе — «памп». В листе **не
   показываются** столбцы κ, m, оборот, дормантность, OI, фандинг — только цена 1 м (окно ±длительность события и
   сутки до), ход %, T, доля монет рынка, ход BTC.
2. **Масштаб — без верхней границы** (владелец: «ВСЁ»). Лист — один файл, разделы по бирже-рынку × знаку, внутри по
   `кластер_id`. Gate futures (2056 событий L0 до L4/кластеров, ×10 к прочим) **не отсекается**; в отчёт до листа —
   диагностика: распределение `событий_монеты_в_месяц` по рынку, доля событий у топ-10 монет, тик в bps и медиана
   оборота/мин монет с событиями против монет без событий. Это описание, не фильтр.
3. **L4 без излома доли** на T/знаке/рынке: условие по доле не применяется (рыночность по доле не отделяется — строка
   в отчёт), остаётся условие по ходу BTC той же биржи. (Отличие от v5 п.2 намеренное: L4 исключает, не отбирает —
   «без излома 0» опустошил бы исключение, а не определение.)
4. **Испытаний K1 = 20:** V0 5 T × 2 знака (10) + излом доли L4 5 T × 2 знака (10). V1 — столбец, порог не отбирает, в
   число не входит.
5. **Правило отказа «не памп > половины»** — по каждой бирже-рынку × знаку отдельно (иначе Gate futures решит за всех).
   Разметка: Судья размечает весь лист, владелец смотрит; при расхождении метка владельца — окончательная (определение
   «пампа» — его). Шаг 3 считает признаки и по «подтверждённым», и по всем кандидатам — расхождение двух профилей
   показывает, сколько внесла разметка.
6. Правило приёмки (§«Правило приёмки определения» пп.1–3: K1∈K2, половины сентября, ≥ 30 кластеров) — в силе для V0.
