## Что сделать (одной сдачей)
1. Весь счёт отчёта — из сданного `run_synth.py` (twoway и новые варианты в `run_family`, `run_power`, `run_candidate`); `data/p40stats-synth-twoway.json` не нужен отдельно.
2. Час суток по §3.5: χ² (с поправкой по выбранной схеме) — p в BH; размах с порядком из D1, применённым на D2, — для п. 1, 3, 4.
3. Варианты интервала: day (протокол), twoway-бутстреп, CGM аналитический (`V_A+V_D−V_AD`, неотрицательная поправка при V<0), при желании wild/с вычитанием ячеек; таблица покрытия и мощности; выбор с причиной (раздел «Алгоритм»).
4. MDE — формула для разности долей с DEFF, учитывающей двустороннюю зависимость (или мощность из симуляции по выбранной схеме); печатать обе.
5. В `SCHEMA` и комментарий TK-500 — `bybit_leg` (0/1), `t_conv_s` и признак цензуры; функция H-Bybit (разность медиан с интервалом по выбранной схеме, «МПУ > X» — контрастом).
6. Отчёт — предложение правки П-40 §3.5 п. 1 и §5.1/§5.2 текстом «было → стало»; правку протокола (r3) утверждает Судья отдельно, до счёта реальных эпизодов.

## Замечания (не причина возврата)
- `run_candidate`: «пустое семейство» для BH строится на D1, а главное испытание — на D1∪D2; для честного m все 24 p брать на D1∪D2.
- Покрытие при n_sim 150 имеет шум ≈ ±0,025 (биномиальный); для выбора между близкими вариантами — n_sim ≥ 400 на сервере 5.231.25.224, не на ПК.
