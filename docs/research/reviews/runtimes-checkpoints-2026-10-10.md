## Обязательные поправки (вносит исполнитель КТ, приёмка КТ без них — «вернуть»)

1. **С-34 → КТ-5** (код Х: `verify`/`import_archive`, резка длинных единиц под тем же гейтом md5 `.abin`);
   **С-52 → КТ-1** (правка `alsched.py` идёт туда же: `Core.tick` резать вместе с отказом по манифесту, гейт —
   `sched_sim` на журнале). С-32, С-56 — дописать номерами в КТ-4a / КТ-1-2-9, чтобы КТ-10 сверял по списку.
2. **КТ-2, правило языка несимметрично:** замеряется только накладная Python против прямого вызова; выигрыш Rust
   (`lob run` — кэш между сутками в процессе) не замерен. Принимаю порог ≤ 1 % как достаточный, потому что кэш между
   сутками закрывает `cold ensure` (КТ-5); но в решение В-## записать именно этот довод, а не «Rust не нужен».
3. **КТ-4b, лазейка в гейте:** «расхождения поштучно объяснены» — допустимый класс расхождений записать ДО прогона
   (например: только исходы, где цена f64 вне сетки тика или сравнение на границе уровня `still_at_level`; число
   таких сделок на d15+d01 — в отчёт). Расхождение вне класса — «вернуть».
4. Значения, назначаемые решением В-## (§5 п.4: порог «< N клеток», срок жизни веток `tk*`, предел длины файла,
   доля стены Холодного) — Судья назначает при приёмке соответствующего КТ из замера, не до него.
