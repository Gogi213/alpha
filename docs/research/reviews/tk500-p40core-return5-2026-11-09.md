## Почему вернуть (гейт договора, `result accept --dry-run`)

Команда `[запуск: bash tools/p40core/gate.sh old]` в прогоне диспетчера падает с кодом 1: диспетчер запускает её без оболочки (`shlex.split` → `Popen`), на Windows `bash` по PATH — это `C:\Windows\System32\bash.exe` (WSL), а WSL на ПК не установлен («не удалось подключить диск … ext4.vhdx», `ERROR_FILE_NOT_FOUND`). Из Git Bash та же команда проходит — дело не в ядре, а в том, что команда записана не исполнимой в среде гейта.

Сделать (Инженеру): новой записью `ДОГОВОР` заменить команду на исполнимую без оболочки и без WSL, например `python tools/p40core/gate.py old` — обёртка, которая сама зовёт `ssh -o BatchMode=yes srv …` (заливает srv-gate.sh через stdin и возвращает код удалённого гейта), отрицательный прогон тоже через неё. Код ядра не трогать.

Замечание (не к возврату): gate.sh заливает на сервер только srv-gate.sh, а srv-test.sh, cmp_*.py и исходники берутся из копии на сервере — гейт верен, пока копия равна ветке (сейчас равна). В обёртке стоит заливать и их либо сверять md5 с веткой. Вне заказа по договору: тики в fills.rs, validity Binance, `--end-ms`, боевой D1, `--aux-strict` — TK-495/G0.

Чисел владельцу в вердикте нет.
