# TK-409 · П-30 (DEX↔Gate фьюч по событиям: схождение S и «ёршик» Y) — решение Судьи по Q-1…Q-5, 26.10 ~04:10

Протокол `docs/research/P-30-g016-dex-gate-events-redo.md` в основе принят: событийный каркас П-29 (R1–R7), очередь по
потоку gev2, тариф наборами, вход +10 с запрещён, фандинг без нуля при сбое (B8–B11), контроль случайными моментами.

|---|---|---|
| V1 (Q-1) | главное L, A | Принять: L = 250 мс, A = 5 с. A — **живость потока монеты по R1 П-29** (последняя любая запись gev2 монеты ≤ A, час не дыра), не возраст последнего изменения BBO (§2 сейчас читается как второе — исправить). Метки gev2 квантованы 0,1 с → L = 0 и 100 мс различимы на 1 тик; оговорить. |
| V2 (Q-2) | отмены впереди в очереди | Два режима достаточно. **Вердикт — по пессимистичному** («ничего не отменяется», вся очередь впереди съедается только принтами); «пропорционально» — чувствительность вне семейства. |
| V3 (Q-3) | 01.09–14.10 без gev2 | **Исключить** из вердикта и из N: без событийной книги нет цены исполнения и очереди; сделки мс вместо BBO — то самое упрощение, что запрещено. В отчёте — строка «нет данных», без чисел. |
| V4 (Q-4) | базис 24 ч | Принять окно 24 ч без заглядывания, но медиана **взвешенная по длительности** (значение живёт до следующего события пары), не по числу событий: всплески событий — это и есть эпизоды отрыва, они тянут базис к отрыву. Сырой отрыв рядом — как в протоколе. Первые сутки без истории — вне, счётчик. |
| V5 (Q-5) | семейство Холма | Отдельно по классам P и G (разные утверждения). Размер назвать числом: S 3×4×2×4 = 96 + Y 3×2×3 = 18 → **114 на класс**. H — не тестируется, только контроль: «край» в H = подозрение на дефект метода, разбор до вердикта. Утверждение про отдельную монету P — только с поправкой ещё ×13 (монеты); главный тест P — кластерный по 13 монетам (df = 12). |
| V6 | одна главная клетка | Как R4 П-29: назвать **по одной главной клетке S и Y до счёта** — клетку, на которой стоял недействительный вердикт TK-386/388 (S) и TK-385 (Y): переделка проверяет именно его. Итог отчёта — по главной клетке, Холм — по семейству; лучшая клетка — не итог (урок TK-407). |
| V7 | «знак в ≥ 6/8 суток» при дырах 15, 16, 19–21.10 | Дыры — часы, не сутки; сутки годные, если ≥ 12 часов вне дыр у монеты. Правило: знак в ≥ 75 % годных суток и годных суток ≥ 4; иначе «мало данных», не «край есть/нет». Сутки — все с индексами, годные помечены. |
| V8 | `mid_src` | Главная — только события с настоящей серединой пула (sqrtPriceX96 / Sync / swaps3+состояние); запасной вариант «исполнение ± ½ комиссии» — чувствительность, доля по монетам в отчёт. |
