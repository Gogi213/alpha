# Удаление пампов по слову владельца — приёмка Судьи

Сверено по живым источникам: коммит удаления (список файлов `git show --name-only`), отчёт в папке разборов, статусы тикетов закачки, протокола и ядра пампов.

| пункт | итог | доказательство |
|---|---|---|
| София: юнит закачки остановлен, каталог закачки удалён | держится | отчёт, раздел про Софию |
| ветки закачки и ядра — под архивными тегами, удалены, в origin не было | держится | отчёт, раздел про ветки |
| доки, протоколы, проверки, скрипты, БД признаков — одним коммитом под архивным тегом | держится | `git show --name-only` коммита удаления: только `docs/` и скрипты счёта пампов, база признаков |
| тикеты закачки, протокола и ядра закрыты | держится | статус `stopped` у всех трёх |
| Deck не тронут, отмечено в отчёте | держится | отчёт, раздел про Deck |
| П-сорок и данные стаканов не тронуты | держится | в коммите нет путей статарба, `src/`, `vps-check` |

## Запись надзирателя («ломает принятое», проверки ошибок статарба)

Ложная. Коммит удаления не содержит ни `src/`, ни `tools/compute/statarb/`, ни `tools/vps-check.sh` (`git show --name-only … | grep -E "statarb|vps-check|^src/"` — пусто). Задержка гейта — очередь сборок сервера счёта, а не поломка: проверки ошибок идут через `vps-check` на новый сервер. Продолжать.

## Хвост

Три скрипта пампов с чужими незакоммиченными правками — отдельным тикетом Инженеру (закоммитить в архивный тег, затем удалить); данные пампов на Deck — там же отметкой, Deck не включаем по решению владельца.
