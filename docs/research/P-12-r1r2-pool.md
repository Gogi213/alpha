## 1. Вопрос и решение

Улучшает ли каждая из 38 семей (R1 — 26, R2 — 12; клеток 59) главный KPI базы B1 (В-120, «дней/часов до перехая») **на периоде 01.01–02.10, каждый месяц отдельно**, не вредя деньгам.
Если «в отбор» — семья идёт на живую проверку/следующий шаг владельца (не «кандидат в бота»). Если «опровергнуто» — строка в пул. Если «не ясно» — «края нет на этом пуле».
Основание: владелец 06.10 ~04:25–04:30 («первые два входа невероятно важные», «ставь задачи»). Владельцем утверждается **этот протокол и назначенные в спецификации числа** — до счёта (§5).

## 7. Бюджет испытаний и множественность

- Семей **m = 38** (R1 26 + R2 12), клеток 59; клетки одной гипотезы вложены/упорядочены — **p семьи = max по клеткам** (одна находка). Холм по пакету, m = 38, α = 0,05; `m` меняется только в сторону «не определена, p = 1, m не уменьшается» (П-10 п. 15).
- Сквозной счётчик испытаний — П-10 §8 + 59 клеток этого пакета (+1 если `e65`). Описание без Холма (не считаются в m): Г-132 (таблица по K), Г-60, Г-125 (вне пакета), окна/колонки вне клеток.
- Родословная базы B1 в счётчик не растёт.
- Достижимость (п. 17, до счёта, на 8 месяцах ≈ 240 суток): Холм m = 38 достижим при 20 000 повторах бутстрепа (минимальное p ≈ 5·10⁻⁵ < α/m ≈ 0,0013). Минимально различимый эффект ≈ 2,8·σ/√n по суткам — **σ суток B1 по месяцам и итог пишет Исследователь в JSON охвата до чтения** (измерение, не число протокола).
- Ожидание ложных «в отбор»: при 38 семьях и условии в каждом месяце ≲ 1; «в отбор» — допуск на следующий шаг, не вывод.

## 8. Охват и замена до счёта

Как П-11 §4 механически: признаки считаются без колонок исхода; ожидаемое число сделок клетки = доля × сделок B1 в месяце; клетка, оставляющая > 90 % сигналов или ожидающая < 30 сделок (на месяц), получает ярлык «почти не действует»/«мало сделок» **без замены порога**. Месяц, где клетка «не определена» (§10.1 П-10: сделок < 10 или суток с сделкой < 10), выпадает из критерия **этой клетки** (p = 1 для месяца не вводится — клетка читается по оставшимся определённым месяцам, если их ≥ 6 из 8; иначе «не определена», p = 1, m не уменьшается). Один JSON `docs/findings/p12-coverage-<дата>.json` — коммитом **до первого исхода**; Судья смотрит его до чтения.

## 9. Правило вердикта (числами, до счёта)

Семья — «в отбор на следующий шаг», если **хотя бы одна клетка семьи** удовлетворяет всем пунктам:

1. **КПИ-1 (деньги, пул):** нижняя граница 95 % парной Δ$ к B1 по суткам **всех определённых месяцев счёта** > 0 после Холма (m = 38);
2. **КПИ-2 (KPI):** доля часов KPI клетки ≤ доля B1 − 0,10 в пуле месяцев счёта (порог С1 П-08, источник) **и** Δ KPI ≤ 0 в каждом определённом месяце;
3. **С3 по месяцам:** в **каждом** определённом месяце верхняя граница 95 % Δ$ ≥ 0 (нет значимого вреда ни в одном месяце, В-115 «месяцы отдельно»); месяцы с отрицательной точечной оценкой Δ$ — перечисляются в отчёте;
4. **С2 (устойчивость):** без любых двух суток и без самой «дорогой» монеты пункт 1 (по точечной оценке и нижней границе без Холма) остаётся ≥ 0;
5. определена по §8 минимум в 6 из 8 месяцев.

**«Опровергнуто»** — верхняя граница Δ$ < 0 после Холма в пуле месяцев и это не одни-двое суток/монета (п. 3 R2). **Иначе — «не отобрана» / «не ясно».** «Лучшая из пакета» не называется; «края нет» — нормальный исход.
Печатаются, не блокируют: B2, ожидание максимума, DSR/PBO (`scripts/selection_bias.py` по счётчику §7), эффективное N (`scripts/effective_n.py`).
Отдельная колонка «поиск»: август/сентябрь (где подобрана B1) — вердикт по ним не выделяется (Q-1).
