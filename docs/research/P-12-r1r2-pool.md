**Объём и равная экспозиция (П-10 п. 5, п. 3 договора).** (1) Клетка, у которой в месяце сделок > 1,25 × B1 или пик одновременных позиций выше B1, — «в отбор» только если условия §9 держатся **и на B2** (потолок 3 позиции), иначе ярлык «на объёме». (2) Равная экспозиция (Судья, повторная проверка 06.10): `$_норм(сделка) = $(сделка) × m`. `g92-n3/-n5`, `g93-k2` (база = лестница B1) — `m = N_B1 / N_peak`, где `N_B1` — нотионал базового входа B1 этой сделки, `N_peak` — пик нотионала открытой позиции этой сделки в клетке (сумма нотионалов исполненных ордеров на момент пика); `g94-thirds`, `g87-fresh`, `g95-w3` (первая нога/доли — база не B1) — `N_ref` = плановый нотионал полной лестницы B1 на сигнале (сумма ног × цены, известен на взводе), `m = min(1, N_ref / N_peak)` — только вниз сверх плана B1, вверх не масштабировать; `e114-halfstop`, `e114-halflevel`, `e65-t2`, `e65-t2x` — `m = 1`. ## 7. Бюджет испытаний и множественность

- Семей **m = 39** (R1 26 + R2 13), клеток ≈ 238 (сетки). **Поправка на перебор внутри семьи (v3; Судье — на утверждение):** «минимум p по клеткам» при сетке до 20 клеток в семье занижает p. **Основное:** p семьи — по **максимуму t-статистики по клеткам семьи со ступенчатой калибровкой Уэстфолла–Янга (max-T)**: статистика клетки — парная средняя Δ$ к B1 по суткам / её ошибка (на равной экспозиции §6); бутстреп блоками суток (⌈n^{1/3}⌉, 20 000 повторов) — **одни и те же блоки суток для всех клеток семьи** (корреляцию сетки учитывает сама процедура), центровка Δ$ клетки до нуля под H0; p семьи = доля повторов, где max-T* ≥ наблюдённого max-T. Затем Холм по 39 семьям. **Запасная (консервативная):** p семьи = min(1, k_f · min p клеток) (Бонферрони по клеткам семьи, k_f — число различных клеток), затем Холм; при k_f = 20 (Г-68) предел бутстрепа 20 000 (5·10⁻⁵) уже на границе α/(39·20) ≈ 6,4·10⁻⁵ — поэтому основной путь max-T. **Обязательные печатные условия:** DSR (`selection_bias.py`, N = число испытаний по счётчику, ≈ 238 + П-10) и PBO (CSCV по клеткам семьи по месяцам счёта) по каждой «в отбор»-семье; «в отбор» требует PBO < 0,5 (0,5 — «не лучше монеты» по определению метода, не назначенное число) и DSR > 0 — **Судье: утвердить пороги/форму**. Клетки одной гипотезы по-прежнему одна семья в m. Г-06 и Г-61 — две семьи (уже две из 26 R1). Холм по семьям пакета, m = 39, α = 0,05; `m` меняется только в сторону «не определена, p = 1, m не уменьшается» (П-10 п. 15).
- Сквозной счётчик испытаний — П-10 §8 + ≈ 238 клеток этого пакета. Описание без Холма (не считаются в m): Г-132 (таблица по K), Г-60, Г-125 (вне пакета), окна/колонки вне клеток.
- Родословная базы B1 в счётчик не растёт.
- Достижимость (п. 17, до счёта, на 8 месяцах ≈ 240 суток): Холм m = 39 достижим при 20 000 повторах бутстрепа (минимальное p ≈ 5·10⁻⁵ < α/m ≈ 0,0013; p семьи по max-T — одно число, перебор клеток размер m не меняет). Минимально различимый эффект ≈ 2,8·σ/√n по суткам — **В JSON охвата до чтения клеток — по каждому месяцу счёта:** доля KPI B1, наибольшее ожидание (ч), σ суток $ B1, минимально различимый эффект. **Если доля KPI B1 в пуле месяцев < 0,10 (порог КПИ-2 недостижим) — стоп и отступление в §12 до чтения исходов клеток.**

## 9. Правило вердикта (числами, до счёта)

Семья — «в отбор на следующий шаг», если **хотя бы одна клетка семьи** удовлетворяет всем пунктам:

1. **КПИ-1 (деньги, пул):** нижняя граница 95 % парной Δ$ к B1 по суткам **всех определённых месяцев счёта** > 0 после Холма (m = 39; p семьи = минимум по клеткам); для клеток с добавками/долями — на равной экспозиции (§6);
2. **КПИ-2 (KPI):** доля часов KPI клетки ≤ доля B1 − 0,10 в пуле месяцев счёта (порог С1 П-08, источник) **и** Δ KPI ≤ 0 в каждом определённом месяце;
3. **$ ≥ 0 в месяце (В-144/В-146, П-10 §10.2 п. 2):** итог клетки за **каждый** определённый месяц ≥ 0 (на равной экспозиции, §6; объём — §6 п. 1).
4. **С3 по месяцам:** в **каждом** определённом месяце верхняя граница 95 % Δ$ ≥ 0 (нет значимого вреда ни в одном месяце, В-115 «месяцы отдельно»); месяцы с отрицательной точечной оценкой Δ$ — перечисляются в отчёте;
5. **С2 (устойчивость):** без любых двух суток и без самой «дорогой» монеты пункт 1 (по точечной оценке и нижней границе без Холма) остаётся ≥ 0;
6. определена по §8 минимум в 6 из 8 месяцев.

**«Опровергнуто»** — верхняя граница Δ$ < 0 после Холма в пуле месяцев и это не одни-двое суток/монета (п. 3 R2). **Иначе — «не отобрана» / «не ясно».** «Лучшая из пакета» не называется; «края нет» — нормальный исход.
Печатаются, не блокируют: B2, ожидание максимума, DSR/PBO (`scripts/selection_bias.py` по счётчику §7), эффективное N (`scripts/effective_n.py`).
Авг/сен — в пуле и в С3 (§4); строка «без авг/сен (фев–июл)» справочно, не условие.

- **Q-8, Г-114** («отложка на половину объёма у уровня, вторая половина остаётся»): «отложка» — отложенный (условный) ордер; для
  лонга ниже рынка это стоп, не лимитка выше рынка. Клетки: `e114-halfstop` (как в спецификации: половина по срабатыванию `pct2`)
  и **`e114-halflevel`** (буквально: половина по рынку при первой сделке ниже `level_px` стены входа; та же половина, округление и
  защёлка, что у `e114-halfstop`). У обеих: остаток без жёсткого стопа, прочие выходы B1 (тейк-трейл, дедлайн, «съели»/«сняли») —
  как у B1; в отчёте — доля сделок, где половина и полный выход сработали на одном событии. Новых чисел нет.
- **Q-9, Г-65** («цель за вторую плотность»): для лонга от бид-стены цель — вверх, «плотности» цели — аск-стены по критерию стены
  B1 (возраст ≥ 2700 с, порог размера набора), в видимом стакане на момент исполнения входа (глубина — как пишет коллектор, без
  нового числа); меньше двух таких стен — тейк B1 (`tr1x1`), сделка = B1. Клетки: `e65-t2` (вторая аск-стена − 1 тик, перед стеной)
  и **`e65-t2x`** (вторая аск-стена + 1 тик — буквально «за», исполнится только после съедания второй стены). Стоп `pct2`, дедлайн —
  как B1. «1 тик» — шаг цены биржи, не назначенное число.
