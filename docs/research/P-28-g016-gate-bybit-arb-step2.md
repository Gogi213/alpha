# П-28 · TK-394 шаг 2 — двуногий арбитраж Gate ↔ Bybit, два режима (протокол до счёта)

Источник слов владельца: CEO 25.10 03:15 и 03:20 в логе TK-394 («прострел — две позы, взял забрал»; «стат-арбитраж — один стабильно выше»; «перебрать варианты перекосов, точно торгуем отклонения»). Статус: v2 (правки Судьи 25.10 п.1–6, `reviews/tk394-step1c-p28-2026-10-25.md`), замораживается после таблицы покрытия BBO (§8.0) и ответа Судьи; правки после счёта — только зачёркиванием и §12.

## 1. Вопрос
Есть ли у пар рынков Gate×Bybit (клетки вердикта: FF, FS; SF и SS — только справочно, §3а) исполнимое схождение, дающее net > 0 после круга издержек (4 ноги) и фандинга, при задержках 0/100/250/500/1000 мс; отдельно для режима A (прострел, опора 0) и B (перекос, опора по прошлому).

## 2. Данные и без заглядывания
Миллисекундная сетка событий (не посекундная): сделки Gate/Bybit в мс; BBO Gate фьюча — пересобрать с мс-метками (сейчас `tk394-gate-bbo.py` пишет секунды — нужна версия `--ms`); BBO Bybit — из бинлогов TK-366. Решение принимается по состоянию на `t`, исполнение — по BBO на `t + задержка` (первая сторона книги, которая видна к этому моменту). Опора считается только по `<t`. Спот Gate без стакана: исполнимой разницы нет — пары SF и SS **не клетки вердикта**, §3а.

## 3. Режимы
- **A (прострел):** опора = 0 (или медиана за прошлые 24 ч, если |медиана| ≤ 1 бп — проверено заранее по каждой монете). Вход обеими ногами, когда исполнимая разница > порога; выход при возврате к опоре или по таймауту.
- **B (стат-арбитраж):** опора — ось испытаний (см. §4); вход при |исполнимая разница − опора| > порога; выход при возврате к опоре или по таймауту.

## 3а. Справочно (вне N)
SF и SS: разница середин по сделкам Gate-спота (без «последняя сделка ±» — это изобретённое число), распределение и частота, без вердикта и без Холма. Задержка 0 мс — тоже только справочно (недостижима); вердикт — по 100/250/500/1000 мс.

## 4. Оси (число испытаний фиксируем)
| ось | значения | n |
|---|---|---|
| режим | A, B | — |
| опора B | медиана 5 мин, 30 мин, 1 ч, 4 ч, 24 ч; EMA с полупериодом 5 мин, 1 ч, 24 ч; медиана прошлых суток (фикс на день); накопленная разница фандинга к ближайшей выплате | 10 |
| порог | круг издержек × 1 / 1,5 / 2 | 3 |
| тайм-аут (сетка владельца) | 1, 5, 30, 60, 90, 120 с, 1 ч, 4 ч | 8 |
| задержка (вердикт) | 100, 250, 500, 1000 мс (0 мс — справочно) | 4 |
| пара | FF, FS | 2 |
| издержки | Gate без скидки; с 35 % | 2 |

Режим B: 10 × 3 × 8 × 4 × 2 × 2 = 3840 клеток; режим A: 3 × 8 × 4 × 2 × 2 = 384 (опора фиксирована). **N = 4224** на монету-неделю (было 10 560). Число испытаний каждой опоры — отдельной строкой в таблице.

## 5. Издержки (круг = 4 ноги)
Gate фьюч 2/5 бп (maker/taker), спот 10/10; со скидкой 35 % на комиссию Gate: ×0,65. Bybit фьюч 2/5,5, спот 10/10 — **сверено 25.10 по странице** `bybit.com/en/help-center/article/Trading-Fee-Structure` (обновлена 02.09.2026, VIP 0: фьюч maker 0,0200 % / taker 0,0550 %; спот maker/taker 0,1000 %; страница оговаривает «зависит от региона» — проверка в «My Fee Rate» владельцем остаётся). Фандинг: обе ноги за удержание по факту выплат (`tk394-funding.csv`), для удержаний < 1 выплаты — только выплата, попавшая в интервал.

## 6. Метрики
net за сделку (бп) после круга и фандинга; число сделок; медиана/квантили удержания; доля сделок с исполнением обеих ног по свежему BBO (возраст ≤ задержки + 1 с); глубина по лучшему уровню (размер сделки = min размера уровней, чтобы не покрыть глубину); по дням отдельно (7 дней 15–21.10), монеты — классы Binance/OKX да/нет, оборот; эфф. N по независимым эпизодам (склейка < 5 с).

## 7. Правило вердикта (заморозка, v2)
Единица теста — эпизод (склейка сделок < 5 с). Статистика клетки — среднее net за эпизод. p — блоковый бутстрап по **часам** (≥ 168 блоков за 7 суток, склейка внутри блока), повторов B ≥ 20·N/α = 20·4224/0,05 ≈ 1,7 млн на клетку (при меньшем числе клеток в опоре — по её N); Холм — к p по всем N клеткам. Эфф. N (число независимых эпизодов) — **порог отбора** клетки (≥ 30), не часть Холма. Клетка «годна» — прошла отбор, p после Холма < 0,05, net > 0 в ≥ 5 из 7 дней. Вердикт по каждой опоре отдельно; итог — число годных из N. Если после отбора по эфф. N клеток нет — вердикт «окон нет в области», без Холма.

## 8. Порядок

Если не проходит > трети — сначала причина (гипотеза Судьи: поток Gate с ограниченной глубиной, уровни вне топ-N не удаляются и всплывают в лучшие при истончении книги; проверка по сырью одной монеты, DOOD 15.10), не обходить.
1. Пересобрать BBO Gate фьюча с мс-метками (проверка: доля бид≥аск = 0; ≥ 95 % сделок в [бид; аск] по мс). 2. Проба: 1 монета × 1 сутки, `--cells` одним проходом. 3. Один боевой проход alsched 15 ядер. 4. Отчёт `docs/findings/tk394-gate-bybit-arb-2026-10-25.md` + csv, Судье. Глубина: размер сделки = min размеров уровней обеих ног (Gate и Bybit), в метрики пишется обе глубины.
