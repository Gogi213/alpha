# TK-419 протокол: марк-аут вперёд событий пампа (принятые vs непринятые vs O), spot ob200, эталон θ 6–7 % (до счёта, 27.10)

Статус: **черновик на утверждение Судьи** — до утверждения счёта нет. Основание: аудит `docs/research/reviews/tk414-method-audit-2026-10-27.md`, варианты 1, 2, 6. Цель владельца (G-016) — поиск пампов по 5 точкам. Торговых выводов нет; это замер сигнала прежде стратегии (издержки не вычитаются). Только событийные данные (сделки мс, книга из потока изменений); посекундных агрегатов нет.

## Вопрос
Помогает ли правило (B, O1, O3, O4) находить памп: знаковый ход вперёд после события у **принятых** событий больше, чем у **непринятых** той же популяции и чем у класса **O** (событие вне ноги эталона того же знака)? T/P/R здесь только как разрез.

## Популяции (события θs=5 TK-414, 5half не читать)
- A: Bybit linear, 48 инстр. (`pump-dump-detector-ob200-bybit-events-2026-10-27.csv`, 6299 событий, признаки B/R5/O1–O5 уже в строках), сентябрь.
- B: Gate futures_usdt, 37 инстр. (events `flowgate2-*` + признаки стакана Gate из TK-414 ob-gate), сентябрь; без признака стакана — только правило B.
- C (вариант 2): Bybit spot, 17 инстр. с ob200 (calc `/data/tk415/ob/bybit/bybit-spot`, TK-416 принят), события θs=5 по spot-свечам; плюс «событие linear той же монеты, книга spot» (где пара есть).
Исключения — как в TK-414: событие без признака (история < 360 мин, нет срезов, срез старше 5 мин) исключается из всех правил той же популяции; ноги с плохим принтом/сомнительные — как в детекторе. Равный вес инструментов.

## Марк-аут
`M_h = s · (close[τ+h] − close[τ]) / close[τ] · 1e4` (бп), s — знак события, τ — минута подтверждения события (закрытие минуты известно онлайн; вход «по закрытию минуты события», лаг ≤ 1 мин сверх сделан в признаках). h ∈ {5, 15, 60, 240} мин (из аудита, не подбирается). Закрытия 1 м — из тех же сделок мс (как детектор TK-414). Событие, у которого τ+h выходит за конец данных инструмента, на этом горизонте отбрасывается (число записать). Положительный M = ход продолжился в сторону события.

## Группы (на каждую популяцию, правило, горизонт)
- **Принятые** правилом X ∈ {B, O1, O3, O4} (определения — `P-TK414-flow-window`, `P-TK414-ob200`: B — surgeB ≥ 3 и imbB ≥ 0,1; O1 — ob_dz ≤ 1/3; O3 — ob_sp ≥ 3; O4 = B и O1). Пороги не меняются, новых чисел нет. Контроль: R5 (OI+поток) на популяции A.
- **Непринятые** — те же популяции без принятых.
- **O** — события вне любой ноги эталона θ=10,48 % того же знака (класс O TK-414). **Принятые∩O vs принятые∩(T∪P∪R)** — отдельная строка.
- Разрезы: T/R/P/O; формы ног (прямая/ступень/лестница/вынос/каскад/пила); по формам «прямая» и «вынос» помечать: пауз нет — T/P пусто.

## Статистика
- Мера по группе: медиана M по инструментам (≥ 5 событий в группе), кварт. 25/50/75 по инструментам; сверху — разность «принятые − непринятые» и «принятые − O» (медиана по инструментам) с 95 % интервалом: кластерный бутстрап **по инструменто-суткам** (10⁴ перевыборок). События одного инструмента внутри горизонта перекрываются → вторая строка «прорежено»: берём первое событие, следующее не раньше чем через h мин (непересекающиеся). Эфф. N = число прореженных событий; < 30 — «совместимо с», не «объясняется».
- **Месяцы:** данные ob200 только сентябрь → разрез «1–15 / 16–30 сентября» вместо месяцев; это не замена месяцам, второй месяц — вариант 5 аудита (после итога). Вывод по одному месяцу не обобщается.
- **Число испытаний:** (4 правила × 4 горизонта) × 2 биржи (A, B) = 32 основных; spot: 3 правила (O1, O3, O4 — по книге) × 4 полосы × 4 горизонта = 48; контроль R5 — 4. Всего 84. Интервалы дать без поправки и с Бонферрони (84).

## Правило вердикта (заранее)
Правило X «различает» на (популяция, h), если: разность «принятые − непринятые» > 0 и 95 % интервал (по прорежённой выборке, с Бонферрони по числу испытаний своей популяции) не содержит 0, **и** знак совпадает в обеих половинах сентября. «Сигнал для поиска пампа найден» — если это на ≥ 1 правиле и h в **обеих** биржах (A и B). Иначе — «не показан в этой выборке», **не** «края нет». Размер эффекта в бп сравнить с полным кругом издержек Bybit/Gate (тариф — SETTLED) только как справку, не как стратегию.

## Вариант 2: spot ob200, полосы
Срезы конца минуты (`tk414-obmin.py` с параметром BAND, событийно: книга из snapshot/delta) для spot, полосы 25/50/100 бп от середины и «всё ob200» (все уровни файла). Признаки ob_dz/ob_imb/ob_sp и правила O1/O3/O4 — как в `P-TK414-ob200` (срез floor(t)−1, база 360 мин, правило последнего среза ≤ 5 мин). Полоса 25 бп (назначена в TK-414, не подбиралась) — одна из четырёх; сравнение полос — описательное, лучшую полосу не выбирать для вердикта (число испытаний выше). Флаги TK-416 для spot (ленты впереди книги, дыры) — оговорка, затронутые сутки в отдельной строке.

## Вариант 6: эталон θ близко к θs
Эталон θ ∈ {6 %, 7 %} при θs = 5 % (назначено здесь; θ=5 % вырожден — пауза < θ внутри ноги не может содержать событие θs=5, P пусто по построению, поэтому не считается; θ=10,48 % — прежний). Ноги и формы пересчитать зигзагом `tk413-episodes.py` по закрытиям 1 м; классы T/R/P/O и доля принятых (B, O1, O4) по прежней мере (`tk414-obsum.py`). Что смотрим: разрыв T−P при θ 6–7 %; если T≈P сохраняется — не артефакт эталона; если разрыв > 10 п.п. (порог из `P-TK414-flow-window`) — вывод аудита п.2 подтверждён. Испытания: 2 θ × 3 правила × 2 разворота = 12 (включены в «число испытаний» отдельной строкой).
