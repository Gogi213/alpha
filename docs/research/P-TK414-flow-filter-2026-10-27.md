# TK-414 возврат Судьи 27.10 02:02 — онлайн-правило «свечи + сделки мс» (протокол до счёта)

Заморожено до счёта (этот файл — коммитом до запуска `tools/compute/tk414-flow.py`).

**Выборка.** Ликвидные инструменты слоя 2 (85: Bybit linear 40, spot 8; Gate фьюч 22, спот 15) — только для них сделки мс качаются
(`--kind net`, потоком, сырьё не сохраняется; Gate `download.gatedata.org`, Bybit `public.bybit.com`, сентябрь 2026). Свечи, эталон
(зигзаг θ=10,48 %), онлайн-события θs=5 % и «5half» — как в `tk414-detector.py` (принято Судьёй), плохие/сомнительные ноги исключены тем же образом.
Охват 4624 инструментов по свечам остаётся «только свечи»; сравнение «свечи» против «свечи+сделки» — на тех же 85 инструментах и тех же событиях.

**Признаки события (i, знак s, оценка старта ext).** Окно W = минуты [ext, i] (оценка старта ноги → подтверждение).
- `imb` = s·(B−S)/(B+S) по $ агрессоров в W (агрессор = сторона тейкера, как в `tk414-aggr.py`).
- `surge` = ($/мин в W) / база, база = медиана $/мин за предыдущие 1440 минут до ext (если 0 — среднее); история < 360 мин → событие без признака (в фильтрованную статистику не входит, в нефильтрованную входит).
- Альтернативное окно W5 = последние 5 минут [i−4, i].

**Правило «свечи+сделки» (главное, заморожено):** событие принимается, если `surge ≥ 3` И `imb ≥ 0,1` в окне W.
Чувствительность (один проход, признаки пишутся на каждое событие, пороги применяются при сводке): surge 2 и 5; imb 0 и 0,2; окно W5; только surge; только imb. Всего 1 главный + 7 чувствительностей.

**Мера (то же, что в детекторе, на тех же ногах):** лаг D (мин, доля хода) первого принятого события знака s в ноге; доля ног, где принятого D нет (пропуск); ложные срабатывания «нога началась» на инструмент-сутки (события вне ног того же знака); **путаница пауза/разворот (п.3 возврата, не по θs):** событие −s в ноге знака s «ложное», если ход ноги продолжился дальше экстремума события (пик эталона позже оценки пика события, т. е. i ≤ t1 и ext < t1), «верное» — первое событие −s после пика эталона; точность = верные / (верные+ложные) для принятых против всех событий.
Равный вес инструментов (медиана по инструментам, кварт. 25/50/75), месяц один — сентябрь; число испытаний — 8 вариантов правила × 2 разворота (5, 5half).
Торговых выводов нет.
