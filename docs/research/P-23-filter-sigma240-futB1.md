# П-23. Фильтр «не входить при низкой σ240» для фьюч B1 — ЧЕРНОВИК (TK-330, G-012)

Статус: **черновик Исследователя 20.10, до счёта; → Судья (постановка) → цитата владельца через CEO.** Ничего не считается до утверждения. Основание: правило отбора LF-1 (Летопись, `docs/registry/loss_findings.jsonl`, партия TK-330/1): единственный кандидат — σ240 Q1 (спот S0: лифт 1,71, 8/9 мес.<0, Σ$ −646; фьюч B1 половина А: лифт 4,0, 8/9 мес.<0, Σ$ −176). Это описание на данных подбора, не правило.

## 1. Вопрос
Улучшает ли отказ от входа при σ240 ниже порога итог фьюч B1 **на данных, не участвовавших в подборе порога**? Одно испытание, один порог.

## 2. Что фиксируем до счёта
- База: фьюч B1 как в TK-326/327 (`ladder3x0..0.0409sw2-pct2-tr1x1-14400-ttl1800`, прогон `p18a6vv2_10000`, psim cap0), тариф (а), Σ$ как в TK-329.
- Порог **не придумывается**: σ240 = 94,2 bps — граница Q1 половины А (TK-329, измерено; половина = `sha256(symbol) % 2 == 0`).
- Подбор — половина А (1 132 сделки, Σ$ +89; Q1 −176, n 283). Проверка — **половина B** (другие монеты, те же сутки/месяцы), ни разу не смотревшаяся на признаки. Порог на B не пересчитывается.
- Фильтр: пропуск сигнала, если σ240 на t0 < 94,2 bps (σ240 — по прошлому, в событийном цикле доступна).

## 3. Данные: есть / считать
Есть: rounds B1 половины А и B в `/data/tk0289/f6v/out`, `tk327-features.py` (признаки по ленте). Считать: `tk327-features.py fut` с инверсией половины (≈ 1 100 сделок, без нового прохода рынка, В-213); затем одна таблица Σ$ по месяцам с фильтром/без.

## 4. Правило вердикта (до счёта, назначаемое — утверждает владелец)
«Фильтр держится», если на половине B одновременно: (1) Σ$ сделок с σ240 < 94,2 отрицательна в ≥ 6 из 9 мес. и в агрегате; (2) Σ$ B с фильтром > Σ$ B без него в ≥ 6 из 9 мес.; (3) нижний край 90 % bootstrap по суткам для разности (с фильтром − без) > 0. Иначе — «не подтверждено ≠ опровергнуто». < 30 сделок/мес. в Q1 B — «совместимо с».

## 5. Шум и честность
Порог выбран по 36 группам (9 признаков × 4 квартиля) × 2 рынка → без проверки вне подбора вывода нет. Половина B независима по монетам, но не по времени (общий режим рынка): вывод ограничен янв–сен 2026. Спот-совпадение — подтверждение направления, не независимый тест (те же месяцы). Влияние фильтра на n входов (~−25 %) и на комиссионный выигрыш — описательно, в отчёте.

## 6. Ресурс
Calc, один скрипт-проход по ленте половины B (по замеру tk327 half A) + расчёт на ПК; код Rust не нужен.
