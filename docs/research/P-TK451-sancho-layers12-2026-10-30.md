## 3. Определения и оси титрования

Все расстояния в вычислении — bps от цены; ATR — единица автора только для воспроизведения слоя 1 (в отчёте дублируется в bps).
Якорь = ближайшее к тексту автора (подчёркнуто); остальные значения — титрование. Кривые по осям (одна ось за раз от якоря =
OAT), полная декартова сетка — только по {k, исход X, N}. Всё в сетках — описательно, вне семейства (рамка §7).

**Уровень (пул):**
- L-S(k): свинг-хай/лой k свечей по каждую сторону, **k ∈ {1, 2, 4, 8}**, якорь k = 2 (14:27). Уровень известен с бара i+k
  (подтверждён) — до этого его нет (нет заглядывания вперёд).
- L-E(τ): «равные экстремумы» — два подтверждённых свинга одного знака, различающиеся ≤ τ; уровень = крайний из них;
  τ ∈ {нет, ATR14·{1/8, 1/4, 1/2}} в bps. Якорь — «нет» (пул = одиночный свинг).
- Жизнь уровня: до первого касания (без ограничения). Касание: **строго** (h > L для хая; якорь) | нестрого (h ≥ L).
- «Первое касание» = первый бар после подтверждения, чей диапазон достигает уровня; уровень после этого расходуется.
  Чувствительность: любое касание (не только первое).

**Класс бара-касания t (для хая-уровня L; лой — зеркально):**
- пробой: close_t > L; глубина d = (close_t − L), в ATR14 (A2–A4: <0,2 | 0,2–0,5 | >0,5 — числа автора) и в bps;
- свип: h_t > L и close_t ≤ L (якорь) | вариант «тело»: max(o_t, close_t) ≤ L;
- остальное (касание без выхода) — отдельный класс (проверка 98 тыс.).
- ATR14: **TR-SMA (якорь)** | Wilder | SMA(h−l); на баре t−1 (известно до касания; якорь) | на баре t (включая касающийся).

**Исход (от момента, когда условие известно — см. §4):** t0 = закрытие бара подтверждения, p0 = close этого бара;
**N ∈ {1, 2, 4, 8, 16, 32} баров ТФ** (сетка ×2; горизонт не назван — титруем). Для свипа хая ожидаемая сторона = вниз
(«разворот»), для пробоя хая = вверх («продолжение»); обозначим «вдоль события» = ожидаемая сторона.
- X1 «состояние»: close_{t0+N} по ожидаемую сторону от L (для свипа — не за L; для пробоя — за L).
- X2 «удержание» (дополнительность 62,2 + 37,8): для свипа — ни один close в (t0, t0+N] не закрыт за L (иначе «стал пробоем»);
  для пробоя — ни один close в (t0, t0+N] не вернулся к L или ниже. **Якорь X2** — единственное прочтение, где
  «разворот + пробой = 100 %» выполняется по построению.
- X3 «ход»: первым достигается m·ATR14 (в bps, на t) в ожидаемую сторону от L либо возврат за/на L; m ∈ {1/4, 1/2, 1, 2}
  (×2); порядок внутри бара — по минутам; ничья по горизонту N (без достижения) = «нет».
Верный выбор — не отбор по результату: каждая из X1–X3 × N даёт кривую; «воспроизводится при …» = область осей.

**Имбаланс (A6):** тройка баров (i, i+1, i+2), бычья (ожидается разворот вверх после свипа лоя): high_i < low_{i+2};
медвежья — зеркало (low_i > high_{i+2}); размер щели g = low_{i+2} − high_i. Известна по закрытию бара i+2.
Оси: окно **K ∈ {3, 4, 8, 16}** баров от бара свипа t (i + 2 ≤ t + K − 1; якорь K = 3: i = t — «сразу»);
начало i: i = t (якорь) | i ∈ [t, t+K−3]; g ≥ {>0 (якорь), ATR14·{1/8, 1/4, 1/2}}; зеркало для свипа хая (автор его не назвал): применяется (якорь) |
не применяется (имбаланс только после свипа лоя; свипы хая в A6/A8 исключаются).

**Слом структуры (A7):** после свипа хая — закрытие (якорь) | тень ниже последнего **подтверждённого к моменту t** свинг-лоя
порядка k (k = 2; ось k как в уровне); окно K ∈ {1, 2, 4, 8, 16} баров после t (якорь K = 1 — «сразу»). Свинги, созданные
внутри окна, в якоре не учитываются (вариант: учитываются).

**Все три (A8):** свип ∧ имбаланс ∧ слом, оба в окне K; t0 = закрытие бара, где выполнено последнее условие.

## 4. Слой 1 — воспроизведение (без подгонки)

Считается для 1H (заявления только по нему), все монеты и отдельно BTC+ETH (A4); для каждой ячейки области осей — доля
(A1–A8), N и доля класса. **Допуск** на цифру автора = полушаг последнего знака его числа (61 % → ±0,5; 62,2 → ±0,05;
66,5 → ±0,05; 84,1 → ±0,05; 89 → ±0,5; 91,6 → ±0,05; доли 28,2 / 28,8 / 15 — тем же правилом), плюс интервал бутстрепа
(день-кластеры, §6) — **попадание = интервал ячейки пересекает допуск**. Число ячеек — K_grid — пишется в заявку до счёта.
Вердикт по заявлению (запись заранее):
- **воспроизводится при …** — есть непустая область ячеек (определения названы), попадающих в допуск; ширина области
  (ячеек из K_grid, какие оси её держат) пишется всегда; **одной ячейки мало** (случайное совпадение в сетке) — нужна
  связная область по соседним значениям хотя бы одной оси, а при единственном «острове» — «не различимо»;
- **не воспроизводится ни при каких разумных** — ни одна ячейка не пересекает допуск, разброс по осям вокруг цифры
  показан (минимум/максимум по всей сетке);
- **не различимо** — иначе (остров, или допуск пересекается только на краю области/по одному ТФ).
Совместность: отдельно — существует ли **одно** определение, воспроизводящее A1–A8 вместе (пересечение областей);
если пусто — «не одним определением» (само по себе не оспаривает отдельные числа).
Диагностика (не критерий): N автора против нашего (A1 239 тыс., A5 444 тыс., A6 125 тыс., A7 128 тыс., A8 68 497, всего
781 692) — какие определения уровня дают его общий счёт; его остаток 98 тыс. против нашего класса «касание без выхода».
Для слоя 1 условие считается как у автора (с исходом от касания, возможно с заглядыванием — это и воспроизводим); честная
проверка — слой 2.

## 5. Слой 2 — честная проверка

**Момент знания:** исход считается от t0 (закрытие бара, где условие стало известно) — для A1–A5 t0 = закрытие t; для A6/A7/A8
— закрытие бара подтверждения; горизонт N отсчитывается от t0, цена отсчёта p0 = close_{t0}; ничего из (t0, ∞) в условии.
Сравнение «с условием» против «без условия» — **на одном и том же t0 и среди не решённых к t0**: базовая группа =
свипы того же ТФ, у которых к t0 исход ещё не определён (не было закрытия за L; для X3 — не достигнуто m·ATR) и условие не
выполнено в окне. Иначе заявленные 84/89/92 % включают исходы, решённые до подтверждения (механическая выживаемость).

**Контроли (сопоставимые по волатильности), все — тот же код событий:**
- C1 «случайные уровни»: для каждого реального уровня L (бар касания t) — до 5 псевдо-уровней: хай/лой несвингового бара той
  же монеты/ТФ, того же возраста (бары от формирования до касания) и первое касание которых случилось в ±30 сут от t,
  ATR14_bps касающегося бара в пределах ×2 вниз/вверх от реального; детерминированно md5, seed 451.
- C2 «бар без условия»: бары той же монеты/ТФ, того же часа UTC (для 1D — дня недели), ±30 сут, не содержащие касания
  свинг-уровня (ни реального, ни псевдо), ATR14_bps в пределах ×2; псевдо-уровень = хай/лой предыдущих k+1 баров
  ровно так, как реальный свинг-уровень; события A1–A8 применяются тем же кодом.
- Базовая группа выше (§5 «момент знания») — для A6–A8.
Метрика: **разность долей** Δ = p_событие − p_контроль (контроль — медиана по контролям события; события без контроля не
входят, воронка), и p_контроль самой по себе (ориентир: что даёт случайная ячейка без структуры).

**Срезы:** по годам 2020…2026 (отдельно), по монетам (таблица всех 84), BTC и ETH отдельно (и BTC+ETH вместе как у автора),
по ТФ (1H, 4H, 1D, 15m), по направлению (хай/лой). Монета с < 8 событий в срезе и срез с < 5 монет — «нет данных».

**Независимость и интервалы:** кластеры = календарный день UTC (все монеты дня — один кластер: рыночные дни коррелируют);
бутстреп по кластерам, B = 4000, seed 451, p = 2·min(доля ≤ 0, доля ≥ 0) + 1/B (как рамка §5); вторая оценка — по монетам
(кластер-монета) как проверка; эффективное N (кластеры) пишется рядом с сырым N. Корреляция монет — доля дней, где у ≥ 2
монет событие в одну и ту же минуту (отдельная строка воронки).

**Семейство (число до счёта):** строка = (заявление A1/A4/A5/A6/A7/A8 в якоре и в лучшем по слою 1 определении) ×
(ТФ ∈ 1H/4H/1D) × (направление ∈ хай/лой) × (исход X1/X2/X3 при N якоря). Якорь N — выбирается слоем 1 **до** просмотра
контролей и не пересматривается; K = 6 × 2 × 3 × 2 × 3 = 216 строк; Холм по семейству. Кривые по осям, срезы по годам/монетам,
15m — описательно, вне семейства; накопленное число испытаний по задаче ведётся в `docs/plan/EXPERIMENTS.md`.

**Вердикт по строке (записан заранее):** *подтверждено* — нижняя граница интервала Δ (по Холму) > 0 **и** знак Δ одинаков в
каждом году с N ≥ 8 и ≥ 5 монет (рамка §5) **и** знак совпал против обоих контролей C1 и C2; *оспорено* — верхняя граница ≤ 0
при тех же двух проверках; иначе *не различимо*. Заявление «цифра автора (напр. 84 %) верна» отдельно: верна, если цифра
автора попадает в интервал нашей доли при ближайшем определении **и** вердикт строки — подтверждено; доля при условии, но
Δ ≈ 0 против C2 — «воспроизводится как арифметика, не как преимущество».

## 7. Сдача и алгоритм

`docs/findings/sancho-<дата>.md` (первая таблица: заявление → наш результат при ближайшем определении → вердикт, числа
1H; затем слой 2, срезы, воронка, смещение выжившего, оговорки) + `sancho-<дата>-layer1.csv` (ячейка осей × заявление),

монете: бары ТФ → уровни → касания → классы → исходы по сетке), счёт на calc через alsched NX=15; прогон > 15 мин —
`calibrate.sh` (В-178); пилот BTC/ETH 1H на малом (скорость и корректность) до боевого. Алгоритм: варианты — (а) питон-циклы
по событиям; (б) numpy-векторизация уровней/классов по монете + кумулятивные максимумы/минимумы для исходов по всем N за
один проход; (в) полная декартова сетка против OAT; замер — на BTC 1H до выбора; выбран — (б) с OAT + декартовой по {k, X, N}
(объём сетки ∝ ячейки × события), потому что (а) на 4,4 млн баров × сетка не укладывается в калибровку, а полная декартова по
всем осям — сотни тысяч ячеек без добавочной информации (оси почти ортогональны, проверяется OAT-кривыми).
