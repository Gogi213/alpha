Заморожено коммитом до счёта. Зеркало `P-TK414-ob200-2026-10-27.md` на стакане Gate: те же признаки ob_dz / ob_imb / ob_sp, те же правила O1–O5 (пороги 1/3, 0,1, 3 не менялись), база 360 мин до окна B, срез события — конец минуты floor(t)−1, события θs=5 (5half не читать), мера и вывод прежние (`tk414-obsum.py`), торговых выводов нет.

**Данные:** calc `/data/tk415/ob/gate/gate-fut/<SYM>/` (TK-415: 220 486 час-файлов, пропусков нет, 429/403 нет). Час-файл = snapshot (`set`) + `make`/`take`, знак size: + бид, − аск; книга каждого часа строится с нуля (`tk414-obmin-gate.py`, формат срезов как у Bybit: минута,bb,ba,dB25,dA25; 25 бп — как в пилоте и ob200). Действия `make`/`take` суммируются без отсечки отрицательных (как пилот слоя 3, принят Судьёй); уровни с q ≤ 0 в срез не входят.

**Популяция:** события Gate `futures_usdt` из `flow/flowgate2-events.csv` (22 инстр., вариант 5; спот — отдельно не считается, книги спота — второй проход, не в этой сдаче), с историей ≥ 360 мин (surge). Ноги — `flowgate2-legs.csv`, формы — `pump-dump-scenarios-legs-2026-10-27.csv`.

**Правила и число испытаний:** O1–O5 × 2 разворота = 10 (+ контроли: свечи, главное B; R5 для Gate не считается — OI Gate не считался, строка вырождена и исключается из сравнения).

**Не меряется (оговорки):** OI Gate; спот; глубина за 25 бп; события без срезов (нет часа/базы < 60 срезов/последний срез старше 5 мин) — считаются отдельно как «без признака».
