# P-TK472 — кор монет (устойчивое ядро, на котором выходы Санчо/bp/S дают плюс)

Записано 31.10 до просмотра результата. Данные: `d2b-out{,-bp,-bp3,-s}` (calc), сводка `tools/compute/tk472_core_agg.py` — без пересчёта ядра (В-213).
Протокол TK-461 не менять. Слова владельца: «может есть конкретный пул монет который торгуется в плюс?», «окей найди кор из всех этих монет».

## 1. Единицы
- **Конфиг** = ключ ячейки (tf, ev, dir, stop, take, par, be_r, ot, otp) в одном из источников (sancho, bp, bp3, s). Сигнал = (src, tf, ev, dir); выходов на сигнал много.
- **Плюс** монеты в конфиге на окне = сделок n ≥ 5 и средний net за сделку > 0 (bps, после издержек ядра). Конфиги с n < 5 у монеты в окне не считаются.
- **Доля плюса f(монета, окно)** = плюсовые конфиги / конфиги с n ≥ 5. Подбора лучшего выхода на монету нет: считаются все конфиги.

## 2. Окна (md5 из P-TK461 §8)
- **Отбор** = сделки ≤ 2023 всех монет (чётные = «открытие»; нечётные = «xb»). Отступление от тикета: одно «открытие» покрывает лишь чётные монеты, поэтому для нечётных отбор идёт по xb; обе части показываются в отчёте отдельно.
- **Проверка** = сделки 2024+ (нечётные = «проверка»; чётные = «xa»), монета в отборе не участвует. Это вперёд по времени.

## 3. Правило кора (числа назначены здесь, не подобраны по данным; методика — Судья)
Монета в коре, если на окне отбора одновременно:
1. f ≥ 0,80 (доля плюсовых конфигов; свободное среднее по рынку CEO-пробой ~0,74 — порог выше него);
2. ≥ 2 источников из 4 с f_источника ≥ 0,60 при ≥ 20 конфигов с n ≥ 5 в источнике (много сигналов сразу);
3. сводный net за сделку (Σb/Σc по всем конфигам монеты, ≤ 2023) > 0 и нижняя граница интервала > 0: интервал — по суткам UTC как кластерам (отношение сумм).
Число испытаний: проверяются все монеты пула (≈ 80–90) — Холм не нужен для правила 1–2 (порог, не p); для п.3 интервал 95 % без поправки, указать.

## 4. Вердикт кора (на проверке 2024+)
- Кор «держится», если на 2024+: f ≥ 0,60 и сводный net > 0, **доля монет кора с f > 0,5 ≥ 0,75**, и это выше, чем у не-кора (разность долей, интервал Уилсона).
- Контроль «кора не отбирает шум»: то же правило на случайном делении (перестановка метки монет, 200 раз): доля попавших в кор при случайной метке; кор значим, если реальная доля монет с f>0,5 на 2024+ выше 95-го перцентиля случайных наборов того же размера.
- Иначе «не отличим от рынка».

## 5. Выход
`docs/findings/core-coins-2026-10-31.md` (простыми словами сверху: список кора, монета / сделок / net по годам / доля конфигов в плюсе, кор vs не-кор по ликвидности, возрасту листинга, волатильности — описательно) + `core-coins-2026-10-31.csv` (все монеты).
Описательные признаки не подбираются и в правило не входят. Ограничение: интервалы по монете — сводные по сутки-кластерам; конфиги одной монеты делят сделки (зависимы), поэтому доля конфигов — мера устойчивости, не независимое число испытаний.
