## 1. Постановка

Разрыв пары `d_t` — как в П-40 §3 (`d⁽¹⁾`: `ln(mid_A/mid_B)` минус уровень `P̄_L`; запасной `d⁽²⁾`). Эпизод: вход при `|d| ≥ θ_t`, выход при `dir·d ≤ q·d_вход`, `q ∈ {0; ¼; ½}` (П-40: ½). Снимаемый разрыв по построению — `(1−q)·|d_вход|` (bps номинала ноги).

**Издержки эпизода** `K_t = C_fee + s_вх + s_вых,t`:
- `C_fee` — круг по тарифу Bybit (В-88): **8,82** bps (вход мейкером 2×1,26 + выход тейкером 2×3,15) — ведущая; 5,04 (всё мейкером) и 12,6 (всё тейкером) — печатаются рядом;
- `s_вх = 0` (мейкер стоит на своей стороне); `s_вых,t = (spr_A + spr_B)/2` по **текущему** L1 на момент `t` (медиана спреда за час — только справкой).

**Пол:** `Φ_t = max(Φ, K_t)`, `Φ` — число сетки (полный пол «издержки + маржа»); подразумеваемая маржа `m_t = Φ_t − K_t ≥ 0`. Вход только при `(1−q)·|d| ≥ Φ_t`, т.е. `θ_t ≥ Φ_t/(1−q)`.

**Д-1 (владельцу через `CEO`):** «условно 20» = полный пол `Φ = 20` (при `C_fee` 8,82 маржа ≈ 11,2 минус спред выхода); второе чтение — 20 сверх издержек (≈ 29) — в сетке. Сетка `Φ ∈ {20; 29}` для адаптивных кандидатов, `{15; 20; 29; 40}` для чистого пола A0.

## 2. Кандидаты порога входа

`θ_t = max(Φ_t/(1−q), S_t)`; `S_t` — масштаб «нормального» разрыва пары, **только по прошлому** (окно до `t − 1 с`).

| № | правило | сетка |
|---|---|---|
| **A1** | **контроль: фиксированный `θ` = 12,6 bps, БЕЗ пола** — ровно как `p40-d1-naive` (438 640 эпизодов); пол не применяется | `q` |
| A0 | чистый пол: `θ_t = Φ_t/(1−q)` | `Φ ∈ {15;20;29;40}`, `q` |
| A2 | `S_t` = скользящий квантиль `|d|` за окно `W` | `W ∈ {1;6;24} ч`, `p ∈ {0,90;0,95;0,99}` |
| A3 | `S_t = med(d) + k·1,4826·MAD(d)` за окно `W` | `W` как в A2, `k ∈ {3;5}` |
| A4 | EWMA-квантиль (стохастическая аппроксимация, O(1) на тик) | полураспад `{1;6} ч`, `p` как в A2 |
| A5 | A3 раздельно по режиму: класс (крипта / TradFi) × терциль 5-мин волатильности подвижной ноги; пересчёт `W,k` без предвыбора | `W`, `k` как в A3 |

## 3. Выбросы: мусор против настоящего всплеска

Флаги, на входе и при обновлении `S_t`:
1. спред любой ноги ≥ `X_s`; **в подборе `X_s = 50` bps** (середина сетки `{30;50;100}`; на `p40-d1-naive-masked` итог +10,8/+11,2/+11,5 — слабо зависит), остальные — чувствительность выбранной клетки (не в `m`);
2. возраст лучшей цены ноги `> S_max`; 3. одиночная котировка: нога не обновлялась `> u` при движении другой ноги.

**Правило вывода `S_max` и `u` (без чтения `net`):** `S_max` = квантиль 0,99 распределения возраста лучшей цены ноги по классу (крипта / TradFi) на подборе-днях D1 (G0); `u` = квантиль 0,99 распределения «возраст цены ноги в моменты, когда mid другой ноги сдвинулся ≥ 1 bps». Чувствительность выбранной клетки: квантили `{0,95; 0,99; 0,999}`. Первые 10 с часа UTC — только флаг справкой.

**Правило:** флагованный тик не входит в окно/квантиль `S_t` и не открывает эпизод. Настоящий всплеск (спред в норме, обе ноги свежие) торгуется, печатается отдельно: доля, `ȳ`, МПУ. Проверка (разметки «правды» нет): доля под флагом; `ȳ` и МПУ у отсечённых против оставленных; дрейф `S_t` с отсечкой и без; число эпизодов, где отсечка меняет решение.

## 4. Догоняющая нога и исполнение

Разрыв закрывает нога, которая **отстала** (по П-40: за 10 с двигался mid только одной ноги — она лидер). Правило задаёт сторону: на отставшей — в ту сторону, куда она должна пойти; на лидере — хедж.

- **E1 (верхняя оценка, потолок):** обе ноги мейкером по цене t0, без очереди (В-125), ликвидность ≥ 100 $. **Ведущей для вывода не служит.**
- **E2 (ведущая для вывода):** заявки на лучшей цене `t0 + L`, исполнение — только если цена подошла (сделка/пересечение), `L ∈ {0; 500 мс; 2 с}`; нет исполнения = 0 (ITT).
- **E3 (справкой):** тейкер на отставшей ноге — правило 08.11 запрещает; только «что теряем, не беря», без вывода.

Печатается на кандидата и `E`: доля исполнения, снимаемый разрыв, результат после комиссии, **доля «лидер определён неверно»**: эпизод, где за время входа→выхода на ход mid отставшей (по правилу) ноги пришлось **≤ ½** `|Δd|` (иначе разрыв закрыла она — «закрыла» = > ½ `|Δd|`).

Нужно от ядра (TK-522): L1 `qty` на t0/t_end, bid/ask на t0, t_end, t_peak, `H=600`. **Без них E2 и 100 $-фильтр не считаются, вердикта нет (§7).**

## 12. r2: канал по В-130 (центр ± полуширина, вход на границах, выход у центра)

**Решение владельца (В-130, дословно):** «глянь вот ответ из другого чата. считаю разумным» — подход: канал = центр EMA раздвижки ± max(пол ≈ 21 bps, k·StdDev), вход на границах, выход у центра; защита от смены режима (v_max, предел доборов, остановка при долгом выходе за границу); на истории сравнить фиксированный канал 21–30 bps с лесенкой K, EMA±k·σ и Калмана; в робота Viking — победитель; при равенстве — фиксированный канал. От CEO (по критику, не владелец): вариант с робастным масштабом.

**Определения.** `d_t` — раздвижка П-40 §3 (`d⁽¹⁾`, bps), центр `c_t` (только по прошлому, до `t − 1 с`), полуширина `w_t`. Вход «продать раздвижку» при `d − c ≥ w`, «купить» при `c − d ≥ w`; выход — когда `d` вернулось к `c_t` (`q'=0`; `q'=¼` — чувствительность). Пол: `w_t ≥ Φ = 21` bps (= `C_fee` 8,82 + спред выхода ≈ 3 + запас ≈ 9; Д-1 Судьи: пол 21 — главный, 29 — чувствительность). Снимаемый разрыв `≥ w_t(1−q') ≥ 21` при неподвижном центре; сдвиг центра за эпизод печатается (`c_вых − c_вх`).

**Кандидаты** (одинаковые флаги мусора §3 до обновления `c`, `σ`):

| № | центр `c_t` | полуширина `w_t` | сетка | клеток (лестница нет / `K`=10) |
|---|---|---|---|---|
| **F** | фиксированный — уровень `P̄_L` П-40 (`c=0`) | `w` | `w ∈ {21;25;30}`; лестница: доборы на `w + j·K`, `K ∈ {5;10}`, `j ≤ 3` | 3 + 3×2 = **9** |
| **E** | EMA `d`, горизонт `τ ∈ {10 мин; 1 ч; 6 ч}` | `max(Φ, k·σ_EWMA)`, σ — EWMA-СКО с тем же `τ` | `k ∈ {1,5;2;3}`; лестница нет / `K=10` | 9 × 2 = **18** |
| **R** | EMA `d`, как E | `max(Φ, k·1,4826·MAD)` по окну `W = 6τ`, медиана/MAD по скользящему окну | как E | 9 × 2 = **18** |
| **Kal** | контроль: скаляр Калмана, постоянные `Q,R` | — | не в сетку | 0 |

**Калман-контроль:** скаляр с постоянными шумами в установившемся режиме = EMA с `α_∞(Q/R)`; проверка тестом — центр Калмана при `α_∞ = α(τ)` совпадает с E-центром (макс. расхождение на сутках ≤ 0,01 bps после прогрева). Совпал — Калман не отдельный кандидат (в сетку не входит, в таблицу — строка «≡ E»). Калман с адаптивным `R` (по инновации) — не считать без слова владельца.

**Защита от смены режима** (числа выводятся по прошлому и по распределениям, **без чтения `net`**; стопа цены нет — правило 08.11 в силе):
1. **`v_max`:** вход/добор запрещены, если `|d_t − d_{t−60 с}| > v_max`; `v_max` — квантиль 0,99 распределения `|Δ60 с d|` по классу (крипта / TradFi) на подборе-днях D1; чувствительность `{0,95; 0,99; 0,999}`.
2. **Предел доборов:** `j ≤ 3` (≤ 4 доли на пару в одну сторону).
3. **Остановка:** `d` за границей (`|d−c| > w`) непрерывно дольше `T` → новые входы и доборы запрещены, пока `d` не вернулось внутрь на `T_рест = T/2`; **открытая позиция не закрывается принудительно** (нет стопа) — доля эпизодов в остановке и их `ȳ` печатаются; `T` — квантиль 0,99 распределения длительности «за границей до возврата к центру» (D1 подбор, класс); чувствительность `{0,95; 0,999}`. Принудительное закрытие по `T` — только чувствительность, справкой (это стоп, владелец 08.11).

**Исполнение как в Viking (§9), E-V ведущая; E1 — потолок:** первая нога — лимитка на лучшей цене своей стороны (котирование), исполнение только когда цена подошла (сделка/пересечение), `L ∈ {0; 500 мс}` (как E2 §4); вторая — лимитка по лучшей цене стороны, `k_отст = 0`, после сделки по первой с задержкой хеджа `δ_h ∈ {300 мс; 1 с}`; не исполнилась за `T_хедж = 2 с` — хедж «по рынку» (тейкер 3,15 bps + проход до лучшей цены, как `Hedge (sec)`); нет исполнения первой ноги = 0 (ITT). Какая нога первая: ведущая — **с большим медианным спредом за прошлый час** (котируем там, где спред шире), справкой — первая = отставшая нога (§4). Комиссия по ногам: мейкер 1,26 / тейкер 3,15 (В-88), круг — три `C_fee` как §1. **Фандинг:** ∑ ставка × нотионал × знак ног за удержание по mark/funding выходов ядра/CHFT; нет данных по паре — строка «фандинг не учтён» и клетка по ней справкой (П-38: −10,2 bps на сделку — фактор первого порядка).

**Метрики** — §5 плюс: число доборов на эпизод, время удержания (медиана, p95), доля эпизодов в остановке, доля `|c_вых − c_вх|` > ½ `w`, незакрытое на конец окна — усечение П-40 §2.2, доля печатается. **Правило выбора (В-130 «при равенстве — фиксированный»):** допуск — как §7 (`n_мин` = 30, ≥ 5 активов, Холм 0,05 на `m` = 222, доля под полом = 0). Лучшая допущенная клетка семейства F — `F*`; лучшая допущенная адаптивная (E/R, и A2–A5 r1) — `Ad*`; обе — по наибольшей нижней границе 90 % bps/сутки/пару на D1 (E1). **Адаптивный `Ad*` берётся вместо `F*`, только если нижняя 90 % граница парной разности `Ad* − F*` (актив×сутки, D1) `> 0`;** иначе — `F*` («не лучше фиксированного — берём фиксированный»). Нет допущенных F и адаптивных — «канал на D1 не доказан» (D2 не открывается, A0/F0 `w=21` справкой). Далее — §7: перечитать выбранную клетку на E-V (все `L`, `δ_h`, три `C_fee`) и один раз на D2 (выбранная, `F*`, `A0 Φ=21`, `A1`); те же слова «в плюсе / в минусе / не различимо» и «лучше F* / A0 / A1» (нижняя граница парной разности на D2 `> 0`).

**Алгоритм (В-170):** F без лестницы и `A0` — это ядро П-40 при `θ = w`, `q = 0` без правки (после TK-526 `P40_Q`); лестница `K` = сумма эпизодов с порогами `w + j·K` и общим выходом у центра — эквивалентность проверить тестом против одиночных эпизодов (число и `net` на 1–2 сутках × 20 активов); E/R требуют центра `c_t` в ядре (`d' = d − c_t`, `θ_t = max(Φ, k·σ_t)` на `d'`) — **дополнение к TK-526 (Инженеру)**: EMA/EWMA-СКО O(1) на событие, медиана/MAD по окну (Fenwick, как A3), остановка и `v_max`. Сетка Python отвергнута §8 (замер: теряет 60–90 % эпизодов). Строка «Алгоритм: варианты; замер; выбран потому что» — в отчёте.
