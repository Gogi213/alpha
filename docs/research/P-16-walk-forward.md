# П-16. Walk-forward (Г-02): подбор на прошлых месяцах — проверка на следующем, не виденном — ЧЕРНОВИК

Статус: **черновик Исследователя 16.10 (TK-275, В-29); → приёмка Судьёй → цитата владельца через CEO. Ничего не считается до цитаты.** Опора: П-14 §4–5, §11 (сито, плато, А/Б), П-15 §5 (Г-03, три исхода), П-12 §7/§9 (DSR/PBO), В-115, В-211, В-213, В-224. Это **метод проверки, а не торговая идея** (Г-02: «режим, ну хз» — механизма нет, ожидание «не различимо» записано в §2).

## 1. Вопрос и решение
- Вопрос: **выбирает ли процедура подбора П-14 (сито → центр зоны) на месяцах до N клетку, которая на месяце N, не виденном при выборе, лучше B1 и лучше случайной клетки той же семьи?** Объект проверки — *процедура выбора*, не конкретная клетка.
- «Держится вперёд» → метка в Летописи на семье; принятым/финалистам — довод «выбор не подгонка» рядом с Г-03 (это про параметры, Г-03 — про причину). «Не держится» → красная метка семье: подбор по П-14 на этой оси ничего не предсказывает, вывод «в отбор» сохраняется только как описание. «Не различимо» → без метки, печать интервала и достижимости (нет мощности — нет вывода).
- Протокол **ничего не отбирает и не отбраковывает сам**: контроль в духе Г-03, не поиск. В Холм П-14/П-15 не входит, N П-14 не растёт (клеток новых нет).

## 2. Механизм и ожидание
Механизма нет: тест устойчивости выбора. Предыдущее знание (TK-180, `early-prune-assessment-2026-10-11.md`): ранг клетки по первым 1–4 месяцам против авг+сен — Спирмен −0,51 … +0,05, т. е. ранние месяцы годность не предсказывают. Честное ожидание: **«не различимо» или «не держится»**; «держится» было бы находкой, требующей проверки Судьёй на подгонку. Записано до счёта.

## 4. Что заморожено
- **Процедура выбора на обучающем окне = §11.2 п. 1 П-14 дословно:** кандидаты — определённые клетки (≥ 20 сделок, ≥ 10 суток на обучении, m применён); центр = клетка с минимальным односторонним p (парная ΔSR_норм к B1, блочный бутстреп по суткам, блок ⌈n^{1/3}⌉, 20 000 повторов, seed фиксирован); ничья — больший ΔSR, затем больше суток со сделками, затем ближе к прежнему значению оси. Если годных (p ≤ 0,20) нет, центр — по тому же порядку среди определённых (при ΔSR ≤ 0 все p = 1 ⇒ решает ΔSR). Плато в WF не требуется: проверяется выбор, а не плато; метка «центр на плато/нет» печатается.
- **Окно подбора — растущее (expanding), от 01.01 до конца месяца N−1; минимум 3 месяца; шаг — 1 месяц.** Тестовые месяцы: **апр, май, июн, июл, авг, сен** (6 фолдов). Скользящее окно не используется (месяцев мало, а TK-180 показывает, что ранние месяцы шумят — растущее окно усредняет шум; сравнение вариантов окна = лишний перебор, не вводится).
- **Монеты — все** (без деления на А/Б): защита от подгонки здесь — время, а не монеты; деление вдвое отняло бы мощность. Следствие: отбор WF ≠ отбор П-14 (А-половина); результаты не смешиваются, а сопоставляются (§7).
- **Семьи (m):** гипотезы, у которых в Летописи на дату заморозки JSON ≥ 5 определённых клеток по общей оси и есть посуточные closes. На 16.10 это 10 из 14 гипотез сита с определёнными клетками (Г-10, 112, 117, 114, 110, 104, 129, 119, 65, 133); Г-87/92/93/95 — «не определена (m не применён: нет нотионала)» — **не в WF, p = 1**, пока Инженер не закроет дыру нотионала (П-14 §11.6). **Принятые/финалисты — это ровно эти семьи плюс семьи П-12/П-13 (g93, g94 …), поэтому на g93 WF становится возможен только после закрытия дыры m** (оговорка, а не пропуск). F2/F3 клетки добавляются в семью по мере счёта (только дельта, В-213), перезапуск WF — только на дельте клеток. **m фиксируется в `P-16-scope.json` до первого фолда и не уменьшается.**

## 5. Метрика и статистика
- Основная: **склеенный OOS-ряд** — для каждого фолда посуточные $ выбранной клетки и B1 в тестовом месяце, склеены в один ряд (≈ 183 суток); **ΔSR_норм (клетка − B1)** на нём (Шарп по календарным суткам, равная экспозиция П-12 §6(2), как сито).
- Вторая: **выбор против случайного в семье** — Δ_с = SR_норм(выбранная) − SR_норм(медианная клетка семьи, среди определённых на обучении), на том же склеенном ряду: «подбор лучше жребия». Отвечает именно на вопрос В-29.
- Для обеих — парный блочный бутстреп по суткам (блок ⌈n^{1/3}⌉, 20 000), p односторонний по центрированному Δ*; **p семьи = max(p_B1, p_жребий)** (пересечение гипотез — поправки внутри семьи не нужно), затем **Холм по m семьям** (α = 0,05).
- Печать (не ворота): по каждому фолду — выбранная клетка (хеш, значения оси), p обучения, ΔSR и Δ$ к B1 и к медиане на тесте; число фолдов с Δ > 0 (из 6); устойчивость выбора (сколько раз подряд выбрана одна и та же клетка/зона; доля смены центра); KPI «до перехая» (В-120) склеенного ряда; сделки и пик позиций; Спирмен ранга клеток «обучение ↔ тест» по фолдам (сопоставимо с TK-180); DSR (N по родословной П-12 §7) и **PBO (CSCV, П-12 §9)** на той же матрице клетки × месяцы — PBO симметричен по времени, WF причинен: расхождение печатается, не разрешается.
- Эфф. N — справочно (`scripts/effective_n.py`); t-статистика по сделкам не считается.

## 6. Достижимость (до счёта — шаг 0)
Скрипт печатает до чтения исходов: по ряду B1 на 183 тестовых сутках — минимальная обнаруживаемая ΔSR_норм при α = 0,05 (≈ 2,8·σ/√n в единицах Шарпа) и то же для Холма по m. **Если она больше правдоподобного эффекта (порядка ΔSR +0,03 у g93 на Б), протокол не отсекает ничего — это записывается в отчёт первым абзацем, вердикты «держится» заранее невозможны, возможны только «не держится»/«не различимо».** Пороги сита (p ≤ 0,20 и др.) не меняются.

## 7. Правило вердикта (до счёта; три исхода на семью, как П-15 §5)
- **«Подбор держится вперёд»:** p семьи ≤ α_Холма (§5) **и** ΔSR к B1 > 0 в августе и сентябре отдельно (В-115, ≥ 20 сделок в каждом) **и** C2 (без двух суток с наибольшей парной разностью и без монеты с наибольшим вкладом). Потолок формулировки — «выбор устойчив вперёд на янв–сен, внутри выборки»; «работает» не пишется.
- **«Подбор не держится»** (красная метка семье, решение владельцу): точечные ΔSR к B1 ≤ 0 **и** Δ_с ≤ 0 на склеенном ряду **и** ΔSR ≤ 0 в августе и в сентябре; опровержение не держится на одних-двух сутках/монете (проверяется, как для «подтверждено»).
- **«Не различимо»:** всё остальное (интервал накрывает 0 при положительной точке; смешанные знаки; достижимость §6 выше эффекта). Без метки; печать интервала и эфф. N.
- Смешанные результаты по семьям — по каждой отдельно, общего «ок» нет. Правило не меняется после счёта; чтение исходов один раз (повтор с другим окном/шагом — подгонка, запрещён).

## 8. Ворота до чтения
(а) **Сверка сумм:** Σ посуточных $ по каждой клетке-месяцу = `results.pnl_usd` Летописи (cap 0) в пределах округления; несовпадение — стоп. (б) **Причинность:** скрипт для фолда k получает только месяцы < k (проверка автотестом: подмена данных месяца k не меняет выбор фолда k); выбор фолда пишется в файл **до** загрузки тестового месяца. (в) **Те же клетки и вселенная,** что у сита (число клеток по семьям = таблица покрытия `tk237-grid-coverage`). (г) Воспроизводимость: seed бутстрепа фиксирован, два прогона дают тот же файл.

## 9. Как сочетается с остальным
- **С Г-03 (П-15 §5):** независимы и дополняют: Г-03 — «причина эффекта — стена?», WF — «выбор параметра переносится во времени?». Порядок: сито/финал Б (П-14) → Г-03 → WF. Метки Летописи отдельные; семья с «Не от стены» или «Подбор не держится» помечается красным независимо. Общий вывод «принять» не выводится из пересечения — решает Судья/владелец.
- **С DSR/PBO (П-12 §9):** они учитывают перебор *внутри* окна (PBO — случайные симметричные разбиения, использует будущее для выбора); WF причинен. Обе меры считаются на одной матрице, печатаются рядом, ворот не заменяют и друг друга не отменяют.
- **С сквозным счётчиком N:** WF — не новые клетки (ноль новых хешей); N П-14/П-15 не растёт, Холм П-14 не меняется. Своя m — только для этого протокола.
