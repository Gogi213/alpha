# G-015 — бюджет края: какие ручки могут дать заработок (черновик v1 для критики Судьи, 22.10)

Статус: **черновик Исследователя (TK-355), до подписи Судьи ничего из «назначаемого» не зафиксировано** (В-53). Задача владельца:
«откуда брать идж — какие ручки крутить, чтобы в теории заработать: комиссия, задержка, что-то ещё». Ответ — таблица
ручка × потолок × безубыточность × «стоит/не стоит». Это **не поиск края** (край B1 не доказан, Г-03), а бюджет: сколько bps
вообще может дать каждая ручка и хватает ли этого на издержки.

## 1. Каркас (переработка предложения CEO)

net круга = **S** сигнал (ход цены после касания, до любых правил) − **E** исполнение (спред, очередь, заполнение против нас)
− **F** комиссия − **L** задержка ± **X** выход (стоп/тейк/время) ± **O** отбор (какие сигналы брать) ± **Z** размер ± **R**
рынок/сторона/монета. Поправки к каркасу:
1. **Слагаемые не складываются.** E, L, X зависят от S и друг от друга (стоп решает, чем кончится сигнал; задержка меняет
   цену входа). Поэтому потолок ручки = «улучшаем **одну**, прочие — как есть (реальные)»; **сумма потолков ≠ потолок
   суммы** — в таблицу пишем только по одной ручке, сумму не выводим.
2. **Оракул-потолок — верхняя граница, не стратегия.** Лучший выход/отбор «с подглядыванием» всегда ≥ 0 по построению
   (максимум шума > 0). Поэтому «стоит» нельзя выводить из «потолок > 0»; только из «потолок > издержки **и** реальное правило
   берёт заметную долю потолка» (п. 4).
3. **Что внутри S.** `m_h` кэша касаний — markout «в сторону отскока» от `start_ms` (центр книги, без исполнения, без
   издержек); средний S ≈ 0 на всех горизонтах и силах (`docs/findings/touch-excursion-2026-09-18.md`) — значит весь «идж»
   B1 должен прийти из X/O/E, а не из S. Проверяем это числом по ячейкам, не принимаем.

## 2. Ручки: что считаем, из чего, что «не крутить»

| ручка | потолок = | источник | «не крутить», если |
|---|---|---|---|
| S сигнал | средний `m_h`, h = 100мс…2ч, по страте (месяц × первое/повтор × сила w20) | кэш касаний **готов** | |m_h| < издержек круга на всех h и месяцах |
| L задержка | кривая затухания: средний `m_h − m_d` при входе через d = 0,1 с/1 с/10 с/60 с | кэш касаний **готов** (без очереди); с очередью — проход 1 ячейки × RTT 1/10/100/1000 мс (**новый**, п. 5) | кривая при d≈0 уже < издержек: ускорять нечего |
| X выход | оракул-выход = средний `favour_H` (H = 60 с/10 мин/1 ч/2 ч) и доля касаний с `favour_H ≥ издержки` | кэш касаний **готов**; реальный выход — rounds TK-326 | оракул-выход − `adverse_H` (цена, которую платит стоп) < издержек |
| F комиссия | безубыточная комиссия на ногу f* = (средний gross круга B1) / 2 при maker+maker; сетка: тариф В-47 (5,625/6,75), VIP, ребейт | rounds B1 fut/spot **готовы** (gross = net + модель фьюча, как TK-326) | f* < 0 (gross ≤ 0): комиссия не причина |
| E исполнение | очередь оптимист/пессимист (`prob:n` vs `risk-adverse`); доля заполнений против нас (`fill_frac`, `legs`) | rounds (`fill_frac`, `legs_filled`) **готовы** — срез; сравнение моделей очереди — проход 1 ячейки (**новый**) | разница моделей очереди < 1 bps |
| O отбор | оракул-отбор = средний `m_10m`/`m_1h` верхних k % (k = 5/10/25/50) по страте; **реальный** отбор = верхний квартиль по признакам TK-327/329 | кэш касаний + TK-329 **готовы** | реальный признак берёт < ½ потолка, либо потолок < издержек |
| Z размер | проскальзывание/частичное заполнение при номинале ×0,5/×2/×10 (`--order-usd`, `prob:n`) | проход 1 ячейки (**новый**) | при ×2 net падает на ≥ эффекта (нет ёмкости) |
| R рынок | S, X, O по срезам: сторона, монета (ранг), σ240, режим, спот/фьюч | всё выше, срезами | срезы по тем же данным — только описание (G-013) |

Издержки круга (bps, тариф В-47): maker+maker 11,25; maker+taker 12,375; taker+taker 13,5; модель фьюча (а) ≈ 2,5–4,4
(`tk326-spot-loss-breakdown`). Порог «стоит» — запись в п. 4, число назначает Судья.

## 3. Правила честности (из G-013, действуют здесь)
- Месяцы отдельно (янв–сен), не пул; интервалы — по суткам как кластерам; n и n_дней в каждой клетке.
- Потолок печатается **с издержкой рядом** («потолок 18 бп при издержках 11,25 бп»), не голым.
- Число испытаний: ручек 7 × страт ≈ 8 × горизонтов 4–7; потолки — описание, **не** гипотезы; вердикт «стоит» требует
  отдельного протокола П-NN (утверждает владелец через CEO), здесь его нет.
- Оракул-отбор и оракул-выход помечены «подглядывание» в таблице; реальная доля потолка — отдельной колонкой.
- Срез не по признакам, выбранным по исходу этих же данных (TK-329 — «описание, не правило»).

## 4. Назначаемые числа (ПРЕДЛОЖЕНИЕ, фиксирует Судья до счёта)
- «стоит», если (потолок − издержки круга) > 0 в ≥ 6 из 9 месяцев **и** реальное правило берёт ≥ 50 % потолка (прочее — «не стоит»
  или «неясно», если n_эфф < 30 клеток-суток);
- k оракул-отбора: 5/10/25/50 %; горизонты: как в кэше; издержки — только тариф В-47 + публичный (б) + модель фьюча (а).
