## 1. Данные

Нет середины → цена исполнения ± ½ комиссии пула против направления, метка `mid_src`. Время события ts = блок/слот (разрешение секунда — оговорка в отчёте).
- **Видимость:** свопом можно пользоваться с `tv = ts + V`, V = 1000 мс главное, 2000/3000 — чувствительность (TK-409). Всё, что считается «после свопа», стартует от tv + L, L = 250 мс главное (0/100/500 — чувствительность). Ход X считается только по прошлому (ts).
- **Gate:** фьюч — gev2 `/data/tk0402/gev2/<COIN>/<час>.npy` (t_мс, bid, ask, bq, aq) + сделки мс; спот — сделки мс (`/srv/alpha-sda/tk372-gate/raw`). Значение на t = последняя запись ≤ t, возраст ≤ A (A = 5 с главное; 1, 30 — чувствительность). Дыры gev2 (15, 16, 19–21.10; нет файла / .n < 100) — вне, события в дыре не считаются.
- **Окно:** 15–22.10 (8 сут.), дни отдельно. 01.09–14.10 по 13 монетам практиков — только где есть событийный Gate (иначе «нет данных», не заполнять).
- **Классы:** P — 13 монет практиков (по монетам отдельно); H — тяжеловесы (BTC, ETH, SOL, BNB… — отрицательный контроль, в агрегат не входят); G — остальные монеты Gate с пулом (475 общих — по покрытию TK-402/407), один пул на монету — с наибольшим оборотом за окно, без обёрток/токен-акций. «13 монет без тяжеловесов отдельно, остальные» (слово владельца) = P и G раздельно; H — третьей строкой.
- **USD-ноги:** стейблы = 1; WBNB/WETH/WSOL — середина gev2 той же монеты на tv по правилу A.

## 2. События хода (общие для вопросов 1, 3, 5)
- Окна W ∈ {1, 5, 10, 30 с; 1, 2, 5, 10, 15, 30 мин; 1, 2, 4, 8, 12, 24 ч} (16).
- Для каждой (монета, W): якорь i = своп; ход X_i = s·ln(mid_i/mid_j), j = последний своп с ts_j ≤ ts_i − W и ts_j ≥ ts_i − 2W (иначе якоря нет). **X непрерывен: порогов нет, берётся каждый якорь.** Без перекрытия: следующий якорь той же (монета, W) — не раньше ts_i + W (жадно по времени, без выбора по величине — чтобы не отбирать по исходу).
- Знак: вверх/вниз отдельно (Gate спот — только лонг-нога, фьюч — обе).
- Отклик Gate (в направлении хода DEX): R_h = s·ln(G(tv+L+h)/G(tv+L)), горизонты h ∈ {1, 10, 60, 300, 3600 с} и h = W. G — середина gev2 (mid-to-mid, «отклик») и, второй строкой, цена-к-цене по касанию (вход по стороне против хода на tv+L, выход по противоположной на +h): «исполнимый». Спот — по последней сделке.
- Пред-ход Gate (R5): P_i = s·ln(G(tv)/G(ts_i − W)). Страты: P_i < 25 % X (Gate ещё не ушёл) vs ≥ 25 %. Главный отчёт — по первой страте; вторая рядом.
- **Контроль (R2):** случайные якоря той же монеты-дня с |X| ≤ нижнего квартиля |X| этой (монета, W), знак s = знак собственного хода, n = числу событий, сид фиксирован; та же R_h, тот же tv+L. Избыток = R_h(событие) − R_h(контроль), по монета-дням.

## 3. Вопрос 1 — порог реакции
- Кривая: |X| → избыток (бп) и доля хода (избыток/X) по 20 интервалам |X| (квантили по пулу класса, граница — на классе, не на монете), для каждой W и h = W (+ фикс. h), вверх/вниз, классы P/G/H, фьюч/спот.
- ДИ 95 %: бутстрап блоками «монета-день» (кластер — монета; в классе P 13 монет, эфф. N = число монет, не событий). Эфф. N по блокам в таблице.
- **Порог:** наименьший |X|, с которого нижняя граница ДИ избытка > 0 в двух смежных интервалах подряд; второй порог — то же для > 2,6 бп (нетто после двух мейкеров), третий — > 3,25 бп + реальный спред на tv+L для исполнимого отклика. Если порога нет — «нет порога в области», с областью.
- Поправка на перебор: Холм по семейству (W × направление × класс × рынок), число испытаний в отчёт; ДИ дополнительно Бонферрони по W (16).
- По суткам: знак избытка на порогах по каждым из 8 суток (число суток с плюсом); сутки — не смешивать.

## 4. Вопрос 2 — время схождения
- Расхождение d(t) = ln(mid_Gate(t)/mid_DEX(t)) − базис; базис = медиана d за предыдущие 24 ч по событиям пары (без заглядывания; часы без истории — вне), сырой d рядом. Считается только в моменты событий (своп с tv либо изменение BBO Gate), другая сторона — по возрасту (A, A_dex = 60 с; слои ≤5/≤15/≤60 с).
- Эпизод: первое |d| ≥ D (D по лог-сетке 0,3…20 %, непрерывно по интервалам), старт = tv; следующий эпизод той же монеты — после схождения или таймаута. Схождение = |d| ≤ D/2 (чувствительность: ≤ 0; ≤ D/4).
- Выход: время до схождения — Каплан–Майер с цензурой (конец суток, дыра, 24 ч), p50/p90 и доля несошедшихся за 24 ч, по интервалам D, по классам. «Не сошлось» — отдельная доля, не выкидывается.

## 5. Вопрос 3 — кто к кому
- Для эпизодов Q2: разложение Δd = ΔlnG − ΔlnD от старта до схождения: доля схождения ходом Gate = −ΔlnG·sgn(d)/|Δd|-сумма (с оговоркой, когда обе стороны идут одним знаком — доля вне [0,1], показывать как есть) vs ходом DEX.
- Первый ход (конкурирующие риски): что раньше пройдёт долю a = 0,25 |d| к схождению — Gate-середина или середина DEX (по событиям); доли «Gate первым / DEX первым / никто» по D и классам.
- Опережение: событийная взаимная корреляция — для каждого якоря хода DEX (окно w ∈ {1, 10, 60, 300 с}) корреляция r_D(ts−w, ts] с r_G(tv+τ−w, tv+τ] на лагах τ ∈ {−300, −60, −10, −1, 0, +1, +10, +60, +300 с}; значения Gate по событиям (не по сетке); ДИ блоками монета-день; максимум по τ → кто ведёт. Знак/значение τ* — по классам P/G/H.

## 6. Вопрос 4 — соотношение денег
- По (монета, сутки): оборот DEX-пула в $ (сумма |ногa| свопов); ликвидность пула в $ (глубина ±1 % из состояния пула, если извлекаема из sqrtPrice/L или резервов; нет — только оборот, **вопрос Судье Q-2**); оборот Gate фьюч и спот в $ (сделки); глубина Gate = медиана за сутки суммы bq·bid + aq·ask лучшего уровня (по gev2).
- Соотношения: ρ₁ = оборот DEX / оборот Gate фьюч; ρ₂ = оборот DEX / оборот Gate спот; ρ₃ = ликвидность пула / глубина Gate (если Q-2 разрешён).
- Отклик на ρ: по монета-суткам считаются (а) избыток отклика на фикс. (X-интервал середины, W = 60 с, h = 60 с), (б) p50 схождения (D=1 %), (в) доля «Gate первым» и τ*. Разрез по терцилям ρ (границы на классе) и непрерывно (ранговая корреляция Спирмена + изотоническая кривая, ДИ блоками по монетам). Вывод вида «при ρ в области … один рынок ходит за другим с запаздыванием τ*» — только если ДИ τ* не пересекает 0 в крайних терцилях и тренд в ρ значим после Холма (m = число показателей × ρ). Монет мало (P = 13) — для P только описание; значимость — на G.
- Исходы не пересчитываются под результат: ρ и показатели заданы здесь.

## 7. Вопрос 5 — «DEX улетел — CEX догоняет»
- Эпизоды: якоря Q1 с |X| ≥ 5 / 10 / 15 / 20 % при W ∈ {10 с, 1 мин, 5 мин, 30 мин} (+ остальные W — в приложение). Список csv: монета, сеть, пул, ts, X, W, направление, `mid_src`, число свопов в окне, оборот окна $, ликвидность пула (если Q-2).
- Фильтр «мираж» (не удаление, метка): ход DEX держится? DEX-середина через 1 мин и 10 мин от ts (доля хода сохранена) — классы «закрепился / вернулся / слив-бэкап»; тонкие пулы с оборотом окна < оборот Gate за то же окно отдельным разрезом.
- Путь Gate (фьюч, спот): значения G(ts + offset) по событиям для offset ∈ {−W, −W/2, 0, +tv, +1, +10, +60, +300, +1800 с, +2, +8, +24 ч}, возраст ≤ A (для offset ≥ 5 мин — также A = 60 с, чувствительность; «нет значения» считается и выводится, не заменяется).
- Догон: g₀ = ln(mid_DEX(tv)) − ln(G(tv)) − базис; доля догона C(h) = (G(tv+L+h) − G(tv+L))/g₀·; время до 50 % и 90 % — первое прохождение, цензура 24 ч, КМ p50/p90 + число эпизодов; отдельно «DEX вернулся» (двойной ход) и «Gate не пошёл».
- Сверка: список 20 самых крупных ходов руками (3 подробно): путь Gate по сырым записям.
- Малые n: эпизодов при 15–20 % мало — интервалы через 0 → «не читать»; число эпизодов по монетам и сетям — в отчёт обязательно.
