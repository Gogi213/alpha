# P-25 — G-016: банк гипотез лидлага DEX↔CEX, псевдотест недели 15–21.10.2026 (TK-369)

Статус: **договор до счёта** (23.10 03:57 GMT+4). Слово владельца 23.10: «найти просто альфу как угодно, желательно несколько; инфру/комиссию — потом» (В-54-формат: сырой эффект,
без цены исполнения). Утверждение — цитата владельца через CEO; пороги и правило вердикта ниже заморожены до первого исхода.

## 1. Что мерим
Событие e (монета c, секунда t, сторона s=±1) → **маркаут** `M_h = s · (P_B(t₀+h) − P_B(t₀)) / P_B(t₀) · 1e4` бп, где `P_B` — последняя цена сделки Bybit (перп; спот — для семьи J),
протянутая вперёд (staleness: возраст последней сделки на t₀ ≤ 5 с, иначе событие отброшено и посчитано в `dropped`).
Время DEX = время блока, **секунды** (выгрузка outw*, мс нет) → два опорных момента, оба считаются и показываются рядом:
- `t₀ = ts` (начало секунды блока) — «кто ведёт»: включает ход до/внутри секунды блока; положительный M при h≥1 = Bybit идёт вслед за DEX;
- `t₀ = ts+1` (конец секунды) — «что остаётся после»: ближайшее, что можно было бы взять; основной для вердикта.
Горизонты h = 1, 5, 30, 60, 300, 900, 3600 с (все считаются, выбор «лучшего» — запрещён; вердикт по каждому отдельно, поправка на все).
Цена пула события — из `sqrtPrice`/резервов (знак свопа: покупка токена = +1). Пара «монета ↔ контракт» — `docs/findings/tk364-universe-v3-*.csv` + проверка Судьи
(`reviews/tk364-dex-universe-v3-*.md`): обёртки/копии/peg вне «пул есть».

## 2. Банк
Генератор `tools/compute/tk369-bank.py` → `docs/research/g016-hypothesis-bank-2026-10-23.csv`: **55 гипотез** (семьи A–L: размер свопа, кластер, приоритетная плата,
новый кошелёк, органика/арбитражёр, расхождение пул–Bybit, ход Bybit→пул, ликвидность, Binance→Bybit, спот↔перп, пулы одной монеты, дисбаланс потока). Из них
**39 считаются на уже выгружаемом** (свопы пула + сделки Bybit), **16 «ждёт данных»** (кошельки/плата/Mint-Burn/Binance) — считаются вторым шагом, только когда данные
появятся; в отчёте они идут отдельной строкой «не посчитано + чего нет», в число испытаний m — только посчитанные. Порогов-чисел нет: все — квантили собственного
распределения пула/монеты **нарастающим итогом с начала недели** (causal; событие зачтено, если до него в пуле ≥ 200 свопов; прогрев не оценивается).

## 3. Страты (общие для всех гипотез, все считаются, без отбора)
группа монеты (мажор / high / mid / мем — `group` из universe-v3), сеть пула (ETH/BSC/Base/…), час суток (Азия 00–08 / Европа 08–16 / США 16–24 UTC),
режим волатильности (терциль σ60 с монеты по Bybit), сторона (buy/sell). Страта на эффект не фильтрует вердикт — только объясняет.

## 4. Контроль (назначен до счёта)
1. **Сдвиг времени ±3600 с** (как D20): тот же набор событий и сторон, момент сдвинут; `Snet_h = M_h(событие) − M_h(сдвиг)`; интервалы — парный бутстрап.
2. **Случайные секунды той же монеты, те же сутки и часы**, число событий то же, 200 повторов, знак случайный; `p_rand` = доля повторов ≥ факта.
3. **Перестановка стороны в сутках монеты** (ломает связь «сторона ↔ ход», сохраняя размер событий) — для семей A, B, L.
Контроль 1 и 2 обязательны для строки в топ; 3 — для семей, где знак задаёт сторона.

## 5. Статистика
- Единица независимости — **монето-сутки** (не событие): интервалы — бутстрап по монето-суткам (≥ 2000 повторов), эффективное N = число монето-суток с ≥ 1 событием.
- Поправка на перебор: **Бенджамини–Хохберг, q = 0.05**, по всем посчитанным клеткам «гипотеза × горизонт × опорный момент» (m печатается); дополнительно Холм по лучшим 10.
- Показывать всё: и «выше издержек» (ориентир 11–13 бп — только метка, не фильтр), и «похожее на альфу» = устойчиво ≠ 0.

## 6. Правило вердикта (заморожено)
Гипотеза **«похожа на альфу»**, если одновременно:
1. `Snet_h` (t₀=ts+1) > 0, нижняя граница интервала > 0 и BH-значимо (q=0.05) при хотя бы одном h;
2. знак `Snet_h` одинаков не менее чем в 5 из 6 полных суток (16–21.10; 15.10 — прогрев) и не менее чем у 8 монет (или у всех, если монет в семье < 8);
3. без топ-3 монет по n знак и значимость (по нижней границе парного бутстрапа без топ-3 > 0) сохраняются (Sex3); доля топ-3 в n ≤ 0.6;
4. **доза–отклик**: Snet растёт с силой события (квантильные бины силы, Спирмен по бинам ≥ 0.5) — иначе «эффект фона»;
5. `p_rand` < 0.05 и контроль 1 того же знака.
«Выше издержек» — отметка, если Snet_h ≥ 11 бп при тех же условиях 1–5. Не прошло 1–5 → «шум / описание», не вердикт. Исход одной недели = **кандидат**, не торговый вывод;
следующий шаг для кандидата — другая неделя (OOS) до любых разговоров о комиссии (слово владельца).

## 8. Что может снять гипотезу заранее (до счёта)
- Секундное разрешение DEX-времени + 12 с блока ETH (3 с BSC/Base 0.4 с): на ETH сигналы быстрее блока не разрешимы — смотреть BSC/Base отдельной стратой.
- Peg-обёртки/копии токена (DOGE на ETH, PEPE на BSC) → не та цена; исключаются по universe-v3 (пометки Судьи).
- Если у монеты < 50 событий за неделю — клетка пишется, в сводку не входит (но в m — входит).

## 12. Поправки после счёта v1 (23.10, по проверке Судьи `reviews/tk369-bank-v1-2026-10-23.md`; §1–§8 не переписаны)
1. **~~§1: `P_B` — последняя цена сделки~~ → середина стакана Bybit** (`lob seconds`, `mid2` на момент t: состояние книги на t·1000 мс = строка t−1; фьюч и спот,
   бинлоги TK-366, только `verify == ok`, К1). Причина: маркаут по последней сделке ловит отскок bid–ask (F024/J045 v1). Цена в бп = отношение, тик сокращается; абсолютная
   цена для F (расхождение пул–Bybit) = `mid2 · tick/2`. Событийные ряды G/J (ход за w с) тоже по середине. Столбец v1 (по последней сделке) остаётся в отчёте только справкой, в m не входит.
2. **~~§4.2: 200 повторов случайных секунд~~ → знаковая рандомизация по собственным событиям**: `p_rand = 1 − Φ(ΣSnet / √ΣSnet²)` (под H0 знак события независим от хода; дисперсия — по самим событиям, не по случайным
   секундам). Причина: v1 брал дисперсию из случайных секунд, события сидят в повышенной волатильности → p_rand=0 у всех.
3. **§4.3 (для A, B, L): перестановка стороны внутри монето-суток аналитически**: E = (Σs)(Σd)/n, Var = (n − (Σs)²/n)(Σd² − (Σd)²/n)/(n−1) по монето-суткам, d = s·Snet; `p_perm = 1 − Φ((ΣSnet − E)/√Var)`; одна сторона (Var=0) — неприменимо, критерий пропускает. Обязателен в §6 для A/B/L (c6).
4. **A008**: событие известно в ts+60 (свопов ±60 с нет) → t₀ = ts+60 (v0) / ts+61 (v1), без заглядывания.
5. Добавлены 8 гипотез из §2: F025/F028 (был своп ≥ q95 любого пула монеты за 60 с), F026/F029 (расхождение ≥ порога каждую из последних 10 с, того же знака), G031/033/035/037 (G030/032/034/036 и цена
   последнего свопа в монете не менялась за w с), K046 (первый своп ≥ q95 среди пулов монеты за 60 с; монеты ≥ 2 пулов), K047 (свопы ≥ q95 ведущей сети; лидер — по сумме произведений 1-с доходностей
