### 3.1 Фракция 1 — широкий диапазон, грубая сетка (8–12 точек на ось)

### 3.3 Фракции 2 и 3 — сужение вокруг прошедшего сито
- Вход: **плато** (§4) фракции k. Окрестность = плато плюс по одному соседу-«не прошедшему» с каждой стороны (чтобы поймать край).
- Шаг = шаг фракции k / 4, округление к разрешимости параметра (целое для n/w/N/K/тиков, 1 процентиль для квантилей, 1 с для секунд); если шаг < разрешимости — ось в этой фракции не дробится (закрыта).
- Потолок на ось: F2 ≤ 12 новых точек, F3 ≤ 8; на двух осях — сетка окрестности плато, потолок 100 клеток на гипотезу в фракции.
- Объём F2/F3 заранее не известен (зависит от числа прошедших); оценка сверху в §6.
- **Остановка:** после F3, либо если плато не нашлось в F1 (гипотеза закрывается «плато нет в [диапазон] на сетке F1», остальные фракции не считаются), либо плато упирается в границу диапазона F1 (тогда **расширение диапазона** — отдельное решение владельца, не автоматическое).

## 4. Правило сита (записано ДО счёта; числа — решения Судьи Q-1 от 11.10)
Сито — **только на половине А монет** (разбиение §0 п. 4; скрипты сита читают только А, числа Б не печатаются до финального теста), окно **01.01–30.09** (В-211), одним числом на клетку (TK-180: ранние месяцы не предсказывают, раннее отсечение запрещено). Месяцы печатаются, в сите не участвуют. Счёт клеток идёт по всем монетам (клетки одни), разбиение — на чтении.
1. **Статистика клетки:** парная **ΔSR_норм** к B1 (Шарп по календарным суткам, равная экспозиция П-12 §6(2), `m` по сделке своей базы — как П-13 §4), блочный бутстреп по суткам, блок ⌈n^{1/3}⌉. Δ бп на исполнение — печать.
2. **Годна:** односторонний p ≤ 0,20 (ΔSR_норм > 0) **и** сделок ≥ 20 **и** суток со сделками ≥ 10 (K = 10, прецедент v128). Меньше — «не определена»: не годна, p = 1 в семье.
3. **Достижимость (до счёта, §0 п. 3):** печатается минимальная обнаруживаемая ΔSR_норм при p ≤ 0,20 по ряду B1 (половина А, янв–сен); если она больше правдоподобного эффекта, сито ничего не отсекает — это записывается, а не скрывается.
4. **Плато** (вход в F(k+1)):
   - 1D: клетка и оба соседа годны; на краю — единственный сосед годен + метка «у границы».
   - 2D: ≥ 5 из 8 соседей годны; на краю — большинство существующих.
   - Категориальная ось (trigger Г-114, be Г-104, день недели Г-14): плато только вдоль числовой оси внутри каждой категории; чисто категориальная ось — без плато, каждая категория — клетка семьи с меткой «без плато».
   - Час суток — круговая ось (соседи h±1 mod 24).
   - Вложенные `keep_q` (5 ⊂ 10 ⊂ 20 …): соседство частично механическое — печатается доля общих сделок соседей.
   - «Слабое плато < 3 клеток» из первой редакции **снято** (в 1D плато ≥ 3 клеток по определению).
5. Из каждого плато в F(k+1) идёт его окрестность (§3.3). Сито ничего не утверждает: это отбор для следующей сетки; вывод — только по §5.

## 5. Вне выборки, поправка на перебор и вердикт (по П-13 §5–6, решения Судьи Q-2/Q-4)
