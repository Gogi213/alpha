### 3.1 Фракция 1 — широкий диапазон, грубая сетка (8–12 точек на ось)
Правило построения: диапазон — из смысла механизма и измеримых границ (минимальный лот, дедлайн B1, ttl B1, размер позиции), **шире прежнего** в обе стороны от прежних значений; шаг — лог-2 (множители) или квантильный (хвосты гуще); **все прежние значения входят в сетку** (уже посчитанное переиспользуется по ключу клетки, В-213). Две оси — полной сеткой (оси × оси), не OFAT.

**Квантильная ось `keep_q`** (R1, 30 осей: 9 одноколоночных гипотез, 18 колонок у 7 многоколоночных, 3 `common_q`): было {20,33,50,67,80}; **стало {5,10,20,33,50,67,80,90,95}** (9 точек, прежние 5 внутри). Колонки признака — только существующие в таблице касаний (окна 15/30/60 с и т. д. из текущих колонок); новые окна = новый код = вне этого протокола. Направление отбора («оставить верх/низ») — как в П-11; зеркальную половину добавляет Инженер как тот же `keep_q`, если П-11 допускает (**Q-3**).

### 3.3 Фракции 2 и 3 — сужение вокруг прошедшего сито
- Вход: **плато** (§4) фракции k. Окрестность = плато плюс по одному соседу-«не прошедшему» с каждой стороны (чтобы поймать край).
- Шаг = шаг фракции k / 4, округление к разрешимости параметра (целое для n/w/N/K/тиков, 1 процентиль для квантилей, 1 с для секунд); если шаг < разрешимости — ось в этой фракции не дробится (закрыта).
- Потолок на ось: F2 ≤ 12 новых точек, F3 ≤ 8; на двух осях — сетка окрестности плато, потолок 100 клеток на гипотезу в фракции.
- Объём F2/F3 заранее не известен (зависит от числа прошедших); оценка сверху в §6.
- **Остановка:** после F3, либо если плато не нашлось в F1 (гипотеза закрывается «плато нет в [диапазон] на сетке F1», остальные фракции не считаются), либо плато упирается в границу диапазона F1 (тогда **расширение диапазона** — отдельное решение владельца, не автоматическое).

## 4. Правило сита (записано ДО счёта; пороги назначает Судья, §9)
Сито — по **всему периоду 01.01–02.10 одним числом на клетку** (TK-180: ранние месяцы не предсказывают, раннее отсечение запрещено). Месяцы печатаются, но в сите не участвуют.
1. **Статистика клетки:** разность чистого результата на исполнение к базе B1 на тех же сигналах (бп, после комиссий и В-68), блочный бутстреп по суткам; t-статистика Δ.
2. **Годна:** t ≥ t_s и исполнений за период ≥ n_min (**t_s и n_min — назначаемые, Q-1; предложение: t_s — на уровне ≈ 20 % ложных проходов при нуле, т. к. сито широкое и не вердикт; n_min — из дисперсии B1: полуинтервал среднего < |порога|**).
3. **Плато:** клетка проходит в следующую фракцию, только если и **большинство её соседей** по сетке (1D: оба; 2D: ≥ 5 из 8 внутри диапазона, край — все существующие) годны. Одиночный пик отбрасывается. Связная компонента годных клеток с этим свойством = плато.
4. Из каждого плато в F(k+1) идёт его окрестность (§3.3). Плато с < 3 клеток в F1 — «слабое»: идёт в F2, но флаг «слабое» остаётся до вердикта.
5. Сито ничего не утверждает: это отбор для следующей сетки; торговый вывод — только по §5 и вердикту П-12/В-208 после F3.

## 5. Поправка на перебор и финальный вердикт
- **Семья = гипотеза со всеми клетками всех фракций** (включая отвергнутые на сите: сито — часть отбора, молчаливое «не прошла» не скрывает испытаний).
- Статистика семьи — **max-T по всем клеткам семьи F1∪F2∪F3** (блочный бутстреп по суткам, Westfall–Young); консервативно: адаптивный отбор F2/F3 по тем же данным завышает оценку, поэтому нуль-распределение строится по **всей сетке**, а не по финалистам. Лучше (**Q-2**, решает Судья): прогнать весь процесс сито→сужение на перестановочных копиях — дороже, но честнее.
- Между семьями — **Холм**, m = число семей с клетками в охвате (список фиксирует JSON охвата до счёта; ориентир ≈ 55: 27 R1-колонок сворачиваются в 17 гипотез, + R2/Д 17 + П-класс 20).
- Единый счётчик испытаний N = Σ клеток всех фракций всех семей (+ родословная П-12 §7); DSR/PBO — по П-12 §9 в редакции Судьи (`reviews/P-12-2026-10-08-sharpe-rule.md`).
- **В-115 (август/сентябрь отдельно):** решение по гипотезе фиксируется по авг и сент раздельно — «годна» = результат > 0 в **каждом** из двух месяцев при ≥ 20 исполнений. Авг/сен входят в период сита (01.01–02.10), поэтому это не отложенная выборка — честная метка «ворота В-115 внутри выборки»; вердикт «в отбор» = max-T семьи (Холм) **и** ворота В-115 на финальной клетке. Данных после 02.10 нет (коллектор остановлен) — «вперёд» отложено (П-13 §6 п. 3).
- Печать всегда: $/бп по месяцам и монетам, Шарп (сутки), k_c (месяцев > 0), число сделок, пик позиций.

## 7. Метрики, которые печатаются в любом случае
Плато: границы по каждой оси, число клеток, Δ-статистика, месяцы отдельно, разрез по монетам, доля исполнений, поведение у краёв диапазона (упирается ли плато в границу).

## 8. Правило вывода (до чисел)
- «Плато есть» — связная область ≥ 3 соседних клеток F3, проходящих сито, при max-T семьи после Холма и воротах В-115 на центре плато; формулировка потолка — «в отбор»; «работает» не пишется без окна вперёд.
- «Плато нет» — F1 не дал связной компоненты годных клеток; пишется «нет плато в диапазоне …», не «механика не работает».
- «Плато у границы» — расширение диапазона по решению владельца.
