## 5. ТЗ Инженеру (Rust; вне зоны Исследователя; один тикет, оценка и план — Инженер)
Общее для всех: ключи выкл по умолчанию = прежний байт в байт (7 семей, как TK-204); новый ключ — в каноническом хеше, `parse_entry`/реестр форм различает формы с разными параметрами (урок Г-102, П-15 §7); тест «два разных значения → две клетки и два хеша»; бой по `bounce-grid --cells`, без Python-обходов (В-21).
1. **Г-81 `--entry-gate cxl<W>q<Q>`** — на `touch+W` снять неисполненные ступени при мере ≥ Q. Мера — тот же код, что у `ExitForm::Cxl` (`bounce_grid/forms.rs`); не новое определение. Требует `--tape-log ≥ W`. Отдельный счётчик `n_gate_cancelled`. Если мера пуста (нет отмен) — ворота открыты.
2. **Г-98 `stack_span_bps`** — колонка в `LevelTracker`/`r1.rs`, append-only (+счётчик, +тест), считается на кадре взвода по уровням стороны (первый→последний живой уровень стека, как `stack_levels_at_arm`); ключ `--size-risk <R$>` (`plan.rs`: лот из `--order-usd` по умолчанию как раньше; пол — min-лот символа, сделка ниже min-лота пропускается и считается).
3. **Г-101 `--ladder-regime` / `--stop-regime`** — T берётся из файла порогов месяца (как `btc4h` в наборе), множитель f целочисленный (бп) к шагу ступени / стопу pct2; режим определяется на кадре взвода из уже вычисленного `btc4h` (без нового чтения).
4. **Г-135** — `swept_min` (ключ набора, нормированный на `level_qty`, пороги из файла); `postsweep<R>` — форма входа по рынку (taker; комиссии и очередь `prob:3` не применимы — исполнение по BBO + В-68), окно ≤ 30 с от касания.
5. **Г-136/Г-137** — ключи набора `repeat_min=<k>`, `age_max=<мин>` над готовыми колонками `repeat_count`/возраст; **`repeat_window_ms` не менять** (иначе перестроение кэша касаний).
Тесты — `tests.rs` модуля; проверка на VPS (`tools/vps-check.sh … all`); гейт — «выкл = прежний».
