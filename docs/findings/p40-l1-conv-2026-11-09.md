# П-40: L1-конвертер `pq2bin l1` + бит2 ухода из L1 в ядре — гейты G-L1a/G-L1b (TK-515, 09.11.2026)

Ветка `tk515-l1` (от `tk500-p40core` @a72dc8d3). Назначение — `docs/research/reviews/tk514-l1-format-2026-11-09.md` §2–§3, §5 (ветка `tk493-xdl9`). Счёт — srv 5.231.25.224, 1 поток на конвертер.

## 1. Что сделано

- `tools/p40core/pq2bin/src/l1.rs` (`L1Enc`) + режимы `pq2bin l1 book|bybit|gate` → `<ЧЧ>.l1.bin.zst` (zstd, `P40_ZSTD`, умолч. 3; `P40_L1_RAW=1` — ещё и несжатый `<ЧЧ>.l1.bin`). Формат — те же 33 Б ядра; бит2 = «уровень вышел из L1, не удалён из книги»; в начале часа — снимок текущего L1, состояние между часами переносится (Bybit — потоково; CHFT/Gate — час независим, как в полной книге).
- Ядро (`fills.rs`, `book.rs`, `feats.rs`, `main.rs`): строки с бит2 не двигают очередь и не исполняют (в drain тоже); возврат цены в L1 — по правилу §2.3 (`q1 < q0` → `on_depth` без `on_trade`); заявка, поставленная на цену вне L1, берёт последний видимый размер уровня (**добавлено инженером как часть класса «очередь при уходе цены из L1», в назначении нет**). `P40_L1=1`: `depth_slip → l1_notional`, `bookimb → bookimb1` (по лучшим ценам). Без флага и без бит2 — прежнее поведение.
- `p40core l1series <dir>` — ряд `(t, bid, bq, ask, aq)` для G-L1a; `P40_L1_STAT=1` — `<префикс>.l1leave*.csv`; `l1_diff.py` — таблица расхождений fills/exits с классом.
- Скрипты гейтов: `tools/p40core/l1_gate.sh` (G-L1a + МБ/с), `l1_gate_b.sh` (G-L1b).

## 3. G-L1b — ядро, DOGE 17.09 Binance × OKX, L = 500, оба прогона с `P40_L1=1 P40_L1_STAT=1`

- Проход 1 (эпизоды): sha **121e8403ba03** у полной книги и у L1 — равен прежнему.
- Признаки: `features.csv` полная = L1 байт в байт (включая `l1_notional`, `bookimb1`); общие 10 колонок (`theta … d_in, spread, vol5m, plevel, flow1m, leader, hour`) с прогоном без флага — различий 0.
- fills: 50 строк, расходятся 50 — **все класса «L1-очередь», класса «ИНОЕ» 0**. exits: 50 строк, расходятся 2 — оба «L1-очередь», «ИНОЕ» 0.
- Доля ухода цены из L1: заявки входа — полная 58/100 (58 %), L1-файл 57/100; выходы/страховки — полная 14/30 (46,7 %), L1-файл 13/30.
- Сдвиг net_bps (`pnl_bps` exits, n = 30): полная −7,0684, L1 −7,0684, сдвиг **0,0000 bps** (общих эпизодов 30).
- Оговорка: класс «L1-очередь» присваивается строке, если цена одной из заявок уходила из L1 в любом из двух прогонов (критерий Судьи §3); расхождение, у которого уход из L1 случайно совпал с иной причиной, этим критерием не отделяется. Полная таблица — `/root/tk515/l1_gate_b.out` на srv.

## 4. Тесты и гейт «без флага»

- `pq2bin`: 11 тестов (`L1Enc`, включая свойство «воспроизведение L1-файла = L1 полной книги» на 4000 случайных групп) — зелёные на srv.
- Ядро: `cargo test --release` 25/25 (5 новых на бит2); без `P40_L1` и без бит2 выходы DOGE 17.09 байт в байт с `/tmp/old.csv*` (5 файлов).

## 5. Алгоритм

Варианты — в `l1.rs` выбран быстрый хеш цены `Fx` (умножение + свёртка старших бит) вместо стандартного, книга — кучи с ленивым удалением как в `book.rs`; Gate читается `read_line` в переиспользуемый буфер. Замер — только итоговый (§2); сравнения с другими вариантами (стандартный хеш, другие структуры книги, уровни zstd) в этой сессии не измерялись, выбор не подтверждён замером — пробел против В-170. Порог 11 МБ/с достигнут на всех четырёх источниках, поэтому поиск дальше не вёлся.
