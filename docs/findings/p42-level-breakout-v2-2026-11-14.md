## Основное чтение: задержка 4 мс на входы и выходы (§13.4 п. 8, В-157; §13.6)
- **Отклонение протокола (§13.4 п. 8).** Основное чтение шага B менялось дважды: lat 0 (предрегистрация §13.2) → 200 мс (§13.4 п. 6, слова владельца «ну давай задержка будет 0.2») → **4 мс по слову владельца (В-157, 14.11 ≈ 23:10, дословно): «я те кажется кривую задержку сказал. не 200 мс а 4 мс»**. Смена — после счёта шага B, по слову владельца, а не по результату; запись в протокол сделана до счёта при 4 мс (коммит `0f303188`). Величина 4 мс — параметр модели, названная владельцем; испытаний не добавляет (Холм m: лонг 207, шорт 199). 200 / 250 / 1000 мс и lat 0 — справочно.
- **Почему не lat 0.** При lat 0 вход — следующая агрессивная сделка стороны, часто в ту же миллисекунду, что сделка-сигнал: лонг A 189/344, B 198/373; шорт A 199/311, B 187/313 (55–64 %) — внутри чужой серии рыночных заявок, реагирующий ордер так не исполняется. Шорт B: эти входы несут −$640 из −$778 за половину. При 4 мс входов в ту же миллисекунду, что сигнал: лонг 0 из 704, шорт 0 из 620. Задержка была предрегистрирована как справочная ось (§13.2 п. 5).
- **Задержка выходов.** Документация робота Викинг (`https://fkviking.github.io/bot-doc/docs/algorithm-comments.html`, «О ценах выставления заявок второй ноги» и «Особенности поведения заявок, переставленных по SL или Timer»): стоп-лосс на стороне клиента — при срабатывании робот переставляет заявку на `bid − k_sl` / `offer + k_sl` и переставляет её раз в секунду до сведения в сделку. Модель `latx`: стоп/БУ/трейл срабатывают на сделке `T` по правилу §13.2, исполняются по цене первой сделки ≥ `T + latx` (тейкер, −1 bp), тейки до этого остаются лимитками; `k_sl` и очередь не моделируются. **Оговорка:** задержка позволяет цене вернуться после «вика», поэтому задержка выходов улучшает результат (модель без ценового сдвига `k_sl`) — справочное чтение, не прогноз.

## Вердикт стороны — толкование (как в v1: §10 даёт вердикт кандидату, а не стороне)
- **Лонг: на минутках опровергнуто (устойчиво, без 2 худших суток и монет), на сделках при реализуемой задержке (4 мс) — не ясно** (знак смешанный, интервалы накрывают 0, без 2 худших суток знак «+»); опровержение на сделках держится только при lat 0. Перекрёстный кандидат не торгует; подтверждённых кандидатов 0.
- **Шорт: не подтверждено.** Минутки — «не ясно» (оба кандидата, знак «+» у базы, интервалы накрывают 0); сделки (4 мс) — база опровергнута через половину B (знак «−» держится без 2 худших суток и монет, интервал накрывает 0), перекрёстный «не ясно» (интервал ±$30 накрывает 0). Расхождение шагов записано, не сглажено: положительная минутная база — следствие минутного приближения входа/выходов (вход по открытию следующей минуты, стоп по low минутки), на сделках она уходит в минус.
- **Что не охвачено:** новые сутки (всё — окно 15.09–13.11, одно окно); исполнение внутри секунды (основное чтение — 4 мс на входы и выходы; 0 / 200 / 250 / 1000 мс — справочно; `k_sl` и глубина не моделируются; размер сделки не моделируется); монеты вне универсума ≥ $12 млн; другие биржи.
