## Строки aggTrades, которые не читались (3,4 млн → 0)
- **Что это.** Binance пишет цены меньше 0,001 в Java-записи с экспонентой (`9.16E-4`, `5.996E-5`); разбор `parse_dec` принимал только десятичную запись и отбрасывал такие строки. Не заголовок (заголовки — по одному на файл — пропускаются отдельно), не смена схемы (0 строк с числом полей ≠ 7, 0 с нецелым временем), не пустые строки.
- **Масштаб.** Базовый прогон v6 — 3,43 млн из 556 млн строк (0,6 %); полный прогон v7 — 4 992 063 из 708 371 498 строк, прочитанных на фазе 1 (0,70 %); после правки (v8) — **0** плохих строк, разобрано 708 371 498.
- **Какие монеты.** 18 бессрочных, у которых минутный минимум хоть раз был ниже 0,001: IOST (10,06 млн строк с экспонентой из 27,0 млн), VTHO (9,51 из 9,86 млн), HOT (4,63), BOME (4,51 из 6,52), TAG (4,03), NEIRO (3,90), PTB (3,62 из 5,99; 53 файла), XPIN (2,36), NOT (2,33), DOGS (2,27), MEW (2,04), SLP (1,47), SPELL (1,23), ONE (1,07 из 56,5), HMSTR (1,04), CKB (0,22), TAC (0,11), TLM (0,007). Полный просмотр всех 1311 файлов этих монет: 54,4 млн из 139,2 млн строк в записи с экспонентой, других отклонений нет. Частичный полный просмотр (9,6 тыс. файлов всех монет) других монет с недесятичной ценой не нашёл. Остальные 548 монет — цены ≥ 0,001, их строки читались целиком.
- **Влияние на результат.** Базовый лонг +8 сделок (IOST 4, PTB 2, HOT 1, VTHO 1; −$11,7 за 60 суток), базовый шорт +8/−2 сделки (+$11,5 / −$11,8).
