# Где есть стены для лонга и шорта: 100 монет пула, сентябрь (2026-09-24)

Просьба владельца 24.09: «сложи данные о том, какие монеты не имеют плотностей вообще лонг/шорт, где нет только лонга,
где нет только шорта, где есть плотности, но не дотягивают по времени» — под будущий тюнинг: шорты — через рост
объёма и возраста стены, лонги — через снижение издержек, затем сложение лонгов и шортов ради числа сделок.

**Данные.** Все 100 монет пула до В-95 (включая 24 снятые), сентябрь 01–23 (история 01–15 — архив Bybit, запись 16–23),
кэш подходов D20 (`study/approaches/D20`, обе эпохи): подход цены ближе 20 bps к стене ≥ $10k (порог — при
построении кэша, `approach-scan.sh`: `--h3-mode notional --h3-usd 10000`), возраст стены `age_ms` — от момента, когда
её размер впервые превысил порог (`lob::levels`), разметка — по топ-50 книги. Лонг — бид-стены, шорт — аск-стены.
Машиночитаемая таблица (строка = монета × сторона): `wall-availability-2026-09-24.csv` — сутки наблюдения, подходов,
самая старая стена (мин), подходов к стене возрастом ≥ 15/30/45/60/90/120 мин (шаги сетки возраста титрования
`t-*-age-*`), среди ≥ 45 мин — со стеной ≥ $10k/$25k/$50k/$100k в момент подхода.

**Статус стороны:** «нет» — ни одного подхода к стене возрастом ≥ 15 мин (самый короткий шаг сетки возраста);
«коротко» — есть ≥ 15 мин, но ни одной ≥ 45 мин (порог кандидата); «есть» — хотя бы одна ≥ 45 мин.
Обозначения: `*` — меньше 20 суток наблюдения (вывод слабее), `†` — снята с записи и бэктеста 24.09 (В-95).

## Группы

**1. Стен нет ни для лонга, ни для шорта — 21:** ACE†, AKE*†, ARB, ARK†, ASTR†, AVAAI*†, AXL†, BR*†, BTW*†, CASHCAT†,
CVC†, ENA, GOOGL, MTL†, MU, SENT†, SKHYNIX, TAO, USELESS*, VVV†, XMR*. (ARB, ENA, TAO, GOOGL, MU, SKHYNIX, USELESS,
XMR — в пуле: стен ≥ $10k у них много, но ни одна не живёт 15 мин.)

**2. Стен нет только для лонга — 3:** FARTCOIN, FF†, POWER† (у шорта стены есть, но короче 45 мин).

**3. Стен нет только для шорта — 8:** CYS, DELL, LSK*, RAYDIUM*, STEEM, STORJ (лонг — «есть»); CAP†, PUFFER† (лонг —
«коротко»).

**4. Стены есть, но не дотягивают по времени (до 45 мин):**

**5. Стены ≥ 45 мин есть с обеих сторон — 49:** 1000BONK, 1000PEPE, ADA, AERO, APT, ASTER, ATOM, AVAX, BCH, BNB, BZ,

Стены для шорта встречаются так же часто, как для лонга. При ужесточении условий материал быстро тает: стена ≥ 90 мин —
~0,85 тыс. подходов за месяц на сторону, ≥ 120 мин — ~0,43 тыс.; стена ≥ 45 мин и ≥ $100k — ~0,2 тыс. Это верхняя
граница числа сигналов до фильтра режима и до исполнения, не число сделок.

## Чему не верить

- Подход — не сделка: дальше фильтр режима, лестница, очередь (у кандидата ~270 сделок из ~3,7 тыс. подходов к
  стене ≥ 45 мин за тот же месяц).
- «История» — поток 200 уровней/100 мс, запись — 50/20 мс; разметка по топ-50 одинакова, но шаг времени разный.
- Август (эпоха `epochs/e-aug`) — после его счёта таблицу стоит дополнить (пул августа — 76 монет, без снятых).
