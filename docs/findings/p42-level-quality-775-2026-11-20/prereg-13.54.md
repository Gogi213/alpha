#### 4. Определения (все причинные; значения — как в таблице эпизодов f12 §13.17, ничего не переопределяется)
- `pierce_ep` — число проколов уровня (эпизодов минут с high ≥ LP) от бара первого пивота до `t−1`, кроме баров-членов; **0 = чистый уровень**, ≥ 1 = зона. `spread_tau` — разброс цен пивотов версии уровня в единицах τ (20 бп; ≤ 2): больше = шире «зона».
- `mv5` — ход к уровню за 5 мин в NATR (+ = к уровню; больше = резче). `cons60` — минут из `t−60…t−1` с закрытием ниже LP и не дальше 0,5 % (проторговка; 0 = без проторговки).
- `zv6h` — доля минут с нулевым оборотом среди `t−360…t−1` (больше = разреженнее; окно < 30 мин от листинга — пусто). `tpm60` — записей aggTrades в минуту за 60 мин до сигнала (меньше = разреженнее).
- `bk_K` — по эпизодам U0 той же стороны той же монеты, закрытым к времени сигнала: `n` — их число, `k` — из них пробоев (`y = 1`), `bk = k / n` при `n ≥ K`, иначе пусто (§13.26 п. 4, без изменений).
- **Пусто проходит** (как §13.36 / §13.37): кандидат без строки эпизода f12 или с пустым значением не исключается; число таких сделок базы печатается.
- **Пороги лестниц — ОДНО абсолютное число на все монеты:** общий квантиль `p` ∈ {0,2; 0,4; 0,6; 0,8} величины по всем сигналам базы h775 этой стороны (кандидаты, трёх окон вместе, зачётные диапазоны, перекрытие окон не считается дважды, пусто не входит), метод `linear`, **округление до 2 значащих цифр** (у целых `pierce_ep`, `cons60` квантиль `linear` может быть дробным — после округления сравнение идёт с тем же числом: `≥ X` / `≤ X`, без отдельного правила для целых). **Дубли — по множеству исключённых:** клетки стороны (лестницы, именованные, `bk`), исключающие одно и то же множество строк таблиц `--ftab` трёх окон (в том числе совпавшие после округления пороги и целочисленные совпадения `k` §13.26), — одна клетка, все подписи в строке; клетка, не исключающая ни одной строки (например `≥ 0`), — «≡ база», в прогон не идёт, в таблице строкой «≡ база».
- **Лестницы:** на каждом из 6 признаков два направления на тех же четырёх числах: «только если `x ≥ X_p`» и «только если `x ≤ X_p`» — до 8 клеток на признак.
