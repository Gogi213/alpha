### Решения реализации (протокол допускает два прочтения)
R1 условие порога поминутно со своей sigma; R2 короткий базис по [t-60, t), при < 20 наблюдений Q6 запрещает вход; R3 взвод по m_r валидным наблюдениям после rest_from; R4 rest_from: после CV, сессии, таймаута u+2, после стопа u+T, после expired t+K_stale+1, после дедупликации t+1; N_stop = 3 — исключение после третьего стопа; R5 выход по ноге: open[u+2], если close[u+1] и open[u+2] конечны, иначе последний известный close; решение u с u+2 за концом данных — позиция открыта, MTM; R6 S3/S1/S0/CV только на минутах с обеими ногами; S2, сессия, таймаут по часам; R7 каждая непрерывная серия «в сессии» — своя сессия (обеденный перерыв Гонконга = закрытие), серия на границе данных закрытием не считается; R8 фандинг: ставки строго между заполнениями, цена ноги — последний конечный open. Дополнительно: кэш рядов раздельный по конвейерам (`<out>/calib|train|window/cache`), Pi_train не видит кэш с поздними сутками; пара A/B упорядочена по (биржа, символ).
