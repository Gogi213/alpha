# TK-378: отрывы Gate-фьюч (сделки, мс) vs DEX Solana (SQD-свопы + USD), 15–22.10.2026 — дозапуск TK-377

**Итог:** на сделках Gate сходимость быстрая (медиана 10–70 с, 80–100 % эпизодов закрылись ≤ 5 мин), но **края не доказано**:
среднее net-к-контролю +20…+100 бп тянут хвосты (медиана net ≈ 0…+30 бп, у многих 0), а у SI/FONE σ отрыва 1,5–3 тыс. бп
после чистки — остались плохие своп-цены. Издержки (Gate тейкер ×2, комиссия и проскальзывание DEX-ноги) **не вычтены**;
DEX-нога не моделировалась (только Gate-нога в сторону DEX). Это срез «есть ли предсказуемое сближение», не вердикт.

## Метод (код `tools/compute/tk378_sol_lag_trades.py`, calc `/data/tk0378/lagtr/`)
- Gate: сделки фьюч `raw/fut/<C>_USDT` (TK-372), последняя цена в корзине 10 с; DEX: `sqd-swaps-usd.csv`, чистка — USD ≥ 5 и
  цена в ±30 % от медианы ±30 соседних свопов (отсеяно 30–40 %), последняя цена в корзине; ffill ≤ 60 с.
- Отрыв = ln(Gate/DEX)·1e4, центр — медиана монеты (учёт постоянного сдвига). Эпизод: |отрыв−мед| ≥ X (50/100/200/500 бп), вход Gate в
  следующей корзине против отрыва, выход при |.| ≤ X/2 или через 5 мин. Контроль: до 10 случайных входов того же знака с похожим
  движением за 60 с. Окно 15–22.10 (8 суток; KIMCHI — только с 22.10 — Gate-фьюч там появился).
- Покрытие: SI 47,6 тыс. корзин, HOOKED 25,1, FONE 16,8, CLAUDIA 16,5, KIMCHI 3,3 (1 сутки), STAMP 0,8, TQQQX 0,5.

## Оговорки (не снимать без Судьи)
1. **Эпизоды зависимы** (кластеры по минутам, 1–8 суток); эфф. N ≪ числа эпизодов, интервалов нет — это не оценка с ДИ.
2. **Хвосты:** среднее ≫ медианы; σ отрыва SI 3 041 бп, FONE 1 537 бп — остаточные плохие DEX-цены (многопуловые свопы, сторона/кросс-курс); чистка порогом ±30 % не доказана. Вердикта «край» по среднему нельзя.
3. **TQQQX:** отрыв −6 983 бп (≈ ×0,5) — DEX-цена/единицы не совпадают с Gate (xStock vs перп-токен, маппинг mint↔тикер не подтверждён) — исключить до проверки.
4. **KIMCHI** — 1 сутки (22.10), 3,3 тыс. корзин; **STAMP/TQQQX** — < 1 тыс. корзин, свопов 564/375 — выводов нет.
5. Издержки не вычтены: Gate тейкер ≈ 5 бп × 2 стороны, DEX-нога (комиссия пула + проскальзывание + priority fee из `sqd-swaps-usd.csv`) в сигнал не входит; арбитраж «обе ноги» не моделирован.
6. Испытаний: 7 монет × 4 порога = 28 клеток, один проход, без подбора параметров.

## Что дальше (для Судьи)
Проверить чистку цен (эталон — пул-реестр/TK-380: цена только из свопов основного пула SOL/USDC, а не «любой своп с mint»), затем пересчёт по SI/HOOKED/FONE/CLAUDIA с блочным бутстрепом по суткам и издержками; решение владельца не требуется.
