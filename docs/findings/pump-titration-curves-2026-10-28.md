## Что кривые показали
1. **A1:** подъём растёт с кратностью оборота до ×200–660 по месяцам (не ×70–140: прежний вывод Судья снял), потом исчезают срабатывания. Цена — редкость: ~0,1 срабатывания/сутки/монету при ×111, на порядок меньше при ×500. Сентябрь слабее всех месяцев (пик 13,5 против 22–35 янв–июнь) — сдвиг режима, а не шум (CI не пересекаются с мартом/апрелем).
2. **A2:** подъём растёт до ×15–20 и дальше не подтверждается (N<100). Волатильность одна, без оборота, слабее A1.
3. **A3:** короче ход и жёстче квантиль — лучше; ограничения по D от владельца («≥1,5 ч») здесь не нужны: наилучшее D = 15–19 мин. Это **не** замена определения пампа владельца, а ось титрования: подъём по D монотонно убывает без пика.
4. **A4:** без изменения (сетка та же): при r60>0 среднее направленного возврата отрицательно на всех горизонтах (откат), на проверке знак тот же; при r60<0 знак нестабилен по месяцам; пика кривой нет, 1/6/24 ч — произвольные точки на монотонной кривой (png, нижние панели).
