# TK-446 — титрование кривыми (В-58) · 28.10.2026

Владелец: «меня не устраивает что в ответе ты даёшь фиксированные значения 3-30-100, или 1-6-24. почему именно такие интервалы? они не будут титроваться?»

**Артефакты:** `pump-titration-curves-2026-10-28-all.csv` (все кривые, 9 мес. × 900 строк), `-selected.csv` (выбранные пороги по месяцам), `.png` (кривые; цвета — июль/авг/сент.). Код: `tools/compute/tk446-curves.py` (счёт, calc, куб TK-436/439/440, метка/база/кластерный бутстрап как TK-443), `tk446-report.py` (выбор и сводка).

## Правило (заморожено до счёта)
Лог-шаг ×1,25 по всем осям. Порог на семью = argmax от **min по янв–июнь** нижней границы CI подъёма (число не назначается, самоограничивает хвосты с малым N). Проверка июль / август / сент. **без подбора**, месяцы отдельно. Направление «любой». Подъём = точность / база (база метки той же ячейки). Испытаний: 900 строк на месяц (A1 4 семьи×28 порогов, A2 2×14, A3 102 пары D×q, A4 29 горизонтов×6 срезов); выбор — по 6 месяцам, проверка чистая; CI без поправки на 3 тестовых месяца, но все нижние границы >> 1, поправка порядка ×100 их не отменит.

## Что кривые показали
1. **A1 (оборот):** подъём растёт с порогом до ×70…140, дальше CI расходятся (N падает до сотен): **край найден внутри сетки**, не на её конце (в TK-443 край был у ×100 — теперь видно, что максимум ≈ ×70–140, а не «чем выше, тем лучше»). Цена — редкость: 0,06–0,12 срабатывания/сутки/монету.
2. **A2 (волатильность):** лучший порог ×14,6 вплотную к концу сетки (×18,2, выше — мало ячеек): **край надёжно не найден**, нужно больше данных/монет для хвоста. D=360 слабее D=90 везде.
3. **A3:** оптимум в углу сетки (самая короткая D=90, самый жёсткий q99,9): **кривая монотонна, край не найден** — вниз по D и вверх по q нужна расширенная сетка (D<90 — вне задачи владельца «≥1,5 ч»).
4. **A4 (горизонт после S10, направленный возврат = знак r60 × ход, б.п.):** при r60>0 среднее **отрицательно на всех горизонтах** (откат): −1,4 б.п. за 5 мин, −5,6 за 37 мин, −13 за 73 мин, −24 за 142 мин, −46 за 278 мин (мед. янв–июнь; 0 из 6 месяцев с плюсом при h≤37). На проверке знак тот же; CI исключает 0 только у части (авг., сент. при h 73–142; сент. 542). При r60<0 знак **нестабилен по месяцам** (янв −22,6, апр +2,2 при h=5) — устойчивой картины нет. Продолжения хода по средней нет ни на одном горизонте до ~12 ч; разворот знака (+119 б.п. у h≈2070 мин по мед. янв–июнь) на проверке не повторился (авг. −5,6, сент. −66). Горизонт «наилучший» правилом min-lo выбрать нельзя — кривая не имеет пика; 1/6/24 ч оказываются произвольными точками на монотонном снижении.
