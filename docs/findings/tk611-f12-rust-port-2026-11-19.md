### `ep_u0`: что различалось и почему
- `emp_coin` — различался на всех строках: доля пустых минут считается по сетке `N_MIN = SIGFEAT_DAYS·1440`; у TK-594/`ep_u0` — 74 суток (кэш `/data/p42-t566/cache`), у TK-599 — 80, порт был зашит на 80. Лечение: `--days` (по умолчанию `SIGFEAT_DAYS` или 80). С `--days 74` совпадает побитово.
- `ep_no`, `n_sig_ep`, `last_sig_ms` — различаются по построению и после `--days 74`: `ep_u0` — маршрут `Worker.do_universe` (сигналы одного уровня, не уходившие от него, сливаются в эпизод; признаки — на первом сигнале; `ep_no` — номер эпизода внутри `(монета, уровень)` по всем сигналам). Порт — `CandWorker`: строка sigsx = эпизод (`n_sig_ep = 1`, `last_sig_ms = sig_ms`, `ep_no` — номер кандидата по монете). Проверка классов (`rustfeat_f12_u0_classes.py`): на эпизодах из одного сигнала `n_sig_ep`/`last_sig_ms` совпадают (18 748 long, 21 315 short — 0 различий), на слитых различаются все (3 024 long, 2 959 short — ровно те строки, где `n_sig_ep > 1`); `ep_no` различается на 21 067 / 23 574 строк. Признаки от слияния не зависят (60 столбцов без этих трёх — 0 различий). Порт слияния не делался: он нужен только для служебных столбцов и требует полного sigsx с тиковым `away`.
