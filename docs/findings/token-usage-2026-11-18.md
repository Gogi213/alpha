# Расход токенов: разбор и меры (18.11.2026, В-158)

Источник: транскрипты Claude Code всех сессий alpha (`~/.claude/projects/*alpha*`, 7,2 ГБ), окно 12.11–17.11 (6 дней, 152 сессии, ~16 тыс. шагов).
Инструмент: `python -X utf8 tools/token-usage.py [дней]`. Единица — «эффективные токены»: вход ×1 + запись кеша ×1,25 + чтение кеша ×0,1 + вывод ×5; Opus ×1, Sonnet ×0,6, Haiku ×0,2 (соотношение цен API; точная формула лимита подписки неизвестна).

## Механизм

Каждый шаг перечитывает весь контекст треда, поэтому стоимость ≈ шаги × размер контекста.
- 66 % расхода — шаги с контекстом > 200 тыс., 18 % — > 400 тыс.
- Сессии: медиана 93 шага, p90 180, максимум 1 007 (исполнитель CPU-оптимизации коллекторов — 10 % недели).
- Состав контекста (оценка): результаты инструментов ~20 % (ssh 3 %, cat/sed/grep 5 %, Read 6 %), стартовый груз (~34 тыс.) 11 %, остальное — собственные размышления и ответы модели.
- Шаги с выводом < 300 токенов (опрос, ожидание, мелкий шаг) — 15 %.

## Проверка эффекта

Через неделю `python -X utf8 tools/token-usage.py 7`: контекст исполнителя на шаг (цель ≤ 120 тыс.), доля шагов > 200 тыс., доля коротких шагов, ед./день.

## Ограничения

Роль — по названию треда bb; сессии в основной папке без треда засчитаны координатору. Вклад инструментов — оценка по символам результата (/3) и числу следующих шагов до сжатия.
