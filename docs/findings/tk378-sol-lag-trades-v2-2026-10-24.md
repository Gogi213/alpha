# TK-378 v2: отрывы Gate-фьюч (сделки) vs DEX Solana — после возврата Судьи (24.10 01:06)

**Итог:** Gate-нога к DEX на сделках: после тейкера Gate (−15 бп) среднее по монето-суткам **положительно**, ДИ по суткам не
включает 0 при X = 50/100/200 бп (ALL4 = CLAUDIA+FONE+HOOKED+SI: +20,9 / +32,1 / +51,2 бп). Но медиана эпизода pnl 16–30 бп

это верхняя граница, не вердикт. Окно 8 суток, 29 монето-суток, зависимых (одни и те же дни SOL).

## Что исправлено (пункты Судьи)
1. **Цена DEX:** один квот-токен на монету. CLAUDIA/FONE/HOOKED/KIMCHI — WSOL (квот главного пула в пул-реестре TK-380 = SOL); у SI
   (главный пул SI/NVDAx) и STAMP (STAMP/ZEC) главного пула в слое свопов нет (SQD-выгрузка — только USDC/WSOL/USDT-ноги) —
   взят квот с макс. USD (SI: WSOL, STAMP: USDT). **ID пула в выгрузке нет, поэтому «свопы основного пула» не восстановимы; это proxy.**
   Чистка: USD ≥ 5, ±10 % от медианы ±30 соседей (было ±30 %).
2. **TQQQX исключён:** DEX-цена mint `XsjQP3…` 142,2 $ (мед., 375 свопов) vs Gate TQQQX_USDT 72,4 $ (×0,509); соответствие
   mint↔контракт не подтверждено (возможно сплит/другой токен) — до проверки вне расчёта.
3. **Издержки:** Gate тейкер 0,075 % ×2 = 15 бп (как TK-377) вычтен. DEX-нога: priority fee из свопов (мед. 14–50 тыс. лампортов ≈ 0,03–0,1 бп
   на ноге 1000 $) — пренебрежимо; **комиссия пула и проскальзывание в данных нет** (не измерены) — расчёт одноногий (Gate к DEX),
   DEX-нога не торгуется, поэтому комиссия пула сюда не входит; для арбитража «обе ноги» нужна отдельно.
4. **Блочный бутстрап по суткам** (4000 ресэмплов монето-суток), ДИ 95 %; «с контролем» — число эпизодов с контрольным входом.
5. `tools/compute/tk378-sol-lag.py` (1м-справка) закоммичен.

## Оговорки
1. **Спред и проскальзывание Gate-ноги не вычтены:** вход/выход по цене последней сделки в 10-с корзине, тейкер-вход платит спред;
   у тонких Gate-перпов он 8–85 бп (TK-377) — при медиане pnl 16–30 бп и 15 бп комиссий это может обнулить net. Главный риск вывода.
2. **Эфф. N мала:** 8 суток, ДИ по суткам с 5–8 единицами на монету; монеты коррелируют (общие SOL-сутки). ALL4 «29 монето-суток» — не 29 независимых.
3. Цена DEX — proxy основного пула (нет ID пула); у FONE/SI остаточные плохие принты (σ 2,6–4,3 тыс. бп).
4. Окно 15–22.10, один режим рынка; месяцев нет. STAMP — пропуск, TQQQX — исключён, KIMCHI — 1 сутки.
5. Испытаний: 6 монет × 4 порога = 24 клетки (+ ALL4 ×4), без подбора параметров; один проход.
6. Одноногий расчёт: хеджа/DEX-ноги нет, риск «DEX двинется, Gate нет» не в метрике.
