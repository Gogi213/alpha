## 3. Допуск пар и сетка клеток
- Допустимая пара·N: **N ≥ max(3 шага цены, G)** и **2N > комиссии круга 0,126 %** (4 тейкера); G = 2 · медиана полуспреда `hm` на разработке (разрыв пары Sell/Buy, %); шаг цены пары — максимум по двум биржам из `info[...]["tick"]` (наименьшая разность различных bid/ask по всему окну — свойство биржи; оговорка в п. 7). Допуск: 7972 пар·N из 9840 (ok: 302 / 600 / 725 / 764 / 773 из 773, bx: 443 / 908 / 1084 / 1179 / 1194 из 1195 при N = 0,1 / 0,2 / 0,3 / 0,5 / 1). Все N также печатаются в единицах G (медиана N/G при N = 0,1…1: 2,1 / 2,3 / 3,0 / 4,6–4,8 / 9,2–9,4).
- Клетка = группа {ok, bx} × N {0,1; 0,2; 0,3; 0,5; 1,0 %} × удержание L {300 мс; 10 с} × горизонт H {1; 6; 12; 24 ч} × предиктор {glob, win6, reg}. Базовая линия (не клетка) — naive24 в той же (группа, N, L, H).
- **Популяция клетки в точке t** — допустимые пары группы с ≥ 1 качелей (данного N, L) до t (отбор по прошлому). Клетка **считается**, если популяция ≥ 30 пар в первой точке теста (она растёт со временем). Это определяется по истории ≤ `t_split` — до счёта теста: допустимых пар с ≥ 1 качелей к `t_split` (L = 300 мс / 10 с): ok 40 / 8, 20 / 8, 14 / 4, 7 / 2, 3 / 1; bx 408 / 146, 547 / 58, 334 / 38, 118 / 19, 39 / 3 (N = 0,1 … 1). Значит считаются **9 из 20 троек** (группа, N, L): ok N = 0,1 L = 300 мс; bx L = 300 мс — все пять N; bx L = 10 с — N = 0,1 / 0,2 / 0,3. **Клеток: 9 × 4 горизонта × 3 предиктора = 108** (плюс 36 базовых). Остальные клетки в отчёте — «пар < 30», не вердикт.

## 4. Предикторы и исход (только данные ≤ t; частота — качелей/ч)
- `naive24` — «круги вчера»: качелей за последние 24 ч, (0,1 + k) / (1 + min(24, часов с начала пары)).
- `glob` — (0,1 + k) / (1 + часов с начала пары), k — все качели до t. `win6` — то же по последним 6 ч (боковая линия).
- `reg` — режим потока качелей: BOCPD по интервалам между качелями (`bocpd.bocpd_exp`, λ ниже), частота (0,1 + r) / (1 + возраст режима, ч); **режим берётся, только если его возраст ≥ задержки обнаружения + 3 интервала и ≥ задержки в часах**, иначе — `glob`. Задержка обнаружения — длина нового режима в момент, когда MAP-длина режима упала на ≥ 3 (по разработке, медиана); возраст на момент t идёт до t (тишина после последней качели снижает частоту).
- OU/AR(1) для прогноза не используются (`scale.md`: полураспад зависит от шага и длины оценки); PELT — только описание.
- Исход — число качелей, закрытых в (t, t + H]; качели — на исполнимых ценах Sell / Buy, удержание L.

## 6. Успех, плацебо, поправка
- **Метрика клетки** — среднее по точкам теста кросс-секционного Спирмена (предиктор, исход) по популяции клетки. Для H = 24 ч — одна точка.
- **Успех клетки** — выполнены все четыре: (i) Спирмен > Спирмена naive24 в той же (группа, N, L, H); (ii) Спирмен > θ; (iii) ≥ 30 допустимых пар с ≥ 1 качелей в истории (п. 3); (iv) Спирмен ≥ 0,2.
- **Плацебо (две штуки), R = 200 каждого, сид 20261115.** «Пары»: на каждой точке прогнозы реального ряда перетасованы между парами популяции. «Фаз-рандомизованное»: для каждой допустимой пары·N·L часовые счётчики качелей первых 56 ч (AAFT: набор значений сохранён, фазы случайны) → события расставлены равномерно внутри часа (события после 56-го часа — как есть) → **те же предикторы** (BOCPD заново, λ и задержки заморожены) и тот же Спирмен по тем же точкам теста. Фаз-плацебо — «худшее плацебо»: сохраняет разнородность пар и линейную память по часам, ломает остальное.
- **Поправка на множественные проверки — против худшего плацебо по всей сетке:** θ_пары и θ_фаз = 95-й процентиль по репликам от **максимума** плацебо-Спирмена по всем 108 клеткам (max-T); **θ = max(θ_пары, θ_фаз)**. (Буквальный вариант «максимум по клеткам от p95» не выше max-T; выбран max-T как более строгий; оба печатаются.) Клетка, прошедшая (ii), обгоняет худшую клетку худшего плацебо.
- **Флаг «≥ 1 качели/ч»** (горизонт 1 ч, часовые точки теста — каждая 2-я точка отсчёта; флаг — предсказанная частота ≥ 1): успех, если подъём (точность / базовая доля по популяции) **≥ 1,5 при ≥ 30 флагах (пара·час), больше подъёма naive24 в той же клетке и больше θ_флаг** — 95-го процентиля по репликам фаз-плацебо от максимума подъёма по клеткам флага (там, где флагов ≥ 30; реплик с флагами ≥ 10, иначе порог не применяется и это пишется в отчёте).
- Оговорка на числа: Спирмен усредняется по 30-минутным точкам, перекрывающимся по исходу; независимых наблюдений у клетки меньше, чем точек. Поэтому порог — по плацебо, а не по классическому p-значению.

## 7. Правило вердикта (до счёта)
- Если успешна ≥ 1 клетка или флаг — «предварительное свидетельство предсказуемости, 56 ч; требует повторения на новых данных»; в отчёт — список клеток, не «лучшая клетка».
- Если ни одной — **«на 56 ч (разработка 32 ч → тест 24 ч) ни один предиктор не превзошёл базовую линию и худшее плацебо; края нет»**; предложение колонок живой вкладки — только описательные (качелей за 1/6/12/24 ч, возраст и частота режима, глубина), без метки предсказуемости.
- Порог (ii), (iv), список клеток и правило флага не меняются после счёта; любое отступление — в раздел «Отступления» отчёта и в журнал.
