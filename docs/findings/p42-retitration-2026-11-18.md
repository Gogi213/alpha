## Отклонения и находки (финальный аудит критика `thr_7ijaib76qx` на `15dbabbd`: FIX — только текст отчёта, без пересчёта и без второго чтения августа)

Выбор заново по {0.5…8}: сглаженный счёт `s=1` = (−2,54 + 1,60 + 2,33)/3 ≈ +0,46, у `s=1.5` = (1,60 + 2,33 + 1,26)/3 = **+1,73** (лучший); плато `s=1.5` выполнено (соседи +1,60 и +1,26, порог 2,33 − 2,21 = +0,12).
