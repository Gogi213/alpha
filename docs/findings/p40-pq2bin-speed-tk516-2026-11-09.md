Правило в коде: словарь только при сжатой странице словаря < 64 КБ (`DICT_PAGE_MAX`; price ≤ 6 КБ, quantity ≈ 400 КБ, event_type/side < 100 Б; у OKX то же).

В коде оставлен BTreeMap + пакетная загрузка снимка; гибрид (хеш для количеств + порядок только для лучшего) по источнику не делался.
(3) Уровни zstd выхода (`tk516.sh zl`, cycles на bn/okx/bybit/gate, G; размер .zst bn): 3 (сейчас) 10,54/7,90/7,18/10,84, 12,75 МБ; 2: 9,67/7,42/6,06/9,46, 13,00 МБ (+2 %); 1: 10,97/6,95/6,97/9,69, 12,97; −3: 9,81/7,31/6,00/9,76, 15,84 МБ (+24 %).
