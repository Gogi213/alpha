# Почему минус в сделках Санчо + bp — разложение (В-70), финал 30.10

**Статус: финал — контроль п.4 и X1/X2 посчитаны.** Вердикты строк «объясняет» — после контроля.

1. **Объяснено:** комиссии = 71–100 % минуса (точный учёт). Совместный МНК (только O2 — у O1/O3 прошло ≤ 1 строки): средняя+высокая доля комиссий/риск даёт −11,8 bps из −6,75 (остаток при z=0: **+5,77 [3,96; 7,61]**, накрывает ≥ 0), тренд BTC по тренду −0,70 [−1,14; −0,26]; корр. z1,z2 = 0,02. Это стратификация по размеру стопа (механическая), без контроля п.4 — не рыночная причина.
2. **Главное:** минус — это комиссии В-47/В-71 (тейкер 3,15 / мейкер 1,26 bps по ногам), а не фандинг и не новости. Gross у O1 +2,5, у O2 −2,0, у O3 −0,13 bps.
3. **Недоступно:** минутный SPY/QQQ (<1 года) — «палки вниз на SPY» проверены только по дневным барам; гэп стопа в симуляции не моделируется (X3).

**Контроль п.4 (шаг 4а, `tools/tk462_step4.py` → `P-TK462-step4a-control-2026-10-30.csv`):** контроль = сделки C1/C2 из кэша TK-455 (случайные касания/псевдо-уровни той же монеты и ТФ, те же правила выхода, якорные ячейки: O2 — 2,74 млн, O1 — 4,87 млн) вместо «случайных баров ±30 сут» плана — готов, уже посчитан тем же симулятором (В-213). Итог: **C7** вклад реальные 11,85 [10,59; 13,12] против контроля 10,48 [9,80; 11,15], разность +1,38 [−0,06; 2,81] → «свойство правил (ширина стопа), не сигнала»; **FOMC SPY<0 (O1, в окне)** реальные 83,7 [50,6; 116,9] против контроля 75,3 [44,3; 106,4], разность +8,4 [−37,0; 53,8] → «свойство окна, не сигнала»; **C5 BTC L=20 по тренду (O2)** реальные 0,845 [0,40; 1,29] против 0,242 [0,03; 0,45], разность +0,60 [0,11; 1,10], но у контроля знак по годам не един (2020, 2023, 2024, 2026 ≤ 0) → «объясняет (после контроля)», малое: 0,6 bps из −6,8. (Вклад в окне/всей выборке: строки «в окне» и «все сделки» не складывать.)

**План добора (шаг 4, calc, выполнено частично):** контроль п.4 — для 4 строк «объясняет (предв.)» (C7 средняя/высокая O2, C5 BTC L=20 O2, FOMC SPY<0 O1): до NC=5 случайных баров той же монеты/ТФ/слота суток ±30 сут, тот же выход через `tools/compute/tk461_sim.py` (`trade`, `fee_bps`), seed 462; C7 механичен (комиссия фиксирована, стоп шире — доля меньше), контроль ожидаемо повторит знак — это свойство ширины стопа, не сигнала. X1/X2 — тем же симулятором по минуткам на подвыборке O2 (X1: обе цели в одной минуте; X2: вход +1/+2 мин).

## Что значит
- Гипотеза владельца «фандинг» — не подтверждена (≈0 bps). Гипотеза «новости/отчёты Google/Amazon → палки вниз на SPY» — не подтверждена (дневной SPY, ≈0); единственный сигнал — FOMC у O1, предв., n=1393, без контроля.
- Кандидаты для TK-461 (фильтры/отмены): сетапы с долей комиссий/риск ≥ q33 (O2) — минус в них больше; это объяснение задним числом (пороги по всей выборке), не сигнал вперёд.

Алгоритм: варианты — полный пересчёт сделок / чтение кэша TK-455/458; замер — 0 расхождений fee/gross с кэшем (O3, f=кэш); выбран — кэш + признаки по минуткам, потому что В-213 (не пересчитывать) и пересчёт даёт тот же net.

Оговорка X1/X2: фандинг за месяцы с отказом REST (269 монета-месяцев, в основном 2026-10 и 2021) взят 0 — вклад фандинга ≈0 по шагу 1, на сдвиг X2 не влияет (разность задержек).

Алгоритм X1/X2: варианты — повтор слоя 3 на подвыборке / по всем 84 монетам × ТФ; замер — 168 заданий, 0 отказов; выбран — все монеты, NX=15, симулятор `tk461_sim.py` (тот же, что TK-455).
