### 7.2 Где мы позади / впереди (по осям запроса)

| Ось | Позади | Впереди / на уровне |
|---|---|---|
| 1. Роли и SOP | нет — устав ролей, тикеты, блокноты соответствуют MetaGPT/Gas Town | у нас SOP закреплён уставом и хуком роли (молчание, один тикет на запуск) — формальнее, чем у большинства |

Кто решает «дальше» | **Gas Town** и **CrewAI Flows** держат «что дальше» в детерминированном коде/сторожах, LLM — внутри шага; у нас продолжение после ожидания всегда запуск роли (§6, ось б): wait_for-met 177 запусков, 139 млн контекста, 0,82 млн выхода | диспетчер и таймер — детерминированные (как Flows); `--next` — явная передача, не LLM-менеджер |

**Предостережения из практики других (учитывать, не копировать слепо):** (а) Cognition — параллельные агенты ломаются на скрытых
решениях; наш аналог — Инженер ×3 на пересекающихся файлах (риск уже виден в `git commit -o`); (б) Claude Code teams — «task status
lags», тиммейты не переживают resume; (в) Magentic-One — без счётчика застоя агенты ходят по кругу, у нас аналог `loop-warning`
(1/сутки) и `blocked ×5`; (г) популярность ≠ качество: claude-flow при 73,9 тыс. звёзд и 716 открытых issue показывает
собственные бенчмарки скорости, а не решений — как образец не брать.

**Не заимствовать:** параллельные агенты-«коллеги» с прямой перепиской (Claude Code teams) — Cognition и сама документация Claude Code
называют риск конфликта решений и роста токенов; у нас параллельность через тикеты и общий сервер уже ограничена
замком. Рои с консенсусом (claude-flow) — нет подтверждения качества. Миграция на фреймворк (CrewAI/AG2/LangGraph) — наши роли
уже реализованы как CLI-сессии с уставом; выгода заимствований п. 1–5 достигается правкой диспетчера.

**Итог по вопросу владельца:** по роли/SOP и ревью мы на уровне лучших открытых проектов, по связи/памяти/автономии — на уровне
Gas Town с недостающими двумя деталями (детерминированное продолжение; формализованный старт сессии). Главный разрыв — п. 1: ≈ 40 %
расхода токенов идёт на пробуждения, где решение известно заранее.
