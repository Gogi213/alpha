# TK-373 / P-25: направление Bybit → DEX с контролями и «догон» пула как альфа — 23.10.2026

**Итог.** (1) Направление **Bybit → DEX** держится при всех контролях: после резкого хода середины Bybit (≥ q95 своей монеты) цена пула идёт вслед на +1,6 / +3,9 / +6,6 бп (10 / 60 / 300 с; p_rand 0,0002, q_BH < 0,001), Bybit дальше ≈ 0 (+0,26 / +0,33 / −0,16; на 300 с p = 0,71). Среднее положительно в каждые из 6 суток (незначимо 20.10 на 60 с и 21.10 на 300 с), у 90–94 % монет (60 / 300 с), на v3-пулах без комиссионного «отскока» цены (+1,5 / +3,5 / +6,1), в каждой сети. «DEX ведёт Bybit» по знаку Snet L/F — не подтверждено ни прямым, ни обратным тестом, ни контролем предхода (`tk373-pre-control-2026-10-23.md`: наклон Snet на предходе отрицательный, размер 0,3–3 бп). (2) Как самостоятельная альфа «догон пула» **не доказан**: брутто +2…+7 бп на типичном событии ниже комиссии любого пула, кроме 1–5-бп уровней; выше круга издержек только Base (+15,7…+28,9 бп, 12 монето-суток) и сильные события (+12,8 бп) — оба на малом N, комиссия пулов и газ **не измерены** (см. «Не сделано»).

**Метод.** Данные и события — `tk373-rev-2026-10-23.md` (77 монет, 16–21.10, W ∈ {10, 60} с, порог q95 по 15.10, не чаще раза в 60 с; контроль — те же моменты ±3600 с, net = M − среднее контролей). Добавлено `tools/compute/tk373-dir.py` (на calc, ≈ 12 с, 15 ядер): SE по кластерам монето-сутки; **p_rand** — знаковая перестановка кластерных сумм net (4000 перестановок; минимум 0,0002 = 1/4001); **BH** по 28 строкам «все»; срезы по суткам, силе события (доля порога), сети, монетам; прирост dpx между горизонтами (вход с задержкой на 10 / 60 с). v2/v3: `tk373-rev.py` с `VERS=v2|v3` (метка Dexscreener `pools-all.json`; пулы без метки — Aerodrome, Sushi, часть Pancake — в обе версии не вошли). ## Догон пула как альфа: брутто против издержек (`-costs.csv`)
Брутто = net-ход цены пула по стороне события. Вход по текущей цене пула реален (цена v3-пула — маржинальная, цена v2 — по суммам свопа). Реалистичный вход — после задержки блока и отправки, поэтому берём прирост после задержки (+2,3 бп на 10→60 с, +2,7 бп на 60→300 с).

| Страта (брутто, бп) | круг по DEX при комиссии 1 / 5 / 25 / 30 / 100 бп |
|---|---|
| все, вход t0, выход 300 с: +6,6 | +4,6 / −3,4 / −43 / −53 / −193 |
| все, вход +10 с, выход 60 с: +2,3 | +0,3 / −7,7 / … |
| v3, вход t0, выход 300 с: +6,1 | +4,1 / −3,9 / … |
| сильные ≥ 3 порога, 60 с: +12,8 | +10,8 / +2,8 / −37 / … |
| Base R60, 300 с: +28,9 | +26,9 / +18,9 / −21 / … |

Положительно только при комиссии пула ≤ 5 бп (tier 0,01 %/0,05 % — у альтов такие пулы редки и мелки) и до газа и проскальзывания собственного свопа. Вход на DEX с хеджем на Bybit (ход Bybit дальше ≈ 0) не спасает: нога Bybit платит свой taker и ничего не добавляет. **Вывод: на типичных пулах «догон» не покрывает комиссию; кандидаты — Base и сильные события при низкой комиссии пула, N мало (12 монето-суток / 2 837 событий), не проверено на месяцах.**

## Не сделано / ограничения
- **Комиссия пулов (fee tier) и газ на дату не измерены:** в swap-данных нет tier, `fee()` читается eth_call по пулам (публичные RPC отвечают 429 — тот же затык, что у Mint/Burn); газ — baseFee блоков 16–21.10 по сетям. Таблица издержек даёт безубыточность по уровням комиссии, а не оценку конкретного пула. Следующий шаг при слове Судьи: fee() по пулам выборки + baseFee, затем net по пулам.
- Окно: одна неделя, 77 монет, месяцев нет; эффективное N = число монето-суток (402, по сети 12–204), не событий. Суточная картина dpx300 нестабильна (21.10: p = 0,23).
- Предпоток DEX > 0: часть хода идёт на обеих площадках одновременно (общая причина, блоки с интервалом 0,45–12 с не разведены).
- Цена пула = цена последнего свопа; слаботоргуемый пул даёт «первый своп после хода» как догон — сильнее всего заметно на малых монетах; реальный вход был бы по текущей марже пула, не по последнему свопу.
- Месяц на проверку не отдан; Bybit-нога (исполнение, taker) не моделировалась.
