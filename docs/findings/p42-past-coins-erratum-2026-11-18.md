# П-42: дефект докачки двух монет в `p42-past`, `p42-past06`, `p42-holdout` (поправка 18.11.2026, TK-596)

**Что случилось.** Скрипты докачки `dl_past.sh` (`/data/p42-past`, `/data/p42-past06`) и `p42-dl_holdout.sh` (`/data/p42-holdout`) строили файл задач из `/data/p42-t566/symbols.txt` через `tr ',' '\n' | sed "s/\$/ <дата>/"`. В `symbols.txt` нет перевода строки в конце, поэтому последняя строка дня (`龙虾USDT`) склеивалась с первой строкой следующего дня (`0GUSDT`): обе задачи уходили в `curl` с испорченной датой и получали 404. Остальные 564 монеты скачаны полностью.
