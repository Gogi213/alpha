# П-07 — Г-85б ступень 2 (σ-лестница) и H6 at/behind Г-85а — решение А/Б/В (TK-004)

Протокол `docs/research/P-07-g85-titration.md` (§6, §10, §13 поправки 1–4), правило продолжения —
`docs/research/reviews/P-07-2026-09-27-continuation-rule.md` (записано до чисел). Август и сентябрь — каждый
отдельно (В-115); суждение по точке на двух месяцах, не статистика. Числа — **до приёмки Судьи** (на дашборд не
выкладываются: TK-003).

## Итог

- **Г-85б — случай В (стоп титрованию на августе–сентябре).** «Проходит» нет ни у одной клетки ступени 2.
  Условие Б1 выполняет только H14 `k1` (только первый подход стены): август 0,156 ≤ база − 0,10 = 0,174, сентябрь
  0,159 ≤ 0,256; но Б2 не держится — без худших одних суток август 0,508. Сдвигающих осей нет.
- **База Г-85б — «на границе»** (август 0,274, сентябрь 0,256; $171 / $116 на $500). Для сравнения (описание, не
  вердикт, Судья `6f01bb3` п.3): база Г-85а — «не проходит», 0,421 / 0,148, $109 / $174. Лестница лучше в августе,
  хуже в сентябре — как у `single@fr+1` на Г-85а.
- **Г-85а H6 `at`/`behind`** (замена вырожденной `before`, `e01719d`): доля ≈ 1,0 в обоих месяцах, деньги в минус —
  «не проходит»; решение В по Г-85а (`4d49252`) не меняется. У Г-85б то же: стоп на уровне стены или за ней
  не работает на обоих вариантах.
- **В архив январь–июль** по правилу: базы Г-85а и Г-85б, главный (H0); справочно — лучшая клетка ступени 2
  каждого варианта по доле августа: у Г-85б — H14 `k1` (0,156), у Г-85а — `single@fr+1` (0,164).

## Как считали

Сетка — `bin/alpha-e74f200-v3 --hold-step skip --exit-group on`, одни сутки — один вызов `--cells` на все 61 клетку
пачки (В-136, `tools/compute/archive/p07-cells.py`), 54 суток, 3243 клетка-суток, 55 заданий gridq без падений. Метод
сверен пробой 03.08: база Г-85а в одном вызове с σ-формами на новом бинарнике — побайтно та же, что прежняя.
Чтение — `tools/compute/archive/p07-read.py --variant b` (busy-replay → portfolio-sim $2500/$500 без потолка, TRX вне
пула → KPI H = 5 сут); H10 — `p07-h9h10.py --variant b --no-pauses`; H9р/H14 — `p07-h9r-h14.py --variant b`.
Тождество: клетка `keep` (busy-replay без исключений) = база Г-85б, побайтно по числам.
Форма Г-85б: `ladder3x0..0.0409sw2` (В-131, k₀ = 4,5 / σ₂₄₀ медиана 110 bps). σ на взводе: без σ — 233 сигнала
из 4 019 305 до фильтров наборов, все — TRXUSDT 23.09 (таблица σ TRX кончается 23.09 16:35 UTC); TRX вне пула
(В-105), на составы Г-85а/Г-85б не влияет.

Доля — часы с ожиданием перехая > 5 сут (точка); в скобках — худшая при исключении любых одних суток / любой
монеты. Δ$ — парная разница с базой своего варианта по суткам, 95 % блочный бутстреп. §10 — вердикт клетки с
правкой Судьи 27.09 («не проходит» — минимум по исключениям > 0,10). Б1/Б2/Б3 — условия правила продолжения.

## Счётчик испытаний (В-124)

Прибавка этой пачки к родословной Г-85 (записана до счёта, Судья 23:29): Г-85а +25, Г-85б +52, сравнение
Г-85а ↔ Г-85б +1 = +78. Прочитано по правилу: Г-85б ступень 2 — 23 клетки (база, H2 3, H6 4, H7 4, H10 2,
H9р 3, H14 6), Г-85а — H6 at/behind 2. H10 «первые 3/5 сделок эпизода» у Г-85б не считались (как и у Г-85а —
не реализовано), в счётчик не входят.

**Печать ступени 3 — нарушена частично (пишу как есть).** По решению В ступень 3 не читается. Но в выводе
фоновых прогонов в сессии исследователя промелькнули строки итога (n, $, доля) семи запечатанных клеток:
Г-85а `H3-100000`; Г-85б `H1-f25/f50/f75`, `H13-gone90wall0/wallx0/wallk0` (у H13 — только n и начало $ августа).
Для выбора они не использовались; по правилу продолжения эти 7 клеток входят в счётчик и в родословную.
Остальные клетки ступени 3 обоих вариантов (Г-85а 22, Г-85б 21 — из 24 сеточных + 3 H1) — посчитаны, запечатаны, не читались.
