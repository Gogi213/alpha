## Что не проверено / оговорки

- Глубокая проверка hl (вся книга по свечам) — на 9 файлах одних суток (15.09), по минутным экстремумам; на всех файлах вместо неё — сверка со сделками (п. 4б): цена вне всей глубины в момент сделки у 0,14 % сделок linear (220 файлов), у spot 0; разобраны 4 файла 15.09 (всплески на резких движениях, лента впереди книги на секунды), остальные 216 файлов не разбирались.
- 4,4 % (linear) / 7,6 % (spot) сделок с ценой, которой нет в книге даже со сдвигом ≤ 2 с, — причина не установлена (п. 4б).
- Свечи TK-411 — минутные: пересечение bid/ask внутри минуты и порядок событий внутри нее они не проверяют.
- Содержание уровней глубже 20-го сверялось только в выборке (на снапшотах — только топ-20 каждой стороны).
- Часы биржи: `ts` (системное время отправки) против `cts` (матчинг) в архиве расходятся на 0,1–8 с (пример ICXUSDT 15.09: 7,6 с на первом снапшоте) — время событий в книге берётся по `ts`; для лид-лаг-исследований с DEX это нужно учитывать отдельным разбором (не мерено).
