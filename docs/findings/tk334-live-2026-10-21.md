# TK-334 [вживую] — продление живого задания на calc (21.10, PR #78@688a14f2)

Код: `alsched.py` `_extend_live` + `SystemdBackend.extend_live` (drop-in `/run/systemd/transient/<юнит>.service.d/50-live.conf` + `daemon-reload`;
`systemctl set-property RuntimeMaxSec` на systemd 257 отказывает — `/data/tk0334/probe-systemd.txt`). Демон на calc перезапущен 22:24 CEST при нуле
замороженных; бэкап `jobs/` — `/data/tk0334/jobs-backup`. Сырьё: `/data/tk0334/live-mon.txt`, `live-a.out`, `jobs/<id>.json`.

Отличие от плана Судьи (review-1, п.3): лимит 600 с (не 1200), скрипты 900 с (не 2400) — тот же механизм, короче ожидание. Ядро 1, prio 5, kind gate.

| | (а) живое, id 1020222445105 | (б) зависшее, id 1020222446111 |
|---|---|---|
| задание | цикл ЦП 55 с + запись файла, всего 900 с | `sleep 900` |
| лимит заявки | 600 с | 600 с |
| ЦП за окно 300 с | 100 % заявки (122,4 ЦП-с на 122,5 с) | 0 % (0,0167 ЦП-с, не растёт) |
| решение демона | `22:29:56 ЛИМИТ ПРОДЛЁН … живо (ЦП 100 % …, свежие файлы да); max_runtime +3600 с → 4200 с, продление 1` | `22:45:30 ЛИМИТ НЕ ПРОДЛЁН … не живо (ЦП 0 % …); снимется по max_runtime` |
| `RuntimeMaxUSec` юнита | до 10min → после (22:30:17) **1h 10min** | 10min (не менялся) |
| конец | работало 936 с (> старого лимита 600 с), `rc=0`, `finished` в live-a.out | снято systemd на 591,6 с активных (~607 с стены), `rc=143`, `ЗАДАНИЕ УПАЛО … timeout (RuntimeMaxSec)` 22:50:31 |

Итог: живое продлено и дожило до `rc=0` за старым сроком (юнит реально принял drop-in); зависшее снято по лимиту, как раньше.

Замечания:
- (б): в строке «свежие файлы да» — файлом-«прогрессом» стал `live-mon.txt` монитора в том же `cwd`; на решение это не повлияло (правило: ЦП ≥ 0,02 заявки **и** (ЦП ≥ 0,5 или диск/файлы)); (б) отсечён по ЦП.
- Код выхода снятого по лимиту — 143 (SIGTERM systemd), а не 124: так alsched фиксировал timeout и до TK-334 (причина `timeout (RuntimeMaxSec)`).
- Старый `extend` (после разморозки) на calc так же не меняет срок юнита — не трогал, ошибка E-005.
- Пороги (0,02 / 0,5) — `docs/findings/tk334-thresholds-2026-10-21.md`.
