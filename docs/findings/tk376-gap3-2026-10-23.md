# TK-376 (G-016) проход 3 — цена CEX = середина стакана Bybit (lob seconds)

**Срез:** 477 монет, 802 монето-суток (эпизоды), 808 пул-суток, ETH/Base/BSC, 15–21.10, свопы пулов с fee() (проход 2). Цена CEX на секунду i = середина на конец секунды i−1 (до свопа). Скрипты: `tools/compute/tk376-gap3.py`, `tk376-summary3.py`; сырьё calc `/data/tk0376/run4/{episodes,ctrl}.csv` (628 тыс. эпизодов); таблицы — `tk376-gap3-strata-2026-10-23.csv`, `tk376-gap3-ctrl-2026-10-23.csv`. Охват: не покрыты Solana, Arbitrum и др. сети, пулы монет вне 367 с fee; доля оборота DexScreener **не посчитана**.

## Числа (ALL, mid Bybit; проход 2 по последней сделке в скобках)
- Эпизодов 627 923 (888 тыс.); max-gap p50/p90/p99 = 12,2 / 48,3 / 124 бп (22,9 / 69,6 / 196). >30 бп 185 тыс., >50 бп 59 тыс., >100 бп 16,2 тыс.
- Длительность до |gap| ≤ fee: p50 7 с, p90 115 с, p99 1 136 с (11 / 206 / 1 895).
- Закрывает ход CEX (только mid) 60 %, пул — 40 %; открывает пул 30 %; один своп в той секунде — 30 %. Доля закрытия в том же блоке, что открытие, ≈0 (не информативно: сравнивался блок первого свопа эпизода).
- Net_1 (вход через 1 с, − taker Bybit − fee пула, **без газа и глубины**): медиана −1,9 бп, в плюсе 30 %, среднее +0,1 бп [−0,6; +0,8] (bootstrap по монето-суткам, 802 кластера). Net_5: −0,6; net_blk: −0,9.
- По сетям (net_1 среднее / медиана): Base −0,9 / −2,4 (131 кластер); BSC −0,7 / −1,3 (383); ETH +2,6 / −3,5, интервал [−0,2; +5,9] (288).
- По капу (прокси — оборот Bybit 24 ч, рыночной капитализации в данных нет): <5 млн +2,4 [+0,9; +4,1]; 5–50 млн −1,4; ≥50 млн −1,6 [−2,0; −1,2]. Тонкие пулы (<200 свопов/сут) +16,5 [+5,8; +31,5] — это артефакт устаревшей цены тонкого пула (контроль ниже), не вывод.

## Контроль (|gap| в ВСЕ секунды пул-суток, без условия эпизода)
Медиана |gap| в случайную секунду = **30,9 бп**, 66 % секунд выше fee, 25 % выше 50 бп, 10 % выше 100 бп (ALL, 69,7 млн с). Ликвидные пулы (≥1000 свопов/сут): 12,9 бп / 6,6 % выше 50 бп; тонкие (<200): 53,9 бп / 57 % выше 50 бп. ETH 41 бп, Base 35, BSC 19.
Вывод: «расхождение > fee» — **обычное состояние** пула относительно CEX (две трети времени), а не редкое событие; эпизоды по определению «|gap| > fee» почти равны этому состоянию. Величины эпизодов (p50 12 бп) не выше контроля — отдельный сигнал в них не доказан.

## Что не так в этом проходе (по честности)
1. **Страта max_gap[50,100) net_1 = +11 бп [10,2; 11,7], 70 % в плюсе — смещение вперёд**: max_gap берётся по всему эпизоду (знание будущего), net_1 из-за этого завышен. Использовать нельзя; нужны страты по open_gap (на момент входа). Не пересчитано.
2. Цена пула после свопа по sqrtPriceX96 / резервам — **не сделана**: в данных свопов (`price_usd`, `price_quote`) состояния пула нет, нужен RPC-разбор Swap/Sync; цена только по свопу (fee очищена).
3. Адреса/роутеры закрывающих свопов — **не сделаны** (в данных нет `from/to`; есть `tx`, `block`; нужны receipts).
4. Газ: выборка 60 receipt/сеть через публичные RPC запущена (`tk376-gas.py`, `/data/tk0376/run4-gas.json`), к сдаче не завершена; в net газ не вычтен.
5. Страты по суткам и по монетам (топ/хвост): сутки и топ-15 монет — в csv; интервалы монето-суток есть у страт со ≥30 эпизодов.
6. Глубина (размер ≥1000 USD, проскальзывание v3/v2) — не сделана; net выше — оценка сверху.
7. Охват DexScreener (доля оборота монеты в наших пулах) — не сделан.
