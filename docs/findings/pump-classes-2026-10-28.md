**Согласованность срезов.** vol_pre и v_in выше контроля на обеих биржах и во всех терцилях оборота, где ячейка не мала (Gate: vol_pre +0,27/+0,29, v_in +0,67/+0,57). **Что исправлено по возврату.** (1) Нулевая модель — перестановка каждого столбца независимо на тех же признаках (200 повторов, 95-й проц.), а не C1 с другим набором. (2) vol_pre/оборот24 Gate: свечи разрежены, пробел ≠ «нет данных» → пропуски ≤20 %, признаки вернулись в классы. (3) D-подмножества {90,180}, {720,1440}, ход ≥×1,5, ×2, без D/длит — k=2…6 во всех сильнее нулевой (силуэт 0,09–0,23 против 0,05–0,09). (4) Срезы «общего» по терцилям оборота и по бирже посчитаны.

**Оговорки.** (а) Силуэт 0,18 мал в абсолюте: «сильнее нулевой» ≠ «есть кластеры» — глядя на ARI, это непрерывный градиент по D. (б) Справка: C1 без ход/X давал 0,3 (неравный набор) — для сравнения не годится. (в) Выборка 433: 4761 кластеров сент. с признаками из 32 529, доли с весом 1/π: класс 0 — 80 %, класс 1 — 20 %. (г) Август — только охват и ARI сент.→авг., отдельный счёт «общего» на августе не делался; общее подтверждено только на 16–30.09 (протокол требует оба месяца — не закрыто). (д) Каталог TK-414 и notes-2: кросс-таблица не построена (каталога событий нет в входе).

**Что дальше / нужно решение.** Не закрыто по протоколу: «общее» на августе (оба месяца); кросс-таблица с каталогом TK-414. Классы — по ARI не подтверждены; вопрос Судье: принять «один непрерывный градиент по D, классов нет» как итог шага 3 или требовать V0/V1 и Jaccard-бутстреп на k=2.
