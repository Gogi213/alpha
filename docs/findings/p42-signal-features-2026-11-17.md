## Коротко

**Пошло в пробой (метка O3: цена на ≥ 1 % выше уровня раньше, чем вернулась ниже уровня; окно 60 мин от сигнала; опорная цена — среднее пивотов): лонг 4,4 % (76 из 1 726 эпизодов подхода; 95 % по блокам суток 2,7–5,2 %), шорт 4,6 % (64 из 1 377; 3,4–6,2 %).** Контроль — случайные моменты тех же монет и суток с псевдоуровнем на том же расстоянии: 3,2 % и 2,9 % (разница +1,2 и +1,7 п.п.). Эпизодов 3 103 (сигналов 3 143, уровней со ≥ 1 сигналом 1 593); пробоев всего 140 (на 37 монетах лонга и 34 монетах шорта; на 5 монетах лонга — 26 из 76). **Из 16 первичных проверок (8 признаков × 2 стороны, Холм по 8 на сторону) не подтвердилась ни одна**; различимый эффект AUC при фактической доле метки 4,4–4,6 % — около 0,17 (лонг) и 0,19 (шорт) от ½ (записанная до чтения сетка p = 0,1…0,5 давала 0,117 / 0,131, доля оказалась ниже сетки), так что «связи не видно» значит «не больше этого», не «нет». Результаты по четырём темам владельца:

1. **Чистый уровень против зоны (есть переколы):** лонг — чистый 3,5 % (41 из 1 170), зона 6,3 % (35 из 556): разность +2,8 п.п. [−1,4; +6,5], но в половине A −2,1, в B +6,8 (знаки разные); шорт — чистый 4,9 % (44 из 901), зона 4,2 % (20 из 476): −0,7 п.п. [−4,0; +3,0], знаки по половинам разные. AUC `pierce_ep` 0,576 / 0,504, `spread_tau` 0,490 / 0,435 — связи не видно. На независимых подходах (843 / 772 эпизода) разности +0,3 и −0,5 п.п.
2. **Разреженный график.** Мера «доля пустых минут за 6 ч» (`emp6h`) вырождена: в пуле (U1) и вне пула (U0, 226 580 эпизодов) пустых минут перед сигналом нет ни у одного — группы Z нет, AUC ровно 0,500. По числу сделок в минуту (`tpm60`): нижний квинтиль (≤ 91 сделки/мин лонг, ≤ 97 шорт) — лонг 8,7 % против 3,4 % вне (разреженных пробивает **чаще**), шорт 2,8 % против 5,2 % (реже); знаки разные, AUC 0,363 (Холм 0,244) / 0,465. Вне пула (U0) нижний квинтиль `tpm60` пробивает реже на 0,4–0,5 п.п. (1,1 % против 1,6 %; 1,4 % против 1,8 %), объясняет 0,1 % непробоев (модельное число). Сделки `ow_e` в разреженной группе по `tpm60` (добавлено после чтения): лонг 62 сделки −$46 (среднее −0,75), шорт 62 сделки −$99 (среднее −1,60); вне группы лонг −$82 (−0,36), шорт +$67 (+0,39). **Что нашлось вместо разреженности — оборот (найдено на этих данных, разведка):** пробой по метке 1 % падает с 8,3–9,0 % в двух нижних квинтилях суточного оборота до 0,8–0,9 % в двух верхних (лонг; шорт 9,0 % → 1,7 %), AUC `turn24h` 0,271 лонг / 0,336 шорт, `turn1h` 0,282 лонг (Холм по 40 — 0,020 на пределе разрешения бутстрепа; знак тот же в A и B). Волатильность не объясняет: NATR по квинтилям оборота 57–66 бп (у верхнего шортового 82), метка «1 NATR» даёт тот же градиент (лонг 9,2 % → 2,3 %). Но при возврате глубже 0,1 % (вместо любой сделки ниже уровня) градиент почти исчезает (лонг 12,7 % → 8,4 %, шорт 14,8 % → 13,2 %): значит, часть эффекта — свойство метки «ни одной сделки ниже уровня» при редких сделках.
3. **Резкий подход и проторговка.** `mv5` (ход к уровню за 5 мин в NATR): AUC 0,553 / 0,554 (Холм 1,0 / 1,0); верхний квинтиль (> 3,2 / > 3,6 NATR) пробивает 6,9 % и 6,7 % против 3,6–4,0 % и 3,7–4,9 % в остальных — знак в A и B тот же только у шорта. `cons60` (минут проторговки у уровня за час): шорт AUC 0,371 (p 0,009, Холм 0,076, знак в A и B тот же, не подтверждено): **без проторговки (`cons60` = 0) шорт пробивает 6,9 % (48 из 699), с проторговкой ≥ 1 мин — 1,8–2,6 %**; лонг 4,9 % против 3,3–4,6 % (AUC 0,475, связи нет). То есть данные показывают обратное ожиданию «резкий подход без проторговки — ничего не улетит»: у резкого подхода без проторговки доля 7,3 % (лонг, 13 из 177) и 8,0 % (шорт, 15 из 188), у резкого с проторговкой — 6,4 % (10 из 157) и 3,0 % (2 из 66). Различия на пределе различимого и держатся на 140 пробоях — не подтверждены.
4. **Корреляция с BTC и ETH.** `c5_btc_7d` / `c5_eth_7d`: AUC 0,443 / 0,457 лонг, 0,438 / 0,437 шорт, интервалы (0,33–0,59) накрывают ½, Холм 1,0 — связи не видно; верхний квинтиль корреляции с BTC пробивает 2,6 % (лонг) и 3,0 % (шорт) против 3,0–6,9 % в остальных корзинах, знак AUC − ½ отрицательный в A и B, но не подтверждено. Пары владельца за 74 сут.: STXX–CLANKER r = 0,126 (остаток после беты BTC 0,032, частная по BTC+ETH 0,018), STX–CLANKER 0,214 (0,066) — вместе не ходят, остаток — шум; STXX–KORU 0,555 (0,498; 95 % суток ≥ 0,3) — ходят вместе, как акции. Корреляции всех монет со всеми — раздел «Корреляции всех со всеми».

**Достижение расстояния до уровня** (лонг / шорт, 60 мин от сигнала): 0,2 % от уровня достигают 97,3 % / 97,3 % эпизодов (в среднем за 51 / 73 с), 0,1 % — 93,8 % / 94,6 % (109 / 145 с; средний неблагоприятный ход до этого 32,1 / 34,9 бп), 0,05 % — 91,9 % / 93,0 % (129 / 195 с; 37,5 / 40,9 бп); среди достигших 0,05 % пробой 4,8 % / 5,0 %. Расстояние 0,1 % от уровня (вход ближе к уровню — для шорта) достигают 94,6 % шортовых эпизодов в среднем за 145 с. **Метка считается строго: «возврат» — любая сделка ниже уровня после касания; поэтому O4 «возврат раньше пробоя» = 86,6 % / 87,5 % (почти все касания), O2 «касание» = 0,0 %.** С возвратом глубже 0,1 % пробоев 10,7 % (лонг, 184) и 13,4 % (шорт, 185).
