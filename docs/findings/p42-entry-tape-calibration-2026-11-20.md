# П-42 §13.58 (TK-658): калибровка входа по ленте на всех сутках окна — 21.11.2026

**Риск и прибыль баз (первым делом):** `L_base` h775 — R:R 1,24, стопов 21, стоп в среднем −25,40 $ = 10,16 % маржи при плече 2; `S_base` — R:R 2,63, стопов 7, −16,29 $ = 6,52 % маржи. Откалиброванные варианты: лонг R:R 1,10 (движок `slip = 0`), шорт 2,80 (`P_V`); убыток стопа меняется меньше чем на 0,2 $.

Слова владельца: «Что то осталось досчитать?» (решение координатора В-165; аудит TK-637 строка 22). Протокол — летопись PS-930 (§13.58) и PS-931 (§13.58.1), записан до счёта; критик `thr_n2ij7m7n7z`: PASS протокола (`d7f0bba4c`) и кода (`e07b8d761`, исправление `c8e1a29f3`). Окно 01.07–13.11 (136 сут.), h775, сутки ≥ 14.11 не читались. Задержка 4 мс (В-168). Всё — **найдено на этих данных**, описательно (0 испытаний).

## Ответ

**По ленте вход не хуже модели (модель, на допущении «книга в момент входа ≈ то, что съели следующие тейкеры»); единственная сверка с настоящей книгой говорит обратное — не доказано.** Знак у лонга держится лишь в 2 из 5 месяцев, покрытие правды < 80 % (Δ\* = 1000 мс с оговоркой). Числа: заявка на 500 $ по ленте против заменителя — лонг −0,52, шорт −1,19 бп (ср. |e| 4,6 / 4,7 бп; модель закладывает +1 бп). При калибровке P&L баз по точечной оценке растёт: **лонг +40,3 $ [+22; +58]** (193 → 234 $, Sharpe 1,96 → 2,37) — это движок `slip = 0` (запасной путь после провала G-path), он обнуляет и проскальзывание тейкерских выходов, **поэтому это не эффект одного входа**; только вход (`P_V`, описательно) — +33,0 $ [+21,6; +44,5]. **Шорт `P_V` +29,6 $ [+19; +40]** (223 → 253 $, Sharpe 4,12 → 4,66). Интервалы не накрывают 0 → по правилу п. 7 «калибровка сдвигает базу» (вверх) — при оговорках ниже.

**Оговорка, которая сильнее числа:** единственная сверка с настоящей книгой (13.11, 33 сигнала) расходится с лентой на 6–7 бп в среднем по модулю, причём лента в среднем на 3–4 бп **лучше** книги. Если права книга, то по ленте стоимость входа занижена и сдвиг вверх ненадёжен. Значит, «вход не хуже модели» — это модель на допущении «книга ≈ то, что съели следующие тейкеры», а не измерение. Заморозка TK-626 не меняется (В-167).

Что это значит в деньгах, на каждой стороне:
- **W (окно возраста заменителя) не влияет:** у всех 972 лотов возраст заменителя ≤ 4 мс, при `ew = 5` ни один вход не отвергнут по возрасту. Любое W ≥ 5 мс даёт те же сделки по построению; правило §13.16 на ленте снова даёт W\* = 5 мс.
- **Чувствительность к проскальзыванию** (движок, вход и тейкерские выходы вместе): каждый лишний 1 бп стоит лонгу −28…−40 $, шорту ≈ −25 $ за 136 сут. При `slip = 5` (в 5 раз больше модели) база остаётся в плюсе: лонг +48,9 $, шорт +118,2 $.
- **Объём лучшего уровня** (модель, на допущении: виден только в событиях, которые съели уровень целиком): из лотов, где класс известен, L1 < 500 $ у 59 % лонговых (крипто 73 %, TradFi 33 %) и 45 % шортовых (крипто 62 %, TradFi 27 %); не известно у 54 % / 42 % лотов. На 13.11 по книге L1 < 500 $ у 25 из 33 сигналов. То, что L1 меньше 500 $, разницы с моделью не даёт: средняя цена прохода на 500 $ (`e_V`) всё равно ≈ заменителю.
- Проскальзывание выходов (стоп, `rt`, трейл) здесь заново не мерилось: у них та же модель 1 бп (заметка критика 2).
