## Как пополнять
Только через загрузчик, без ручных правок: новый csv в уже описанном формате = строка в `SPEC` (`g017db.py`: загрузчик, тикет, файл, таблица,
соответствие колонок), затем `python tools/g017db/g017db.py load` (идемпотентно: тот же md5 пропускается, изменённый файл заменяет свои строки);
затем `verify`; затем `scp` БД на calc `/data/g017/g017.db`. Новый признак появляется в `features` сам (из `feature_lift`; правило — первая строка
кода с `"имя"`). Заголовки csv докладов — источник, БД — индекс.

## Запросы-примеры (`python tools/g017db/g017db.py queries`)
**Q1 — топ признаков по подъёму в сент. (верх. дециль, D=360) рядом с медианой янв–июнь:**

```sql
SELECT feature, lift FROM feature_lift WHERE month='2026-09' AND d=360 AND bucket=10 AND source_file LIKE '%lift-all%' ORDER BY lift DESC LIMIT 10;
```
**Q2 — подтверждено в ≥7 из 9 месяцев** (верх. дециль, нижняя граница CI подъёма > 1):
```sql
SELECT feature, d, COUNT(*) m FROM feature_lift WHERE bucket=10 AND lift_lo>1 AND source_file LIKE '%lift-all%'
GROUP BY feature, d HAVING m>=7 ORDER BY d, m DESC, feature;
```
