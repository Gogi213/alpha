**Base (просто).** Пул Aerodrome AERO/VVV-типа 0x0178…09A5Ce (WETH, $13 млн ликвидности): 338 свопов на 4000 блоков → ≈3 600 свопов/сут. Блоков Base 43 200/сут → 432 вызова ≈ 90 с на пул-сутки, **≈2,3 ч на пул за 90 сут** одним потоком; параллель с drpc не проверена (лимит неизвестен). Ядро на Base — 5–6 пулов (AERO, AXIS, FLOCK, VVV + CL-пулы, у которых другое событие Swap) → ≈12–14 ч одним потоком. Время блока — в getBlock (на 100 блоков можно брать по границам либо eth_getBlockByNumber на лог). Для меток времени с точностью блока (2 с) годится.

**Solana (тяжело).** Пул ZEREBRO/SOL Raydium: 5 000 подписей = 58 700 с → ≈7 400 подписей/сут; страницы подписей 12 с/сут, но тело каждой сделки — getTransaction: 7 400 × 1,16 с ≈ **2,4 ч на пул-сутки**, 90 сут × 1 пул ≈ **215 ч**, ядро Solana (≈8 пулов) ≈ 1 700 ч одним потоком. Параллельность режется 429. Бесплатным публичным путём — неподъёмно; нужен либо ключ с высоким лимитом, либо Bitquery/Flipside free (не пробовались — нужна регистрация владельцем).

**BSC.** Публичный RPC истории не держит (≤6 сут) — как в прошлой записи; нужен архивный ключ (NodeReal/Alchemy/Graph).

**Что нужно от владельца (один вопрос):** регистрация (бесплатная) любого одного из: Alchemy (Base+Solana+BSC? — BSC архив у них платный), The Graph, Flipside/Bitquery для Solana. Без регистраций: Base за 3 мес. на drpc сделать можно (≈12–14 ч, без трат).
