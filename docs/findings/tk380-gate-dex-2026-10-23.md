# TK-380 — DEX всех монет Gate ≥30k$/сутки (шаг 1: пулы; шаги 2–3 впереди)

**Итог шага 1:** из 871 монеты Gate (спот+фьюч USDT, оборот 24ч ≥ 30k$; 23.10 ~18:35 GMT+4, API Gate) DEX-пул найден у **514**, всего **855 пулов**, DEX-оборот 24ч ≈ 618 М$ (в нём стейблы USDC/PYUSD/RLUSD/USDG — не торговые; XDP, AGT, AXIS, BTR — единичные гиганты). Список монет инженера (`gate-30k-universe`) ещё не пришёл — взят 24ч-тикер Gate API (разрешено тикетом).

Метод ограничен: берётся пул с токеном как base-стороной, найденный по контракту из CoinGecko `platforms` → монеты без записи в CoinGecko (новые) не найдены; на одну пару токен-сеть DexScreener отдаёт ограниченное число лучших пулов.
