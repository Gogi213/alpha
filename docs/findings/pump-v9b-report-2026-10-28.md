## 4. Почему у 87 из 256 событий нет контроля ±30 сут (вопрос владельца)
Разбор 708 кандидатов-окон на событие (59 суток × 12 сдвигов по 5 мин, тот же час UTC), по причине отказа (`pump-v9b-nocontrol-2026-10-28.json`):
| причина (доля кандидатов) | доля | событий, где главная причина |
|---|---|---|
| окно выходит ДО 1 сентября | 40,7 % | 60 |
| окно выходит ПОСЛЕ 30 сентября | 33,4 % | 23 |
| пересекает другую ногу ≥ 90 мин той же монеты | 23,9 % | 4 |
| нет свечей (листинг, пропуски) | 2,0 % | 0 |
Короткая история (< 3 сут до старта) — 3 из 87 (в тех же категориях). **Главная причина — длительность:** у этих 87 медиана ноги 18 032 мин (≈ 12,5 сут), окно «до + нога» просто не помещается в месяц ±30 сут. Октября в данных нет — сколько он закрыл бы, посчитать нельзя (для хвоста в 23 события — потолок). Август (свечи есть, TK-420): у 73 из 87 есть хотя бы одно окно без ноги и со свечами в августе (оценка сверху: занятость августа ногами не проверена, зигзаг августа не считался). Расширение — решение Судьи/владельца: даёт контроль всем, но сравнивает сентябрь с августом (другой режим рынка).
Описательно: события с/без контроля — hist_days медиана 34,1 / 31,3; без контроля чаще spot (34 из 87).
