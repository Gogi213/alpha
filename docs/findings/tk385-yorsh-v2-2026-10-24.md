# TK-385 · «ёршик» v2: очередь по L2 Gate + чистая середина пула DEX (EVM) — промежуточный, 24.10 ~17:10 GMT+4

**Модель.** Котировки DEX·(1∓k), округление к тику внутрь стакана; заявка стоит, пока округлённая цена не сменилась (смена = потеря очереди). Линия DEX — середина пула (SUE: Sync v2, ×BNB BBO; LAPTOP: sqrtPriceX96), возраст ≤ 60 с, +1 с задержка. `med` — вычет скользящей медианы базиса Gate−DEX за 24 ч без заглядывания (как в TK-386), `raw` — без вычета. Очередь: стакан = снимок `set` (раз в час) + `make` (+) / `take` (−) по цене; объём впереди — на момент постановки; сделка строго сквозь цену → заполнение, на цене — копим объём, заполнение при накопленном > впереди; отмены впереди не учтены (консервативно). `queue=0` — касание без очереди. N=1 лот, выход встречной котировкой (дороже входа) либо рынком через T; ребейт мейкера 1 бп, тейкер 7,5 бп (как в шаге 2).

N ≈ суток 6–8), 32–41 круга, интервала нет, поправка на 24 (здесь) × 96 (TK-386) испытаний не сделана ⇒ **не отличимо от нуля**. Знак зависит от линии (med/raw) и k — типичный признак шума.
3. **Очередь:** в 14 из 24 пар ячеек `queue=1` и `queue=0` различаются (по cумме бп; на SUE med k=0,2 % T=5 мин 146 против 147 кругов, −9 533 против −9 818) — то есть очередь реально отсекает часть касаний, но мало: большинство исполнений идёт «сквозь» цену. Это число — верхняя оценка: отмены/уходы впереди не учтены, объём впереди берётся из часового снимка + make/take (take смешивает сделки и отмены).
4. Принудительные выходы 60–100 % — «пила» работает как односторонний вход с выходом по рынку, а не как сбор спреда с двух сторон; спред Gate (SUE 164, LAPTOP 14 бп) + тейкер 7,5 бп съедает ход.
