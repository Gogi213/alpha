# arb-holding: ручная проверка 30 эпизодов по сырой ленте, 16.11.2026

Код — `tools/arb_stats/hold_check.py raw` (srv, `/data/arb-hold/v2/check-raw2.md`). Выборка: 30 эпизодов «от нуля» из таблицы `table.pkl` (244 148 строк), без BingX, незавершённых нет; 5 корзин длительности (1–2 с, 2–5 с, 5–30 с, 30–300 с, ≥ 300 с) по 6, разные пары, зерно 7.
Пересчёт не использует ни разобранные куски `npz`, ни `hold_scan`: строки `b` берутся прямо из файлов сборщика (`*.tsv.zst`: время E = накопленная сумма `dns` по ВСЕМ строкам файла ÷ 10⁶ − `lag`), состояние ноги — последняя запись с E не позже момента (при равных E и приёме — порядок строк в файле), разрыв — `Sell = bid_A/ask_B − 1` или `−(ask_A/bid_B − 1)` в bps, эпизод — подряд идущие моменты (любое изменение любой ноги) с разрывом ≥ θ, длительность — до первого момента без разрыва.
Допуск: начало 0 мс, длительность ±1 мс, максимум разрыва 0,05 bps.
