# Монеты без сделок кандидата: где не сложились условия входа (2026-09-24)

Кандидат «лонг от старой бид-стены в просадке BTC» (`t-bid-btc1h-q1`, форма `ladder3x2..20w2-pct2-tr1x1-14400-ttl1800`),
пересчёт `u500r` (`recompute-u500-2026-09-24.md`), сентябрь 01–23 (история + запись). Из 100 монет пула сделок не было у
**64**. Воронка по каждой: подходы цены (D20) к бид-стене ≥ $10k — кэш `study/approaches/D20` обеих эпох; возраст стены в
момент подхода; сигналы базы `t-bid-age-45` (стена ≥ 45 мин) и кандидата (+ просадка BTC за 1 ч) — `forms.csv` прогона.

**Ограничения замера (ревью 24.09):** разметка стен — по топ-50 книги (стена глубже 50-го уровня не видна), порог
$10k — при построении кэша (`approach-scan.sh`: `--h3-mode notional --h3-usd 10000`), возраст стены `age_ms` —
от момента, когда размер впервые превысил порог (`lob::levels`). У части монет короткая история: в группе «стен почти
нет» 11 из 24 наблюдались меньше 20 суток (AVAAI 5, BR 6, POWER 6, AXL 7, PUFFER 9, ASTR 12, SENT 12, AKE 14, ARK 14,
BTW 14, CVC 14) — для них вывод предварительный; В-95 сняло их вместе с остальными по решению владельца.
