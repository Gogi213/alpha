### 13.57 Шорт: рычаги сверх `S_base` («больше сделок» / «лучше сделки») — перепроверка §13.30 на честной вселенной h775 с парной Δ $/сделку — записано 20.11.2026 ДО счёта клеток (TK-657 v1, ветка `bb/tk-657-p42-short-levers-775-v1-thr_q27tz72ea3`; аудит TK-637 строка 17; критик `thr_n2ij7m7n7z`; номер §13.57 = номер задачи)

Слова владельца (дословно): **«Что то осталось досчитать?»**; решение по полномочию В-165 — координатор. #### 1. Вопрос и ответ
Есть ли на h775 рычаг шорта из семейств A («больше сделок») или B («лучше сделки», без выходов) §13.30, при котором **средний $ на сделку выше `S_base`** (при сумме не хуже), и это держится после поправки на весь перебор, по месяцам, без двух лучших суток / монет и выше шумовой планки? Ответ — «кандидат вперёд (найдено на этих данных)» или «нет, база остаётся»; по каждой клетке — Σ $, $ на сделку, число сделок, $/сут., годовой Sharpe, парная Δ $/сделку с интервалом, разложение по сделкам; без бп; **первой строкой отчёта — R:R и убыток по стопу при плече 2**.

#### 4. Механика (по коду, `src/breakout/params.rs`; значения базы — умолчания движка)
- `reentry` (база 0): 1 — уровень расходует только жёсткий стоп; 2 — выходы уровень не расходуют (`tick.rs:2215`, `:2363`). При `pb = 1` на 566 `reentry=1` побайтно = база — если повторится, клетка «не действует» (п. 9 G-key).
- `t1h` (база 0,5 млн $): порог оборота монеты за 1 ч на сигнале; ниже — больше монет-сигналов. `t24 = 12` (оборот 24 ч) остаётся.
- `tf` (база 60 мин): таймфрейм уровня; `n_bounce` (база 2): касаний для уровня; `l_days` (база 7): глубина поиска уровня; `d` (база 0,5 %): допуск касания; `k` (база 2): ширина экстремума. Все — ключи сигнала: меняют поток кандидатов и, через занятость монеты, набор сделок.
- `n_tp` (база 8): число тейков лестницы; `t_low` (база 1 NATR): первый тейк (`t_high` 5 остаётся); `a` (база 2 NATR): активация трейла (откат `rr` 2 остаётся). Выход сделки меняется, набор сигналов тот же; через время удержания может сдвинуться и набор сделок.

#### 5. Клетки (записаны здесь до P&L; значения — как §13.30, `tk618-cells.json`)
Клетка = `S_base` (с ` t24=12`) + патч (ключ после базы заменяет её значение).
- **Семейство A — «больше сделок» (14):** `reentry` 1 / 2; `t1h` 0,25 / 0,1; `tf` 30 / 240; `n_bounce` 1 / 3; `l_days` 14 / 3; `d` 0,3 / 1; `k` 1 / 3.

#### 6. Что считаем на клетке
Как §13.55 п. 6 (код `tk643_run.stat_row`): сделок; Σ $; $ на сделку; $/сут.; годовой Sharpe; по месяцам (июль, август, сентябрь, октябрь, 01–13.11) — сделок, Σ $; 90 % интервал $ на сделку; максимальная просадка; R:R; стопов, убыток стопа; доли видов выхода. **Парная Δ $/сделку к `S_base`** — `tk604_stats.delta_stat` (одни блоки суток; нижняя граница — 5-й перцентиль; односторонний p; ΔΣ и SE_Σ), Δ по месяцам — `month_table`, устойчивость — `robust` (без двух суток, без двух монет). **Разложение по ключу (монета, `sig_ms`)**: «добавлено» (сделки клетки, которых нет у базы) — число и Σ $; «убрано» — число и Σ $ базы; «общие» — число и ΔΣ по ним. ΔΣ ± SE_Σ и z_Σ печатаются как справка (прежняя метрика §13.30, ворот не даёт). Медиан нет, t по сделкам нет.

#### 7. Правило ответа (записано до счёта; семейство — все 20 клеток)
Клетка — **«кандидат вперёд, найдено на этих данных»**, если выполнено **всё** (а)–(ж) (как §13.55 п. 7 для блоков E / D):
(а) минимум сделок: ≥ 70 за окно и ≥ 20 в каждом месяце (01–13.11 — ≥ 8);
(б) **Холм** по одностороннему p парной Δ $/сделку по всем m = 20 клеткам (α = 0,05) отвергает H0: Δ ≤ 0;
(в) Δ месяца > 0 в ≥ 4 из 5 месяцев;
(г) Δ > 0 без двух лучших суток и без двух лучших монет;
(д) охрана суммы: ΣS клетки > 0 и ΔΣ ≥ −1·SE_Σ;
(е) плато: упорядоченные оси с базой — `reentry` (0 < 1 < 2), `t1h` (0,1 < 0,25 < 0,5), `tf` (30 < 60 < 240), `n_bounce` (1 < 2 < 3), `l_days` (3 < 7 < 14), `d` (0,3 < 0,5 < 1), `k` (1 < 2 < 3), `n_tp` (4 < 8 < 12), `t_low` (0,5 < 1 < 2), `a` (1 < 2 < 3); сосед — ближайшее значение оси в каждую сторону; если сосед = база (Δ ≡ 0) — берётся следующее значение в ту же сторону; нет — направление выпадает; нужна хотя бы одна сторона с соседом, и **все** найденные соседи — с Δ ≥ 0,5·Δ клетки (код `tk643_run.plateau_ok`);
(ж) **шум:** годовой Sharpe клетки выше шумовой планки `selection_bias.significance` при N = m + 34 клетки §13.30 на 566 = **54**, и `survives = да`; печатаются планка и дефлированный Sharpe.
Ни одна клетка не прошла ⇒ **«нет: база остаётся»**. Прошли несколько ⇒ ответ — **множество**, не «лучшая»; сочетания прошедших не считаются (новый раздел). Сильная Δ без (б) или (ж) — описательно, решений не двигает. Клетка «не действует» (п. 9) остаётся в Холме с Δ ≡ 0, p = 1 (консервативно).

#### 8. Мощность (модель, на допущении нормальности бутстреп-Δ)
Холм на первом шаге: p ≤ 0,05 / 20 = 2,5e-3 (z ≳ 2,81). SE парной Δ у клеток стопа §13.43 шорта (блок A, 63 клетки, те же сделки; измерено, `cells43-S.json`): 0,16…0,19 $/сделку (10–90 %). Клетки A меняют набор сделок ⇒ SE больше (на 566 у A — до 0,56 $/сделку, TK-618) ⇒ MDE ≈ 0,6…2 $/сделку при базе +0,700 $/сделку (модель). У B (`t_low`, `n_tp`, `a`) набор почти тот же ⇒ SE мала (на 566 `t_low` 0,009…0,017), MDE ≈ 0,05…0,6. Ожидаемый исход — «нет»; записано до счёта.

#### 9. Ворота
- **G-bin:** sha256 бинаря ∈ `tk625_run.BIN_SHA_OK`.
- **G-base:** строка базы (без патча) в пакете = готовые сделки `S_base` h775 (ключи, P&L |Δ| ≤ 1e-6) на всех окнах; расхождение — остановка.
- **G-key:** клетка, у которой набор сделок и P&L равны базе, помечается «не действует» (ожидается у `reentry` при `pb = 1`; остановки нет, в Холме p = 1); если «не действует» больше 2 клеток — остановка (ключи не дошли до движка).
- **G-dup (контекст):** клетки с одинаковым P&L — списком; в Холме остаются.
- **G-win (контекст):** зачётных сделок, закрытых концом данных окна, — число.
- Данные: `tk604_stats.check_abs_ms` (время ≥ 14.11 — отказ), как §13.55.

#### 10. Что делаем при «да» / «нет»
«Да» ⇒ клетка (множество) — кандидат для отдельной проверки вперёд; заморозка — только решением координатора по В-167 (α из долей `L_base` / `S_mk1`, каждая ≥ 0,005; сумма 0,05 не меняется). «Нет» ⇒ `S_base` остаётся, строка 17 аудита закрыта «проверено на h775» со списком проверенного.
