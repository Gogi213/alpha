## 4. Как вернуть

```bash
# каталог целиком (жёсткие ссылки внутри арбитражной группы вернуть одним rsync с -H всех нужных каталогов)
rsync -aH -e "ssh -o BatchMode=yes" box:offload-srv-2026-11-18/arb-hold box:offload-srv-2026-11-18/arb-tokyo /data/
# сутки коллектора
rsync -a box:alpha/collect/<биржа>/<день>/ /data/collect/<биржа>/data/<день>/   # bybit: /data/turbo-probe/soak-bybit/data/<день>/
```

Коды путей в старых отчётах (`/data/arb-hold/…`, `/data/swings/…`, `/data/bingx-trades/…` и т.д.) теперь указывают на пустоту до возврата. На srv остался журнал сверок `/root/tk608/offload-{a,b}.log`.
