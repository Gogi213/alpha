# TK-383: межбиржевой фандинг-арбитраж (Bybit/Binance/Gate/Bitget/BingX), сент–окт 2026

**Итог:** на сентябре–октябре стратегия «вчерашняя разница ставок > θ → шорт дорогой/лонг дешёвый фандинг» после комиссий и хода базиса — **ноль/минус**: 490 сделок θ=50, сумма −1,2 тыс. бп, без 5 лучших монет −12,2 тыс. бп, медиана −10 бп на сделку. Фандинг-часть положительна (+33…+48 бп/сделку нетто тейкер для «heavy»), её съедает базис (среднее −33…−57 бп) и тяжёлый хвост (MAE p99 ≈ 1300 бп). «24 % за цикл» (практики): по фандингу **есть** — 4 цикла ≥ 24 % gross, все ONE gate/okx 18–25.09 (до 37 %), но это один памп-дамп токена с базисом ±тысячи бп (исполнимого дохода не даёт); см. «Поправка v3» и «Поправка v4» (v3-числа базиса ONE зачёркнуты: 1м-охват 4–42 %).

Скрипты: `tools/compute/tk383-funding-fetch.py` (история 01.09–24.10, 3422 инструмента, 851 тыс. записей), `tk383-funding-analyze.py`, `tk383-basis.py`. Сырьё — `data/tk383/`. Таблицы — `data/tk383/analyze.txt`, `basis-agg.txt`; JSON — `tk383-funding-arb-2026-10-24.json`.

## Метод
- Фандинг-интервал: у большинства 4 ч (Binance/BingX/Bitget/Bybit/Gate ~370–400 инструментов), 8 ч — 100–490, 1 ч — единицы. Суммы ставок по суткам UTC, разность пары (шорт A − лонг B) в бп/сутки. 903 монеты на ≥2 биржах; классы: heavy = есть на Binance/Bybit (810), light = только Gate/Bitget/BingX (93). Пары — любые из пяти бирж.
- Сделка ex-ante: вход на начало суток d, если вчерашняя |разность| > θ ∈ {10,20,50,100} бп/сут (направление по знаку); выход, когда вчерашняя разность сменила знак/нулевая. Комиссии: 4 ноги, тарифы VIP0 (тейкер Bybit 5,5 / Binance 5 / Gate 5 / Bitget 6 / BingX 5 бп; мейкер 2/2/1,5/2/2) — принятые публичные, не проверены по аккаунтам.
- Базис: 1-часовые close двух бирж на входе/выходе; b = ln(Pшорт/Pлонг), PnL базиса = b0−b1, MAE = max(b_t−b0) по часам (1м-свечи не брались — MAE занижен).

## Числа
Распределение |разности пар| бп/сутки (p50 / p90 / p99): heavy сент 0,4 / 7,6 / 31,6; окт 0,5 / 5,9 / 26,6. light сент 0 / 6,9 / 47; окт 0 / 9,0 / 58. Корреляция разности d−1→d: heavy 0,24 (сент) / 0,31 (окт); light 0,21 / 0,10.

Сделки, нетто фандинга тейкером, бп на сделку (θ=50): heavy сент +32,9 (448 сд., 87 монет, hit 49 %, sd 187), окт +47,5 (211, 63, hit 42 %, sd 213); light сент +22,3 (9, 5 монет), окт −29,9 (18, 8 монет). θ=10: heavy +7,2 / −3,1; light +4,4 / −14,5. Мейкером +14 бп выше.

С базисом (θ=50, 490 сделок с ценами): heavy сент n=272 фандинг +44,3, базис −56,5, итого −12,2 (медиана −7,7); окт n=198 +53,3, −33,3, итого +20,1 (медиана −10,4). light сент n=4; окт n=16: итого −122. MAE (рост b против позиции): p50 ≈ 42–44, p90 130–190, p99 ≈ 1300 бп.
Концентрация: положительна сумма у 57 из 125 монет; топ — ARK, BIRB, STONK, MTL, G, ERA; без топ-5 сумма −12,2 тыс. бп.

## Оговорки
- Один пул из ~2 месяцев, два месяца отдельно — картина одна; N испытаний: 4 θ × 2 класса × 2 месяца (+ выбор θ=50 для базиса) — θ=50 выбран до расчёта базиса по таблице фандинга (поправка на выбор не делалась).
- Тикер = монета предположено; на экзотике (ONE, ARK, G, BIRB) возможны разные токены под одним тикером, а экстремальные ставки (до −2 % за период) — признаки делистинга/сжатия, не исполнимые объёмы. Глубина стакана, лимиты позиции, проскальзывание, ввод/вывод, OKX не учтены.
- Базис по часовым close: интрачасовой MAE не виден.
