Порядок «кто первым»: Binance ≳ Bybit (≈ 1 бп) > DEX (секунды–минуты). Вывод по альфе: ниже издержек Bybit (≈ 1 бп остаточного хода против taker-комиссий); догон DEX — тот же эффект, что в `tk373-direction-2026-10-23.md` (+5,8 бп на 300 с против +6,6 от событий Bybit), к комиссии пулов то же «не покрывает» (`tk373-fees`).

## Оговорки
- **Откат Binance — частично артефакт**: событие выбрано по последней сделке (край спреда: bid-ask bounce 0,5–1 бп для крупных, больше для альтов), поэтому «Binance дальше < 0» и часть «Bybit дальше > 0» смещены; чистый тест — по середине стакана/bookTicker Binance (в архиве bookDepth только снимки, секундной середины нет) либо обратное событие «Bybit ≥ q95 → Binance после» — **не сделано**.
- Направление «кто ведёт» между Binance и Bybit по этому срезу — **≈ 1 бп** (против 4–7 бп у DEX); этого недостаточно для вывода «Binance ведёт Bybit» без обратного теста и без Binance-середины.
- Одна неделя (17–21.10, 5 суток), месяцев нет; эфф. N = монето-сутки (525, с DEX 310; по сети 10–165). Порог из одних суток 16.10.
- Hypotheses P-25 «Binance↔DEX» по потоку (aggressor, объём-дельта Binance) и bookDepth — **не сделаны**; Mint/Burn (ETH 15/18 заданий 408, BSC/Base 429), receipts, Solana — по-прежнему ждут RPC-ключа.
- Издержки не моделировались; ход Bybit +1 бп на taker-комиссии (≥ 5,5 бп) не покрывается.
