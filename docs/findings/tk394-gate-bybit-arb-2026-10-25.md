## Метод и пометки
- Пары: FF = Gate фьюч / Bybit фьюч; FS = Gate фьюч / Bybit спот; SF = Gate спот / Bybit фьюч; SS = Gate спот / Bybit спот; GB, BB — спот–фьюч внутри бирж (контроль базиса).
- **У спота Gate стакана нет** → SF, SS, GB — по цене последней сделки (не исполнимая разница), исполнимые числа для них не считались.
- Исполнимая разница e = max(бид_B − аск_A, бид_A − аск_B) в бп от середины. Вход = сумма тейкер-тарифов двух ног, круг = 2 × вход (тарифы по тикету: Gate фьюч 2/5 бп, спот 10; Bybit фьюч 5,5, спот 10; тарифы Bybit по странице не перепроверены; скидка владельца 35 % не применялась; фандинг не учтён).
- Вход FF = 10,5 бп (круг 21), FS = 15 (30), BB = 15,5 (31).
- BBO Gate фьюча пересобран после исправления float-остатков (бид ≥ аск: 0 секунд); сделки Gate внутри [бид; аск] по 100-мс корзинам: ETH 96,5 %, BONK 95,7 %, ARIA 85,1 % (промахи — свипы внутри 100 мс).
- Задержка 1 с: решение по секунде t−1 (e > входа, сторона по максимуму), исполнение по значению той же стороны на t.
- Класс монет (есть на Binance/OKX), оборот, спред — **не размечены** (в таблицах только по монетам).

## Что видно и чего нет
- Секунды с e > входа составляют 4 % (FF) и 0,9 % (FS) — но это в основном **долгие эпизоды и постоянный сдвиг монеты**, а не короткие всплески: после задержки 1 с валовая остаётся > 0 в 99,8 % сигналов. Взвешивание по секундам смещено к длинным эпизодам; по числу эпизодов медиана длины 2,5 с.
- Контроль BB (внутри Bybit, одна биржа) окон сверх круга не даёт (0 %) → метод ложных окон на ровном месте не рисует.
- Монеты с долей сигнала > 60 % (ERA, LAB, BLUAI на FF; ERA, CAKE на FS) — постоянно расходящиеся рынки (разные контракты/метка/ликвидность), не арбитраж; без выхода по схождению прибыли это не говорит.
- Валовая ≠ прибыль: выход (схождение) и фандинг двух бирж, выход тейкером второй раз, не смоделированы — это шаг 2. Круг 2×вход предполагает схождение к нулевой разнице; при ненулевом постоянном сдвиге итог хуже (строка с поправкой на |d_med|).
- Не проверено: тарифы Bybit по странице, класс монет, оборот/спред, глубина (размер по BBO не ограничен), длительность окон кроме медианы/p90 (в csv).

## Критика метода (для Судьи)
1. «Сигнал → то же значение на t» без выхода — оценка сверху на входе; для вердикта нужна двуногая сделка с выходом/таймаутом (шаг 2, сетка владельца 1 с…4 ч).
2. Валовая включает постоянный сдвиг; нужно решить, что считать «сходимостью»: к нулю или к собственной медиане монеты (скользящей).
3. SF/SS/GB по сделкам, а не по BBO — спот Gate исполнимо не измерен (нет стакана).
4. Одна неделя, 104 монеты, эфф. N по эпизодам сильно меньше числа секунд (автокорреляция).
