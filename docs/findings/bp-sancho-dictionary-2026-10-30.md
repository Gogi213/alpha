## 2. Число испытаний — зафиксировано до счёта (заявка по §9 рамки P-G017)

Строка семейства = тест × ТФ × направление (хай/лой, лонг/шорт). Оси титрования (k, X, N, g, K, τ, порог закрепления, «затяжная») — **описательно, вне семейства** (рамка §7, как TK-451 §3): якорь в семействе, остальное — кривые. Холм по семейству; вердикт — единое правило §3 п.3 плана (знак в каждом году с N≥8 и ≥5 монет).

## 4. Алгоритм (В-170)

Варианты — (а) таблицы осей по авторам рядом, сопоставление потом; (б) общий каталог осей Санчо+bp с полной сеткой; (в) словарь с идентификаторами, одна ось на понятие, семейство по якорям; замер — подсчёт по таблице §1: 26 определений, из них 7 общие у двух авторов (`swing_k, level_pool, sweep, close_break, imbalance, bos, horizon`) — в (а)/(б) их оси титровались бы дважды; выбран — (в), потому что общая ось титруется один раз, семейства B2/S считаются по якорям, оси — описательно, число испытаний не растёт произведением осей (в (б) оно было бы произведением, см. план §15).
