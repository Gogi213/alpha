## L4 v8 (периоды BTC/ETH + доля монет) = 0 периодов
Правило записано до счёта (v8 п.2, решение 3: «без излома = 0»; `reviews/tk421-l4v8-zero-2026-10-28.md`). Лидер — по z* своего хода (K1, +10 испытаний, всего 70).
- z* лидера найден K1 для T = 5/15/60/240 мин оба знака на всех 4 рынках; для T = 1440 излома у лидера нет (`k1: None`) → периодов 0.
- θ доли монет: «нет хвоста» (x_lo > x_max) — у доли в минуты хода лидера нечего отделять; минут хода лидера (z ≥ z*) на ячейку 44–173 (Gate fut 240−: 461); для T = 1440 — 0. Две ячейки Gate fut (60−, 240−) имеют x* лидера 122,8 и 60,1 — на порядок выше остальных, в отчёт как есть, без толкования.
- Событий до/после v8/после v6: Bybit linear 204/204/204; Bybit spot 198/198/198; Gate fut 391/391/390; Gate spot 223/223/223. Периодов в таблице периодов — нет (пусто с числом минут лидера по ячейкам: `tk421-l4v8-2026-10-28.json`, поле `минут_хода_лидера`).
- Вывод: сентябрь ни разу не «летел весь за BTC/ETH» на ход, сравнимый с пампом альта. Это исход «излома нет», а не отказ метода.
