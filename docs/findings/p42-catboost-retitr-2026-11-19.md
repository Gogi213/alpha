## Что произошло с фильтром (измерено до и после чтения)

Порог `q` = −0,443 взят из однофолдовых OOF (n = 1 031); у августовских кандидатов `ŝ` — среднее четырёх моделей (другой масштаб, п. 4), и `ŝ ≥ q` у **4 из 529** (0,8 %); по окнам доля `ŝ ≥ q` у всех кандидатов окна: `wa` 0,4 %, `wb` 8,8 %, `wc` 59,8 %. Сдвиг масштаба предсказан в п. 4 (у TK-598 доля выбранных у лонга — 0,125) и в G8; `q` не менялся.
- **Шорт: фильтр оставил 58 из 307 августовских кандидатов (18,9 %)**; клетка (глубина 2, `min_data_in_leaf` 200, `l2` 10), 122 итерации (потеря CV 2,200); `q` = +0,148 (n_oof 501). ## Отступления и оговорки

Все — п. 11 §13.27 (движок `a112684a` TK-607 вместо `a03c91df`; f12 считает Rust; обучение на периодах после проверочного месяца — не walk-forward; C\* подобрана с учётом августа; цель T1 выбрана исполнителем, видевшим строку «шорт T1» TK-598; кандидаты одного уровня; короткая предыстория `wa`; перенос состояния портфеля из отфильтрованного июля входит в эффект фильтра; малая мощность) плюс найденное при исполнении:

1. **Заморозка заменена до чтения.** Первая заморозка (`066ba3008`, sha256 `b3285821…63ec`) сделана до репетиции `cmd_read` на синтетике; репетиция выявила, что `aug_compare` падает (`GuardError` бутстрепа «повторы без сделок») при n_B < 30 — то есть именно в исходе, который G8 уже предсказал; на реальном чтении это сожгло бы маркер без результата. Исправление: при n < 30 ошибка бутстрепа не прерывает чтение, вердикт «не определено», печатаются описательные числа; при n ≥ 30 ошибка остаётся ошибкой. Код — `ec585fb1a`, новая заморозка `f3681f6d8` (`tk610_lib.py` — единственное изменение кода между ними); август до этого не открывался. Файл первой заморозки — `/data/p42-tk610/freeze/tk610-frozen.v1-superseded.json`.
2. **Лонг: интервал Δ не определён** (в бутстрепе при n_B = 2 есть повторы без сделок B); печатаются только точечные числа и сумма.
3. Раскладка R2 — по сторонам (`<окно>-R2-<S>`); `r2_outputs_sha` и `read` исправлены под неё (`ee9465100`); `accepted` в `load_gates` — только G4, `ok` в файле остаётся красным.
