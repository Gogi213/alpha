# TK-373 / P-25: net догона пула по fee tier и газу — 23.10.2026

**Итог.** Fee tier измерен по 482 пулам (GeckoTerminal `pool_fee_percentage`; для v2 без tier — константа форка: Pancake v2 25 бп, Uni/Sushi v2 30, Aerodrome volatile 30; файл `tk373-fees-2026-10-23.json`). По 67 монетам R10 (100 740 событий, 16–21.10) **круг по DEX (вход t0, выход +300 с) отрицателен: −29,7 бп**, доля монет с net > 0 — 19 %. Положителен только на пулах с комиссией < 2 бп (pancake v3 BSC 0,01 %; 20 монет, 36 % событий): **+2,2 бп, но это RAVE** (gross +107 бп, 1 113 событий); без RAVE **−1,0 бп** (19 монет, медиана +0,3, доля >0 = 53 %). Газ ничтожен (0,01–0,05 USD за своп: 0,01–5 бп от размера 1k–10k USD, ≈0,05 бп на 10k) — решает комиссия пула. «Догон» как отдельная альфа **не подтверждён**.

**Метод.** `tools/compute/tk373-fees.py` (локально, 77 файлов `out4/coin`, секунды): gross по монете = ср. net-ход цены пула по стороне события (dpx300, R10, net после вычета контролей ±3600 с); net_круг = gross − 2·fee − 2·газ; net_конец (одна нога на DEX, вторая — хедж Bybit без учёта его комиссии) = gross − fee − газ. Fee монеты: **min** по её пулам (оптимистично — лучший пул) и взвешенная по vol24. Газ: eth_feeHistory/eth_gasPrice публичных RPC на 23.10 (ETH baseFee ≈ 0,04 gwei, BSC 0,05 gwei, Base 0,005 gwei; ×150k газа; **не по датам 16–21.10**, архивных baseFee нет — публичные RPC хранят ~1000 блоков). Таблицы: `-summary.csv`, `-pools.csv` (по монете, размеры 1k и 10k USD).

**Читать так.** (1) Типичный пул альта — v3 0,3 % / 1 % или v2 0,25–0,3 %: круг стоит 50–60 бп при gross 5–13 бп. (2) Дешёвые пулы (0,01 %, всё BSC/Pancake v3, плюс Uniswap 0,01 %) — единственное место, где net около нуля; плюс держится на одной монете (RAVE; цена на Ethereum, последний своп — возможный артефакт слабого пула). Из дешёвых плюс есть у ERA/BLUAI/MIRA/PUFFER (+2…+7 бп), STBL (+0,6; сильные +26), минус у Q (−13). (3) «Сильные» события на дешёвых пулах не дают плюса (17 монет, 1 263 событий: −3,4). (4) Base: Aerodrome-пулы без Gecko-tier (константа 30 бп) и только 2 монеты из R10 — вывода по Base нет.

## Не сделано / ограничения
- Газ — по состоянию 23.10, не по датам; baseFee/priority за 16–21.10 нужен архивный RPC. Вывод от газа не зависит (≤ 0,05 бп на 10k).
- Проскальзывание собственного свопа, MEV и блочная задержка не учтены: вход с задержкой 10 с даёт прирост gross лишь +2,3 бп (`tk373-direction`) — на дешёвых пулах net ≈ 0.
- Цена пула = последний своп (завышает догон на слабых пулах); fee_min — лучший пул монеты, не тот, что дал цену. Одна неделя, месяцев нет; эфф. N = монето-сутки.
- Aerodrome v2 volatile (30 бп) и пулы без метки Gecko заданы константой; Aerodrome stable (5 бп) не различены.
- 16 гипотез P-25 и Solana: не начаты; Mint/Burn ждёт `liq-bsc.done` (BSC — 429 drpc, `liq-ethereum.done` готов). Порядок Судьи: Mint/Burn → Binance → receipts → Solana.
