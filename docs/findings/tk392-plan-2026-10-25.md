## Что нужно сделать (в порядке)

1. **Середина DEX.** v3: `sqrtPriceX96` из сырого `data` Swap (цена пула после свопа, учёт decimals — как в `tk380-evm-lag3.py`). v4 ETH/Base: то же поле в Swap v4 (проверить смещение). v2: сырых Sync-логов в `sqd/` нет → середина недоступна, цена исполнения со сдвигом на ½ комиссии против направления (по п.3 спека, пометка «приближение»). Solana: Whirlpool/CLMM — `sqrt_price` из данных tx, если нет — исполнение со сдвигом; пометка по классу.
2. **Событие:** ход середины главного пула (наибольшая ликвидность, п.2 спека) ≥ X∈{0,5; 1; 2; 5 %} за окно W∈{10 с; 1 мин; 5 мин}, вверх/вниз отдельно, без перекрытия (после события — «мёртвая зона» до конца максимального горизонта 4 ч нельзя: тогда событий почти нет; поэтому окно непересечения = W, а отклик события считается независимо; перекрытие горизонтов называется в отчёте и учитывается в эфф. N по монето-суткам).
3. **Отклик:** log(середина Gate на t0+h / середина Gate на t0), t0 = момент пересечения порога; 39 точек h по сетке владельца; фьюч и спот отдельно (середина Gate: BBO 1 с; для спота — по сделкам, середина ближайших buy/sell, пометка).
4. **Показатели:** доля догона = ход Gate / ход DEX, бп; t50/t90; ход DEX после t0 (откат); контроль — те же статистики на случайных t0 той же монеты/суток (число = числу событий, 5 повторов).
5. **Разрезы:** класс (тяжеловесы / нет, список TK-384), сеть, терцили ликвидности пула, спред Gate, оборот; по каждой монете, по суткам. Единица бутстрапа — монето-сутки.
6. **Проба:** 1 монета (BSC v3, не тяжеловес) × 1 сутки, 1 ядро → проверка: число событий, сверка середины v3 со ценой исполнения (≤ комиссия), отклик на 39 точках. Затем один боевой проход alsched, 15 ядер.

## Известные ограничения до счёта
- v2 и часть Solana — без истинной середины: отдельный слой «середина / приближение», итог по слоям.
- Gate спот 22.10 — сделки есть, стакана спота нет → середина спота по сделкам.
- Число испытаний: 4 X × 3 W × 2 направления × 2 рынка = 48 ячеек × 39 горизонтов — поправка на перебор в отчёте (Холм по ячейкам, ряд горизонтов — одна кривая).
- Окно 15–22.10 — одно; вывод не сильнее одного окна.
