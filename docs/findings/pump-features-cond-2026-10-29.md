# TK-448 — механичность подъёма признаков (условный подъём внутри страт |ret24h|×vol24h)
Счёт: `tools/compute/tk448-cond.py`, calc `/data/tk0448/out` (9 мес. 2026-01…09, все 9 rc=0). 25 страт (5×5 квантилей месяца), только данные ≤ t; корзины признака — 5 квантилей внутри страты (ZERO: корзина 0 + 5 ненулевых); условный подъём = попадания / Σ база страты по ячейкам корзины; CI — бутстреп кластеров монета-сутки, B=100. Метка и D=360 — как TK-447.
Машинночитаемо: `pump-features-cond-2026-10-29.csv` (сводка по признаку), помесячно — `cond-<мес>.csv` на calc.

**Разброс** = медиана по месяцам (подъём лучшей корзины / подъём худшей), корзины ≥ 2000 ячеек. «Подъём/спад» — месяцев, где CI лучшей корзины > 1,2 / худшей < 0,83. Вердикт: «держится» — разброс усл. ≥ 2 и подъём ≥ 70 % месяцев; «механика» — безусл. ≥ 1,5, усл. < 1,5; «нет эффекта» — оба < 1,5.

## Итог
- Вердикты: {'держится': 28, 'нет эффекта': 13, 'слабо/частично': 9, 'не оценить: корзина с 0 попаданий (2 мес.)': 2, 'механика': 1}.
- **Держатся после контроля ret24h/vol** (разброс усл. 2–6, во всех 9 мес.): ev90_* (события ≥ 90-го перц.), dmin/dmax (глубина просадки/взлёта 1–7 д.), path7d, ret7d/24h/4h/1h/5m/15m, liq_share24h, liq_rank7d, sq1h/4h. Теряют 55–90 % безусловного разброса (доля_сохр 0,1–0,6) — часть подъёма механическая (через ret24h/vol), остаток значим. Сильнее всего падают path7d (41→4,2) и ev90_hrs_since (31→4,8).
- **Нет эффекта и до, и после:** m_* (рынок/монета 15 м–1 ч), btc_z60/vr/qr, hod_cos, dow_sin — разброс ≈ 1,1–1,4 (шум).
- **Механика:** spot_fut_to7d_ln (1,7 → 1,5; спад 6/9 мес. остаётся — граничный).
- Слабо/частично: dmax*_sig, m_up24h/m_dn24h, hod_sin, dow_cos — разброс 1,6–1,9, подъём ≤ 3/9 мес. (m_*24h, hod_sin) — нестабильно по месяцам.
- fund_chg/fund_last — данные только 2 мес. (авг., сент.), худшая корзина с 0 попаданий → отношение не оценивается; fund_abs держится (3,3; 2/2), liq_usd1h_log/liq_to_turn1h/lsr_taker/liq_imb1h — 1 мес. (сент.), вывод без помесячной проверки не делаем.
- Эфф. N: ячеек на страту-корзину ≥ 2000, кластеров много (монета-сутки); число испытаний — 53 признака × 5 корзин × 2 вида; поправки на множественность нет — сильные эффекты (≥ 2, 9/9) её переживают, граничные (1,5–2) — нет.
