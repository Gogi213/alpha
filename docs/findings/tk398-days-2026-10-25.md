# TK-398 — кластеризация по суткам слоёв отклика Gate на ход DEX (2026-10-25)

Артефакт: `docs/findings/tk398-days-2026-10-25.csv` (48 строк = 4 слоя × fut/spot × down/up × h 60/300/900 с).
Скрипт `tools/compute/tk398-days.py`, заявка calc 1025021905186 (rc 0). X=1 %, W=60 с. excess = отклик Gate − контроль на монето-сутки,
вес = число событий. Слои: v3stable, v3quota, v2v4, sol. По слою **5 суток** (сутки 3..7 из колонки `day`).

## Числа
SE трёх видов: по монетам (как final2), по суткам (кластер = сутки, df=4), по монето-суткам.

- p по монетам < 0,05: **19 из 48**. p по суткам < 0,05: **10 из 48** (случайно ждали бы ≈ 2,4 при независимости; ячейки по h коррелированы).
- p по монето-суткам < 0,001 (порог Бонферрони 0,05/48 ≈ 0,001): 6 ячеек — v3stable spot up 60; v3quota spot up 60; sol fut down 60; sol fut up 60;
  sol spot down 60 и 300. По суткам не проходит ни одна (мин. p 0,0024, sol spot down 60); df=4 даёт нижний предел p,
  поэтому «по суткам» — самый консервативный и самый грубый из трёх.
- Положительный excess по суткам: fut v3stable up — 5/5 суток на h 60 (+4,7 бп), 4/5 на h 300; spot v3stable up 60 — 5/5 (+11,1 бп);
  v3quota spot up 60 — 5/5 (+14,6 бп); sol fut up 60 — 5/5 (+18,7 бп), 300 — 5/5 (+27,2 бп); sol spot down 60/300 — 5/5 (+11,0 / +14,0 бп).
- v2v4 fut — вблизи нуля (|excess| ≤ 3,1 бп на h 60/300, p по монетам 0,63–0,95, кроме up 60: 3,12 бп, p_coin 0,0069, p_day 0,28).
- v3quota fut down — отрицательный excess на всех h (−2,2 / −4,3 / −23,7 бп), но по суткам и монето-суткам p 0,45–0,69; p по монетам 0,0002 на h 900
  разваливается при кластеризации по суткам (по суткам −97 / −50 / −6 / +84 / +31 бп).
- Крупные excess на h 900 (до +24 бп) держатся на одних-двух сутках (напр. v3quota fut up 900: +111 / +28 / −13 / −85 / −15).

## Что читать из этого
- SE по монетам заметно занижает неопределённость относительно кластера «сутки» там, где сутки сильно расходятся (v3quota fut, h 900: se_coin 6,0 против se_day 34,2).
- На 5 сутках вывод «значимо по суткам» невозможен (мин. p 0,0024 при 48 сравнениях); возможно только «знак совпадает во всех сутках + монето-суточный p».
- Совпадение знака и p по монето-суткам есть у sol (fut/spot) и у spot v3stable/v3quota на h 60; число испытаний — 48 ячеек × (X, W не варьировались здесь, но выбирались раньше в TK-392).
- Причинность и торгуемость не проверялись: это отклик Gate после хода DEX без издержек и очереди.
