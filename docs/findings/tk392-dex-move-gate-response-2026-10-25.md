## Критика метода (для Судьи)
1. Средняя по событиям взвешена числом событий — доминируют монеты с шумной тонкой DEX-ногой (ход 156 бп за 60 с часто = единичный своп в тонком пуле, который откатывается). Нужен срез по ликвидности пула и по размеру последнего свопа.
2. Середина v3 = цена после последнего свопа секунды, не спред; в тонком пуле «ход» может быть следом одной сделки, а не информации.
3. Спот Gate по сделкам даёт bid-ask отскок (± полспреда) — нижняя граница отклика не определена.
4. События перекрываются на длинных горизонтах (окно непересечения = W, горизонт до 4 ч) → CI на ≥ 1 ч занижены; эфф. N не посчитан.
5. Монеты с BBO фьюча — 56–74 из ≈350: смещение отбора не проверено.
6. Окно одно (8 суток).
