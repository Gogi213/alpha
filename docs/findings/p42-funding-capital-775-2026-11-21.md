## 1. Фандинг за время удержания

**Что считали.** Платёж Binance USDT-M на отметке `ft` (фактические отметки, интервал свой у символа) платится, если вход строго раньше, а выход строго позже отметки (как `settle_tick_mk` движка; отметка округлена вниз до минуты). Сумма = −s · ставка · 500 $ · (марк / цена входа), s = +1 лонг, −1 шорт; плюс = получили. Сутки для Шарпа — по дню входа, как на странице «Эквити»; Шарп — годовой по дневному (136 суток, как в TK-662).

**Данные (проверено).** На srv уже были: zip `fundingRate` июль–сентябрь (`/data/p42-metrics/funding`, без марка) и `funding.csv` с `mark_price` с 01.09 по 14.11 (`/data/klines/binance`). Докачано то, чего не было: 21 монета сделок (1000SATS, BAS, BROCCOLIF3B, DOLO, GUA, HFT, HOLO, KLAC, MAV, MELANIA, O, RIF, SCRT, SQD, STORJ, TOSHI, USUAL, VANRY, VIC, YB, YFI) — `fapi/v1/fundingRate`, 01.07–13.11, 13 205 строк; всё после 13.11 отброшено. Контроль: BTCUSDT и ETHUSDT из API против склада — 408 / 408 отметок, расхождений ставок 0, марки равны на 222 отметках. Сентябрь, zip против `funding.csv`: 68 101 общая отметка, расхождений ставок 0. Монет без данных: 0 из 454.

**Марк июль–август.** В zip марка нет — берётся open минутки `ft` из 1m свечей. Проверка замены на сентябре–ноябре (все 101 выплата, нужные сделкам, свеча против `mark_price`): среднее |отличие| 0,03 %, максимум 0,27 %. На сумму не влияет (при марке = цене входа Σ фандинга A_n_1 −27,37 $ против −27,52 $ с маркой).

**Что модель не знает (допущение).** В `<сторона>-trades.csv` нет размеров лотов и времён тейков: позиция — два лота по 250 $, второй может не открыться, часть закрывается лимитными тейками. Модель берёт полный лот 500 $ от входа до выхода — это **верхняя оценка по модулю**. У самого движка поле `funding` заполнено только с 01.09 (у S_base 5 ненулевых строк из 319; июль–август у него фандинга нет). Сверка на 63 строках сентября–ноября (S_base, A_n_1, L_base, L_n24), где есть и поле движка, и модель (строк «движок есть, модели нет» и «модель есть, движка нет» с 01.09: 0 и 0): отношение движок / модель — 0,5 у 39 строк (второй лот не открыт), 1,0 у 19, 5 промежуточных, минимум 0,44. Отсюда **оценка**: сентябрь–ноябрь — поле движка (точные лоты), июль–август — модель × k линии (k = Σ движка / Σ модели на сверочных строках: S_base 0,498; A_n_1 0,672; L_base 0,725; L_n24 1,00; L_mk2 нет строк → 1,00). Для июльско-августовской части k — допущение, не измерение.

## 2. Занятый капитал

**Что считали.** Позиция открыта на интервале [вход, выход), маржа 500 $ / плечо 2 = 250 $ (полный лот от входа до выхода: второй лот и частичные тейки не уменьшают маржу — верхняя оценка). Развёртка событий, выход раньше входа в ту же миллисекунду. В прогонах лимита позиций нет (`rej[cap]` = 0 в `meta.json`), поэтому число одновременных позиций — спрос без отказов. «Пары» — сумма позиций двух линий, пересечение по монете допускается (хедж-режим, маржа каждой отдельно).

Депозит «без пропусков сигналов»: **D1** = 250 $ × максимум одновременных позиций (P&L не считается); **D2** = минимальный депозит, при котором депозит + реализованный P&L закрытых сделок (после фандинга) покрывает маржу в любой момент (нереализованный P&L не учтён — по минуткам его в готовых файлах нет). Доходность — Σ после / депозит за 136 суток; «на год» — линейно ×365/136, без реинвестиции (модель, на допущении).

## 3. Что остаётся недосчитанным (не считалось)

- **Июль–август фандинг — модель × k**: у движка фандинга за эти месяцы нет, лоты в CSV не записаны; точная цифра требует прогона движка с фандингом июля–августа — по условию задачи не запускался; диапазон по A_n_1 — −14,9…−23,4 $ (остальные линии ± 0,3 $).
- **Депозит без нереализованного P&L и без частичных лотов**: D1 / D2 считаны по полному лоту 500 $ и закрытым сделкам; маржа по минуткам с учётом нереализованного и открытого только первого лота — отдельным счётом по свечам.
- **Платежи только Binance USDT-M** (по заданию); ставки Bybit не загружались и не сравнивались.
- **Не проверялось**: биржевые ограничения маржи (лимиты плеча, минимальные размеры ордера по монетам) и влияние размера депозита на исполнение; вердикта по линиям и парам нет.
