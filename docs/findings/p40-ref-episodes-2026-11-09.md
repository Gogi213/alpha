2. **S_max = 1 с** (p99 возраста обновления ноги); кроссированная книга исключена (Binance 07 ч: 251 событие).
3. **Очередь prob:3** — снято правкой по hftbacktest (вердикт TK-500 §7 а, раздел «Правка 09.11»); исходная трактовка («мой разбор») устарела.
4. **Страховка**: нога, исполненная при снятии, закрывается мейкером на своей стороне ещё T_life; нет — тейкер на t_cancel+L+T_life+L.

7. **Спред** — максимум по двум ногам; **vol5m** — sd приращений ln mid на сетке 1 с за 5 мин, среднее по ногам; **OI** — относительное изменение стоимости OI за 5 мин (последнее значение строго до t против t−5 мин), среднее по ногам; **ликвидации** — любое событие любой ноги за 5 мин; **лидер** — нога с большим |Δln mid| за 10 с (A=1, B=0, равенство = −1).

## Правка 09.11 (Судья TK-500 §7 а, шаг 2 сверки очереди)

`tools/p40ref/sim.py` приведён к `vendor/hftbacktest` (`queue.rs` ProbQueueModel, `nopartialfillexchange.rs`) — ошибки эталона, найденные по сверке:
1. **Исполнение при пересечении:** заявка исполняется по своей цене на первом событии BBO в (приход, снятие], где противоположная лучшая цена ≤ (покупка) / ≥ (продажа) цены заявки. Было: только мгновенно при постановке.
2. **Вероятность очереди была перевёрнута:** `prob = f(back)/(f(back)+f(front))`, `est = front − (1−prob)·chg + min(back − prob·chg, 0)`, `f(x)=x³` без обрезки отрицательного front; было `f(front)/(…)`.
3. **Сделки не вычитались из `chg`:** `chg = prev − cum_trade − new`, `cum_trade` сбрасывается при каждом изменении уровня. Было: двойной счёт.
4. **Полное исполнение:** сделка по цене лучше заявки — исполнение сразу; по цене заявки `front −= qty`, `front < 0` — исполнение всей заявки (NoPartialFill). Было: частичное.
Переключатель: `CROSS` / `P40_NO_CROSS=1` (старое поведение п. 1 для сверки). Лот обменника не учтён (`round_ha(−front/lot) > 0` заменено `front < 0`).

Результат на DOGE 17.09, L=500: θ=12,6 — 7 эпизодов, одна нога 4 (мейкер-страховка 3, тейкер 1), без ног 3; θ=5,04 — 43: одна нога 26 (мейкер 23, тейкер 3), без ног 17. Относительно e1c30813 изменились исходы времени/вида у 2 из 7 и 14 из 43. Таблицы `/root/p40ref/out/ep/maker_<θ>.csv` (прежние — `nocross/`, промежуточные — `cross_v1/`).
