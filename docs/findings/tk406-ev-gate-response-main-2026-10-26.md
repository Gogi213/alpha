## Критика / что не закрыто (для Судьи)
1. Solana — своп-история TK-380 (`mid5`), не swaps3 с дедупом (задача требовала swaps3): охват мал (11–35 монет на ячейку спота), выводы по Solana только «значимого нет».
2. Нога BNB/ETH→USD пересчитана по последней сделке Gate спот (≤ 30 с, иначе своп вне) — добавляет шум в ход DEX у монет с такой ногой.
3. Первый запуск считал часть монет с чужой ногой (баг xargs -L1, исправлен и пересчитан) — в агрегате только пересчитанные 402 монеты, `rc=0` у всех.
4. Семейство Холма 1344 взято из П-29/TK-401; ячейки с < 3 монет не ранжируются. Точные сутки: 8 (15–22.10), по суткам — `-days.csv`, поразрезно не разбирал.
5. Пред-ход Gate ≈ 45–75 bp при ходе DEX ≥ 50 bp: события уже в основном отыграны на Gate до свопа DEX — «отклик» после свопа — 2–3 bp на 5 с.
6. Спот h=5 с: Холм зависит от A (1 с — 1,0; 5 с — 0,46; 30 с — 0,035): результат неустойчив к пределу возраста; Судье решить, какое A главное.
