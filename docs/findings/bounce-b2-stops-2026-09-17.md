# B2: три формы стопа на живой записи (2026-09-17)

Артефакт к тикету **B2** (В-58 п. 2: стоп `P+1` / `P` / `P−1`). Первый прогон B2
(2026-09-17, коммит `48510c0`) оставил числа только в плане и памяти — аудит
`docs/findings/plan-audit-2026-09-17.md` записал это как находку R3 («шаг закрыт только
с артефактом на диске»). Здесь прогон **воспроизведён** тем же бинарником и записан
вместе с командой.

**Это инженерная проверка формы, а не испытание сетки В-58.** Вердикт по формам даёт B5
на пригодных сутках; строки в `docs/plan/runs.csv` этот прогон не добавляет — иначе один
и тот же взгляд на данные считался бы дважды.

## Команда (одна и та же, менялся только `--stop-mode`)

```
target-ci/release/alpha.exe lob backtest --touches \
  --session-root data/always-on/20260912T201737Z --symbol ZECUSDT \
  --h3-mode floor --median-rtt-ns 20000000 --p95-rtt-ns 20000000 \
  --order-qty-e9 10000000 --stop-mode {before|at|behind}
```

Запись: местный олвейс-он `20260912T201737Z` (10 монет, 2026-09-12T20:47Z → 09-13T16:22Z,
0 разрывов), символ `ZECUSDT`, порог `H3` — из `instruments.csv` каталога записи
(`k = 1.0`), RTT `assumed(20 мс, В-37)`, дедлайн 60 с (умолчание, из сетки В-58).
Касаний 26 124, `incomplete = false`.

## Что из этого следует (числа, не вывод о стратегии)

- **Три формы дают разные числа** — требование приёмки B2 выполнено: `before` −0.0948,
  `at` −0.0945, `behind` −0.0886 bps. Значения воспроизводят прогон 17.09 (в плане
  записаны как −0.0948 / −0.0945 / −0.0886).
- **Все три отрицательны**: вердикт T38 (`net_fill < 0`) формой стопа не переворачивается.
- **Стопы доминируют**: 226–302 выхода стопом из 309–324 кругов (69.8 % у `behind`,
  93.2 % у `before`), тейков 22–83, дедлайнов и трейлов ноль. «За плотностью» даёт
  больше тейков (83) и меньше стопов (226) — согласуется со спекой §4, где стоп перед
  плотностью назван риском наторговки.
- **Разница между формами (0.0062 bps между `before` и `behind`) меньше интервала
  (0.0474 bps от `lo` до `point`)**: по одному инструменту и одной записи формы стопа
  неотличимы. Это не вердикт — вердикт даёт B5 на пригодных сутках с DSR по фактическому `N`.
