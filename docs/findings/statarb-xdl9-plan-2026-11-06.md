### 4.3 Отбор A1 [важно]
- Основной способ - эмпирический нуль.
  - Символы каталога случайно делятся на половины A и B; B сдвигается на +1 сутки.
  - Кросс-пары A×B дают нулевое распределение; реальные пары - внутри половин.
  - Для покрытия повторить с 2-3 разбиениями.
  - Порог берётся на шумовом квантиле нуля.
- Холм по обрезанному p идёт справочно.
- Каталоги `.sap` собираются символьными ссылками до вызова `form`. Одно основное на базу по обороту за 01-14.10.
- Артефакт со списком исключённых и причинами лежит рядом.
- Причина: ADF с лагом 0 без константы на минутных ценах завышает долю коинтегрированных пар.

### 4.4 Позиции без выхода и дыры
- По каждой клетке выводятся `open_at_end`, `entry_deferred`, `exit_deferred`.
- Новая колонка MTM: незакрытая позиция оценивается по последнему валидному close. Это граница чувствительности, а не основной результат. В ядре включается флагом `--mtm-open`, по умолчанию выключена (хеши G6 не меняются).
- Дыры целой биржи (Binance 28-30.10) режутся заданиями по `from_day/to_day`. Если `run` этого не умеет, добавить флаги в F3 или поставить маску NaN в конвертации. Сделки, пересекающие дыру, считаются отдельно.
- По замечанию критика, `exclude_window` в gate_data.py (tk484) пишется в params и ядром не применяется. Проверить в F3.

- Касса США (акции, ETF, индексы США): пн-пт 13:30-20:00 UTC до пт 30.10 и 14:30-21:00 UTC с пн 02.11. Переход на зимнее время - воскресенье 01.11.

### 4.6 Статусы, МРЭ, нормировка (фиксируются в П-37 r1 до счёта)
- Эффективное n - число суточных блоков (блоковый бутстрап по суткам, блок 3), а не число сделок.
- МРЭ = 2,8·σ/√n_эфф, формула из П-32 §8 с n_эфф по блокам.
- Нормировка «bps на сутки»: среднее по активным парам (число активных пар выводится рядом).
- Статусы (формулировка - предложение, числа «назначено без Судьи, подтвердить»):
  - «кандидат»: нижняя граница 90 % блочного интервала > 0 после комиссии; плацебо в нуле; результат держится без лучших 2 суток и без лучшей монеты; N не ниже `min_N`;
  - «не различимо с нулём»: интервал содержит 0 и МРЭ не выше безубытка круга двух ног (12,6 bps);
  - «не ясно»: всё остальное.
- Числа, которые нужно назначить: `min_obs`, `min_span`, порог числа баров, порог корреляции и полоса отношения, `min_N`. Первые три и последние два фиксируются в П-37 r1. Порог корреляции и полоса отношения калибруются только по формированию и коммитятся в P-37-params до F8.
