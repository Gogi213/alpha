# TK-324: спот B1 на тарифе владельца (В-47) — вариант (в)

**Итог:** на фактическом тарифе tiger.com спот B1 по-прежнему не приносит плюса: ни одна из 16 клеток не проходит правило П-21 §8 (≥6/9 мес. плюс, нижняя граница 90 % SR > 0, Холм < 0,10). Лучшая клетка (в) — g-s100-u3: Σ$ −4,6.

Источник — готовые rounds TK-313 (273 сут., янв–сен, В-213), без нового прохода; скрипт `tools/compute/tk324-spot-tariff.py`, сырьё `data/tk324-idx{2,3,4}.json` (копия на calc: `/data/tk0313/tk324-idx*.json`).

## Варианты издержек (на ногу, bps)
- (а) комиссии модели фьючерса (как в TK-313).
- (б) публичный спот 10/10.
- (в) тариф В-47: вход maker 5,625; выход taker 6,75 при stop/deadline, иначе maker 5,625.
- (в2) контрольный: обе ноги taker 6,75 (13,5 bps).

## Что это значит
- Тариф В-47 снимает примерно 40 % убытка (б)→(в) у S0 (−2165 → −1516), но не переводит ни одну клетку в плюс; (а) без издержек тоже ≤ +20.
- Вывод ограничен замером: n сделок в плюсовых по (а) клетках 115–162, интервалы широкие; «не подтверждено» ≠ «опровергнуто».
- `ctl-nn` совпадает с `s0` по определению (порог $10k) — независимого контроля случайных уровней нет (Г-03 открыт), как и в TK-313.
- Испытаний: 16 клеток × 3 варианта издержек (издержки — пересчёт одних сделок, не независимые испытания); Холм — по 16.
