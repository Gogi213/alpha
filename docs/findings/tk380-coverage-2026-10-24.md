## Что не покрыто и почему
- **Ethereum, 90 пулов Uniswap v4 (994 М$ из 1115):** v4 эмитит Swap из синглтона PoolManager, а не из адреса пула; сборщик фильтрует по адресу пула. Оборот в основном стейблы (USDC 416, PYUSD 326, RLUSD 120, USDG 93 М$ — не торговые монеты). Закрыть: фильтр по PoolManager + poolId (SQD, topic0 Swap v4) — отдельный шаг, если нужны ETH-монеты на v4. Остальные 4 пула — Curve (5 М$).
- **Base:** 26 пулов без свопов — Aerodrome (16 пулов, 49 М$; другой тип события Swap) и 9 v4 (1 М$).
- **Solana (1093 М$, 23 %):** пулы найдены, свопов нет; путь — Helius gTFA / SQD / Old Faithful (решение CEO 23.10), в этом запуске не качалось.
- **Sui, Polygon, Optimism, Tron, Avalanche (1,1 % оборота):** свопы не качались; Sui — GraphQL без ключа, прочие — SQD/RPC. Малый оборот.
- Метод поиска пулов (CoinGecko → контракт → DexScreener): монеты без записи в CoinGecko не найдены; оборот пулов — по GeckoTerminal, 8 из 855 пулов с ошибкой, 10 пустых.
