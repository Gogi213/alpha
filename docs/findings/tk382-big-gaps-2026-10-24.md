# TK-382 / G-016: крупные отрывы фьюча Gate от DEX (≥2/3/5 %), долгое удержание

**Итог: нетто < 0 почти везде; ни одна клетка не отличима от нуля в плюс.** Единственные интервалы, накрывающие 0: T=5 % (H=2 ч, 8 ч) — 8 ч все **+0,8 [−16,7; +21,5]**, шорт фьюча **+5,7 [−16,2; +32,5]**; при отсечении «stale» (DEX без свопа > 5 мин) тот же T5/8 ч — **−14,1 [−31,0; +4,1]**. Тип «памп фьюча при стоящем DEX» (шорт фьюча на разворот) на неделе 15–22.10 края не показывает. Это не доказательство отсутствия: 8 суток, одна неделя, T5 — 710 эпизодов на ≈115 монет.

## Что мерили
Данные: Gate фьюч BBO по секундам из стакана TK-379 (середина → ряд отрыва, вход/выход по исполнимой стороне), DEX — свопы TK-380 по 5 сетям (BSC, Ethereum, Base, Arbitrum, Solana-124 пула; 13 тяжёлых Solana-пулов, Sui/Polygon/OP/AVAX не охвачены). Сетка 10 с, `gap = ln(mid/DEX)`, отрыв = |gap − медиана монеты| ≥ T. Вход на следующей корзине тейкером (фьюч выше DEX → шорт по биду; ниже → лонг по аску), выход при |gap−мед| ≤ T/2 либо по таймауту H (30 мин / 2 ч / 8 ч), тоже тейкером. net = pnl − RT 15 бп − фандинг Gate (`funding_rate`, расчёты внутри удержания, знак по позиции). MAE — макс. неблагоприятный ход по исполнимой стороне. Doubled — |gap−мед| достигал 2×вход до выхода. Контроль — 5 случайных входов той же монеты, тот же знак и длительность. «Тяжёлые» = нижний терциль монет-сетей по медианному спреду BBO (≤ 3,59 бп; 138 из 412) — определение TK-380. Бутстрап по монето-суткам (4000). Скрипты: `tools/compute/tk382-biggap.py`, `tk382-summ.py`; calc `/data/tk0380/tk382/`.

- **Знак:** шорт фьюча (фьюч выше DEX) и лонг на T=2–3 % различаются слабо (шорт −31…−35, лонг −26…−29 при H=2 ч); только на T=5 % при H=2–8 ч шорт лучше лонга (−2,5…+5,7 против −15…−6), но интервалы перекрываются.
- **Хвост:** отрыв сначала удвоился лишь в 1–6 % эпизодов; но MAE средний 70–170 бп, p90 180–420 бп — сопоставим с самим отрывом (T=2 % = 200 бп): стоп на размере отрыва сработал бы в ≈10 % эпизодов.
- **Фандинг:** среднее за удержание −0,0…−0,8 бп (T=5 %, 8 ч: −0,36) — не двигает вывод.
- **Контроль** (случайный вход той же монеты, знак, длительность) **хуже** эпизодов на 15–50 бп: это цена спреда + дрейф широкоспрэдных монет (в контроле входы берутся и там, где спред широк); эпизоды ему превосходят, но обе величины ниже нуля, так что «лучше случайного» ≠ «плюс». - **Тяжёлых отдельно нет плюса:** без тяжёлых хуже (спреды выше, на T=2 % −33,7 против −28,4).

## Оговорки (влияют на толкование)
- **stale (28 % эпизодов):** DEX-цена — последний своп, дотянутый до 30 мин; у монет с редкими свопами «отрыв» может быть просто устаревшей ценой DEX, а не стоящим DEX с живым торговым окном. Без stale знак тот же (T2/2 ч −26,1 [−34,7; −17,4]; T5/8 ч −14,1 [−31,0; +4,1]).
- Медиана gap по монете берётся по всей неделе (вычитание постоянного смещения, частично заглядывает вперёд) — как в TK-380.
- Эпизоды внутри монеты-суток зависимы (бутстрап по монето-суткам их учитывает), но одна монета-сеть присутствует и как ряд в нескольких сетях (SI, ZRO…) — монеты разных сетей считаются отдельно.
- Gate-нога — только фьюч, исполнимость без учёта глубины (вход по лучшей цене BBO; объём не учтён, на широкоспрэдных монетах глубина тонкая). Мейкер-вход не мерили.
- Охват: Solana без 13 тяжёлых пулов, Sui/Polygon/OP/AVAX нет; цепочки с DEX-ценой через нативный токен — по минутной цене Gate фьюч (как TK-380).
- Число испытаний: 3 T × 3 H × 6 срезов; выводы «плюс» ни в одной клетке не выдерживают интервала, поправка на множественность не нужна, чтобы отказать.

## Что дальше
Отрывы ≥2 % с удержанием 30 мин–8 ч не дают нетто-плюса на неделе; кандидат лишь T=5 %/8 ч шорт (+5,7 [−16,2; +32,5], 417 эп., 173 монето-суток) — для решения нужны новые недели того же стека (данные TK-379/380 за другие даты) и разность «эпизод − контроль» с бутстрапом. Решение владельца не требуется.
