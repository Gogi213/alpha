# TK-443 · V10 (дамп после пампа, неудачные возвраты), 2026-10-28

Цель В-58. Реестр H-025. Скрипт `tools/compute/tk443-v10.py` (правило — в его шапке, зафиксировано до счёта), артефакт `pump-forward-notes5-v10-2026-10-28.csv`.

**Определение (слова автора V10 «несколько заходов выше уровня без продолжения, закрытия под уровнем ~3 ч → дамп» переведены в числа без подбора):** событие v11 вверх (D=360|720, Bybit linear); уровень = середина хода (c[старт]+c[пик])/2; t0 — первое закрытие под уровнем после пика; неудачный возврат = переход выше уровня, закрывшийся под ним в течение 60 мин; N считается за 180 мин от t0; решение в t0+180 при c[старт] < c < уровень; исход «дамп» = c ≤ c[старт] в следующие 360 мин. База — доля дампа среди всех условных событий месяца.

**Итог: не подтверждено.** Больше неудачных возвратов дамп не повышают.
- N ≥ 1: подъём 0,94 [0,85; 1,02] (сент.), 0,95 [0,86; 1,02] (авг.); N ≥ 2: 0,94 [0,82; 1,04] / 0,97 [0,84; 1,07]; N ≥ 3: 1,02 [0,86; 1,19] / 0,84 [0,66; 0,98]. Все — все D, интервалы через 1.
- N = 2 выглядит по-разному: 0,59 [0,24; 1,01] в сентябре и 1,50 [1,08; 1,97] в августе — знак не держится, это шум.
- N = 0 (без возвратов) слегка выше базы: 1,19 [0,93; 1,49] / 1,17 [0,92; 1,49] — интервал содержит 1.
- Базовая доля дампа высокая (21–22 % при D=360…720 вместе; 25–26 % при D=360, 14–15 % при D=720), потому что условие «под уровнем, но выше старта» само по себе близко к полному откату.

**Воронка (авг. / сент.):** событий вверх D=360|720: 1984 / 1737; без закрытия под уровнем за 720 мин (памп держится) 613 / 530; вне состояния «старт < c < уровень» в t0+180 — 682 / 541; в счёте 689 / 655.

**Ограничения.** Только август и сентябрь (разметка событий v11 для других месяцев не сделана — экзамен янв–июль не проведён). События перекрываются между D и внутри монеты — интервалы по инструмент-дням, вероятно, узки. Один способ определения уровня (середина хода); другие уровни (пик, 61,8 %) не пробовались — число испытаний 6 групп × 3 среза D × 2 месяца. Сигнал вперёд для торговли здесь не получен.
