# TK-326: откуда минус спота B1 (S0) — разбор готовых rounds

**Простыми словами:** почти весь минус дают **стоп-выходы**. 17 % сделок (435 из 2606) выходят по стопу со средним −208 bps до комиссий и это −3208 $ при общем −1516 $ (тариф В-47) — то есть 212 % минуса; остальные сделки в сумме дают плюс (трейлинг +1953, дедлайн −261 при (в), +56 при (а)). Это не «задержка» и не «сидение»: удержание само по себе не причина, а следствие — короткие сделки (<30 мин, 199 шт.) в этих сделках ср. gross −93 bps, т. е. это в основном стопы (разбивка «причина × время» не считалась). До комиссий S0 уже в минусе (−542 $); комиссии на (в) добавляют ещё −974 $ (≈12 bps на круг, 64 % итога), на (а) — −307 $. Тот же разбор фьюч-аналога даёт такую же картину (стоп −205 bps, 11 % сделок, −8416 $; трейлинг +5346). Это описание того, **где** минус, а не доказательство, что стопы «можно убрать»: стоп — защита, без него те же сделки продолжили бы падать.

Источник: готовые `rounds.csv` + `signals.csv` S0 из TK-313 (2606 сделок, 227 суток с сделками из 273, без нового прохода, В-213; join с signals 2606/2606). Скрипт `tools/compute/archive/tk326-spot-loss.py`, сырой вывод — `docs/findings/tk326-spot-loss-tables-2026-10-20.md` (копия на calc: `/data/tk0313/tk326.md`). Издержки как в TK-313/TK-324: gross = net_bps + модель фьюча (1,26 + 1,26 или 3,15 bps для stop/deadline); (а) фьюч-модель, (б) публичный спот 10/10, (в) тариф В-47 (вход maker 5,625; выход taker 6,75 при stop/deadline, иначе maker 5,625). Основной столбец — (в).

## Парето 80 % по признакам TK-327 (ret1/5/30, режим, $ стены, flow_pct, сила w20/w50, σ240) — хвост TK-329

Вход — `tk327-features-{spot,fut}-2026-10-20.csv` (принято Судьёй), скрипт `tools/compute/archive/tk329-pareto.py`, полные таблицы (квартили, группы n · Σ$, помесячно) — `tk329-pareto-2026-10-20.md`. Группы — квартили по выборке режима (дубли порогов схлопнуты, у 18 спот-сделок ret пуст = группа «нет»; strength_w10 не использован). Спот: мера как выше — чистый минус Σ$ (в), −1516 $. Фьюч (А, 1132): чистого минуса нет (Σ +89), мера = сумма Σ$ групп с Σ<0. Описание, не правило: срезы выбраны по тем же данным, интервалов нет.

**Спот S0 — минус размазан по всем квартилям каждого признака** (каждая группа Σ$<0; режим btc4h: −342/−358/−373/−444, т. е. тоже ≈ поровну, в 6/9 мес.). Заметные концентрации: σ240 Q1–Q2 (< 150 bps) — 81 % минуса на 50 % сделок, лифт 1,62, 9/9 мес. (Q3/Q4: −164/−123; низкая σ — худшие); $ стены Q1–Q3 (< 56 тыс. $) 81 % на 75 % (лифт 1,08, слабо); flow_pct и сила w20/w50 — набор из трёх квартилей, 82–90 % на 75 % (лифт 1,10–1,20, 8/9 мес.), худшая группа — верхние квартили силы w50 (Q4 ≥ 873: −751 $ на 652 сделках, 50 % минуса). ret1/ret5 (цена через 1/5 с против нас) — Q1 и «≥ 0» дают 93–94 % на 89–91 % сделок (лифт ≈ 1): ход цены после входа минус не объясняет; ret30 Q1 (< −3,2 bps, 647 сд.) −822 $ = 54 % минуса при 25 % сделок — это следствие (цена уже пошла против нас), не признак на входе. Месяцы: знак минуса держится 9/9 для ret, $ стены, σ240; для остальных 8/9 (сен. +8…+26 $ у flow/силы).

**Фьюч B1 (А) — концентрации нет, суммы групп малы** (все группы −176…+217 $ при итоге +89, интервалов нет). «100 % за 25 %» в таблице — арифметика (в плюсе три квартиля из четырёх, отрицателен один), а не сильная концентрация: ret1 Q1 −16 $, $ стены Q2 −128, flow Q3 −82, сила w20 Q3 −68 (разные квартили у разных признаков — монотонности нет), режим Q1+Q3 −79. Единственное, что держится по месяцам, — σ240 Q1 (< 94 bps): −176 $, Σ<0 в 8/9 мес.; при этом Q4 (> 173) +175 — та же полярность, что на споте (низкая σ хуже). ret30 Q4 (≥ 5,5 bps) +217 — следствие исхода.

**Что общего (описание):** на споте и фьюче низкая σ240 — группа с худшим результатом и стабильным знаком по месяцам; остальные признаки дают лифт ≤ 1,2 (спот) или нестабильны/малы (фьюч). Причинность и «отсечь по σ» не следуют: срез выбран по тем же данным, эфф. N по месяцам мал, σ коррелирует с монетой. Для правила нужен протокол (порог заморожен до счёта) — вне этого тикета.

## Ограничения (шум и подгонка)
- Все срезы выбраны по тем же данным (подгонка): «убрать час/монету/стоп — станет плюс» не следует, проверки вне выборки нет. Условный вывод вроде «без стопов» бессмыслен (стоп — часть формы B1).
- Для часа, монеты n на группу мал (в среднем 100 сделок/час, 28 сделок/монета), интервалы не строились; из помесячной проверки — только «знак держится».
- Помесячные Σ$ набора по каждому признаку — в `tk326-spot-loss-tables-2026-10-20.md`.
- Вход против цены через 1/5/30 с — не посчитан (нет данных без прохода).
