## Сборка из сделок (BOB / TON / SOS, возврат Судьи 03.11)

`tools/compute/spot483/closed.py` (по образцу `tk476-bybit-closed.py`): сутки `public.bybit.com/spot/<SYM>/<SYM>_<день>.csv.gz` (id, timestamp мс, price, volume, side) → минута: `c` = цена последней сделки минуты (внутри последней мс — конец свипа тейкера: buy — max, sell — min), `v` = Σvolume, `quote_v` = Σvolume·price, `n_trades` = число сделок, `o` = `c` последней сделки до минуты (через границу суток), `h`/`l` с учётом `o`. Минуты без сделок **не пишутся** (не выдумываем). Сырьё сделок (2610 суток) хранится в `/srv/alpha-sda/trades-spot-483` (не удалять); файлы заменили пустышки `hist.py` (они — в `/srv/alpha-sda/candles-1m-483/prev-empty/`).

Неоднозначная минута — в последней мс ≥ 2 разных цен: порядок исполнения внутри мс архив не хранит, поэтому `c` (и `o` следующей минуты) может разойтись с REST; `v`, `quote_v`, `h`, `l` от порядка не зависят. Это неустранимый остаток сборки из сделок; число таких минут — в `closed-summary.csv`.

**Сверка сборки с REST** (`python3 tools/compute/spot483/closed_gate.py ГГГГ-ММ-ДД DOGEUSDT ADAUSDT XRPUSDT`, юнит `tk483-final3`, `closed-gate.log`; пары, где есть и REST, и архив сделок; сутки 2023-03-15, 2024-06-10, 2025-09-20, 2026-10-20, 12 пар-суток): общих минут 1248–1440 в паре-сутках, `bad_v` = 0 и `bad_quote_v` = 0 везде (объём и оборот сборки == REST), `bad_h` = `bad_l` = 0; `bad_o` = 1 и `bad_c` = 1 на DOGEUSDT 2024-06-10 (из 1440), в остальных 11 парах-суток — 0; все расхождения объяснены неоднозначной мс (`unexplained` = 0); `built_only` = 0, REST-минуты без сделок (`rest_only`, 0–192 в паре-сутках) — все плоские (o=h=l=c, v=0), в файл не пишутся. rc 0.
