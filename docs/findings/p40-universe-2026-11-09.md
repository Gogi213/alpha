## Метод и оговорки
- Списки: CHFT `/v1/symbols` (orderbook) для Binance, OKX, Bitget, Aster, Hyperliquid; Bybit — REST `instruments-info` (930, из них 814 USDT-бессрочных; все 814 есть в архиве quote-saver); Gate — REST `/futures/usdt/contracts` (1080). У CHFT списки Bybit/Gate пусты (их качаем из своих архивов). Bingx/Kraken/Lighter списков в CHFT не дали — вне таблицы.
- Сопоставление актива: базовый тикер без котировки, множители 1000/10000/1M/k сняты; Bybit — по `underlyingTicker`; алиасы XAU=GOLD, XAG=SILVER, CL=WTI, BZ=BRENTOIL, GOOG=GOOGL; Hyperliquid — без префикса биржи-фабрики (xyz/flx/km/cash/para/io/vntl). Пары USDC/USD/USD1, датированные фьючерсы исключены.
- Класс: Bybit `symbolType` (stock/ETF/commodity/forex) + контракты фабрик Hyperliquid (кроме HYNA и тех, что есть нативно) + список металлов/энергии. **Приблизительно:** TradFi-тикер, которого нет на Bybit и Hyperliquid-фабриках, попадёт в «крипту»; множитель контракта (напр. 1000 vs 1) в сопоставлении не проверен.
- Размер: **не замер по выборке**, а средний МБ на контракт-сутки по уже скачанному (Bybit 28,9; Gate 31,5; OKX 36,6; Bitget 49,4; Aster 34,5; Binance 91; Hyperliquid 10 — ориентир, снимки) × 36 суток. Дельта = (контрактов − уже скачанных 94–100) × то же. У TradFi-контрактов стакан может быть тоньше (меньше событий) — оценка сверху.
- Наличие всех контрактов в архивах CHFT/Gate по дням 17.09–22.10 не проверено (проверка — первый шаг закачки).
- Файлы: `p40-universe-2026-11-09/universe-assets.csv` (актив × биржа → символ), `build.py`, `listsyms.py`.
