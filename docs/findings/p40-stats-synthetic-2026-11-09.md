## Итог
- **Главная схема интервала — аналитическая двусторонняя кластерная дисперсия Камерона–Гельбаха–Миллера (CGM)**, `V = V_A + V_D − V_AD`, t с G−1 = min(активы, сутки)−1; при V ≤ 0 — max(V_A, V_D). Блочный бутстреп по суткам (§5.1 протокола) недопокрывает, когда признак/исход постоянны по активу.
- **Под нулём (D=14, оба вида зависимости) CGM даёт промах интервала 0,095 при номинале 0,10; доля ложных «lo>0» 0,05 (номинал 0,05); мощность при эффекте 2,49·SE = 0,77 (заявлено 0,80).**
- **Правка протокола нужна:** §3.5 п. 1 / §5.1 (схема интервала), §5.2 (MDE), §3.5 «час суток» (χ² с Рао–Скоттом по той же схеме). Предложение — в конце. Правку утверждает Судья до счёта реальных эпизодов.

## Алгоритм
Варианты — наивный, кластер ячейка, сутки, актив, twoway (произведение весов), CGM аналитический, twoway_sub (бутстреп-аналог CGM, B=400); замер — покрытие в 4 режимах × D=14, 22 и мощность k=0…2; выбран **CGM**: единственный из дешёвых с покрытием ≈0,90 в «оба»/«актив» и мощностью 0,77 при 1×MDE; twoway_sub равен ему по качеству, но дороже и случайнее (B), поэтому — для H-Bybit (медиана без аналитики). Слабое место: по суткам при G=14 CGM промахивается 0,16 (малое G; при 22 сутках 0,11) — поэтому min G = 14 суток обязателен, а при <14 интервал не объявлять.

## Предложение правки П-40 (было → стало)
- §3.5 п. 1, §5.1: «блочный бутстреп по суткам, t_{G−1}» → «двусторонняя кластерная дисперсия CGM (актив и сутки), t с G−1 = min(активов, суток)−1, при V ≤ 0 — max(V_A, V_D); бутстреп по суткам — только справка».
- §5.2: «MDE = 2,49·√(p(1−p)·DEFF/n)» → «MDE = 2,49·SE_CGM контраста (разность долей)»; для справки — формула с √(1/n_в+1/n_н).
- §3.5 «час суток»: испытание в BH = χ² (df 3) с поправкой Рао–Скотта по CGM; размах «max−min» с порядком блоков по D1 применяется на D2 для п. 1, 3, 4.
- §3.5 H-Bybit: разность медиан KM (бутстреп twoway_sub) и «МПУ > X» контрастом CGM; Холм на Q1.
