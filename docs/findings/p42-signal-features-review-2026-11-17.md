## Правки

### П1. `emp6h` вырожден из-за формата кэша, а не рынка (ошибка; меняет ответ по теме 2)

Кэш минуток `.b42` плотный: минуты без сделок в нём есть, но записаны как заполненный бар с нулевым
объёмом (`qv = 0`, o = h = l = c = прошлое закрытие). `sparse_features` считает пустыми только
минуты с `o == 0`, а таких после листинга почти нет: это целиком отсутствующие участки.

- Измерено по всем 566 монетам: после листинга `o == 0` — 175 680 минут, а `qv = 0 при o ≠ 0` — **1 948 552 минуты** (3,2 % всех минут; у SNOW, HK0700, TEM, NVDL — около 50 %).
- Поэтому `emp6h = 0` у всех сигналов получился по построению. Фраза отчёта «вне пула (U0, 226 580 эпизодов) пустых минут перед сигналом нет ни у одного» неверна.

Пересчёт той же мерой на минутах с `qv = 0` (`zv6h` — доля таких минут среди `t−360…t−1`; разведка, найдено на этих данных):

| вселенная, сторона | эпизодов с `zv6h` > 0 | группа Z | O3 в Z / вне Z | AUC `zv6h` (A / B) | доля непробоев, объяснённая (модель) |
|---|---|---|---|---|---|
| U1 лонг | 14,7 % | `zv6h` > 0 (80-й процентиль A = 0), 254 эп. | 8,7 % / 3,7 % (сутки [−0,9; +11,2] п.п., монеты [−0,6; +12,2]) | 0,571 (0,633 / 0,523) | −0,8 % |
| U1 шорт | 16,1 % | `zv6h` > 0, 221 эп. | 3,6 % / 4,8 % (сутки [−4,9; +3,1]) | 0,483 (0,458 / 0,510) | 0,2 % |
| U0 лонг | 44,6 % | верхний квинтиль (> 2,8 %), 18 113 эп. | 1,0 % / 1,6 % | 0,497 (0,486 / 0,512) | 0,1 % |
| U0 шорт | 43,8 % | верхний квинтиль (> 2,8 %), 19 398 эп. | 1,4 % / 1,8 % | 0,476 (0,458 / 0,492) | 0,1 % |

Что это значит для вопроса владельца «на сколько проблема разреженный график»:

- В пуле (оборот часа ≥ $500 тыс.) у 84–85 % сигналов за 6 ч до входа нет ни одной минуты без сделок. У остальных доля пробоев не ниже: у лонга выше, у шорта ниже, интервалы накрывают 0.
- Без пула разреженные моменты пробивают реже (1,0 % против 1,6 %; 1,4 % против 1,8 %), но это объясняет около 0,1 % непробоев. Разреженность отсекает пул; внутри пула это не проблема.
- Примеры владельца по правильной мере: KORU — 12,2 % пустых минут за 6 ч, STXX — 3,3 % (оба в Z), CLANKER и NXPC — 0. В отчёте у всех четырёх 0.

Что поправить в отчёте: тема 2, раздел «Монета против момента», строка `emp6h` в первичном пакете
(в первичном пакете признак остаётся как был; это отступление, исправленная мера идёт рядом),
`emp_coin`, `emp2h`. Исправить `sparse_features`: пустая минута — это `qv == 0`. `flat60` тоже
считает минуты с `qv = 0` (h = l), поэтому он был единственной рабочей мерой; AUC 0,523 / 0,521.

### П2. Контроль: сравнение не на одних и тех же эпизодах; эффект уровня неустойчив (существенное)

Отчёт сравнивает O3 по всем эпизодам (4,4 %) с контролем, который есть только у 1 453 / 1 036
эпизодов. У 273 / 341 эпизодов без контроля доля пробоев низкая: 1,1 % (лонг) и 2,9 % (шорт).
Правильно — разность на одних и тех же эпизодах:

| сравнение (строгая метка, если не сказано иное) | лонг | шорт |
|---|---|---|
| в отчёте (все эпизоды против подмножества с контролем) | 4,4 − 3,2 = +1,2 п.п. | 4,6 − 2,9 = +1,7 п.п. |
| на одних эпизодах, их контроль | 5,0 − 3,2 = **+1,8 п.п.** (сутки [−0,1; +3,7], монеты [+0,1; +3,8], p 0,06) | 5,2 − 2,9 = **+2,3 п.п.** ([+0,5; +4,3], [+0,2; +4,3], p 0,02) |
| мой контроль (своя реализация, тот же замысел) | +2,0 [+0,3; +3,7] / [+0,3; +4,0] | +2,4 [+0,7; +4,2] / [+0,4; +4,6] |
| мой контроль, совпадающий по резкости подхода (контрольные моменты из той же корзины `mv5`) | +2,3 [+0,4; +4,1] | +2,0 [+0,3; +4,3] |
| половины A / B (их контроль) | +1,9 / +1,8 | **+4,8 / +0,2** |
| половины A / B (совпадающий контроль) | +1,5 / +3,0 | +4,6 / **0,0** |
| независимые подходы (их контроль) | +0,8 [−0,6; +2,2] | +3,2 [+0,9; +5,4] |
| без 5 монет с наибольшим числом пробоев | +0,2 | +1,1 |
| без 5 суток с наибольшим числом пробоев | −0,1 | +1,0 |
| метка с возвратом глубже 0,1 % (мой контроль) | +1,4 [−1,2; +4,3] | **+5,0 [+1,8; +8,0]** |

Как устроен контроль (вопрос 1). Берётся та же монета и те же UTC-сутки. Минута должна проходить
пул (NATR ≥ 0,4 %, оборот часа ≥ $500 тыс.). Окна ±60 мин вокруг сигналов эпизода исключены.
Псевдоуровень стоит на том же расстоянии `dist` от первой сделки минуты. Режим волатильности
совпадает в первом приближении: касание за 60 мин у сигнала 91–93 %, у контроля 89–92 %. Подход
к псевдоуровню контроль не учитывает; я добавил совпадение по `mv5`, ответ тот же. Псевдоуровень —
произвольная цена, а не экстремум (критика плана п. 2 просила «то же расстояние до ближайшего
экстремума»). Значит, контроль меряет «случайный порог», а не «случайный уровень». Это нужно
написать в отчёте как отступление.

Что из этого следует:
- Сигнал пробивает чаще случайного порога примерно на 2 п.п. по строгой метке, то есть в 1,6–1,8 раза. Это интервалы, найденные на этих данных.
- У лонга эффект держится на 5 монетах (AVA, ALICE, FOLKS, SYN, HEI) или на 5 сутках. На независимых подходах и при возврате глубже 0,1 % интервал накрывает 0.
- У шорта эффект почти целиком в половине A. При возврате глубже 0,1 % он сильнее, +5,0 п.п.
- Фразу «~1,3 п.п. над случайным» в «Коротко» надо заменить таблицей выше.

Шорт, возврат > 0,1 %: сигнал 19,8 / 15,9 / 14,0 / 14,6 / 13,9 %, контроль 11,9 / 9,8 / 10,5 / 11,4 / 9,0 %.

- Отчёт пишет, что при возврате глубже 0,1 % градиент «почти исчезает». В сырых долях так и есть: AUC `turn24h` по этой метке 0,445 (лонг) и 0,474 (шорт).

- Это взаимодействие «уровень × ликвидность»: найдено на этих данных, справочно. В отчёт — таблицу с контролем.

### П4. Темы 1 и 3 зависят от строгой метки (существенное)

Основная метка считает возвратом любую сделку ниже уровня после касания. Поэтому O2 «касание» = 0,0 %,
а O4 = 87 %: метка во многом меряет одну печать по бид после касания. Метка с глубиной возврата 0,1 %
записана в §13.17 до счёта как справочная. По ней (описательно, вне Холма, найдено на этих данных):

| сравнение | строгая метка | возврат глубже 0,1 % | A / B (глубже 0,1 %) |
|---|---|---|---|
| шорт: зона − чистый | 4,2 − 4,9 = −0,7 п.п. [−4,1; +3,0] | **8,0 − 16,3 = −8,3 п.п.** (сутки [−13,2; −3,7], монеты [−13,6; −2,5]) | −5,8 / −10,5 |
| лонг: зона − чистый | 6,3 − 3,5 = +2,8 п.п. | 13,1 − 9,5 = +3,6 п.п. [−1,9; +9,3] | +0,2 / +6,5 |
| шорт: без проторговки (`cons60` = 0) − с проторговкой | 6,9 − 2,4 = +4,5 п.п. | 14,4 − 12,4 = +2,1 п.п. [−1,7; +5,6] | +0,7 / +3,4 |
| лонг: то же | 4,9 − 4,1 = +0,8 п.п. | 9,9 − 11,2 = −1,3 п.п. [−4,3; +1,5] | −5,9 / +2,6 |

У шорта зона пробивает ниже случайного порога (8,7 % против 11,8 % у контроля), чистый уровень — выше (18,5 % против 9,7 %).

Что поправить в отчёте:
- Тема 1: у шорта при возврате глубже 0,1 % зона пробивает вдвое реже чистого уровня. Знак тот же в A и B, интервалы по суткам и монетам не накрывают 0. Это самое сильное описательное различие во всём исследовании, и в отчёте его нет. Подавать как справочное, найденное на этих данных: метка не основная, Холм не применялся.
- Тема 3: «данные показывают обратное ожиданию» (шорт без проторговки 6,9 % против 1,8–2,6 %) верно только для строгой метки. По метке с возвратом 0,1 % разница +2,1 п.п., интервал накрывает 0. Нужна пометка «зависит от определения возврата».
- Для следующих шагов: доля основной метки 4,4–4,6 % дала МРЭ 0,17–0,19. При доле 10,7–13,4 % (возврат 0,1 %) МРЭ было бы 0,114 / 0,115. И выход движка «вернулись под уровень» тоже должен иметь глубину (критика плана п. 2). Рекомендация координатору: в следующем протоколе основная метка — с глубиной возврата.
