# TK-443 V4 «органика» — сделок на $ оборота (28.10)

**Итог: не различимо (ограничено: только сентябрь, 49 монет).** Куб сделок TK-436 есть лишь за сентябрь и 50 монет, норма 7 сут → ts ≥ 8 сент (22,9 сут). База ≈1 % по построению на этом наборе. Скрипт `tools/compute/tk443-v4.py` (копия `tk443-forward.py`), csv `pump-forward-notes5-v4-2026-10-28.csv`, реестр H-022 (пороги заморожены до счёта).

Признак: org = (сделок/$ за 60 м) / (то же за 7 сут, кончающиеся в t−60); >1 — «органика» (много мелких сделок), <1 — «алгос» (крупные сделки). Ход вперёд вверх, D=360, подъём [CI 95 %]:

| сигнал | подъём | срабат./сут/монету |
|---|---|---|
| vr≥3&qr≥3 (TK-442) | 5,9 [2,7–9,8] | 2,65 |
| org≥1,5 | 0,84 [0,5–1,3] | 40 |
| org≥1,5&qr≥3 | 10,3 [0,4–24] | 0,8 |
| org≥1,5&vr≥3&qr≥3 | 18,6 [0–41] | 0,18 |
| org≤0,67 | 1,1 [0,4–2,1] | 22 |
| org≤0,67&vr≥3&qr≥3 | 6,5 [0–19] | 0,25 |
| nr≥10 (число сделок к норме) | 8,8 [3,5–15] | 2,9 |

- Сам по себе org (любая сторона) подъёма не даёт (≈1, ниже порога TK-442): «органика» не предсказывает ход, «алгос» тоже не гасит его (org≤0,67&vr&qr ≈ порог TK-442).
- Добавка org≥1,5 к vr&qr поднимает точку (18,6 против 5,9), но интервал [0–41] содержит и 5,9: на 38 попаданиях не отличить. Для дампа (dn) то же.
- nr≥10 (оборот в сделках) похож на qr≥10: рост от числа сделок, не от их размера.
- Вывод: подтверждения «органика = пробои идут» нет; проверка на янв–август невозможна без куба сделок (нужна докачка/сборка кубов сделок на 9 мес. — задача Инженеру).
