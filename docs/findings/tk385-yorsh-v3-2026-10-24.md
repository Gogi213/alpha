## Что НЕ проверено / почему верить нельзя (критика метода)
1. **Q — одна монета, один пул, 7 дней.** Плюс 7/7, но дни зависимы (одна ценовая траектория). Отбор монет — по обороту на 23.10 (выживший); в сентябре Q не проверялся.
2. **Задержка DEX.** Котировка пересчитывается по середине пула с лагом 1 с от метки блока; в живом режиме сигнал блока придёт позже (узел + сеть). Чувствительность к лагу (2/5/10 с) **не считана** — для монеты, где край = «Gate догоняет DEX», это главный риск.
3. **Очередь оптимистична:** отмены впереди не учтены; заполнение при накоплении объёма > очереди на цене, а сквозной принт заполняет всегда. Размер лота не привязан к объёму сделки (1 «лот» любого размера) — для Q с тиком 0,2 бп размер заявки надо привязать к реальному принтам.
4. **Неблагоприятный отбор** учтён только через исход круга (выход по рынку через T); отдельно по приросту DEX против позиции — не разобран. 22 % принудительных выходов — это и есть его проявление.
5. **Тик Q = 1e-6 при цене 0,051 (0,2 бп)** — округление цены тут не причина плюса (k=0,2 % = 100 тиков), но на Q при ширине спреда 1–7 бп сквозной принт на соседнем тике дёшев.
6. Нет контроля «DEX случайно сдвинут/перемешан по времени» для Q — без него не отделить «Gate догоняет DEX» от «Q просто колеблется на ±0,2 % за 5 мин» (амплитуда цены сама даёт плюс лимитчику при любой разумной линии). **Этот контроль — следующий шаг до любого вывода о крае.**
7. SUE/LAPTOP (v2, предыдущая запись): SUE минус, LAPTOP шум; CAKE/BTR/DGAI в этом проходе не считались.
