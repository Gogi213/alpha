# TK-385 — «ёршик/пила» (G-016): шаг 1, псевдотест (промежуточный, шаг 2 не сделан)

**Итог шага 1:** колебаний середины стакана Gate фьюч вокруг линии DEX (Solana) много — но это *верхняя оценка*: линия DEX строится по последнему свопу (шумная, у тонких пулов скачет на 1 % сама), исполнимость лимитками не проверена. Деньги по ёршику здесь не посчитаны — только частота.

- **Метод.** Сетка 10 с; DEX — последний своп в корзине (своп ≥ 5 $, выброс ±10 % от медианы ±30 соседей, заполнение вперёд ≤ 60 с); Gate — середина BBO из стакана TK-379 (`/data/tk0380/bbo`). d = mid/DEX − 1. «Размах» = полный ход d от ≤ −k до ≥ +k или обратно, k = 0,2 / 0,5 / 1 %. Считались только корзины, где есть обе цены. Скрипт `tools/compute/tk385-yorsh1.py`, таблица `docs/findings/tk385-yorsh-step1-2026-10-24.csv` (по монете: часы с обеими ценами, медианный спред, размахи в час и по суткам, доля времени вне ±k).
- **Комиссия мейкера Gate фьюч:** публичный `GET /futures/usdt/contracts/{c}` отдаёт `maker_fee_rate = −0,0001` (−0,01 %, ребейт), `taker_fee_rate = 0,00075`. Это базовая ставка контракта; персональную (VIP/реферал) без ключа не проверить.
- **Охват.** Только Solana-монеты с готовыми свопами в USD (`solout/swaps-usd.csv`) и BBO: 35 монет. Часов с обеими ценами мало: 6–34 из 192 (редкие свопы + ffill 60 с). Не покрыты: CLAUDIA, FONE, PAID, STAMP, KIMCHI (нет строк в выходе — свопов/BBO не хватило или не скачаны), GT (Ethereum), LAPTOP (Base), SUE (BSC) — EVM-цену нужно подтянуть из `/data/tk0380/sqd/<сеть>-swaps` (шаг 2). Тяжеловесы — как есть в Solana-наборе (USDC, STRK, INJ, PENGU…), не сводились отдельно.

## Числа, которые нельзя читать буквально
- У всех пяти спред Gate 55–267 бп сопоставим с шириной 2k (40/100/200 бп): лимитки на DEX±k стоят *внутри* спреда или рядом с ним — исполнение зависит от очереди, шаг 2.
- Доля времени вне ±0,5 % 70–80 % и MAD отклонения 80–140 бп говорят, что разброс «Gate − DEX» часто больше самого k: часть размахов — шум линии DEX (одиночные свопы), а не движение Gate. AGENCY: стабильное смещение +127 бп (линия смещена, размахи вокруг неё не равны размахам вокруг DEX).
- Акции (HIMS, BABA…) дают сотни размахов/ч из-за расхождения часов торгов — отдельно не разбирались.
- Нет: поправки на неблагоприятный отбор, очереди, учёта «сделка Gate прошла через нашу цену», лимита лотов, выхода по T. Это шаг 2.
