## 5. Как читать сводку

Каталог `~/xdl9/c2/window/`:

- `summary.txt` — одной сводкой: строки основного набора (V1, V2: сделки, активы, `y_d` [t; бутстреп], Холм на `M_окно` = 2, чистая на сделку, метка, метки К-а/К-г/A8/A3b), «испытаний на окне всего», затем **описательные строки «с Gate»** (вне `M_окно`, без Холма и статусов), итоговая строка «основной набор + описательные».
- `class_status.csv` — статус вариантов по R3.3 (`confirmed`, условия 1–3, Холм по t и по бутстрепу, метка). Метка «подтверждено на окне» — статистический статус заранее названной гипотезы, **не** оценка исполнимой торговли.
- `variants.json` — все числа вариантов (ряд `y_d`, интервалы, контроли К-а…К-г, A8, A3b, срезы, хвост); `daily_y.csv` — суточные ряды (закрытые + MTM); `slices.csv`, `cells_table.csv`, `a8.csv`, `a3b_window.csv`, `w2_window.csv` — описательные таблицы.
- `trials_total.json` (основной набор) и `trials_grand.json` (основной + описательные Gate): число испытаний по группам и ожидаемое число ложных срабатываний.
- `gate/` — блок «с Gate»: `gate_lines.csv`, `split_gate.csv` (пары с ногой Gate отдельно от пар 8 бирж), `variants.json`, `summary_gate.txt`, `trials_gate.json`; сетки `gate/grid_V1`, `gate/grid_V2` (сделки в `trades.csv`).
- `grid_V1/`, `grid_V2/` — сетки основного набора (таблицы, сделки); `run_meta.json` — время, освобождённые массивы, блок Gate; `preflight.json`; `logs/` — `df/free` до и после, `resources.csv`, `run.log`; `SHA256.txt`.
- Промежуточные массивы (кэш рядов `work/`, боковые панели оборота `turn/`) раннер удаляет после прогона (`--keep-work` оставляет).

Слов «стоит / не стоит торговать» сводка не содержит; число испытаний на одних и тех же сутках печатается рядом с результатом.
