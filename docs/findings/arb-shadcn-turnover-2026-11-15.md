# Вкладка «Арбитраж»: макет shadcn + тёмная тема + оборот за сутки — 15.11.2026

Слова владельца: «дизайн арбитраж сайта сделаем этот shadcn + темная тема + надо добавить оборот по каждой бирже за сутки». Макет — на живой вкладке не выложен (ждёт «да» владельца).

## Что сделано
- **Макет** `Downloads/alpha-arb-shadcn-mockup.html` (3,5 МБ, один файл, открывается без сети) + `alpha-arb-shadcn-mockup-table.png`, `-chart.png`. Данные — снимок живой вкладки srv (`/data/arb-tab/live`, окно 14.11 17:14 → 15.11 17:14 GMT+4, 1975 пар), подмена только `fetch`.
- **Страница** `tools/collector_health/page-shadcn.html` — копия боевой `page.html` (выложенной 8088/8089, без прототипа «разрыв сейчас / от нуля / полоса мин…макс») с новым стилем и оборотом. Логика графика не менялась, только цвета (из токенов).
- **Выбор: чистый CSS, не React.** Страница — статический HTML на `serve.py` (стандартная библиотека), JS ~400 строк с виртуализацией строк и canvas-графиком; React + Tailwind + сборка дали бы тот же вид, но заменили бы весь код и добавили сборку на srv. Взяты токены shadcn (zinc, dark, `--radius .5rem`; Card, Table, Tabs, ToggleGroup/Toggle, Popover) и шрифт Inter (вшит, кириллица + латиница). Если владелец захочет настоящий React-проект — отдельная задача.
- **Оборот в таблице:** группа колонок «оборот за сутки, $ млн» — «1-я биржа» / «2-я биржа» пары строки (оборот этой монеты на каждой из двух бирж, окно = окно `arb.json`, 24 ч); обе колонки сортируются. Карточки оборота по биржам убраны по слову владельца («зачем оборот по биржам выведен? … сноси»).
- Источник оборота — **наши записанные сделки** (`trade*.tsv.zst` сборщиков), не REST: $ = цена × количество × размер контракта (OKX: `ctVal` из пула), время сделки T = приём − lag − (E−T), окно [t0, t1). Счёт — `tools/arb_stats/turnover.py` (юнит `turnover-shadcn`, 4 ядра, nice 15, 3,5 мин на 55 файлов); сверка — `turnover_check.py`.

## Для выкладки (после «да»)
Бэкенд: `arb_live.py`/`arb_daemon.py` — оборот по минутам и символам (`turnover.py` в инкрементальном виде) → в строку `v: [$ 1-й, $ 2-й]`, в корень `arb.json` — `tot: {биржа: [$, монет, исключено топ, имена]}`; `serve.py` — отдача шрифтов `/fonts/inter-*.woff2` (в макете они вшиты); `page.html` ← `page-shadcn.html`. Прототип «разрыв сейчас / от нуля / полоса» (другой тред) к этому макету не подмешан — его цвета берутся из токенов `--sell`, `--buy`, `--grid`.
