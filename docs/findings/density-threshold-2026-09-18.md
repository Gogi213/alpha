# Порог плотности по данным: сила «×соседи» и деньги на уровне (В-61, 2026-09-18)

Владелец: «числа порога не мне называть — выяснить для каждой монеты индивидуально и, если
возможно, вывести агрегат общий для всех или большинства»; ожидаемая форма — «сила минимум
100/200/300/n %, денег на плотности минимум 1k/10k/100k/n; деньги — фильтр слабее силы».

## Данные и метод

- Касания **любого** уровня (`lob touches --h3-mode floor`, `k = 1.0`) по 94 сверенным монетам пула
  за сутки 2026-09-16 и 2026-09-17 на счётной машине (`/opt/alpha-compute/study/touches`, 1.7 ГБ,
  `tools/compute/touches-all.sh`). На касание: номинал уровня `цена × размер` (USD), **сила
  «×соседи»** на кадре старта касания — размер уровня к среднему размеру остальных уровней той же
  стороны в ±20 bps (новая ось `strength_w20_pct` в `touches`, окна 10/20/50 bps, коммит `9bc8602`),
  исход (`bounced` — уровень жив, цена ушла; `eaten` — касание кончилось смертью), markout.
- Критерий монеты, объявленный до счёта (`tools/compute/threshold-study.py`): **N\*** — наименьший
  порог из сетки $1k/10k/100k/1M, при котором касания «от N» отскакивают чаще базы монеты (доли по
  всем её касаниям) не меньше чем на 10 п.п. при n ≥ 30; **S\*** — то же по силе из 100/200/300/500/
  1000 %. Агрегат — для каждого общего порога и каждой пары «N и S»: сколько монет из 94 проходят
  критерий, сколько касаний в сутки на монету остаётся, доля отскока по всем касаниям всех монет.
- Это разведка на тех же двух сутках, не подтверждение; в `runs.csv` не пишется. Таблица по монетам —
  `threshold-study-2026-09-18.csv` (96 колонок: база, медиана и p90 номинала, N\*, S\*, хвосты по
  каждому порогу и каждой паре).

## Результат

База: доля отскока по всем 6.7 тыс. касаний в сутки на монету — **34.2 %**.

**Крест «сила × деньги»** (ячейка: монет прошло / 94 · касаний в сутки на монету · доля отскока):

| сила \ деньги | ≥ $1k | ≥ $10k | ≥ $100k | ≥ $1M |
|---|---|---|---|---|
| ≥ 100 % | 68 · 738/д · 52.3 % | 56 · 246/д · 53.8 % | 14 · 11.5/д · 59.9 % | 0 · 0.2/д · 94 % |
| ≥ 200 % | 62 · 309/д · 55.6 % | 48 · 83/д · 53.0 % | 12 · 9.4/д · 61.8 % | 0 |
| ≥ 300 % | 52 · 193/д · 57.9 % | 36 · 54/д · 55.0 % | 12 · 8.0/д · 64.9 % | 0 |
| ≥ 500 % | 44 · 117/д · 60.4 % | 28 · 36/д · 59.4 % | 11 · 6.0/д · 72.0 % | 0 |
| ≥ 1000 % | 37 · 63/д · 63.7 % | 23 · 20/д · 65.4 % | 8 · 4.9/д · 76.3 % | 0 |

По одному фильтру: деньги — `≥ $1k` 51/94, `≥ $10k` 54/94, `≥ $100k` 14/94 (остаётся 12 касаний в
сутки, у большинства монет n < 30); сила — `≥ 100 %` 65/94, `≥ 300 %` 52/94, `≥ 1000 %` 36/94.
По монетам: N\* есть у 74 из 94, медиана **$1k** (p90 $10k); S\* есть у 77 из 94, медиана **100 %**
(p90 200 %).

## Что это значит

1. **Форма, которую ждал владелец, подтвердилась: сила — основной фильтр, деньги — слабый пол.**
   Доля отскока растёт с силой монотонно (34 → 52 → 58 → 64 % при 100/300/1000 %), а деньги сверх
   $1k почти не добавляют (52 → 54 % при $1k → $10k на той же силе) и лишь режут число касаний;
   `$100k` практикующих оставляет 8–12 касаний в сутки на монету — сетке нечего считать.
2. **Общий порог для большинства существует**: `сила ≥ 300 % в ±20 bps` и `деньги ≥ $1k` проходят
   52 монеты из 94 при 193 касаниях в сутки на монету и 58 % отскока; `≥ 300 %` и `≥ $10k` —
   36 монет, 54 касания в сутки, 55 %. Монеты, не прошедшие критерий, в основном мелкие: у них
   хвост «от N» короче 30 касаний, а не хуже базы.
3. **Ограничение метода.** «Отскок» здесь — уровень пережил касание, это не прибыль: валидация
   круга показала `net` ≈ −комиссия при геометрии в тиках (`round-validation-2026-09-18.md` §2).
   Порог отбирает касания, у которых плотность держит, а даст ли это денег — решает только сетка
   на этих касаниях с формой, где стоп и тейк соизмеримы с издержками.

## Что запущено следом

Сетка форм на счётной машине за 2026-09-17 в режиме `both` с двумя точками креста: `$10k & 300 %`
(36 монет по критерию) и `$1k & 300 %` (52 монеты); один поток на прогон, два прогона рядом
(`tools/compute/run-grid.sh`, `THREADS=1`). Их `forms.csv`/`rounds.csv` — первый вход вердикта не по
шуму `k = 1.0`. Числа — в дополнение к этому файлу, когда досчитаются.
