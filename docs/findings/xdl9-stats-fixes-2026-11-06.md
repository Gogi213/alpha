## 1. M-04: тест размера и выбор интервала

Скрипт `tools/compute/statarb/size_test.py` (numpy), артефакт `docs/findings/xdl9-stats-fixes-2026-11-06-size.csv`. Нуль: среднее 0, суточные значения нормированы на σ = 1 (кроме разреженных). Доля случаев «нижняя граница 90 %-интервала > 0», **%**, 4000 повторов на ячейку (стандартная ошибка ≈ 0,34 п.п. при 5 %):

| сценарий нуля | n | перцентильный бутстреп | бутстреп-t | **t по блокам (df = n_эфф−1)** | t по суткам (справка) |
|---|---|---|---|---|---|
| нормальные сутки | 15 | 8,65 | 4,60 | **4,50** | 4,25 |
| нормальные сутки | 21 | 8,03 | 4,80 | **5,08** | 4,88 |
| t(3) | 15 | 10,30 | 6,02 | **4,95** | 4,83 |
| t(3) | 21 | 8,90 | 6,43 | **4,80** | 4,83 |
| разреженные (35 % суток с исходом) | 15 | 9,50 | 5,55 | **2,93** | 3,87 |
| разреженные | 21 | 9,02 | 8,00 | **4,40** | 4,93 |
| AR(1) φ = 0,3 (чувствительность) | 15 | 11,75 | 6,15 | **6,10** | 10,42 |
| AR(1) φ = 0,3 | 21 | 11,38 | 6,58 | **6,78** | 11,05 |

Верхняя граница (для метки «минус», «верхняя < 0») ведёт себя симметрично: t по блокам 3,7–5,0 % на независимых сутках (см. csv).

**Критерий выбора:** порог из задания — доля ложных у нижней границы ≤ 6 % на сценариях независимых суток; из прошедших — тот, что ближе к 5 % и не требует случайности (вторая часть сформулирована после пробного прогона тех же сценариев на 4000 повторах — до финального, но не до первого взгляда на числа). Перцентильный не проходит (8,0–10,3 %); бутстреп-t не проходит (t(3), n = 21: 6,4 %; разреженные, n = 21: 8,0 %); t по суткам проходит независимые, но на AR(1) даёт 10–11 % (игнорирует зависимость); **t по блокам проходит все независимые (2,9–5,1 %) и ближе всех к 5 % на AR(1)** (6,1 и 6,8 %). Консервативным он остаётся только на 15 разреженных сутках (2,9 %) — цена в мощности, не в ложных.

**Что остаётся неисправленным.** При AR(1) φ = 0,3 размер 6,1–6,8 % — чуть выше 6 %. φ = 0,3 — допущение аудитора, данными не подтверждено; блок 3 и 5–7 блоков автокорреляцию такой силы не снимают. Это не исправлено и не заявляется исправленным; «ожидаемое число ложных» при зависимых сутках стоит писать как «≤ 0,07·M».

**Что реализовано.** `portfolio.block_t_interval(series, alpha, block=None) → (среднее, нижняя, верхняя, p, df)`: блоки подряд по ⌈n^{1/3}⌉ суток (число блоков = n_эфф = ⌈n/3⌉, последний может быть короче), дисперсия среднего по блокам (кластерная формула, при равных блоках = s²_блоков/n_эфф), границы среднее ± t_{0,95; df}·se, p — двусторонний по t. Квантили Стьюдента — на stdlib (`t_ppf`, бисекция по неполной бете; сверено со scipy до 3·10⁻¹⁰). Случайности нет: B и seed для интервала не нужны. `block_bootstrap` оставлен как был (справочный p для Холма, прежние тесты); боевой статус клетки читает только `block_t_interval`.

## 2. M-06: условия статуса

Модуль `tools/compute/statarb/cell_status.py` (`classify`), статусы как в P-37 §10.4: `candidate` / `indistinguishable` / `unclear` (+ метка `minus`).

| условие | было (P-37 §10.4) | стало |
|---|---|---|
| (а) | нижняя граница бутстреп-интервала клетки > 0 | нижняя граница `block_t_interval` клетки > 0 |
| (б) | плацебо-основное накрывает 0 или ниже | **нижняя граница 90 %-интервала разности «клетка − контроль» по суткам в паре > 0**; контроль — случайные входы того же числа сделок и распределения удержаний (§11.3), его суточный ряд передаёт вызывающий; контроля нет → (б) не выполнено, кандидатом клетка быть не может |
| (в) | без лучших 2 суток **и** без лучшей монеты | **без лучшей монеты** — фильтр; **без лучших 2 суток — справка** (`mean_without_best_days`), в статус не входит |
| (г), (д) | N ≥ 30 и ≥ 5 пар; MTM > 0 | без изменений |
| «не различимо» | интервал содержит 0 и МРЭ ≤ 12,6 | без изменений, кроме N = 0 (ниже) |

**Одно решение сверх текста протокола.** Клетка без единой сделки по букве §10.4 получает «не различимо» (интервал [0, 0], σ = 0, МРЭ = 0 ≤ 12,6) — мощность «достаточна» на пустом месте. В `classify` N = 0 даёт `unclear`; флаг `empty_unclear=False` возвращает буквальное чтение. Это не число порога, а логика: **назначено CEO-сессией без Судьи, подтвердить.**

**Цена условия (б) — мощность.** Измерено (`-joint.csv`, нормальные сутки, 4000 повторов, контроль — независимая копия того же нуля; ρ — корреляция клетки и контроля по суткам, **значения ρ = 0 и 0,5 — сетка чувствительности, не измерение**: общий рыночный фактор реальных клеток и контролей не оценивался):

| n | ρ | доля (а) при нуле | доля (б) при нуле | **(а)&(б) при нуле** | МРЭ (80 % мощности) только (а), в σ суток | МРЭ (а)&(б), в σ |
|---|---|---|---|---|---|---|
| 15 | 0 | 4,85 % | 5,08 % | **1,45 %** | 0,779 | 1,108 (×1,42) |
| 15 | 0,5 | 4,85 % | 5,10 % | **0,92 %** | 0,779 | 0,886 (×1,14) |
| 21 | 0 | 5,42 % | 4,73 % | **1,75 %** | 0,623 | 0,872 (×1,40) |
| 21 | 0,5 | 5,42 % | 4,57 % | **0,90 %** | 0,623 | 0,702 (×1,13) |

Читать: (б) снижает долю ложных кандидатов (при нуле и у клетки, и у контроля — до 0,9–1,75 %), но поднимает минимальный различимый эффект в 1,1–1,4 раза. Это обмен «мощность против дисциплины», как и писал скептик; решать Судье. Оговорка: если у контроля отрицательное среднее (комиссии), а у клетки среднее 0, (б) мягче, и ложных больше, чем 0,9–1,75 % — потолком остаётся доля (а). Поэтому «ожидаемое число ложных» `size·M` печатать с size из `size_test.py` (≈ 0,05 на независимых сутках), не с 0,0175.

Два «хвоста» (б)/(в), не закрытые этой правкой: в таблицу отчёта §15.1 по-прежнему нужны колонки случайных входов и случайных пар (§11.3–11.4) — их считает не этот модуль; плацебо оставить колонкой «проверка на утечку» (ожидается минус).
