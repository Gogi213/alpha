# TK-471: Q-3 по 1622 вариантам (Холм против C-X, Δ>0) — net при худшем и лучшем конце тарифа

Критерий Q-3 (P-TK461 §6/§11): «положительно после издержек» = нижняя граница net при худшем конце издержек > 0 по всем годам.
Ядро `tk471-pair-sim --legs 1` (fb5eed68) пишет сверх c,d,b,k,d2 суммы `bt` (все ноги тейкер — худший конец) и `bm` (все мейкер — лучший)
по тем же сделкам, что `b` (смесь по фазам); прогон 4 набора × 252 пары, 0 сбоев (заявка 1031033257673), агрегат `tools/compute/tk471_q3.py`.

- `tk471-q3-years-2026-10-31.csv` — ячейка × год (11 354 строки): `set` (sancho / bp / bp3 / s), ключ ячейки как в d2b, `year`, `n` (= сделок),
  `base` = sum(b)/sum(c), `net_worst` = sum(bt)/sum(c), `net_best` = sum(bm)/sum(c), bps на сделку.
- `tk471-q3-cells-2026-10-31.csv` — ячейка (1622): `years`, `n`, `net_worst/net_best/base` по всем годам, `worst_min_year/best_min_year/base_min_year` (минимум по годам),
  `q3_worst_all_years_pos` = (worst_min_year > 0). Прошли Q-3: sancho 2 из 345, bp 0 из 111, bp3 46 из 720, s 0 из 446 (всего 48 из 1622).
- Гейт: `base` из этого агрегата против `base` прежних `tk461-d2b-{sancho,bp,s}-years-2026-10-31.csv`: 11 354 из 11 354 строк найдены, n равны, макс. отн. расхождение 2,2e-12
  (текстом равны 6 684: порядок сумм float у `imap_unordered`, как в TK-470); bt ≤ b ≤ bm в каждой строке (net_worst ≤ base ≤ net_best).
  Гейт ядра (без `--legs` == tk469-pair-sim3 побайтно, `--legs` без двух столбцов == тому же) — `tools/compute/tk471-gate.sh`, лог тикета 06:33.
- Алгоритм: варианты — отдельный проход по 252 парам (дубль 25 мин) / суммы по ногам в ядре и повторный счёт только 1622 вариантов (~15 мин) / пересчёт из готового csv (невозможно: ног нет); выбран второй — единственный, дающий net-интервал без нового прохода по всем 163 923.
