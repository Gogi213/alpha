## Определения
- Цены пары (viking `xarb_base` §2), % : Sell = bid_A / ask_B − 1, Buy = ask_A / bid_B − 1 (Sell ≤ Buy). Середина m = (Sell + Buy) / 2, полуспред h = (Buy − Sell) / 2.
- **Качели размера N** — пересечение вверх (Sell впервые ≥ +N) и вниз (Buy впервые ≤ −N). Пересечение **подтверждено**, если условие выполняется на последнем событии ≤ t + L (цены берутся на t + L): L = **300 мс** (основной), 50 мс, 0 (сырое). Качели = два подряд подтверждённых пересечения противоположных сторон (повтор той же стороны не считается: позиция уже открыта); цепочка: закрытие на −N открывает зеркальный круг. Валовый итог круга = Sell_исп − Buy_исп ≥ 2N. Качели относятся ко времени подтверждения второго пересечения. N = 0,1 / 0,2 / 0,3 / 0,5 / 1 %.
- Комиссия круга (строки `arb-outlier-2026-11-15.md`): 4 тейкера 4 × 0,0315 = **0,126 %**; мейкер + хедж — закрытие тейкером **0,1071 %**, закрытие мейкером **0,0882 %** (тариф владельца −10 %). Чистый итог в таблицах = медиана валового − комиссия по этим строкам (не симуляция мейкерских заявок).
- Проверка детектора: тест против эталона на случайных рядах (пропуски, L = 0 / 50 / 300) и ручной пример; на реальной паре SOPH Binance/OKX (N = 0,5 %) валовый итог каждой из первых 4 качелей совпал с пересчётом Sell/Buy на t + 300 мс из сырых кусков.

## Метод (что и почему)
1. **Поток качелей** на событиях (мс) по паре и N — без окон.
2. **Процесс возврата к среднему**: на минутной сетке m — AR(1) (μ, σ, φ → полураспад) и AR(2); остатки — Льюнг–Бокс (10 лагов); на сетке 1 с — автокорреляция 16 лагов 1 с … 6 ч: полураспад по масштабу Δ (у OU один и тот же), одна против двух экспонент. Частота качелей по OU: 2 / (T_вверх + T_вниз), средние времена первого прохода между барьерами середины ±(N + h) (формула проверена имитацией, отклонение ≤ 12 %). **После замечаний проверяющего OU/AR(1) — только описание с оговоркой (п. 6 метода): полураспад не свойство процесса; в прогнозе OU не используется.**
3. **Режимы — BOCPD (байесовский онлайн-поиск смен, Adams–MacKay)** с авторегрессией внутри режима (сопряжённая Normal–Inverse-Gamma, t-предсказание), вероятность смены выбрана по правдоподобию данных. Почему не PELT: PELT оптимизирует по всему ряду (смотрит и назад, и вперёд) — «режим на момент t» из него подглядывание; BOCPD на каждом шаге отдаёт длину текущего режима только по данным ≤ t — это и «возраст режима» для таблицы, и честная проверка вне выборки. Авторегрессия нужна, потому что середина автокоррелирована (ρ за 1 мин 0,2…1): независимая модель видела бы «смену среднего» в каждом медленном колебании. Реализация сверена с перебором всех разбиений (тест, точное совпадение логарифма правдоподобия). Второй BOCPD — на интервалах между качелями (Gamma–Exponential): режимы потока.
4. **Регулярность**: CV интервалов между качелями (1 — пуассоновский поток, ≪ 1 — ритмичный).
5. **Вне выборки — разведка** (прежний прогон): точки отсчёта t каждые 30 мин (с 8-го часа окна); предикторы по данным ≤ t, исход — реальные качели после t. Плацебо: перетасовка прогнозов между парами; исход из другого момента той же пары (сдвиг ≥ 12 ч); фаз-рандомизованный ряд (тот же спектр, нет режимов) через тот же BOCPD + OU. Гиперпараметры (λ) подобраны по всему окну — таблицы помечены «разведка».
6. **Насыщение дисперсии до любой подгонки** (замечание 1, `swings_scale.py` → `scale.md`): структурная функция D(τ), дисперсия в окнах σ²(L), наклон D в логарифмах (2H), отношение дисперсий VR, полураспад AR(1) по непересекающимся блокам длины L (180 … всё окно) с контролями (OU 20 мин и блуждание + шум, по 150 имитаций).
7. **Уровень** (замечание 2): в качелях суточный уровень **не вычитается вообще** (Sell / Buy берутся от нуля); BOCPD по середине (только описание) нормирует по первым 120 мин окна — причинно; структурная функция — по приращениям; в прогнозе уровень — только из прошлого (все предикторы по данным ≤ t).
8. **Прогноз по преддекларации** (замечания 3–5, 7; `swings_oos2.py`): разработка 32,1 ч / тест 24 ч; гиперпараметры (λ потока качелей, задержка обнаружения режима) — только по разработке; режим в предикторе `reg` берётся, лишь если живёт дольше задержки + 3 интервала; PELT — только описание; исполнимые цены Sell / Buy, удержание L = 300 мс и 10 с; допуск N ≥ max(3 шага цены, G) и 2N > комиссии; базовые линии naive24 («круги вчера») и два плацебо (перетасовка пар; фаз-рандомизация AAFT по часовым счётчикам) с поправкой max-T по всей сетке.
9. **Ступень на 20:00 UTC** (замечание 6, `swings_hod.py` → `hod.md`): профиль числа качелей по часам суток UTC и ранг границы 20:00 среди всех границ окна.
