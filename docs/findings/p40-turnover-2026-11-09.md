# П-40: дневной оборот контрактов вселенной, 17.09–22.10.2026 (TK-513)

## Итог
- Оборот = дневная свеча REST (quote volume, USD; Hyperliquid: v·(H+L+C)/3), 36 суток, 4435 контрактов 7 бирж, считано на srv. Оборот контракта = **медиана по дням** (по умолчанию В-113).
- **Фильтр В-113 (Binance ≥ 700 тыс., Bybit ≥ 500 тыс., остальные без порога) не делает закачку возможной:** остаётся 871 актив на ≥2 биржах, 3 890 контрактов, из них не скачано 3 232 → **дельта 2 418 ГБ при свободных 211 ГБ — не влезает** (в 11,5 раза). Закачку не запускать.
- Порог срезает 91 контракт Binance и 365 Bybit (дельта к скачанному почти не меняется: 2 515 → 2 418 ГБ), потому что объём — Binance (924 ГБ), Aster (520, оборот почти нулевой, порога нет), Bitget (377), OKX (241), Gate (186), Bybit (152).
- Даже порог для докачки по всем биржам ≥ 50 млн USD/сутки (68 контрактов) = 324 ГБ > 211 (кривая ниже).

## Алгоритм
Варианты — дневные свечи REST по контракту (1 запрос на контракт, 36 точек) против суммирования минутных свечей (36×1440 точек) против оборота из скачанных данных (только 668 контрактов). Замер — 1 запрос/контракт, 7 потоков по бирже с паузой под лимит; полный счёт ≈ 17 мин. Выбран REST-день: полное покрытие вселенной, без скачивания, точное совпадение с «дневным оборотом биржи».
