## Итог

| вердикт до → после | сеток |

| мало данных → мало данных | 150 |

- **Сеток с DSR ≥ 0,95 было 22, стало 5.** Все пять — сентябрьские сетки на 7 сутках (1–3 формы). При T = 7 и V = 1/T
  достаточно SR0 ≈ 0 при N ≤ 3. Порог 10 суток они не проходят, итог — «мало данных». При N журнала у них DSR 0,004–0,63.
- **Прежние «почти проходы» опустились.** Пример — e-archive titrc 14 суток, btc1h: DSR 0,990 → 0,797, требуемый дневной
  Шарп при N = 3 форм ≈ 0,5–0,9. Главный вариант в августе (e-aug titrc-u500r btc4h, 31 сутки): DSR 0,946 → 0,465,
  дневной Шарп 0,137 при требуемых 0,47. Порядок совпадает с оценкой Судьи.
- **«Красный → мало данных» (33).** Все сетки — сентябрьские, с кругами в 3–9 сутках (13 сеток по 8 суток, 13 по 9,
  4 по 7, 3 по 3). Это прямое следствие порога K = 10: вердикт по одним суткам через часы (В-60) больше не выносится.
  Конфликт с В-60 CEO отдал владельцу.
- **«Мало данных → красный» (1):** `titrc-u500r-t-bid-btc1h-q1` (сентябрь, 10 суток с кругами). Прежде кругов было
  меньше 100, теперь порог суток пройден; нижняя граница ≤ 0.
- **Упали 52 сетки, одинаково у обоих бинарников:** `CSV error: record 606 … 35 fields, previous record 33`. Это
  склейки `titr-v1*` и соседние: в `merged/` сложены сутки из прогонов разных версий `bounce-grid` с разным числом
  колонок `forms.csv`. К T-26 отношения не имеют; вердикт по ним возможен только после пересклейки однородных суток.
- **DSR «—» после (31):** в 29 сетках на 15 сутках (`e-archive-2026-09-23-*` и соседние) у всех форм 0 сигналов,
