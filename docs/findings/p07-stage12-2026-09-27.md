## Правило А/Б/В

- **А (есть «проходит»)** — нет: ни одна клетка (включая базу и H9/H10) не даёт доли ≤ 0,10 в обоих месяцах с
  устойчивостью. Ближе всех H2 fr+1 (сентябрь EDGE) и H10 cap3 (сентябрь доля 0,097 ≤ 0,10 по точке, но август
  0,433 far от порога) — оба «на границе»/«не проходит», не «проходит».
- **Б (есть сдвигающая ось)** — нет: условие 1 (`август ≤ база − 0,10 = 0,321` **и** `сентябрь ≤ база = 0,148`
  по точке) не выполнено ни на одной клетке. Ближайшая по августу — H2 fr+1 (0,164, с запасом), но её сентябрь
  0,215 хуже базы (0,148) — сдвига нет. Остальные оси либо не двигают август ниже 0,321 (H6, H7, H9, H10), либо
  двигают август, но всегда ценой сентября (H2 fr+2/fr+3).
- **Решение: В — стоп.** Ступени 3–4 не читаются (уже соблюдено — печать не нарушена), дека уходит на архив
  (T-30). Сдвигающих осей нет.

**Пометки:**
- суждение по точке на двух месяцах, не статистика; каждая клетка — испытание в родословной Г-85 (В-124); на
  проверке у Судьи.
- ступень 3 — посчитано (запущено) ≥ 1 из 12 определённых клеток (`h3-25000` создана на диске, остальные в
  очереди по приоритету, дни не досчитаны) — запечатано, числа не читались; по решению В дальнейший счёт
  ступени 3 предлагается остановить (решение — Судье/CEO, не в этой сессии).
