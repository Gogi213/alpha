## 3. B. Безубыточность: доли К / С / Т и `p*`

`p* = n_ост / (n_ост − n_С)` — доля стопов, при которой средняя net нулевая при фактических средней net «остальных» (`n_ост`) и средней net стопа (`n_С`); это эквивалентно формуле задачи `(g_К − cost − fund)/(g_К + L_С)` при одинаковом фандинге и воспроизводит 3,2 % отчёта. Фактическая доля — Вильсон при эффективном n (кластерный бутстреп по активам, `n_eff = p(1−p)/Var`), `net` — интервал по активам. К = схождение, С = стоп (V1 / V2: S1 + S2 + S3; B3: S0 + S2 + S3), Т = дедлайн. Сделки, открытые на конце периода, исключены (V1 / V2: 0; B1 окно: 2).

## 5. D. Мощность

МРЭ — по структуре R3.3: `(t_{0,95; df} + z_{мощность}) · SD / √n_эфф` (90 %-интервал, нижняя граница > 0); «Холм-95» — то же при 95 %-границе (случай M_окно = 2); в bps на сделку делением на сделок на активную пару-сутки.
