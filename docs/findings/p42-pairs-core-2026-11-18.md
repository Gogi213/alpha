- AUC на отложенных сутках (CB3 / логистика / только оборот): лонг A 0,646 / 0,641 / 0,566, лонг B 0,637 / 0,635 / 0,566; шорт A 0,534 / 0,553 / 0,480, шорт B 0,533 / 0,552 / 0,479. У шорта CB3 хуже логистики и ниже его AUC вне выборки в разделе 3 (0,618 / 0,639).
- U1r (пул NATR ≥ 0,4 %) в верхней трети: 18 / 20 эпизодов у лонга, 22 / 22 у шорта, по 1 пробою на модель — `E1` на пуле не оценивается (k = 1).
- Справочный набор 48 признаков (`f48`, верхняя треть): лонг A +2,0 [−1,7; +6,1] (223 эпизода, 20 пробоев), лонг B +2,3 [−0,7; +5,8] (271, 23); шорт A −0,3 [−3,2; +3,1] (353, 30), шорт B −2,6 [−4,9; −0,1] (379, 23); AUC лонг A 0,591, B 0,599, шорт A 0,571, B 0,536.

Вывод: на отложенных сутках у лонга знак сохранился, величина не подтверждена (интервалы накрывают 0); у шорта сигнал не воспроизвёлся. Правила-кандидата для движка нет. Числа взяты из `holdout_tree.csv` / `holdout.json`, не пересчитывались.
