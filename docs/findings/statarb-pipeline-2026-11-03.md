- Порог symmap: первая версия (Kneedle на log10 dev) дала 0,195 % и отсекла 84 настоящие пары (dev 0,2…0,6 %, напр. BYD, MDT); заменено на линейную шкалу (0,625 %). Естественного разрыва нет до ≈3,4 %→7,7 %; порог чувствителен слабо: ≤0,5 % — 2336, ≤1 % — 2349, ≤2 % — 2352 пары из 2376. **Судье:** подтвердить выбор алгоритма порога.

- Баг раннера: маркер `.done` проверялся `-s` (пустой файл) → повторная проба; исправлено `-e` (73c57410), потеря времени ≈ 6 мин calc.

Алгоритм: варианты — порог symmap Kneedle на log10 dev / Kneedle на линейном dev / наибольший разрыв; замер — по 2376 кандидатам (log: 0,195 % отсекает 84 настоящих, линейный: 0,625 %, разрыв: ≈3,4…7,7 %); выбран — Kneedle линейный потому что тот же алгоритм, что у колена Gate (§4), и не режет массу настоящих совпадений. Формирование EG — сравнение Rust/numpy/stdlib на следующем шаге (на calc нет numpy).
