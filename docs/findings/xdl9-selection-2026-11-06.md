## 3. Отбор A1: эмпирический нуль (П-37 §7)

### 3.1 Метод (как в протоколе, с одним отступлением)

- Окно EG 02.10–14.10, 13 суток (18 720 минут), `form --window-days 13 --block-chunks 6` (блок 768 минут, половины 9 216 | 9 504) `--min-obs 300` `--alpha 1e9`. `alpha = 1e9` — не порог: `select_pairs` возвращает все пары, у которых есть тест на обеих половинах; порог берётся потом по нулю. Статистика пары `t = max(t_first, t_second)` в лучшем направлении (то же, что p = max(p1, p2) из `select.rs`, но без усечения p).
- Разбиения символов каталога на половины A и B: seed 37, один поток случайных чисел по отсортированным каталогам, 4 разбиения: 1–3 для порога, 4 — контрольное. Реальные пары — «внутри половины» хотя бы в одном из 1–3 (покрытие 87,4 % пар, 461 460 из 528 045). Нулевые пары — A x B, партнёр B сдвинут (n0 = 793 421 по трём разбиениям).
- `FDR(t) = (k0+1)/(n0+1) x M / max(1, R)`, `t*` — наименее строгий `t` с `FDR <= 0,10`. Каталог с `M < 10` или `n0 < 9` — «нет отбора» (8 из 31: aster-metal_energy, binance-eq_nonus, bybit-eq_nonus, bybit-metal_energy, kraken-eq_us, kraken-metal_energy, lighter-fx, lighter-metal_energy).

### 3.2 Отступление: сдвиг нуля на +1 торговый день вне крипты

- Причина измерена. Для недельных рынков (маска США, акции вне США, металлы, фиат) сдвиг партнёра на +1 календарные сутки переносит пн–пт на вт–сб: перекрытие с A в окне падает до 80 % наблюдений. Для пар с обычными случайными блужданиями статистика от числа наблюдений не зависит, а для пар с **стационарной** ногой (SGOV) она растёт как корень из n: реальные пары SGOV x акция имели t = −39,3 / −42,8 на половинах (n = 1 556 / 1 945), нулевые с календарным сдвигом −33,6 / −36,1 (n = 1 167 / 1 556), с торговым днём −38,9 / −41,2 (n = 1 556 / 1 945). Календарный нуль не поймал артефакт: 622 отобранных пары BingX акции США, из них 619 с |β| < 0,05 (25 сильнейших просмотрены — все с SGOV).
- Правило сдвига: крипта — +1 календарные сутки (24/7, перекрытие полное); остальные полосы — +1 торговый день (понедельник берёт пятницу, воскресенье и суббота — пятницу, иначе предыдущие сутки). Реализация — `sel_deck_prep.py formb`, проверка — numpy-эксперимент выше. Запись: `P-37-params` `null_shift_days`; в П-37 §17 предлагается: «F7: сдвиг нуля +1 торговый день вне крипты, причина — перекрытие 80 % при календарном сдвиге; назначено без Судьи, подтвердить».
- Остаточный артефакт: даже с торговым днём 8 пар BingX акции США (t* = −39,0, все с SGOV) проходят порог, а на контрольном разбиении 9 из 52 212 нулевых пар лежат ниже t* при ожидании 0. Клетка A1|bingx|eq_us не торгуется (W = 2, безубыточной точки нет), в волну не идёт; но для других каталогов такой защиты нет: это вывод про слабость самого теста, а не про этот каталог. В BingX есть и другие почти стационарные ноги (например, NCFXGBP2AUD, ADF ноги −9,8, FX).
