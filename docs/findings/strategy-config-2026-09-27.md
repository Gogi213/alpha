## Ответ владельцу: где стоп на Г-85

**Стоп на обоих вариантах Г-85 (а и б) — тот же, что у главного: `pct2`, то есть 2 % ниже цены входа**
(`src/commands/lob/backtest/plan.rs:180`, `StopForm::Pct(pct) => entry_tick - away * bps_to_ticks_ceil(pct * 100.0, entry_tick)`;
подтверждено протоколом П-07 §5, `docs/research/P-07-g85-titration.md:121-129`: «База (Г-85, H7, П-02): …стоп `pct2`…»).
У Г-85 меняется не стоп, а вход:
- **Г-85а** (`single@fr`, одна заявка) — `entry_tick` = цена единственной заявки на **P+1** (1 тик над стеной; на
  сигнале `approach` фронтрана не бывает, T-35, `plan.rs:124-134`, поправка в `P-07-g85-titration.md:13-16` — старое
  название «вход от фронтрана» неверно), и стоп считается на 2 % ниже **этой** цены.
- **Г-85б** (`ladder3x0.1..4.5w2`, лестница из 3) — `entry_tick` = **плановая средняя цена лестницы по долям**
  (0,1–4,5 bps над стеной, ближняя нога — половина объёма, `plan.rs:136-144`), стоп — 2 % ниже этой средней.

В обоих случаях расстояние (2 %) отсчитывается от **плановой** цены входа на момент построения плана; после
фактического исполнения (частичное заполнение лестницы, F4/В-78) стратегия сдвигает и стоп, и тейк на разницу между
плановой ценой и реальной VWAP входа, сохраняя то же расстояние в процентах (`src/lob/strategy.rs:104-127`,
`level_shift`; при полном исполнении по плановой цене сдвиг — ровно ноль тиков; строка «Пересчёт на VWAP» ниже).

**Г-85б пока без чисел** — счёт по П-07 не запускался (В-126 → В-127, `P-07-g85-titration.md:373-377`: «Счёт по
П-07 ещё не начинался: прогон базы не запускался»). В таблице ниже это отдельная колонка с пометкой

## Примечание — выключатель BTC и потолок позиций (общее для всех вариантов)

Заголовочные числа дашборда (счёт, KPI) для **всех** девяти вариантов таблицы считаются одним и тем же способом:
`max_pos=0, day_stop=0, kill=0, exclude="нет"` — без потолка позиций, без дневного стопа, без выключателя BTC, без
исключения монет (`tools/compute/titration-dashboard-merge.py:399-406`, `combo = dict(max_pos=0, day_stop=0.0,
kill=0.0, exclude_name="нет")`). Раздел «Защиты счёта» показывает те же варианты через одну и ту же лесенку шагов
для каждого варианта без исключения (`protection_steps`, там же, строки 388-398):
1. без защит;
2. **+ выключатель BTC −1,5 %/1 ч** (`kill=150.0`, за 1 ч) **и исключение набора монет «прокиды»** (`exclude_name="прокиды"`, фиксированный список монет-выбросов у `portfolio-sim.py --exclude-set`);
3. + потолок 3 позиции (`max_pos=3`) поверх шага 2.

То есть выключатель BTC и потолок позиций (как и всё «Риск» кроме позиции/депозита/плеча) — не параметр
стратегии/формы, а **отдельный слой счёта поверх готовых сделок**, одинаковый для главного и для всех гипотез
П-02/П-07 в этой таблице; `--streak-stop` (потолок на монету) в эту лесенку не входит вовсе (см. группу «Риск»).
