# Волатильные монеты сентября 2026 по свечам 1 м + дневной оборот (TK-412, 2026-10-26)

Вход: свечи 1 м сентября (TK-411, calc `/srv/alpha-sda/candles-1m`), окно 01.09–30.09 UTC; 35 закрытых Bybit linear и инструменты без данных исключены (делисты — слово владельца). Счёт: `tools/compute/tk412-volatility.py` (alsched prod, 15 яд., 1 мин), отчёт `tools/compute/tk412-report.py`. Полная таблица: `docs/findings/volatile-coins-sep-2026-10-26.csv` (все инструменты со свечами, сорт. по медианному дневному диапазону).

## Что посчитано (на инструмент = биржа × рынок)

- **Диапазон дня** = (max high − min low) / open первой свечи суток, UTC; даны медиана и максимум за сутки с данными.
- **σ дня** = √Σ ln(c_i/c_{i−1})² по закрытиям внутри суток (минуты без сделок строки не имеют → нулевая доходность; прыжок через дыру — одна доходность); медиана и макс.
- **Часов с ходом >5 % / >10 %** = часы, у которых (high−low)/open часа больше порога (из часов, где были сделки).
- **Диапазон месяца** = (max high − min low) / первый open; **диапазон часа макс**.
- **Оборот дня** = Σ quote_v за сутки: медиана и среднее по дням с данными. В USD для котировок USDT/USDC/USD/USD1/USDE/FDUSD/DAI/PYUSD/GUSD/RLUSD/USDG/USDD/TUSD (`котировка_usd=да`); пары к BTC/ETH/EUR/BRL/TRY/AED/PLN/SOL — оборот в единицах котировки (`нет`), в списки ниже не входят.
- `тип`: монета / плечевой токен (ABC3L, ABC5S, CSOP…2L) / датированный (поставочный фьюч «-ДДМММГГ»).

## Оговорки

- Gate-свечи собраны из сделок (TK-411): плохие принты (одиночные сделки далеко от рынка) попадают в high/low. Максимумы (диапазон дня/часа/месяца, σ макс) Gate ими загрязнены (напр. STONKS_USDT макс дня 63 603 %); медианы и счётчики часов устойчивее, но не чисты. Фильтр выбросов не вводился (порог был бы придуманным числом) — решение Судьи.
- Инструменты с малым `дней_с_данными` (листинг в середине месяца, пре-маркет) имеют медиану по нескольким дням: SI_USDT — 1 день, XDP — 2.
- Тонкие инструменты: большой диапазон при малом обороте — шум спреда/редких сделок, не ход рынка; оборот дан рядом, порога ликвидности нет (за Судьёй).
- Bybit `o` = close предыдущей минуты (конвенция API); Gate `o` — цена первой сделки минуты.
