## Как читать и что не следует

Правило п. 8: смотрим области (строки / столбцы сетки, соседи того же знака), а не лучшую клетку; все 63 + 8 клеток на сторону показаны. Эта сетка — описание «где деньги на какой ликвидности», не отбор: **испытаний для Холма 0**, «просмотрено» (контекст): 71 клетка на сторону на h775 и столько же на o566 (одни и те же сигналы базы; клетки перекрываются), плюс прежнее по обороту — TK-636 `TOV` (5 ступеней на сторону) и §13.21 (`t1h` ∈ {0,25…5}, `t24` ∈ {100; 500}).

**Число сделок и оборот — связаны, но не одно и то же** (Спирмен на кандидатах зачётных диапазонов, h775): `n24 ~ turn24h` 0,49 (лонг) / 0,60 (шорт), `n60 ~ turn1h` 0,55 / 0,65. Лонг, N24 ≥ 220 000 против клетки D = 25, H = 0,5: общих 155 сделок (Σ +237,0 $), только по числу сделок — 26 (Σ +57,3 $), только по обороту — 140 (Σ −69,8 $); против D = 50: общих 120 (Σ +148,8 $), только по числу сделок 61 (Σ +145,5 $), только по обороту 71 (Σ −52,0 $). У шорта сделки «только по обороту» в плюсе (+84,6 $ / +49,3 $ при сравнении с D = 25 / 50) — картина другая.

**Шумовой эталон (по сетке, из которой смотрели; `selection_bias.py`, 71 клетка на сторону; SE Шарпа — по формуле для 136 независимых суток, без поправки на автокорреляцию и толстые хвосты):** лонг N24 ≥ 220 000: Шарп 5,11, SE 1,67 — шум по 71 независимым испытаниям достигает 4,01, дефлированный Шарп 1,10 (t 0,66), «переживает 5 %»: нет. Шорт N24 ≥ 78 000: Шарп 4,90, SE 1,66 — шум 4,01, дефлированный 0,89 (t 0,54), «переживает 5 %»: нет. Клетки перекрываются (одни сигналы): независимых испытаний меньше 71, значит планка шума завышена, а SE занижен (допущения выше); прирост получен по построению отбора, **это кандидат для проверки вперёд, «найдено на этих данных»**, а не результат. Плато лонг N24: все четыре ступени (q20…q80) лучше базы по Шарпу (2,9…5,1 против 1,96) и по $ на сделку (0,73…1,63 против 0,45); по сумме выше базы три из четырёх (q80: +136 $).
