# TK-376 (G-016): расхождение цены пул DEX ↔ Bybit — проход 2 (fee пулов учтён) — предварительно

**Охват (CEO 23.10, обязательно):** срез = ETH + Base (полные 15–21.10) + BSC (полный 15–17.10, 18–21 частично), 477 монет Bybit, 367 пулов, 1 868 монето-суток. **Не покрыто:** Solana (36 монет, пулы TK-374 найдены, свопов нет), Sui, Arbitrum, Polygon, Avalanche, Optimism; пулы вне наших 367 у каждой монеты; доля оборота DEX монеты, покрытая нашими пулами (DexScreener vol24), в этом проходе **не посчитана**. Binance и Gate как CEX не подключены. Формулировка «нет альфы» неприменима — только «на этом срезе».

**Метод:** цена пула = последний своп, очищенный от fee по стороне (buy: /(1+f), sell: /(1−f); fee() on-chain для v3, v2 по умолчанию 25 бп pancake / 30 прочие — `tk376-pool-fees-2026-10-23.json`, 367 пулов, 0 отказов RPC); CEX = последняя сделка Bybit за секунду (не середина стакана), ffill. Эпизод: |gap| > max(fee, 5) бп; конец — возврат ≤ порога. net = остаток gap через задержку − taker Bybit (5,5 перп / 10 спот) − fee пула; **газ не учтён**. Скрипты: `tools/compute/tk376-{fees,gap,summary}.py`; эпизоды (888 тыс.) — calc `/data/tk0376/run3/episodes.csv`; страты — `tk376-gap-strata-2026-10-23.csv`.

## Что изменилось против прохода 1
Очистка от fee и порог = fee почти не изменили число эпизодов (889 → 888 тыс.) и не снизили величину (p50 gap 20 → 23 бп): расхождение — не артефакт fee в цене. Но оно неотделимо от **лага последней сделки Bybit** (60 % эпизодов закрывает ход CEX, 64 % открывает CEX).

## Ограничения (не снимать без шага)
1. CEX = последняя сделка, а не середина стакана — на тонких монетах «gap» частично = спред/устаревшая сделка. Нужен проход с серединой (`lob seconds`).
2. Цена по sqrtPrice/резервам после свопа — нет в данных (только событие свопа); «пул по последнему свопу» и «по резервам» не различены.
3. Газ и размер сделки (глубина пула) не учтены; net — оценка сверху.
4. Нет доли оборота DEX, покрытой пулами (требование CEO) и Solana/др. сетей.
5. Binance/Gate не подключены; BSC 18–21.10 неполный (дни с малым числом свопов вне счёта — MINSW).
6. Не проведён контроль «случайный момент» (gap в случайные секунды без условия эпизода) — без него хвосты нельзя считать особенностью эпизодов.
