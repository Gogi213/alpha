Выборка: 3584 ноги θ 10,48 % (TK-413), 85 инстр. (Gate фьюч/спот, Bybit linear/spot), сентябрь 2026 одним куском (по месяцам не делится). Источники: `…-literature-…md` (слой 1), `…-layer2-…md`, `…-sensitivity-…md`, `…-legs-…csv` (разметка), `…-aggr-…csv` (агрессоры, `tools/compute/tk414-aggr.py`, свод `tk414-aggr-sum.py`). Прогнозов нет.

**Разметка задним числом** (по следующей ноге) — только для отбора эпизодов; онлайн-признаки ниже — то, что видно к моменту t без будущего. Онлайн-признаки: из литературы [П/Н/Г] — гипотезы слоя 1; из данных — только измеренные в этой итерации (доля агрессивных покупок, оборот к норме, длительность, пауза).

## Что измерено по сделкам (доля агрессивных покупок, $; медиана ноги → медиана по инструментам при равном весе)

Окна: 1-я/2-я половина ноги (от старта до пика), «после» = 30 мин после пика (считается только там, где за пиком нет следующей ноги: 112 ног из 3584 — выводов по нему нет).

Находка: **доля агрессивных покупок на пампе ≈ 0,50 — почти не отличается от нейтральной**, на дампе 0,45–0,48 (чуть ниже). Различия между формами малы (≤ 0,03) и между половинами ноги ≤ 0,02. По $-доле как таковой старт/пик пампа не различается — гипотеза слоя 1 «пик = падение доли покупок» в таком виде **не подтвердилась** (доля целиком по ноге ≈ нейтральна). Не измерено: доля в коротких окнах у пика (последние минуты), дисбаланс по числу сделок, крупные принты — если нужно, отдельный счёт.

## Что не сделано / нужно решение

1. **Слой 3 (стаканы)** — не сделан: окно [−2 ч, конец] на выборку по форме, Gate orderbooks (есть на calc 15–22.10, сентябрь — проверить наличие, закачка `--kind net`) и Bybit архив стакана за сентябрь (наличие не проверено). Без него признаки стакана выше — гипотезы. **Наличие проверено 27.10 (HEAD с calc):** Gate фьюч и спот `download.gatedata.org/{futures_usdt,spot}/orderbooks/202609/<СИМ>-2026090112.csv.gz` — 200 (почасовые файлы); Bybit `quote-saver.bycsi.com/orderbook/linear/<СИМ>/<дата>_<СИМ>_ob200.data.zip` — 200 (сутки ≈180–200 МБ на BTC; ob500 — 404). Сентябрь доступен в обоих; на calc локально стаканов за сентябрь нет (только Gate 15–22.10).
2. OI/фандинг/ликвидации — не скачаны.
3. Оговорка: части форм (лестница, вынос, прямая) зависят от порогов — в стартовой стратегии опираться на устойчивые (ступень, пила, обобщённо «нога с оборотом ≫ нормы»).
