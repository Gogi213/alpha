## Что это значит (толкование, не вердикт)

- **Г-08** — эффект одного знака во всех сутках обоих месяцев почти без исключений, держится внутри монеты (+3,3/+3,2
  п.п.) и после стандартизации по возрасту/размеру; доли малы (+4,6…+5,2 п.п. доли `bounced`), это признак стены, не
  деньги: в деньгах не проверялся. Кандидат в фильтр входа следующим протоколом (П-03, метрика в $; В-117 задаёт
  операционализацию «сигнал в деньгах», принята `6702fee` при условиях).
- **Г-46** (27.09) — объединённая разность держится, но внутри монеты эффект ≈ 0: объединённый сдвиг почти целиком
  состав монет (KORUUSDT/SNXXUSDT), не момент касания. В фильтр входа оснований нет (см. таблицу и «По монетам»).
- **Г-28** — «сильная по сумме завал + фронтран» стена пробивается **чаще** во всех сутках обоих месяцев, эффект
  сильнее внутри монеты (−13,3/−13,2 п.п.), почти все монеты против гипотезы. В пуле это уже Г-134 (обратная Г-28); в
  прямой форме — «не повторять».
- **Г-105** (стоп перед стеной) — в обоих месяцах в минус, в сентябре значимо, август накрывает 0 → по R2 «не ясно»,
  а не «опровергнуто»; главный вариант (стоп 2 %) остаётся.
- Правило изменено после счёта — поэтому Г-28/Г-08/Г-46 выше — находки поиска на тех же месяцах, а не подтверждение
  (Судья `b39d9c5`); это N-я проверка на августе/сентябре (сквозной реестр ещё не построен — аудит правил,
  `docs/research/reviews/rules-audit-2026-09-27.md` п. 8, «заменить формулировку»).

## Ответы на разбор Судьи 27.09

Разбор — возврат сводки `docs/research/reviews/P-02-2026-09-26-summary.md` (коммит `8b99331`); два пункта по смыслу
гипотез, счёт/бутстреп/Холм признаны верными без замечаний.

1. **«Г-46 не может быть подтверждено — вторая часть H5 не операционализирована».** Сделано: строка Г-46 в
   таблице заменена на «H5 не подтверждаема» (не «подтверждено»/«кандидат»); в «Что это значит» и в итоге одной
   строкой явно разделены первая часть H5 (держится только объединённо, у монеты нет — по данным «По монетам») и
   вторая часть (сравнение с `flow_1h_lots` не операционализировано, вопрос заморожен для П-03). Числа не менялись.
2. **«Г-08: нужен интервал стандартизированной по возрасту/размеру разности — точечно все страты „+“, но для
   „подтверждено“ нужен интервал».** Сделано: интервал посчитан самим Судьёй в проверке по монетам
   (`docs/research/reviews/P-02-2026-09-27-by-coin.md`, раздел «Г-08, оговорка H4») по тем же суточным счётчикам без
   нового прохода — по возрасту +4,99 [+4,07; +6,02] август / +5,62 [+5,15; +6,29] сентябрь, по размеру +3,97

   таблице («оговорка H4 закрыта») и в «Что это значит». Число не пересчитывалось в этом файле — источник указан.
