## Источники и сборка

- **Bybit:** `/v5/market/kline interval=1`, категории linear и spot, по списку instruments-info (включая закрытые), 16 потоков
  с ограничителем ≤100 запр/с, бэкофф. 1-й прогон упал на retCode 10016 (сбой сервиса, 253 linear); повторён — готовое
  пропущено, второй прогон rc 0. `n_trades` у Bybit пуст (API не отдаёт); `v` — база, `quote_v` — turnover API.
- **Gate:** свечи API старше ≈7 суток не отдаёт, поэтому собраны из месячных архивов сделок
  `download.gatedata.org` (spot/deals/202609, futures_usdt/trades/202609): OHLCV по сделкам, минута без сделок
  **не выдумывалась** (строки нет). Фьюч `v = |size|·quanto_multiplier` (база), `quote_v = Σ v·цена`; спот `v` — база сделки.
  Закачка 6,7 ГБ gz (net, job 1026191102539, rc 0), сборка prod 15 ядер (job 1026192203141, rc 0, 26 мин). Сырые сделки
  не хранятся.
- Время в причинах — UTC.

## Охват: причины пропусков

- **Gate, нет архива (HTTP 404): 43 фьюч + 13 спот** — в csv с `минут_с_данными=0` (среди фьюч — акции AKAM/SBUX и т. п.,
  4 иероглифических имени; архива сделок нет, свечей API за сентябрь тоже нет).
- **Gate, «частично» (999 фьюч, 2166 спот):** нормальный случай — мало сделок: минуты без сделок внутри окна не заполнены
  (в csv число таких минут по инструменту). Полный месяц без дыр — только 19 фьюч и 3 спот (BTC_USDT и т. п.).
- **Bybit linear, вне окна — 1 032 инструмента:** закрыты/поставлены до 01.09 (`status Closed`), в сентябре свечей быть не может;
  в csv `минут_с_данными=0`, причина — даты запуска и закрытия.
- **Bybit linear, 35 закрытых контрактов, закрытие в сентябре** (ASPUSDT 05.09, датированные BTC/DOGE/… -04SEP26 и т. п.): API
  не отдаёт историю закрытых контрактов — свечей 0, причина в csv.
- **Bybit, частично (79 linear, 1 spot):** листинг позже 01.09 (дата запуска в причине) либо поставка/закрытие до 30.09.

## Что не сделано / оговорки

- Gate-свечи по сделкам, а не по API: `n_trades` — число сделок (есть), `quote_v` — сумма по сделкам; у Bybit `n_trades` нет.
  Сверки Gate-сборки с API-свечами последних 7 суток не делалось (окно сентября API недоступно).
- Контрольная сверка Bybit kline ↔ сделки не делалась (в задаче не требовалась).
