## Возврат Судьи: E-010 (ставки фандинга лежали на другой эпохе минут)

Проверка Судьи (`docs/research/reviews/tk482-delay-funding-2026-11-03.md`) нашла дефект: `funding_min` в загрузчике ставок считал минуты от unix-эпохи, а панели — от своей (`GRID0_MS`); ставки не попадали ни на одну минуту панели, фандинг не начислялся ни в одном прогоне (digest `funding-pp` совпадал с `cross`), D3 давал 0 сделок. **Прежнее объяснение «уровень ставки не перекрывает круг издержек» в этом отчёте было неверным** — ядро и референс видели одни и те же пустые ставки, поэтому дрейф 0 ничего не говорил о фандинге.

## Что сделано

- **(а) задержка ноги X** (`Params.delay_x`, CLI `--delay-x`): нога X входит по open минуты `fill_in + d`; если там нет open у всех компонент — ждёт ближайшей (`Counters::x_deferred`). Позиция (выход, `max_hold`) считается набранной с входа ноги X; фандинг ноги Y платится с её входа. Выход без задержки второй ноги — вне ТЗ, не делался. `d = 0` — прежнее поведение.
- **(б) вход по ставке D3** (`Rule::Funding { k, hold_payments }`, CLI `--funding-k`, `--hold-payments`): трейлинг-среднее `k` последних выплат ноги Y × `hold_payments` в bps номинала Y против круга издержек `round_trip_cost_bps` (комиссии входа и выхода по обеим ногам); сторона — где нога Y получает фандинг; выход — доход позиции перестал быть выше круга; `max_hold` действует. `k ≥ 1` обязателен, без выплат сделок нет.
- **(в) reference** — наивная реализация обоих режимов в `reference.rs`.

## Скорость (критерий «не хуже прежней», строк/с, ядро)

Первая сборка (`96dea169`) была на 0,87–0,91 от прежней (5 чередований: пары 0,903, кросс 0,881, фандинг перп↔перп 0,868) — красно. ## Алгоритм

Алгоритм: варианты — (1) ветка `if delay_x > 0 / rule == Funding` внутри общего `run_pair` (первая сборка), (2) мономорфизации `run_pair` по `delay_x`/правилу через `run_pair_impl<S, const DELAY, const FUND>`, умолчание = прежний путь без лишнего состояния; замер — `speed-prev.sh`, 5–7 чередований: (1) 0,87–0,91 прежней, (2) 1,027–1,090; выбран — (2), потому что единственный проходит критерий «не хуже прежней» при тех же хешах `d = 0`.
