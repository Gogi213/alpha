## Источники и сборка

- **Bybit linear + spot:** `/v5/market/kline interval=1` теми же скриптом и режимом, что в сентябре (`tk411-bybit-kline.py`,
  окно параметром, ≤100 запр/с), по instruments-info (включая закрытые). `n_trades` пуст (API не отдаёт).
- **Bybit закрытые linear (36):** API свечей закрытых контрактов не отдаёт — собраны из архива сделок
  `public.bybit.com/trading` (недельные поставочные BTC/ETH/DOGE/… -07/14/21/28AUG26 и др.); `n_trades` = число сделок.
  Минута без сделок не выдумывалась. В охвате — пометка «собрано из архива сделок».
- **Gate futures_usdt + spot:** API свечей старше ≈7 суток не отдаёт, поэтому собраны из месячных архивов сделок
  `download.gatedata.org` (`…/202608`): OHLCV по сделкам, минута без сделок **не выдумывалась** (строки нет), `v`/`quote_v` как
  в сентябре. Закачка `--kind net` (job …3940), сборка prod 15 ядер (job …5267), сырьё не хранится.
- `/data/tk420` содержит стаканы и сделки, не свечи — повторно ничего не качалось.
- Время в причинах — UTC.
