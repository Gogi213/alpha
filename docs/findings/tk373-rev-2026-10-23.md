# TK-373 / P-25: обратный тест «Bybit ведёт DEX» — 23.10.2026

**Итог.** После резкого хода середины Bybit (≥ q95 своей монеты) цена пула DEX идёт вслед, а сам Bybit дальше почти не идёт: net-ход пула по стороне события +1,6 / +3,9 / +6,6 бп на 10 / 60 / 300 с (W=10 с; SE 0,3 / 0,5 / 1,0), Bybit дальше +0,3 / +0,3 / −0,2 бп (в пределах шума). Поток пула по стороне хода — +0,26 / +0,23 / +0,15 доли объёма. Направление: **Bybit → DEX**, не наоборот. Это согласуется с контролем предхода (моментума Bybit за DEX нет): знак Snet в L/F не говорит «DEX ведёт Bybit».

**Метод.** `tools/compute/tk373-rev.py` (движок tk369-run2: середина Bybit, свопы USD-слоя, окно счёта 16–21.10, 77 монет). Событие: |ход середины за W| ≥ q95 |хода| той же монеты по 15.10 (порог фиксирован до окна, causal), W ∈ {10, 60} с, не чаще раза в 60 с. На t0 = ts+1: imb = s·(buy−sell)/(buy+sell) в USD по пулам монеты, dpx = s·ход цены последнего свопа, by = s·ход Bybit дальше. Контроль — те же величины в t±3600 с (та же сторона s), net = M − среднее контролей. SE — кластеры монето-сутки. Агрегация `tk373-revagg.py`; таблица `tk373-rev-2026-10-23.csv`, `-top.txt`. Счёт на calc ≈ 1 мин (юнит `tk373-rev`).

## Ограничения
- dpx считается от последнего свопа до t0: пул, давно не торговавшийся, имеет устаревшую цену — часть «догона» механическая (первый своп после хода). Это не доходность, а доказательство направления; торговать «догон» на DEX нельзя без исполнения на DEX.
- Предпоток DEX >0 (до события пул уже торговали по стороне хода): события в одной секунде/окне W не разведены — часть хода DEX идёт одновременно с Bybit (общая причина). Разрешить можно только по блокам (интервал блока ≥ 1–12 с).
- Одна неделя, 77 монет, месяцев нет; эффективное N ≈ число монето-суток (402), не событий. Контроль, BH не применялся.
