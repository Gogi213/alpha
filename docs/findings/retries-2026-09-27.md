прошлого подхода, число подходов до 45 мин / номер среди торгуемых, глубина BTC и минута эпизода, семейство
волатильности — все корзины заданы до счёта, границы терциля BTC — по августу).

**disarm_reason предыдущего (уже закрытого) подхода → исход:** touch → «отскок» (23 случая), price_left →
«ушла» (409), level_death → «пробой» (0 случаев — по построению: стена, чей предыдущий подход кончился
гибелью уровня, не доживает до следующего подхода; вырожденность проверена, не замолчана).

**Главная таблица — N внутри корзины возраста стены** (45–60 мин / 1–2 ч / 2–4 ч / 4 ч+, полные клетки —
`approach-slices-summary.md` §1): пул-разница «2+ против 1-го», взвешенная по n корзин (упрощённый суррогат
Мантель-Хензеля, не полные веса) — **август: Δ доли в плюс +0,02, Δ bps/сделку −2** (внутри шума, знак и
величина малы); **сентябрь: Δ доли в плюс −0,15, Δ bps/сделку −20** (2+ хуже 1-го, но n2+ в старших корзинах
2–4ч/4ч+ единицы — не читать как эффект). Знак не совпадает между месяцами → это шум/малые корзины, не
устойчивый эффект. Сырая строка по N (без учёта возраста) — в файле, помечена «смешано с возрастом».
