# TK-385 ёршик — контроли Судьи (y9), Q и ZEC, 2026-10-24

Артефакт: `tk385-yorsh-controls-2026-10-24.csv` (54 ячейки = 2 монеты × 9 сценариев × k 0,2/0,5/1 %; T=300 с, форма sym, очередь L2 включена, тариф Gate 7,5/−1 бп). Счёт: alsched job 1024193512285 (15 ядер), скрипт `tools/compute/tk385-yorsh7.py`, y9.done. Сутки: Q 7, ZEC 6–7. Число испытаний этого шага — 54 (в общий счёт перебора ёршика добавить).

## Итог
- **Нуль у Q положительный.** Если сдвинуть линию DEX на ±1/3/6 ч (связь с реальным DEX разорвана), Q всё равно даёт +25…+48 бп/круг при k=0,2–1 %. То есть значимая часть «края» Q — свойство самой цены Gate (колебание вокруг любой медленной линии + ребейт), а не схождения к DEX.
- **Прирост над нулём у Q есть при k ≥ 0,5 %, и он падает с лагом.** Разница база − нуль (лучший нуль по |сдвигу|): k=0,2 % ≈ −5…+5 (нет); k=0,5 % ≈ +25…+50; k=1 % ≈ +115…+130 бп/круг. Лаг DEX 10 с срезает k=1 % с 157 до 59, k=0,5 % с 74 до 47; лаг 2 с — почти без потерь (135 / 72). Для живого исполнения край держится только при задержке линии ≤ ~2–5 с.
- **Лот = медиана принта (lot1):** почти не меняет (k=1: 149 vs 157; k=0,5: 71 vs 74) — сквозной проход одним крупным принтом не движет результат (big_share ≤ 1,3 %, nobig ≈ база).
- **Выходы раздельно (Q, база):** лимитные круги + (k=0,2: +64 бп, 2771; k=0,5: +146, 1013; k=1: +264, 410), рыночные принудительные − (−80, −72, −2; 799/502/276 штук). При k=0,2–0,5 % плюс — только от лимитных кругов, а 22–33 % выходов по рынку теряют ~70–80 бп; при k=1 % принуд. выходы ≈ 0. Число лимитных кругов при k=1 % — 410 за 7 сут (~58/сут) — малая ёмкость.
- **Сутки:** Q base 7/7 положительных при всех k; в нулях 5–7 из 7 — нуль тоже «по суткам» положителен, поэтому 7/7 само по себе края DEX не доказывает.
- **ZEC — края нет.** base +5 бп/круг (k=0,2, 159 кругов, 5/7 суток), при лаге 10 с −0,9, при сдвиге −3…+3; k=0,5 и 1 % — 19 и 2 круга (выборка пуста). Закрыто как отрицательный контроль.

## Что НЕ покрыто
- Q — одна монета, 7 суток (одна неделя); вывод про Q не переносится на другие монеты (остальные монеты — следующий прод-проход).
- Положительный нуль Q требует объяснения: либо mean-reversion цены Gate на тонком рынке (тогда край не от DEX, и нужен нуль «случайная линия» вместо сдвига), либо артефакт модели заполнения (лимит «прошёл» при касании сделкой). Не проверено: нуль по скользящей средней Gate вместо DEX; чувствительность к очереди (queue=1 только).
- Лаг проверен как задержка линии DEX (2/5/10 с), а не как задержка постановки/отмены ордера на Gate.
- Неблагоприятный отбор: подтверждено только через nobig и рыночные выходы; отдельной оценки «ход DEX против позиции после заполнения» нет.
