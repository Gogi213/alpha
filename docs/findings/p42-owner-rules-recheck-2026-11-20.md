## Оговорки

- Правила приняты в §13.11–§13.15 по 60 суткам 15.09–13.11 (566/544 монеты); эти сутки внутри 136-суточного окна. Исход «правило полезно» (б) не получен ни разу; знак «полезно» у `pk` и `ALL0` — **частично на данных принятия правила**.
- `fh8` и `pb0` у шорта — «найдено на этих данных», в пределах шума перебора; решение — только проверкой вперёд (α — по слову координатора 20.11 только из долей `L_base` / `S_mk1`; эта задача ничего не замораживает).
- Широкие MDE свежего уровня — следствие того, что клетка меняет 40–80 % сделок: это разница двух почти независимых портфелей на 136 сутках. Сужается только длиной окна (вперёд), не повторным счётом.
