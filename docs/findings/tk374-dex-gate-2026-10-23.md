# TK-374: DEX ↔ Gate, монеты Gate без Bybit — 7 суток + net (15–21.10.2026)

**Итог:** на 7 сутках 3 из 72 клеток проходят правило TK-364 шага 3 (все — rev/ethereum, ход Gate ≥ q95 → пул догоняет: T10 h600 +20,5 бп lo +3,0; T60 h60 +19,0 lo +2,0; T60 h600 +23,5 lo +2,5; d13 5–6 из 7 суток, монет с плюсом 10–11, доля макс. монеты 0,20–0,27).
**Но net после комиссий отрицателен во всех 48 клетках**: лучшая −21,6 бп (rev, X 100, T10, h600), в клетках-кандидатах −29…−33 бп. Причина: комиссия пула (20 из 32 пулов — 0,30 %, 8 — 1 %) + тейкер Gate спот 0,2 %; одним входом/выходом платится 25–50 бп при догоне 20–30. Вывод: **Gate ведёт, но торговать это нельзя**; в плюс по net выходят только монета-клетки OFC (Base, fee 0,05 %), AMP (ETH, 0,30 %), WELL — 19 из 584, концентрация в двух монетах (эффект монет, не рынка).

## Числа
- Свод: `tk374-dex-gate-7d-agg-2026-10-23.md/.csv` (все 7 суток 15–21.10, ETH 13 монет в rev / 12 в fwd, Base 6; Бонферрони 54, SE кластерный по монето-суткам, те же контроли, что TK-364). Кандидатов 3/72. fwd (DEX → Gate) кандидатов нет.
- Net: `tk374-net-cells-2026-10-23.csv` (уровень клетки, взвешено по событиям), `tk374-net-coins-2026-10-23.csv` (584 монета-клетки, n ≥ 30), fee пулов `tk374-pool-fees-2026-10-23.json` (on-chain `fee()` по 32 пулам: 30 бп ×20, 100 ×8, 5 ×2, 80,5 ×1, 1 ×1). Формула: rev net = diff − fee_пула − taker_Gate(20 бп); fwd net = diff − 2·taker_Gate. Газ не учтён (улучшил бы только в пользу вывода «нет»).
- Тейкер Gate: API `spot/currency_pairs` fee 0,2 % (VIP0, 23.10 13:10 GMT+4); фьюч 0,075 % — для фьюч-ноги net был бы на ~12 бп лучше, но у этих монет сделок фьюча в банке нет (все 31 — Gate спот).
- Скрипты: `tools/compute/tk374-{bank,agg,fee,usd,net2}.py`; сырьё calc `/data/tk0374/bank/raw.json`.

## Охват и ограничения
- ETH 15–20.10 по всем 24 пулам; **21.10 ETH не докачан** (HTTP 408, 12 из 24 пулов без суток) — неполные сутки входят в свод как есть; Base 15,16,18–21.10 (8 пулов; 17.10 нет). BSC — нет данных (429, решение Судьи `reviews/tk374-overseer-bsc-2026-10-23.md`).
- **Solana не считалась**: публичный RPC `api.mainnet-beta.solana.com` держит ≈ 1 вызов/с (8 потоков → 92 % 429, getTransaction 1,2 с на своп; `tk364-rpc-probe-base-solana-2026-10-23.md`), 36 пулов × 7 суток за один запуск не качаются. Вывод ограничен ≈ 18 EVM-монетами (ETH 13 + Base 6).
- rev-отклик включает «догон устаревшей цены пула» (пул не обновляется без свопа) — это разрыв цен, а не предсказание; на net это не влияет (он и так отрицателен).
- 72 клетки, Бонферрони 54 как в TK-364; эфф. N — по монето-суткам ≈ 80–90 кластеров на клетку.

## Что дальше
Закрыть DEX↔Gate по ETH/Base как «ведёт Gate, net < 0 (−21…−33 бп)». Дополнительно возможна только дешёвая нога — пул 0,01–0,05 % + фьюч Gate 0,075 % (net ≈ diff − 12 бп): нужны монеты с таким пулом (их 4 из 32: OFC и ещё 3) — малая выборка, решение Судьи.
