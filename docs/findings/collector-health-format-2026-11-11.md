# Формат health.json коллекторов G-022 (TK-529, для согласования с TK-527)

Один формат на все шесть бирж. Коллектор раз в 10 с (A8: кадр на диске не реже 10 с) пишет `/data/health/<биржа>.json`
атомарно: во временный файл рядом, затем `mv`. Страница читает все `*.json` каталога; новая биржа = новый файл, страница не правится.

```json
{
  "schema": 1,
  "exchange": "binance",
  "ts_ms": 1762885000000,
  "started_ms": 1762800000000,
  "symbols": {"subscribed": 0, "with_data_1m": 0},
  "ws": {
    "connections": 0,
    "ping_ms": {"p50": 0, "max": 0},
    "timeouts_1h": 0, "timeouts_24h": 0,
    "reconnects_1h": 0, "reconnects_24h": 0
  },
  "lag_in_ms": {"p50": 0, "p99": 0, "window_s": 60},
  "lag_out_ms": {"p50": 0, "p99": 0, "window_s": 60},
  "last_frame_ms": 0,
  "last_write_ms": 0
}
```

Нули выше — места под значения, не измерения.

| поле | что | как считает коллектор |
|---|---|---|
| `ts_ms` | момент записи файла, unix мс | часы коллектора |
| `symbols.subscribed` | символов в подписке | размер пула на старте |
| `symbols.with_data_1m` | символов, по которым за последнюю минуту пришёл хоть один кадр | счётчик по символу |
| `ws.connections` | открытых соединений | — |
| `ws.ping_ms` | пинг WS: время между ping и pong, медиана и максимум за окно | ping/pong протокола биржи |
| `ws.timeouts_1h/24h` | число пауз без кадров на соединении дольше порога | порог — из замера тиков TK-527, не выдуман |
| `ws.reconnects_1h/24h` | закрытий соединения с повторным открытием | скользящие окна |
| `lag_in_ms` | лаг прихода: время приёма (local) − время биржи в кадре, p50 и p99 за окно `window_s` | на каждый кадр |
| `lag_out_ms` | лаг отдачи: запись кадра на диск − время приёма | на каждый кадр |
| `last_frame_ms` | время приёма последнего кадра любого символа | — |
| `last_write_ms` | время последней записи на диск | — |

Что не решено и кем:
- порог «таймаут» и порог устаревшего файла (красная точка) — числа, назначает Судья по замеру TK-527; страница берёт их из `thresholds.json` рядом, умолчания в коде нет;
- у бирж без времени события в кадре (если такие окажутся) `lag_in_ms` = `null`, страница показывает «—»;
- часы биржи и сервера могут расходиться — лаг прихода включает эту разницу; поправка (синхронизация NTP/запрос времени биржи) — решение TK-527.
