## Грабли (чтобы не наступить снова)

- В командах Bash-инструмента обратная косая вдвое «съедается» (`\\n` приходит как `\n`): литерал `\n` в Python-коде из heredoc писать через `chr(92) + "n"`.
- На ПК pandas сломан (numpy ABI): тесты и всё с pandas — только на srv; `hold_mkdoc.py` на ПК работает (stdlib).
- Файлы `.sh` на srv — только LF; `Write`/`Edit` на Windows дают CRLF для новых файлов — перед отправкой проверять `grep -c $'\r'`.
- Отправка кода на srv: `tar -C tools --exclude=__pycache__ -cf - arb_stats | ssh … 'tar -C /opt/arb-hold4/tools -xf -'`.
