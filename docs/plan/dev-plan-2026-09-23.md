## 2. Правила этапа

- **Точки — из данных.** Края корзин режима — квинтили оси по всем минутам «истории» (`titration-points.py`);
  к записи применяются как есть. Возраст — прежние точки ночных наборов (15/30/45/60/90/120 мин).
- **Корзина — испытание.** Титрование идёт с `--log-trials` (журнал считает корзины для DSR).
- **Чтение титрования — не вердикт.** Корзина «держится», если знак net совпал в обеих эпохах при n ≥ 20 в
  каждой (`titration-read.py`). Правило из корзин — только через предрегистрацию (G6) и новые сутки.
- **Контроль «рост рынка» при каждом чтении** (placebo, М19) — титрование режима особенно легко принять
  «рынок рос» за «стратегия работает».
- **Сторона раздельно** (владелец 20.09): лонг от бид-стены и шорт от аск-стены — разные наборы, разные выводы.
- Доклад владельцу — деньги и сделки, первой строкой итог (`.memory/index.md`, правило общения).
- Удаление данных на коллекторе — только по слову владельца (G0).
