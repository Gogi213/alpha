- Протокол «остались / сходятся» составлен исполнителем, без отдельного «ок» владельца (слова пришли через координатора).

- Окно конца — последняя запись минус 2 мин на момент разбора (сборщики идут дальше).
- Окно ПК: сервисные скрипты вне репо (`sx.sh` — ssh с `-i` и `UserKnownHostsFile`, `ship.sh` — tar кода на `/opt/arb-hold4`, перед отправкой привести CRLF → LF: на Windows Write/Edit дают CRLF, скрипты `.sh` с CRLF на srv ломаются).
