## Что титруем (каждый параметр — сетка вокруг базы)

1. Вход: отступ `e` (в т. ч. 0,15) и `e2`; вход 0,3 % / у уровня (TK-591).
2. Стоп: жёсткий `s`; NATR-стоп (`sn sg sr`); стоп за дальним краем зоны + k·NATR, k 0,5–1 (TK-591).
3. Безубыток / трейл: `bm`, `rr`, `tj`, безубыток за уровнем вместо точки входа.
4. Выходы: по времени без пробоя T мин после касания; при возврате за уровень (глубже f, t с) (TK-591).
5. Фильтры сетапа: `t_high`, `q`, `rf`, `natr_min`, ослабление пула.
6. Признаки, уже в движке (фильтры F): 15 клеток TK-595 (`maxmv1`, `tpm15` и др.), отсечки — квинтили.

Сетки — значения §13.21/§13.19. Каждая ось в §13.24 помечена: **упорядоченная** (со списком соседей; `natr_min` — упорядоченная) или **категориальная** (плато неприменимо, вместо него порог ≥ 2,5 SE). Расширение на край — внутри того же шага, до перехода к следующей группе, не в конце. Минимум сделок в месяц на клетку — записать; клетки, меняющие число сделок (как `natr_min=0.3`), сравниваются парно по тем же суткам.

## Порядок

1. **Шаг 0** — инвентарь, кэш, манифест; простые базы и C TK-595 на всём окне помесячно — уровень базы по месяцам, описательно.
2. **Координатный проход** от базы по группам в порядке стоп → выходы → вход → безубыток → фильтры → признаки. Правило принятия шага:
   - парная Δ $/сут. по всему окну ≥ 2 SE (блочный бутстреп по суткам, блок 4, число повторов — в §13.24);
   - знак Δ тот же не менее чем в 4 из 5 месяцев (июль, август, сентябрь, октябрь, 01–13.11);
   - плато (упорядоченные оси): оба соседа с Δ ≥ 0,5 Δ клетки; категориальные — ≥ 2,5 SE;
   - устойчивость: без 2 лучших суток и без 2 лучших монет Δ > 0;
   - граница фандинга не переворачивает шаг.
   Иначе параметр остаётся как в базе.
   Мощность (критик, по SE парной Δ TK-595 на августе 1,53 / 0,99 за 31 сут.): на 136 сут. SE ≈ 0,73 (лонг) / 0,47 (шорт) $/сут.; порог 2 SE = 1,46 / 0,94; 80 % мощности при истинной Δ ≈ 2,1 / 1,3 $/сут.; с условием 4/5 месяцев общая мощность ≈ 0,7. Все шаги, принятые в TK-595 (+0,25…+1,60), ниже порога — так задумано.
3. **Второй координатный проход** тем же правилом от результата первого: если меняется хоть одно принятое значение — «не сошлось», заморозка = база.
4. **Совместная проверка**: принятые параметры — сетка из 2 лучших значений каждого (2^k клеток); каждая клетка против базы по тому же правилу; итог — лучшая прошедшая, иначе результат координатного прохода.
5. **Проверка процедуры вперёд (walk-forward, расширяющееся окно)**: шаги 2–4 автоматом, без ручных решений: подбор на июле → проверка на августе; июль–август → сентябрь; июль–сентябрь → октябрь; июль–октябрь → 01–13.11. Правило знака по месяцам подбора: n = 1 — нет; n = 2 — оба; n = 3 — ≥ 2 из 3; n = 4 — ≥ 3 из 4; правила 2 SE / плато / устойчивость — как в шаге 2. Свёртка без принятых шагов даёт Δ ≡ 0 и считается.
   - Статистика: склеенный ряд парных суточных Δ по четырём месяцам проверки (~105 сут.), блочный бутстреп (блок 4), односторонне 5 %, m = 1 на сторону.
   - В отчёт — что выбрала процедура в каждой свёртке; если выборы по свёрткам расходятся, итоговая замороженная конфигурация не поддержана, даже при ΣΔ > 0.
   - «Месяц без одного» не делаем (смешивает прошлое и будущее).
6. **Заморозка** итоговой конфигурации стороны (шаги 2–4 на всём окне) до чтения вперёд.
7. **Чтение вперёд один раз: 17.11–30.11 (14 сут.)** — 14–16.11 уже прочитаны TK-595 (C и обе базы) и TK-592. Семейство m = 2 (лонг, шорт), Холм, вердикт по правилу §10. MDE (одност. 5 %, мощность 80 %): SE парной Δ ≈ 2,3 (лонг) / 1,5 (шорт) $/сут. → MDE ≈ 5,7 / 3,7 $/сут. — это чтение подтверждает или опровергает только большие эффекты. Монеты с 404 у источника — списком.

## Исходы (записываются до счёта)

- ΣΔ walk-forward ≤ 0 или второй проход не сошёлся → заморозка = база стороны.
- **«Сторона выключена»**: собственный $/сут. итоговой конфигурации в месяцах проверки walk-forward и в чтении 17–30.11 не проходит правило §10 → вердикт «сетапа на этой стороне нет», какой бы ни была Δ.
- Иначе — вердикт стороны по чтению 17–30.11.

## Статистика и множественность

- Результаты: сумма $, среднее на сделку, число сделок, $/сут. по стороне; медиан нет.
- m на сторону = Σ клеток обоих проходов и совместной сетки; Холм — справочно. Доказательство — шаг 5 (m = 1 на сторону) и шаг 7 (m = 2).
