# Реестр производственной эффективности (подроль Инженера, В-132)

Повторная и лишняя работа в счёте и конвейере: одни данные читаются или разбираются больше одного раза,
результат пересчитывается вместо кэша, работа идёт последовательно там, где можно за проход, простаивают ядра или
память, лишние копирования и форматы. Каждая находка проходит путь **находка → оценка → решение → гейт байт в
байт → замер после**. Ускорение без гейта не принимается.

Механизмы, которые находят такое сами (устав `.claude/roles/engineer.md`):
- очередь `alpha-gridq` с метками `queue/ALERT-{underload,idle-deck,rework}`;
- строка «эффективность» в журнале задачи перед серией дольше 1 ч деки;
- этот реестр.
