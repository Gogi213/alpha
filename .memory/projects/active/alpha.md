# alpha — состояние проекта

## Что делаем

Олвейс-он коллектор пишет стакан Bybit по пулу инструментов; дальше — разметка крупных уровней,
профили по осям, вердикт бэктестом с моделью очереди. Архитектура под живого бота с первого дня:
одна стратегия `lob::strategy::on_event<MD, B>` идёт и в `Backtest`, и в `LiveBot`.
