# 09 — Пилот: серия прогонов ≤ 5 минут; G0; G-POWER-B; ставка уровней

**Требования:** R40, R51, R68, R78, R81, A01
**Blocked by:** 01, 02, 08
**Зона:** `src/commands/lob/pilot.rs`
**Волна:** 3
**Status:** blocked

## Что должно заработать

Пилот — **не два часа**. `N` прогонов по ≤ 5 минут по всем десяти сразу, в
разные часы, `N` назначен до запуска. Тем же кодом `levels → классификация →
markout`, что и подтверждающий прогон.

Печатает по инструменту: уровней в минуту **на пол `H3`**, доли исходов,
`m_10s`, Шарп против требуемого из таска 05, перемеренные пороги GC на десяти.
И главное число, которого задача требует прямо: **сколько сессий нужно на
профиль**, посчитанное из ставки, а не назначенное.

Разведка (`RECON-2026-09-11.md`) уже дала первый замер: `eaten` 1.5–7% от
всех уровней, Шарп `m_10s` от −0.40 до +0.24 против планки ≈ 2.7. Пилот
скажет то же с ошибкой, а не точечно. Если разрыв подтвердится — **G-POWER-B
красный, сбор не начинается**, и это результат за часы.

## Критерии приёмки

- [ ] `N` прогонов ≤ 5 минут каждый, по всем десяти, часы старта разные; `N` заморожен коммитом до запуска
- [ ] тем же кодом, что подтверждающий прогон
- [ ] **ставка уровней в минуту на пол `H3`** — строка на инструмент
- [ ] доли исходов, `m_10s` с интервалом, круг в bps — строка на инструмент
- [ ] **число сессий на профиль**, посчитанное из ставки для маргиналов и для тонких ячеек — таблица
- [ ] пороги GC перемерены на десяти: CPU, RSS, лимит топиков, байт на запись
- [ ] границы оси повторяемости назначены по замеру и заморожены коммитом
