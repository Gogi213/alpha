## Разведка (27.09, субагент; ссылки file:line — в выводе разведки, главное здесь)
- Деньги идут драйвером `setups` (умолчание, `args.rs:306`): круг = свежий движок над окном `t0`
  (`backtest.rs:2322-2369`) → перекрывающиеся круги считаются независимо. `full` — один движок, режим невозможен.
- `carry` (сироты) на свежем движке — только учёт (уборка не находит заявку, `strategy.rs:795-807`); `next_id` нигде
  не печатается и на исполнения не влияет (гейт G10 с `rebased` это уже доказывает). Ключ памяти G10 — t0+σ+план+лот.
- `idle_ns` — на (набор, форма, символ-сутки), старт `MIN`, занято при `t0 < idle`; `NotSubmitted` → idle = t0;
  `TimedOut`/`Filled`/остаток → часы после подтверждения. Обрыв суток (`EndOfData`, остаток `ended`, нет окна) — `break`.
  `--carry-root` занятость через полночь не переносит.
- `rounds.csv` — только исполненные круги (`outputs.rs:289`); `idle_ns` по кругам не сохраняется нигде.
- `portfolio-sim` — «одна позиция на монету» по исполненным строкам и `exit_ns`, через полночь: это слабее правила
  движка, но зашито в эталонную цифру → ему надо подать **ровно те же строки** в том же порядке и формате.

## План (27.09)
1. Rust: `--busy-skip on|off` (умолчание `on` = прежнее; `off` только с `--driver setups`, иначе отказ). При `off`:
   проверка `backtest.rs:2030` не выполняется; обрыв (`EndOfData`/нет окна/остаток `ended`) **не** рвёт цикл — шаг
   записывается и счёт идёт дальше (иначе пропадут сигналы, которые правило занятости потом возьмёт).
2. `BounceRun` получает след по каждому сигналу: `sig_idx`, шаг (`not_submitted`, `timed_out`, `filled`,
   `end_of_data`, `no_window`, `inconsistent`), `idle_ns`, остаток (`none|flat|ended`).
3. При `off` рядом с `rounds.csv` — `signals.csv`: `symbol, day_utc, form, signal_index, t0_ns, entry_px, step,
   idle_ns, residual, exit_ns`; `rounds.csv` — все исполненные круги тем же писателем (формат чисел тот же); строка
   шапки `# busy_skip=off`. `forms.csv` в режиме `off` — счётчики другие (n_busy = 0), с эталоном не сравнивается.
4. Python `tools/compute/busy-replay.py <прогон off> <выход> [--keep фильтр.csv]`: по (набор, форма, символ-сутки)
   сигналы в порядке `signal_index`; занято при `t0 < idle`; принятый шаг ставит `idle`; обрыв на принятом шаге —
   сутки дальше не считаются; фильтр — список (symbol, day, signal_index) или (symbol, t0, entry_px) — отбрасывает
   сигнал **до** правила занятости. Выход — дерево прогона с `rounds.csv` принятых кругов в исходном порядке →
   `portfolio-sim` без правок.
5. Гейт: (а) g10 при `on` — байт в байт со старым бинарником; (б) `busy-replay` фильтр «всё» → `rounds.csv` байт в байт
   с прогоном `on` на наборе главного варианта (август и сентябрь, `titrc-u500r` формы); (в) `portfolio-sim` на обоих
   — до цента; (г) тесты: сигнал в хвосте круга при `off` получает свой круг; при `on` — промах «занято» как раньше;
   `off` + `--driver full` — отказ.
