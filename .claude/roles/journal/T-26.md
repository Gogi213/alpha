## План (на проверку Судье, до кода)
1. **Ряд — сутки.** Для каждой формы `r_d` = сумма net (bps) её кругов за сутки `d` по всем символам, для **каждых**
   суток сетки (`data.days`; сутки без кругов — `0`: форма стояла в стороне, это тоже наблюдение). `T` = суток сетки.
   Альтернатива для Судьи: `r_d` = net_fill суток (сумма / сигналов, как `form_day_matrix`) — ближе к интервалу, но не
   к деньгам; предлагаю сумму.
2. **Испытания — суточные Шарпы форм этой сетки**, `V` — их измеренная выборочная дисперсия (как сейчас в
   `expected_sharpe_under_null`); форма с < 2 суток или нулевой дисперсией — Шарп 0 (как сейчас). `DSR` =
   `dsr_from_returns(r_best, trial_sharpes_daily)`.
3. **DSR при числе испытаний журнала и требуемый Шарп** — `SR0` с `N` = испытаний (журнал/процедура) и `V` = та же
   измеренная дисперсия суточных Шарпов сетки (новая `expected_sharpe_under_null_with_variance(n, v)`; прежняя
   `…_for_trial_count` с `V = 1` остаётся только у G-POWER-A, `power.rs`, — там измерения нет). Если `V` не
   измерить (< 2 форм) — `V = 1/T` (дисперсия оценки Шарпа под нулём), помечено в выводе.
4. **Порог данных:** вместо `n ≥ 100` кругов — `≥ K суток с кругами в каждом месяце сетки` (месяц — `YYYY-MM` суток;
   сетка из одного месяца — один счётчик). `K` — не моё число: аудит предлагает 10; прошу Судью/владельца закрепить
   (В-##), в коде — именованная константа со ссылкой. Кластеров ≥ `G_MIN` — остаётся (п. 13 аудита). `n_fills`
   печатается как раньше. `CONFIRM_MIN_N` в `shortlist`/профилях не трогаю — только `bounce-verdict`.
5. **Метка в артефакте:** шапка вывода и `verdict-*.csv` несут `dsr_basis=days`, `v=<измерено|1/T>`, `min_days=K`;
   старые артефакты без `dsr_basis` — прежний DSR «по кругам, не ворота» (строка в `docs/COMMANDS.md`). DSR остаётся в
   `verdict_of` воротами (владелец «починить»); если Судья считает, что до протокола R2 он — только отчёт (п. 12
   аудита), — одна строка: убрать `dsr_ok` из `verdict_of`, печатать.
6. **Тесты:** суточный ряд (нули на пустых сутках, сумма по символам), `SR0` с измеренной `V` = формуле Бейли —
   Лопеса де Прадо на ручном срезе, запасной `V = 1/T`, требуемый Шарп при измеренной `V` (обратная задача к `dsr`),
   порог по месяцам (сетка из двух месяцев — один месяц ниже `K` → «мало данных»), `verdict_of` на синтетике: форма с
   ровным плюсом по суткам проходит DSR, шум — нет.
7. **Сверка «до/после»:** прежние сетки на деке (`b5/*` — выход, режим, E24–E27, обвал) — старый и новый бинарник,
   `--runs-csv` копией (без `--log-trials`), таблица «сетка · лучшая форма · DSR до/после · требуемый Шарп до/после ·
   вердикт до/после · суток с кругами по месяцам» → `docs/findings/bounce-verdict-dsr-2026-09-27.md`. Деньги не читаю —
   только что ворота стали проходимы и на каких формах вердикт сменился.
