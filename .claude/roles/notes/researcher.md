- Эфф. N больше числа суток — «не определено», не число (сбой `effective_n_from_autocorr` на коротком ряде; Г-28 «опровергнута» держалась на 39,1 при 23 сутках — снято, 26.09).
- Перед коммитом правки `tools/compute/*.py` — `python -m pytest -q tools/compute/tests` (26.09 `6f1360a` сломал тест выключателя).
- Коммит — только `git commit -o <свои пути> -m …`: общий индекс с другими ролями, `git add` + `git commit` унёс файлы Инженера (T-14) в 084b189/16c984a (26.09).
  Общий файл (`TASKS.md`): `-o` берёт файл целиком с чужими незакоммиченными строками — перед коммитом `git diff <файл>` (26.09 унёс T-23 Инженера).
- Любой признак «за W до входа» проверять против фильтров базы: у главного варианта возраст стены ≥ 45 мин > W — события на цене стены в окне невозможны (Г-88, 26.09; дважды предложил пустой признак).
- `repeat_count` считается при РОЖДЕНИИ стены (`levels.rs:1910`), не на касании.
- Толкование не сильнее замера: при эфф. N < 30 и интервале через 0 — «совместимо с», не «объясняется»; вывод пре-проверки ограничивать её популяцией (Судья, 26.09).
- Замороженный раздел протокола после счёта не переписывать — только зачеркнуть и дать поправку в §12 (Судья, 26.09).
