СДАТЬ: (1) ПРОТОКОЛ ДО СЧЁТА (Судья утверждает, затем счёт): таблица «есть/считаем» — что уже посчитано в TK-455 (формы A/B для Санчо) и TK-458 (G8.1), считается только дельта (В-213); ось входов (какие сигналы и в каком составе); ось выходов: стопы (фиксированный в bps из волатильности, структурный — за экстремум свипа/свинг/зону имбаланса, по времени), тейки (фиксированные кратные R, структурная цель, трейл — по ATR/bps/по свингам, частичная фиксация + трейл остатка), перенос в безубыток после +k·R (k из распределения хода, не выдуманное), комбинации; режимы по числу сделок: от «очень мало» (жёсткие фильтры, наложение факторов) до «очень много» (без фильтров) — ЧИСЛО СДЕЛОК НЕ КРИТЕРИЙ ОТБОРА, ничего не отбрасывать по малому N: ряды с малым N остаются в семействе с широким интервалом и пометкой «мало данных»; правило вердикта единое (P-TK456 §3 п.3: Холм по K, знак в каждом году с данными, два контроля); число испытаний K объявить до счёта (накопленное по программе было 377 — продолжать счёт, P-TK457 §5).
