Сейчас П-32 v3 (принят Судьёй): расхождение = z-оценка спреда на скользящем окне с β по скользящей OLS, пары отобраны коинтеграцией Энгла–Гренджера на 90 сут формирования (кандидаты — любые пары вселенной), вход/выход/стоп по z, выход по времени max_hold, прибыли как цели в правиле нет (kernel.rs Params), вердикт — пять барьеров подряд. Сделать П-32 v4 до счёта (скилл alpha-research, Судья проверяет): (1) Определить расхождение и кто его определяет — явно, без размытия: модель спреда, оценка параметров только по прошлому. (2) Современный набор вместо учебникового, выбор между вариантами — замером на периоде формирования/малом срезе, не на вердикт-месяцах: динамический β (фильтр Калмана) вместо скользящей OLS; процесс Орнштейна–Уленбека с границами входа/выхода/тейка, которые считаются из подогнанных параметров и издержек (прибыль входит в правило: ожидаемая чистая прибыль и ожидаемое время удержания против круга издержек, тейк-профит, стоп); остаточные по факторам (PCA/эйгенпортфели, Avellaneda–Lee) как обобщение A2/B1; детектор разрыва связи/режима (вход выключается, позиция режется) вместо слепого max_hold; при необходимости обучаемый предсказатель чистого форвард-результата спреда на признаках (z, полураспад, оборот, волатильность, ход BTC, ставка) — строго walk-forward. Что нужно ядру — перечислить Инженеру отдельным списком (после v4 заведу тикет). (3) Вердикт мягче: разведка (широкий поиск, все испытания считаются честно, результат — оценка чистых bps с интервалом по годам, без барьера «каждый год плюс» как приговора) и подтверждение (только кандидаты, строго вперёд на нетронутых месяцах, одно правило заранее). Неизменно: ничего не подбирается на месяцах вердикта, число испытаний честное (В-224), комиссия только из src/lob/costs.rs (В-88), расстояния в bps, числа измеряются, а не назначаются. Что ломает это при v3 — перечислить. (4) Скорость (В-90): новые методы должны считаться на быстром ядре; для каждого — оценка стоимости шага и порядок волн.
