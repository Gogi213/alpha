## Доки: правило артефактов

**Механизм пишет результат по одному адресу, а не «рядом с собой»:**

| что создаётся | куда |
|---|---|
| разбор, вердикт, замер — текст | `docs/findings/<тема>-<YYYY-MM-DD>.md` |
| машиночитаемый артефакт вердикта | `docs/findings/<команда>-<YYYY-MM-DD>[-<SYM>].<csv\|json>` |
| сырое и промежуточное (`levels-*`, `touches-*`, дашборд, binlog) | `data/` (gitignored) |
| журнал испытаний | `docs/plan/runs.csv` |
| протокол исследования / журнал шагов | `docs/research/P-<NN>-<тема>.md` / `docs/research/JOURNAL.md` |
| «где мы» — состояние проекта | **только** `CLAUDE.md` «СОСТОЯНИЕ» |

Заменённое переносится в `docs/archive/` тем же коммитом, ссылки правятся (`git grep` по старому пути — ноль); молча не
удалять. Файл, на который как на единственный источник числа опирается код или живое решение, — не архивный.

## Правила, которые ловят ревью

Семь запретов горячего пути (ноль аллокаций на событие после прогрева, время только через трейт `Clock`, без `async` с
захватом состояния в потоке решений, без REST в событийном цикле, сборка/подпись ордера до триггера, без `f64` для
цены/размера, без `BTreeMap`/`HashMap` на пути события) — `interfaces.md`. Изобретённое число запрещено: измеримое
измеряется, назначаемое — коммитом/решением В-##. Расстояние только в bps. Шаг не закрыт без названного артефакта на
диске. Секреты — только имена переменных (`BYBIT_API_KEY`, `BYBIT_API_SECRET`), значения не печатаются.
Ускорение принимается только с гейтом «байт в байт» против прежнего бинарника.
**Алгоритм (В-170):** искать оптимальный, а не брать первый: узкое место → лучшие известные способы → замер на малом
(скорость и качество) → оптимальный без потери качества → боевой прогон; в отчёте — что сравнивали и почему выбран этот.
Режим исполнения (параллельность, readahead) тоже подбирается до прогона дольше ~15 мин — `tools/compute/calibrate.sh` (В-178).

## Экономия контекста и сроки

- Цена шага ≈ размер контекста: половина трат — шаги при контексте > 300 тыс. (замер 25.09). Клир после законченной
  задачи; субагенты — до ~100 шагов; разведка и чтение больших выводов — субагентом; вывод команд — `tail`/`grep`.
- Вид страницы — текстом (`read_page`, `tools/shot.py --text-only`), скриншот — когда текст не отвечает.
- **Сроки — в темпе Claude Code, не человека:** разбивка «код / сборка + тесты / гейт на Steam Deck / итого» и время
  готовности по `date` (GMT+4).
- Гейты и пробы — минимальным набором: один `--cells` на сутки на версию; промежуточные версии — только при красном.
