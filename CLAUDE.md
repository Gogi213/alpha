# alpha — бот по плотностям стакана Bybit

Rust-проект: олвейс-он коллектор пишет стакан Bybit по пулу инструментов (В-34), разметка крупных уровней, вердикт
бэктестом с моделью очереди. Одна стратегия `lob::strategy::on_event<MD: MarketDepth, B: Bot<MD>>` идёт и в
`Backtest`, и в `LiveBot` крейта `hftbacktest` без правок. Прежние версии этого файла (вся история состояния) —
`docs/archive/claude-md-history-2026-09-{23,25,27}.md`: читать грепом, только когда нужна старая деталь.

## Доки: правило артефактов

**Механизм пишет результат по одному адресу, а не «рядом с собой»:**

| что создаётся | куда |
|---|---|
| разбор, вердикт, замер — текст | `docs/findings/<тема>-<YYYY-MM-DD>.md` |
| машиночитаемый артефакт вердикта | `docs/findings/<команда>-<YYYY-MM-DD>[-<SYM>].<csv\|json>` |
| сырое и промежуточное (`levels-*`, `touches-*`, дашборд, binlog) | `data/` (gitignored) |
| журнал испытаний | `docs/plan/runs.csv` |
| протокол исследования / журнал шагов | `docs/research/P-<NN>-<тема>.md` / `docs/research/JOURNAL.md` |
| «где мы» — состояние проекта | **только** `CLAUDE.md` «СОСТОЯНИЕ» |

Заменённое переносится в `docs/archive/` тем же коммитом, ссылки правятся (`git grep` по старому пути — ноль); молча не
удалять. Файл, на который как на единственный источник числа опирается код или живое решение, — не архивный.

## Команды (полностью — `docs/COMMANDS.md`)

```bash
cargo build --release --target-dir target-ci          # target/release/alpha.exe занят коллектором
cargo test --release --target-dir target-ci 2>&1 | tail -5
cargo clippy --release --target-dir target-ci --all-targets -- -D warnings   # ноль
cargo fmt --check
./target-ci/release/alpha.exe lob --help              # подкоманды — docs/COMMANDS.md
```

- `lob bounce-grid` — сетка форм (вход/стоп/тейк/дедлайн/выход по стене, наборы `--set`), **`--cells <файл>` — список
  клеток одним проходом по суткам (обязательно, В-136)**, `--sigma-from` (σ-лестница), `--hold-step poll|skip`;
  стандартная задержка В-68 и очередь `prob:3` — `docs/COMMANDS.md`. K1: без `verify-<SYM>.status == ok` — отказ.
- `lob bounce-verdict`, `lob touches`, `lob import-archive`, `lob verify`, коллектор `lob session --always-on`
  (остановка — файл `<root>/stop`; пул на ходу — атомарная перезапись `instruments.csv`) — `docs/COMMANDS.md`.
- Скрипты счёта — `tools/compute/`; скрипты на Steam Deck — в `~/alpha/bin/`.

## Структура `src/`

`binlog/` (формат v3, чтение v2) · `book/` · `bybit/` (адаптер: conn, ws, rest, verify) · `feed/` (replay, live) ·
`lob/` (чистая логика: levels, markout, costs, strategy — единственная стратегия, backtest, touch_axes) · `stats/` ·
`commands/` (record, `lob/*` — подкоманды). Тесты модуля — `<модуль>/tests.rs`; `include_str!` в тестах — с `../`.

## Правила, которые ловят ревью

Семь запретов горячего пути (ноль аллокаций на событие после прогрева, время только через трейт `Clock`, без `async` с
захватом состояния в потоке решений, без REST в событийном цикле, сборка/подпись ордера до триггера, без `f64` для
цены/размера, без `BTreeMap`/`HashMap` на пути события) — `interfaces.md`. Изобретённое число запрещено: измеримое
измеряется, назначаемое — коммитом/решением В-##. Расстояние только в bps. Шаг не закрыт без названного артефакта на
диске. Секреты — только имена переменных (`BYBIT_API_KEY`, `BYBIT_API_SECRET`), значения не печатаются.
Ускорение принимается только с гейтом «байт в байт» против прежнего бинарника.

## Экономия контекста и сроки

- Цена шага ≈ размер контекста: половина трат — шаги при контексте > 300 тыс. (замер 25.09). Клир после законченной
  задачи; субагенты — до ~100 шагов; разведка и чтение больших выводов — субагентом; вывод команд — `tail`/`grep`.
- Вид страницы — текстом (`read_page`, `tools/shot.py --text-only`), скриншот — когда текст не отвечает.
- **Сроки — в темпе Claude Code, не человека:** разбивка «код / сборка + тесты / гейт на Steam Deck / итого» и время
  готовности по `date` (GMT+4).
- Гейты и пробы — минимальным набором: один `--cells` на сутки на версию; промежуточные версии — только при красном.

## Грабли — коротко (полностью — `docs/COMMANDS.md`)

- `--h3-mode floor|percentile` обязателен у `levels`/`markout`/`watch`/`profiles`/`shortlist`; `k` для пола H3 — процедура
  пилота (В-30), не число; `lob probe` ставит реальные ордера.
- Бинлог сессии — один резолвер `commands::lob::session_binlog_for`; сутки и час — `session_parts_for`.
- Коллектор: кадр на диске не реже 10 с; остановка — `<root>/stop` (на Unix ещё SIGTERM/`systemctl`); пул на ходу —
  файл должен кончаться переводом строки (пиши атомарно через `mv`).
- Bybit отдаёт `403` с части стран; с этой машины доступ есть.
